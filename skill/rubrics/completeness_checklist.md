# 分析完整性自检清单

每次输出分析报告前，必须自检以下项目。

## 通用完整性（所有报告）
- [ ] 结论先行，位于报告第一部分
- [ ] 三类表达分离（事实/经验/推断）
- [ ] 证据等级已标注
- [ ] 数据来源标签已标注（用户提供/网页检索/训练数据/经验参照）
- [ ] 经验阈值标注了行业适用性
- [ ] 含验证指标与时点
- [ ] 含风险与证伪条件
- [ ] 数据不足时明确说明

## 数据采集完整性
- [ ] 已按 data_protocol.md 执行数据需求评估
- [ ] 已尝试至少一种实时数据源（/browse/WebSearch/WebFetch）
- [ ] 数据充分性等级已评估（充分/部分充分/不充分）
- [ ] 若实时数据不可用，已声明数据采集受限
- [ ] 关键数字已标注来源标签（而非仅凭训练数据）
- [ ] 数据缺口清单已列出（如有）

## 指标异动诊断
- [ ] 异动确认（数据问题 vs 业务问题）
- [ ] 多维度拆解
- [ ] 归因有证据
- [ ] 区分相关与因果
- [ ] 含短/中/长期验证指标

## PMF / 增长诊断
- [ ] 生命周期阶段识别
- [ ] PMF 真伪判断（含伪信号检查）
- [ ] 增长引擎类型
- [ ] Cohort 分析
- [ ] 三指标齐全（结果/过程/护栏）

## 商业模式评估
- [ ] 收入质量分析
- [ ] LTV 用毛利口径
- [ ] Cohort P&L
- [ ] 经营杠杆类型
- [ ] 增长-利润取舍逻辑

## 战略分析
- [ ] 时空条件明确
- [ ] TAM/SAM/SOM 估算
- [ ] 规模效应类型识别
- [ ] 核心假设与证伪条件
- [ ] 领先指标
- [ ] 资源配置逻辑

## 财报分析
- [ ] 先看现金流
- [ ] 三表勾稽验证
- [ ] 红旗清单检查
- [ ] 行业对标
- [ ] 阈值适用性标注

## 竞争对手对比
- [ ] 是否选择了合适的对标公司（至少 2-3 家）？
- [ ] 是否确保了可比性（商业模式/发展阶段/地域）？
- [ ] 是否对比了财务/运营/估值三个维度？
- [ ] 是否标注了行业中位数？
- [ ] 是否对差异进行了归因分析？
- [ ] 是否判断了差异的可持续性？
- [ ] 是否构建了竞争优势矩阵？

## 情景分析
- [ ] 是否识别了关键驱动因素（3-5 个）？
- [ ] 是否设定了 Bull/Base/Bear 三种情景？
- [ ] 每个情景的假设是否合理且可验证？
- [ ] 是否推演了每个情景的财务结果？
- [ ] 是否分配了概率并计算了期望值？
- [ ] 是否明确了每个情景的触发条件？
- [ ] 触发条件是否可观测、可量化？

## 敏感性分析
- [ ] 是否进行了单因素敏感性分析？
- [ ] 是否识别了最敏感的变量？
- [ ] 是否进行了双因素敏感性分析？（复杂分析必做）
- [ ] 是否评估了结论的稳健性？
- [ ] 是否标注了结论反转的临界条件？

## 流程诊断
- [ ] 流程边界明确
- [ ] 现状绩效量化
- [ ] 根因分析
- [ ] 预期收益量化
- [ ] 验证机制
