# 红旗信号检查清单

## 财报红旗

### 收入异常
- [ ] 毛利率显著高于同行（>10% 差距）
- [ ] 应收账款增速远超营收增速
- [ ] 收入季节性异常集中在期末
- [ ] 客户集中度异常（前 5 大客户 >50%）
- [ ] 关联交易占比过高（>30%）

### 现金流异常
- [ ] 净利润+但 OCF 持续-
- [ ] OCF/净利润 <0.5
- [ ] 存贷双高
- [ ] 利息收入/货币资金 <1%

### 资产异常
- [ ] 商誉/总资产 >50%
- [ ] 在建工程长期不转固
- [ ] 存货周转天数持续上升
- [ ] 固定资产增速与营收不匹配

### 报表异常
- [ ] 频繁更换审计机构
- [ ] 审计意见非标
- [ ] 收入与税务数据不匹配

## 商业模式红旗
- [ ] 增长靠补贴驱动
- [ ] 收入依赖单一渠道（>50%）
- [ ] 复购率持续下降
- [ ] CAC 持续上升 + LTV 持续下降
- [ ] 回本周期持续延长

## PMF 红旗
- [ ] 下载高但留存低
- [ ] 口碑弱、无自然推荐
- [ ] 付费意愿低
- [ ] 核心功能使用率低

## 战略红旗
- [ ] 无明确时空定义
- [ ] 无成立前提和证伪条件
- [ ] 资源配置与战略不匹配
- [ ] 无领先指标

## 信号数量判断
- 0 个 → 安全
- 1-2 个 → 留意
- 3-5 个 → 警惕
- 5+ 个 → 高度警惕（宁可错杀）
