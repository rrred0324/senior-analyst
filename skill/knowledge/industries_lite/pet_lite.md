# 宠物 速查

## 商业本质
围绕伴侣动物全生命周期的喂养、健康、护理和情感陪伴需求，提供高复购消费品和高信任服务。核心复利=情感驱动高复购 x 高信任服务 x 生命周期运营。

## 收入公式
收入 = 活跃宠物家庭数 x 购买/服务频次 x 客单价

## 子赛道
- 主粮（极高频刚需）
- 零食/保健品
- 猫砂/清洁
- 宠物医疗
- 美容洗护
- 宠物零售
- 宠物保险

## 核心指标
- 复购率：主粮/猫砂是复购引擎
- 单宠年消费额：LTV核心
- LTV/CAC：情感消费下LTV通常较长
- 医疗复诊率：专业信任验证
- 会员续费率：私域运营健康度
- 品类扩展率：从主粮到全线
- 食安/质量投诉率：信任是生命线
- 门店同店增长：扩张质量

## 关键风险
- 食安与质量事故：一次事故可毁品牌
- 流量依赖与价格战：白牌和电商挤压
- 医疗/服务纠纷：过度医疗或质量波动
- 更换主粮有适应期但仍被低价抢客
- 宠物生命周期有限：用户流失后再获客成本高

## 分析起点
判断品牌或专业信任是否够强，再看高频复购和会员体系是否成立，最后看沿单宠生命周期扩展LTV的能力。
