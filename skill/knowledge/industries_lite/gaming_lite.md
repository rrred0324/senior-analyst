# 游戏 速查

## 商业本质
用创意和产品能力制造"成瘾性体验"，通过精细化运营延长生命周期，在有限窗口期内最大化单用户价值。核心不是"做了多少游戏"，而是"单款LTV能否覆盖成本且概率可预期"。

## 收入公式
流水 = DAU x 付费率 x ARPPU + DAU x 广告展示 x eCPM；收入 = 流水 x (1-渠道分成) - 递延调整

## 子赛道
- MMORPG（重度IAP）
- SLG策略（长线IAP）
- 休闲/超休闲（IAA为主）
- 二次元（抽卡驱动）
- 小程序/H5游戏（混合变现）
- 电竞/竞技

## 核心指标
- 次留/7留/30留：产品力核心指标
- LTV/CAC：获客效率（>3为健康）
- 递延收入趋势：未来可确认收入风向标
- 付费率/ARPPU：变现深度
- 买量ROI（ROAS）：投放效率
- 销售费用率：>50%则买量驱动不可持续
- 研发费用率：产品线投入力度
- 版号获取节奏：国内上线前提

## 关键风险
- 版号政策不确定：最大的政策变量
- 爆款失败率：研发投入大但成功率低
- 买量ROI恶化：CPI持续上涨
- 生命周期衰减：单游戏收入不可逆下滑
- 渠道分成高：苹果30%/安卓CP50%

## 分析起点
看产品力（留存是否够硬），再看获客效率（LTV/CAC是否>3），最后看产品线厚度（能否持续推新）。
