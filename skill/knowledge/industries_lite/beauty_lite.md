# 美妆个护 速查

## 商业本质
通过可信产品力和品牌心智占据用户梳妆台和护肤流程中的固定位置。核心是"产品力+品牌心智→复购占位"的长期消费关系。

## 收入公式
收入 = 新客数 x 首购客单价 + 老客数 x 复购频次 x 复购客单价

## 子赛道
- 护肤（面护/功能性护肤）
- 彩妆
- 洗护发
- 香氛
- 美容仪（设备+耗材）
- 男士个护

## 核心指标
- 复购率：品牌力和产品力最直接验证
- 投放ROI：获客效率决定利润
- 毛利率：60-80%高毛利但被投放吞噬
- CAC与LTV/CAC：用户经济模型是否成立
- 爆品占比：过度依赖单一爆品风险大
- 渠道动销率：真实销售vs渠道压货
- 库存周转天数：滞销和跌价风险
- 达人投放效率：流量成本趋势

## 关键风险
- 爆品衰退：新品接不上则收入断层
- 获客成本上升：平台流量竞价推高CAC
- 平台规则与流量迁移：渠道依赖
- 成分安全与合规：功效宣称监管收紧
- 白牌低价替代：同质化竞争

## 分析起点
看产品是否具备真实口碑和复购，再判断获客成本与LTV是否匹配，最后看能否从爆品走向系列化品牌。
