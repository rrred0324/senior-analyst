# 母婴 速查

## 商业本质
围绕家庭从孕期到婴幼儿成长阶段的连续消费需求，以高信任、高安全、高复购的产品和服务承接持续消费。核心复利=情感驱动高复购 x 高信任服务 x 生命周期运营。

## 收入公式
收入 = 付费家庭数 x 购买频次 x 客单价

## 子赛道
- 婴配粉/营养品
- 辅食零食
- 纸尿裤
- 洗护用品
- 童装童鞋
- 母婴零售（门店/电商）
- 母婴服务（月子/托育）

## 核心指标
- 复购率：高频刚需品的品牌粘性
- 客单价/年消费额：单家庭价值
- 会员续费率：私域深度运营
- 品类扩展率：生命周期LTV提升
- 库存周转天数：母婴品时效敏感
- 质量投诉率/食安事故率：信任生命线
- 月龄阶段留存率：用户流失节点
- 自有品牌占比：利润结构

## 关键风险
- 出生率下降：总量需求萎缩
- 食品安全与质量事故：一次事故可毁品牌
- 流量依赖与平台分流：综合电商挤压
- 月龄需求断层：孩子长大自然流失
- 私域获客转化衰减

## 分析起点
判断是否建立足够强的品牌信任，再看高频复购和会员体系是否成立，最后看是否具备生命周期扩品和提升LTV的能力。
