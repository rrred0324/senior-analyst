# 出海 速查

## 商业本质
在不同国家和地区找到可复制的需求与供给匹配方式，通过产品适配、渠道获取、本地履约与合规经营，把本土能力转化为全球化收入。核心不是"把国内产品卖到国外"，而是"跨区域可复制的商业闭环"。

## 收入公式
收入 = 海外用户数 x ARPU 或 订单量 x 客单价 或 ARR = 海外客户数 x ARPA

## 子赛道
- 跨境电商/品牌出海
- 应用出海（工具/社交/效率）
- 游戏出海
- SaaS出海
- 工业品出海
- 平台型出海

## 核心指标
- 海外收入增速：增长动力
- LTV/CAC：各国单位经济需分别验证
- 复购率/留存率：本地化是否成功
- 区域利润率：不同国家盈利能力差异
- 单一国家收入占比：集中度风险
- 退货率/客诉率：产品适配与履约质量
- 合规事件数：法律与政策风险
- 汇兑损益：财务波动

## 关键风险
- 地缘与政策风险：市场关闭、封号封店
- 汇率和税务风险：跨境成本不可控
- 单一市场/平台依赖：集中风险极高
- 投放成本失控：海外竞价推高CAC
- 本地化失败：水土不服致复购差

## 分析起点
验证单位经济是否按国家分别成立，再看单市场模型是否可复制，最后判断本地化与合规能力是否支撑长期扩张。
