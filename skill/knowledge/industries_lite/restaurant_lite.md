# 餐饮 速查

## 商业本质
在特定时间、地点和价格带下，为消费者提供稳定可接受的口味、效率和体验，通过高频消费、门店复制和供应链优化持续获取利润。核心不是"卖一顿饭"，而是"单店模型验证→可复制扩张"的规模与效率逻辑。

## 收入公式
收入 = 门店数 x 单店收入；单店收入 = 座位数 x 翻台率 x 人均消费 x 营业天数

## 子赛道
- 正餐（堂食体验）
- 快餐（标准化高频）
- 茶饮（高频加盟扩张）
- 咖啡（饮品+第三空间）
- 烘焙
- 火锅/烧烤（社交聚餐）
- 团餐（B端合同）

## 核心指标
- 同店销售增长（SSSG）：门店健康度核心
- 翻台率：产能利用率
- 客单价：定价能力
- 坪效/人效：运营效率
- 门店EBITDA：单店盈利能力
- 回本周期：投资吸引力
- 食材成本率/人工成本率/租金率：成本结构
- 加盟店存活率：加盟体系质量

## 关键风险
- 食安风险：一次事故可致命
- 同店下滑：新店分流老店
- 加盟失控：粗放扩张致品牌崩塌
- 原料/租金/人工刚性上涨
- 平台抽佣：外卖佣金持续上升

## 分析起点
看单店模型是否健康且可复制，再验证同店增长和复购是否成立，最后判断供应链和加盟扩张能力是否足够强。
