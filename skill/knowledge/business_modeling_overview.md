# 商业建模总论

## 1. 什么是商业建模

商业建模是将一个公司的赚钱逻辑从模糊认知转化为可量化、可拆解、可验证的结构化模型。

### 商业建模 vs 数据分析 vs 财务分析

| 维度 | 数据分析 | 财务分析 | 商业建模 |
|------|----------|----------|----------|
| 核心问题 | 发生了什么？为什么？ | 财务结果健康吗？ | 这门生意怎么赚钱？能持续吗？ |
| 输入 | 业务数据 | 财务报表 | 行业认知 + 业务逻辑 + 财务数据 |
| 输出 | 归因结论、优化建议 | 财务质量判断、风险信号 | 商业模式图、收入成本公式、单位经济、竞争判断 |
| 层级 | 描述→归因 | 描述→评估 | 认知→建模→验证→决策 |

### 从现象解释到机制建模

低质量分析停在"描述现象"。高质量分析要回答：
- 这个行业怎么赚钱？
- 价值链怎么流转？
- 规模扩大后是否更赚钱？
- 核心约束是什么？

## 2. 商业建模五层结构

```
行业层  → 行业本质、价值链、关键约束
公司层  → 商业模式、收入来源、客户结构
经营层  → 核心指标、经营杠杆、单位经济
财务层  → 财务映射、资产质量、现金流特征
决策层  → 投资判断、战略选择、风险与证伪
```

每一层都必须与上下层打通，形成闭环：
- **行业层→公司层**：行业约束决定了哪些模式可行
- **公司层→经营层**：商业模式决定核心指标和经营杠杆
- **经营层→财务层**：经营行为最终映射到财务报表
- **财务层→决策层**：财务质量是投资/战略决策的基础

### 核心映射链

```
业务行为 → 经营指标 → 单位经济 → 财务报表 → 估值/决策
```

这条映射链是商业建模的核心。真正强的分析不是分别看业务、数据、财务，而是把三者打通。

## 3. 商业建模标准输出

每个商业建模分析至少包含以下 6 项标准输出：

| 输出 | 内容 | 作用 |
|------|------|------|
| 商业模式图 | 价值链、参与方、资金流向 | 理解生意本质 |
| 收入成本公式 | 变量拆解的收入模型和成本结构 | 量化驱动因素 |
| 指标树 | 结果指标→过程指标→护栏指标 | 识别经营杠杆 |
| 财务映射 | 业务指标→财务科目的映射 | 验证一致性 |
| 风险清单 | 行业特有红旗信号 | 识别关键风险 |
| 推演假设 | 核心假设与证伪条件 | 支持决策 |

## 4. 竞争优势全景框架

规模效应是重要的竞争优势来源，但不是唯一来源。完整的战略分析应识别企业优势来自哪里。

| 优势来源 | 典型表现 | 常见行业 |
|----------|----------|----------|
| **规模效应** | 越大越强，边际成本下降或网络价值增强 | 平台、社交、电商 |
| **品牌心智** | 用户优先想起并信任 | 消费品、互联网平台 |
| **技术/专利壁垒** | 难以复制的技术能力 | 制造、医药、硬科技 |
| **渠道控制** | 对关键流量或终端有控制力 | 零售、快消、平台 |
| **转换成本** | 用户迁移成本高 | SaaS、金融、企业服务 |
| **数据飞轮** | 数据越多，产品越好 | 广告、推荐、智能化产品 |
| **供应链能力** | 交付快、成本低、质量稳定 | 制造、零售、外卖 |
| **组织效率** | 决策与执行效率显著高于同行 | 各行业通用 |
| **牌照/合规壁垒** | 市场准入受监管限制 | 金融、医疗、教育 |

## 5. 战略选择的约束条件

战略不是脱离现实约束去追求理论上的"最高 ROI"，而是在约束条件下选择最优行动组合。

**常见约束**：
1. **能力约束**：组织、人才、系统、产品能力是否具备
2. **时间约束**：窗口期是否存在，是否需要抢占时机
3. **现金流约束**：能否承受持续投入与试错成本
4. **风险约束**：监管、品牌、合规、供应链风险是否可控
5. **管理约束**：高管注意力与组织带宽是否足够

战略正确不等于"理论上收益最高"，而是"在现实约束下最优且可执行"。

## 6. 单位经济口径说明

不同行业的单位经济口径存在显著差异，跨行业对比时必须注意口径一致性。

### LTV/CAC 的行业口径差异

| 行业 | LTV口径 | CAC口径 | 健康标准 | 核心差异 |
|------|---------|---------|---------|---------|
| SaaS | 客户全生命周期收入（含扩单） | 获客成本（含销售提成） | LTV/CAC≥3 [适用：B2B SaaS，成长期以上] | LTV含扩单/交叉销售，CAC含销售团队成本 |
| 游戏 | 玩家生命周期付费总额 | 买量成本（CPA） | LTV/CAC≥3 [适用：中重度IAP，上线6个月以上] | IAA休闲游戏LTV/CAC通常<2但靠广告频次补偿 |
| 电商 | 用户生命周期购买总额×毛利率 | 获客成本（含首单补贴） | LTV/CAC≥3 [适用：高复购品类] | 自营需乘毛利率，平台按take rate |
| 金融 | 客户生命周期净收入 | 获客+开户成本 | 风险调整后LTV/CAC≥2 [适用：信贷] | LTV必须扣减预期信用损失 |

**关键原则**：
- SaaS的LTV包含扩单收入（NRR>100%时LTV远超首年ARR），其他行业通常不含
- 游戏LTV/CAC的CAC仅指买量CPA，不含研发成本分摊；SaaS的CAC含销售团队提成
- 电商自营模式下LTV必须乘毛利率，否则与SaaS不可比
- 金融行业必须用风险调整后LTV，不扣信用损失的LTV没有意义

### 回本周期的行业口径差异

| 行业 | 回本周期口径 | 健康标准 |
|------|-------------|---------|
| SaaS | CAC回收月数（首月毛利累计覆盖CAC） | <12个月 [适用：B2B SaaS，ARR>$1M] |
| 游戏 | 买量ROI回正天数 | <60天 [适用：中重度IAP]；SLG可达90-180天 |
| 消费/零售 | 单店/单SKU回本月数 | <18个月 [适用：标准连锁] |
| 长租公寓 | 单房装修投入回本月数 | <24个月 [适用：集中式长租] |

**跨行业对比时必须声明口径**，否则LTV/CAC=3在SaaS和游戏中含义完全不同。

## 7. TAM/SAM/SOM 与单位经济连接

大市场不等于好生意。判断一个市场是否值得投入，不能只看 TAM/SAM/SOM，还要结合单位经济与现金流压力。

**需要同时判断**：
- 市场空间是否足够大？
- 用户是否愿意付费？
- 单位经济是否成立？
- 回本周期是否可接受？
- 扩张是否会显著恶化现金流？

很多公司不是死在"市场不够大"，而是死在"规模起来以后依然不赚钱"。
