# 新能源行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
新能源的本质是通过新型发电、储能、电能转换与能源管理技术，替代高碳能源并提升系统效率，在设备制造、系统集成和长期运营中创造经济价值。核心是"更低度电成本+更高系统效率+更强安全性"。

### 1.2 与普通行业的核心差异

| 差异维度 | 新能源 | 传统制造业 |
|---------|------|-----------|
| 增长驱动 | 政策+技术+成本下降三重驱动 | 市场需求+产能扩张 |
| 成本曲线 | 学习曲线效应强，成本持续下降 | 下降幅度有限 |
| 资产特征 | 重CAPEX，项目IRR是核心 | 资产周转率是核心 |
| 政策依赖 | 高度依赖补贴、电价、并网政策 | 相对独立 |
| 安全风险 | 安全事故可致命（储能起火等） | 产品质量问题为主 |

### 1.3 分析总框架
技术与成本竞争力 → 出货/项目增长是否伴随盈利质量 → 现金流与政策依赖是否可控 → 安全和质量风险

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 光伏531新政 | 补贴大幅退坡，行业洗牌加速，倒逼技术降本和平价上网 |
| 2020 | "双碳"目标提出 | 2030碳达峰/2060碳中和目标明确，新能源投资确定性大幅提升 |
| 2021 | 新能源车渗透率突破10% | 中国新能源车从政策驱动转向市场驱动，产业链全面受益 |
| 2022 | 锂价暴涨与回落 | 碳酸锂价格从5万涨至60万/吨后回落，产业链利润重新分配 |
| 2023 | 光伏组件价格跌破1元/W | 产能过剩引发价格战，行业从扩产转向淘汰落后产能 |
| 2024-25 | 新能源车渗透率超40% | 电动化不可逆，智能化成新竞争焦点，行业从电动化1.0进入智能化2.0 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
制造型：研发设计 → 产能建设 → 渠道导入 → 销售交付 → 装机 → 运维 → 收入确认

储能型：需求识别 → 方案设计 → 电芯/PCS/BMS集成 → 项目交付 → 并网投运 → 运维调度

运营型：项目开发 → 审批并网 → 建设投产 → 发电/储能运营 → 电力交易/补贴 → 现金流回收

### 2.2 核心飞轮
更优技术与效率 → 更低成本与更强回报 → 更多装机/项目 → 更大规模采购与制造效率 → 更优成本与品牌 → 更优技术

核心驱动：技术、成本、渠道、项目经验和运营数据共同推动规模化，不断降低单位成本并提升项目回报。

### 2.3 商业模式分类
1. **设备销售**：开发商/EPC / 按W/Wh/套 / 收入 = 出货量 × 单位售价
2. **系统集成/EPC**：项目业主 / 按项目合同额 / 收入 = 项目数 × 单项目合同额
3. **项目运营**：电网/用能客户 / 售电+补贴+容量费 / 收入 = 发电量 × 单位收益 + 补贴/容量收入

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 设备销售 + 系统集成/EPC + 运维 + 项目运营 + 软件/平台

制造型：收入 = 出货量 × ASP；项目型：收入 = 项目数 × 均额；运营型：收入 = 装机规模 × 利用小时 × 单位收益

### 3.2 成本模型
- 固定成本：厂房设备折旧、研发团队、系统平台、管理团队
- 变动成本：材料采购、生产加工、物流安装、EPC外包、维修更换
- 前端成本：销售渠道、项目开发、客户认证、招投标
- 后端成本：生产交付、并网调试、质保、运维

### 3.3 单位经济
制造型：单位毛利 = 售价 - 材料成本 - 制造成本
储能系统：单项目毛利 = 合同额 - 硬件成本 - 集成安装 - 质保准备
电站运营：年度现金流 = 发电收益 + 补贴/容量收益 - 运维 - 财务成本
判断要点：出货增长须建立在成本下降和毛利稳定基础上；项目型看回款和现金流；运营型看项目IRR

### 3.4 利润率特征
光伏/电池制造毛利率15%-25% [适用：成熟产能/头部厂商] [局限：价格战期可降至10%以下，新技术路线初期可达30%+]；储能集成15%-25% [适用：大型储能系统集成] [局限：纯硬件贸易仅10-15%，含软件/运营可达30%+]；电站运营毛利率50%-70% [适用：光伏/风电运营] [局限：补贴拖欠时实际利润率偏低]（但财务费用高）

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 光伏组件/逆变器 | 光伏发电核心设备 | EPC/开发商 | 设备销售 | W单价、毛利率、出货量 |
| 风电整机/零部件 | 风机及配套设备 | 发电集团 | 设备销售 | MW出货、招标份额 |

## 5. 核心指标体系

- **规模**：收入、出货量（GW/GWh）、装机规模、在手订单、运营资产规模
- **增长**：收入增速、出货增速、新客户数、国际收入占比提升
- **转化**：线索到中标率、样品到量产率、项目到并网率
- **留存/复购**：客户复购率、续约率、大客户净收入留存、运维续费率
- **变现**：ASP、单位Wh/W收入、单客户年收入、项目合同额
- **供给**：产能、利用率、良率、交付周期、BOM成本
- **效率**：单位成本降幅、发电小时数、系统效率、循环寿命、可用率
- **财务**：毛利率、净利率、EBITDA Margin、经营现金流、CAPEX强度、项目IRR
- **风控**：安全事故率、质保赔付率、并网/消纳风险、补贴依赖度、原材料价格敏感度

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
光伏电池制造端竞争激烈，头部集中趋势明显；储能处于格局重塑阶段；氢能偏早期。

### 6.2 常见壁垒类型
技术与产品壁垒、制造成本壁垒、渠道与客户认证壁垒、项目开发与并网资源壁垒、安全与质量壁垒、融资和资产运营壁垒。

### 6.3 替代风险
技术路线替代（钠电池替代锂电池等）；产品同质化价格战；上下游挤压利润；政策退坡；海外贸易壁垒。

## 7. 行业风险

### 7.1 通用风险项
原材料价格波动、产能过剩、价格战、技术路线变化、安全事故、并网不及预期、政策退坡、回款周期长、高CAPEX。

### 7.2 行业特有风险
安全事故（储能起火、电池热失控可致命侵蚀品牌）；政策退坡后项目IRR不达标；高景气期大量扩产导致产能过剩；新技术路线颠覆现有产能。

### 7.3 风险信号
- 出货增但ASP和毛利同步下滑 → 量增价跌陷阱（传导机制：产能过剩→价格战→以价换量→单Wh毛利被压缩→出货增长无法转化为利润增长）
- 在手订单高但回款慢现金流差 → 回款风险（传导机制：客户资金紧张/补贴拖欠→应收账款增加→收入确认但现金不回→经营现金流恶化→可能需额外融资）
- 新产能投放快但利用率不足 → 产能过剩（传导机制：行业高景气期集体扩产→需求增速放缓→产能利用率低→固定折旧摊薄单位利润→价格战加剧）
- 补贴收入占比过高 → 政策依赖风险（传导机制：补贴退坡→项目IRR不达标→新增项目暂停→收入增长失速→存量项目也面临补贴拖欠）

## 8. 财务分析重点

### 8.1 利润表重点
收入结构；ASP变化；毛利率变化；研发费用率；质保和售后成本；财务费用。

### 8.2 资产负债表重点
现金；应收账款；存货；固定资产；在建工程；有息负债；合同负债。

### 8.3 现金流量表重点
经营现金流是否匹配出货增长；CAPEX是否过重；应收和存货是否恶化。

## 9. 市场空间测算

- **TAM**：全球/区域新能源设备、系统、服务和运营市场总规模
- **SAM**：公司当前技术路线、区域、资质下可服务市场
- **SOM**：中短期可实际拿下的装机、订单和客户份额

测算：1) 装机法 = 年新增装机 × 单位价值量；2) 终端渗透法 = 目标设备数 × 单设备价值；3) 运营收益法 = 可运营资产规模 × 单位收益

注意：市场大不等于盈利厚；设备端区分"量增"和"价跌"；运营端看真实IRR；技术路线变化会重塑TAM归属。

## 10. 快速分析卡

- **一句话本质**：新能源是以更低成本、更高效率和安全性重构能源供给与消费体系的行业
- **核心收入公式**：收入 = 出货量/装机量/项目量 × 单位价值 + 运维/运营/软件服务收入
- **核心成本公式**：成本 = 材料制造 + 系统集成/EPC + 研发 + 销售 + 运维质保 + 财务
- **核心判断三要素**：技术和成本竞争力、出货/项目盈利质量、现金流CAPEX和政策依赖可控性
- **最重要指标**（3个）：出货量/装机量、ASP、毛利率
- **最大风险**（3个）：价格战与产能过剩、安全事故、政策退坡
- **一句话结论模板**：新能源的核心不是追求装机规模，而是能否在技术、成本、安全和资金效率间建立长期可复制优势。决定长期价值的是成本曲线位置、产品可靠性和资本效率。
