# SaaS行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
SaaS的本质是以持续订阅方式嵌入客户业务流程，通过续费与扩模块实现长期复利收入。核心是"持续服务+流程嵌入+复利增长"。

### 1.2 与普通行业的核心差异

| 差异维度 | SaaS | 传统软件/服务 |
|---------|------|-------------|
| 收入模式 | 订阅制，经常性收入为主 | 一次性License+维保 |
| 增长引擎 | 续费+扩单（存量复利） | 新签驱动（增量为主） |
| 利润释放 | 前期亏损，规模后经营杠杆释放 | 当期盈利但增长受限 |
| 客户关系 | 长期嵌入，切换成本高 | 项目交付后弱粘性 |

### 1.3 分析总框架
产品是否嵌入流程 → 续费率是否健康 → 扩单是否自然 → 单位经济是否成立 → 经营杠杆是否释放

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 企业服务投资热潮 | 资本涌入企服赛道，SaaS创业项目井喷，但很多项目PMF未验证即获融资 |
| 2020 | 疫情加速数字化 | 远程办公和在线化需求爆发，协同办公、CRM、HR SaaS用户激增 |
| 2021 | 互联网大厂入企服 | 飞书、钉钉、企业微信加码，SaaS竞争从产品力转向生态和流量 |
| 2022 | 企服资本寒冬 | VC退潮，未盈利SaaS融资困难，行业进入拼产品和现金流阶段 |
| 2023 | AI+SaaS范式切换 | 大模型嵌入SaaS产品，从效率工具向智能助手转型，但商业化仍在探索 |
| 2024-25 | 信创与国产替代深化 | 政府/国企SaaS采购向国产化倾斜，合规成为采购硬门槛 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
发现需求 → 产品开发 → 获客 → 演示与试用 → 首次签约 → 上线实施 → 嵌入流程 → 续费与扩模块 → NRR提升 → 毛利释放

### 2.2 核心飞轮
更多客户使用 → 更多数据与场景沉淀 → 产品更完善、模板更成熟 → 实施效率更高 → 更高续费与扩单率 → 更多收入投入产品和销售 → 更多客户使用

核心驱动：嵌入深度决定续费强度，续费决定扩单自然度，扩单决定单客户价值曲线。

### 2.3 商业模式分类
1. **订阅收费**：企业客户 / 按年月订阅 / 收入 = 付费客户数 × 平均订阅单价
2. **按席位收费**：使用员工 / 按账号数 / 收入 = 客户数 × 平均席位数 × 单席位价格
3. **按使用量收费**：企业客户 / 按调用量、数据量 / 收入 = 使用量 × 单位价格

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 订阅收入 + 席位收入 + 模块收入 + 使用量收入 + 实施服务收入 + 增值收入

核心拆法：收入 = 客户数 × ACV；存量视角：本期收入 = 期初续费收入 + 存量扩单 + 新增客户

### 3.2 成本模型
- 固定成本：研发人员、管理人员、核心平台投入
- 变动成本：云资源、实施服务、渠道佣金、客户支持
- 前端成本：市场投放、销售团队、渠道合作
- 后端成本：研发、实施、客户成功、运维

### 3.3 单位经济
LTV = 生命周期收入 × 毛利率；CAC = 销售营销成本 / 新增付费客户数
LTV/CAC >= 3 [适用：B2B SaaS，成长期以上] [局限：C端产品/低客单价不适用] 为健康，CAC回收 <= 12-18个月 [适用：企业级SaaS] [局限：超大ACV客户回收期可能更长]

### 3.4 利润率特征
优秀SaaS毛利率70%-85% [适用：纯订阅型SaaS] [局限：含实施服务或硬件的SaaS不适用]；成熟净利率15%-30% [适用：成熟期规模SaaS] [局限：成长期通常亏损]；订阅收入占比>70%为健康信号 [适用：标准化产品型SaaS] [局限：垂直行业SaaS可能含合理服务收入]

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 协同办公SaaS | 内部沟通协作 | 各类企业 | 订阅+增值 | MAU、席位、续费率 |
| CRM/销售管理 | 客户与销售流程 | 销售驱动企业 | 订阅+席位 | ACV、NRR、使用深度 |
| ERP/经营管理 | 采购库存财务流程 | 中大型企业 | 订阅+实施 | ACV、实施周期、续费率 |
| 垂直行业SaaS | 特定行业场景 | 行业企业 | 订阅+交易/服务 | 渗透率、复购、交叉销售 |
| 开发工具SaaS | 开发者技术团队 | 技术团队 | 订阅+Usage | DAU、留存、Usage收入 |

## 5. 核心指标体系

- **规模**：ARR/MRR、收入、付费客户数、席位数
- **增长**：ARR增速、新增客户数、新增ARR
- **转化**：试用转付费率、线索转化率、Demo到签约率
- **留存/复购**：Logo Retention、GRR、NRR、续费率、扩单率
- **变现**：ACV、ARPU、单席位收入、每客户模块数
- **供给**：渠道伙伴数、实施伙伴数、集成生态数量
- **效率**：CAC、LTV/CAC、CAC回收周期、销售人效、实施周期
- **财务**：毛利率、订阅收入占比、销售费用率、研发费用率、经营现金流、递延收入
- **风控**：客户流失率、降级率、系统可用性、大客户依赖度、定制化收入占比

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
细分赛道多，整体高度分散；水平SaaS更易出现头部平台；垂直SaaS强依赖行业know-how；大厂可能通过流量、云、生态进入。

### 6.2 常见壁垒类型
产品壁垒（功能深度）、数据壁垒（历史数据沉淀）、流程嵌入壁垒、生态壁垒（集成伙伴）、客户切换成本。

### 6.3 替代风险
被ERP/大平台/办公平台替代；被AI新工具重构功能边界；客户自研或继续用Excel/低代码替代。

## 7. 行业风险

### 7.1 通用风险项
获客成本过高、续费率不足、服务收入过重、产品标准化不足、大客户依赖、与大厂竞争、数据合规风险。

### 7.2 行业特有风险
伪SaaS（名义SaaS实则项目制）、NRR陷阱（依赖少数大客户扩单）、经营杠杆迟迟不释放。

### 7.3 风险信号
收入增长快但销售费用率居高不下（传导机制：获客效率未提升→需要更多销售投入驱动增长→销售费用率不降→经营杠杆无法释放→规模不经济）；NRR低于100% [适用：B2B SaaS] [局限：C端/SMB为主的SaaS波动更大]（传导机制：客户流失/降级超过扩单→存量收入萎缩→必须靠更多新客弥补→获客成本持续高企→增长质量差）；实施收入占比过高 [适用：标品型SaaS] [局限：复杂行业SaaS实施收入是合理的]（传导机制：产品标准化不足→每单需大量定制实施→边际成本高→经营杠杆无法释放→实质为项目制而非SaaS）；前五大客户占比过高 [适用：中型SaaS] [局限：早期/垂直SaaS大客户集中是常态]（传导机制：大客户流失→收入断崖→续费率大幅波动→增长不可预测）；每签客户都要重新定制 [适用：标品型SaaS] [局限：垂直行业定制可能是业务模式]（传导机制：产品无法复用→边际交付成本高→规模化不改善利润→伪SaaS）；ARR增长但经营现金流未改善 [适用：所有SaaS] [局限：高速扩张期合同负债增加可能导致暂时性背离]（传导机制：ARR增长但回款差/应收增加→现金未实际流入→利润表好看但现金流差→可能依赖融资维持）。

## 8. 财务分析重点

### 8.1 利润表重点
订阅vs服务收入占比；毛利率结构；销售费用率；研发费用率；是否接近经营杠杆释放点。

### 8.2 资产负债表重点
现金储备；合同负债/递延收入（预收是SaaS优势信号）；应收账款；资本化研发；商誉。

### 8.3 现金流量表重点
经营现金流是否优于利润表（预收使现金流领先利润）；回款周期；高增长是否伴随现金消耗失控。

## 9. 市场空间测算

- **TAM**：企业数字化软件总体支出空间
- **SAM**：公司能力可服务的特定行业/客户类型软件市场
- **SOM**：公司中短期可获得的实际份额

测算：1) 客户法 = 目标客户数 × 年均ACV；2) 席位法 = 可服务员工数 × 渗透率 × 单席位价格；3) 模块法 = 企业数 × 模块渗透率 × 模块年费

## 10. 快速分析卡

- **一句话本质**：SaaS是通过持续订阅嵌入客户流程，靠续费和扩单形成长期复利收入
- **核心收入公式**：收入 = 客户数 × ACV
- **核心成本公式**：成本 = 获客成本 + 实施交付 + 云资源 + 研发 + 客户成功
- **核心判断三要素**：续费是否强、扩单是否自然、标准化是否足够高
- **最重要指标**（3个）：NRR、CAC回收周期、毛利率
- **最大风险**（3个）：伪SaaS实则项目制、单位经济不成立、被大厂/AI工具替代
- **一句话结论模板**：SaaS的核心不是签了多少客户，而是客户是否把产品嵌入流程、是否持续续费扩单。决定长期价值的是NRR、标准化和单位经济质量。
