# 传媒广告行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
通过流量、内容、媒介资源、数据和策略能力，帮广告主高效完成"曝光-认知-转化-复购"某一环节，并证明自身创造的传播或转化价值。核心不是"帮客户投广告"，而是"证明投放价值"。

### 1.2 与普通行业的核心差异

| 差异维度 | 传媒广告 | 普通ToB服务 |
|---------|---------|-----------|
| 收入口径 | 毛收入vs净收入差异巨大 | 收入即净收入 |
| 现金流 | 垫资常见，回款周期长 | 通常先收后付 |
| 平台依赖 | 强依赖流量平台规则 | 客户关系更自主 |
| 交付标准化 | 项目制高度非标 | 多数可标准化 |
| 宏观敏感性 | 强相关品牌投放意愿 | 相对稳定 |

### 1.3 分析总框架
客户预算获取 → 策略与媒介计划 → 流量/内容采购执行 → 效果证明与复盘 → 续约与预算留存 → 从项目制走向标准化/平台化

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 信息流广告超越搜索广告 | 短视频平台广告收入快速超过搜索引擎，广告市场格局重塑 |
| 2020 | 疫情冲击+直播电商崛起 | 线下广告预算缩减，电商直播和短视频广告份额扩大 |
| 2021 | 个人信息保护法+广告标识要求 | 数据隐私监管收紧，精准投放效率受限，广告行业合规成本上升 |
| 2022 | 互联网广告大盘下滑 | 经济下行+监管收紧，互联网广告收入首次同比下降 |
| 2023 | AIGC重塑广告生产 | AI生成创意素材降低制作成本，但同质化和版权问题浮现 |
| 2024-25 | 程序化+AI投放深化 | AI自动优化投放策略成为标配，广告从"人决策"转向"AI决策" |

## 2. 价值链与商业模式

### 2.1 价值创造链条
代理型：获取广告主预算 → 策略与媒介计划 → 采购流量媒体 → 执行投放优化 → 复盘效果 → 服务费/返点/续约
内容营销型：洞察传播需求 → 创意策划 → 内容生产/达人合作 → 多平台分发 → 曝光/互动/转化 → 项目费
程序化/平台型：连接广告主与媒体 → 数据定向自动投放 → 提升效率优化ROI → 技术费/抽佣

### 2.2 核心飞轮
更强客户案例和ROI证明 → 更多预算与客户续约 → 更大媒体资源和数据积累 → 更强投放创意交付能力 → 更强客户案例

### 2.3 商业模式分类
- **代理服务费**：广告主，按预算比例或月费，公式=投放额 x 服务费率
- **媒介价差/返点**：采买折扣与售卖价差，公式=售卖价 - 采购价
- **效果分成**：广告主，按线索/成交/GMV分成，公式=成交量 x 单位分成
- **项目制收费**：广告主，按campaign/活动，公式=项目数 x 项目客单价
- **技术平台收费**：广告主/代理商，订阅/抽成，公式=客户数 x ARPU

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 代理服务费 + 媒介价差 + 效果分成 + 项目制收入 + 技术平台收入 + 广告位售卖
代理公司：收入 = 客户数 x 单客户预算 x 服务费率
项目制：收入 = 项目数量 x 单项目客单价
MCN：收入 = 合作品牌数 x 单品牌投放额 x 抽佣率

### 3.2 成本模型
固定：管理团队、核心创意团队、技术研发、平台系统、办公运营
变动：媒介采买、KOL/KOC成本、内容外包、项目执行、提成奖金

### 3.3 单位经济
代理型：单客户贡献毛利 = 客户收入 - 媒介/达人/执行 - 客户服务人工
项目制：单项目毛利 = 项目收入 - 外包制作 - 执行成本 - 人工分摊

### 3.4 利润率特征
代理净收入率10-25% [适用：品牌广告代理] [局限：效果代理通常5-15%]、整合营销毛利20-40% [适用：全案型整合营销] [局限：纯执行类代运营通常10-20%]、MCN抽佣毛利15-30% [适用：头部达人MCN] [局限：中小MCN受达人议价挤压通常10-20%]、MarTech毛利50-70% [适用：标准化SaaS型MarTech] [局限：含大量实施定制的通常30-50%]。很多公司"收入大利润薄"，关键看净收入口径和真实毛利

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 品牌广告代理 | 品牌曝光和传播 | 大中型品牌主 | 服务费/返点 | 客户续约率、预算规模 |
| 效果广告代理 | 聚焦获客和ROI | 电商/APP/游戏 | 服务费/分成 | ROAS、CAC、回款 |
| 整合营销 | 创意+媒介+传播整合 | 品牌主 | 项目费 | 项目毛利率、复购率 |
| 内容营销/MCN | 达人合作/种草/短视频 | 消费品牌/电商 | 抽佣/项目费 | GMV、转化率 |
| 程序化广告 | 自动化投放和撮合 | 广告主/代理商 | 技术费/抽佣 | Fill Rate、eCPM |
| 户外广告 | 楼宇/交通/商圈媒体 | 品牌主/本地商家 | 广告位售卖 | 上刊率、点位利用率 |
| MarTech平台 | 营销自动化/数据分析 | 中大型企业 | 软件费/服务费 | ARR、续费率 |

## 5. 核心指标体系

- **规模**：收入、净收入(Net Revenue)、广告消耗额、客户数、项目数、媒体点位数
- **增长**：净收入增速、客户增长、续约率、项目复购率、新渠道收入增长
- **转化**：提案转签约率、CTR、落地页转化率、内容互动率
- **留存/复购**：客户续约率、NRR、老客户收入占比、Top10客户收入占比
- **变现**：单客户ARPU、服务费率、Take Rate、单项目客单价、人均净收入
- **供给**：媒介资源数、达人资源数、广告位库存、创意团队产能
- **效率**：人均净收入、回款周期、应收周转天数、垫资规模/收入比
- **财务**：毛利率、净收入率、销售费用率、EBITDA Margin、经营现金流、坏账率
- **风控**：单一客户收入占比、单一平台收入占比、应收占收入比、超账期应收占比

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
整体分散，头部大集团和大量中小并存；平台侧挤压纯中介代理利润；MCN竞争激烈更新快

### 6.2 常见壁垒类型
客户关系、媒介资源、创意内容生产、数据技术、达人资源、大客户服务交付、行业垂直know-how

### 6.3 替代风险
平台直营广告系统削弱代理价值；AI工具降低内容制作门槛；品牌主自建投放团队；达人直接接单绕过MCN

## 7. 行业风险

### 7.1 通用风险项
客户预算波动、平台规则变化、流量成本上升、低毛利竞争、回款拉长、垫资压力、客户集中度高

### 7.2 行业特有风险
平台依赖：单一平台政策变化可致业务大幅波动；垫资陷阱：大客户回款慢+垫资=现金流压力；人效天花板：项目制人均净收入有上限；收入口径陷阱：毛收入大但净收入薄

### 7.3 风险信号
收入增长但净收入利润不增长 → 收入口径虚胖（传导机制：扩大代投规模→毛收入增长但净收入率低→真实毛利不增→规模扩大反而垫资和人力成本攀升→利润恶化）；代投规模增长但毛利率下滑 → 定价权丧失（传导机制：竞争加剧→被迫压低服务费率/返点被压缩→毛利持续下滑→规模不经济→越大越不赚钱）；应收账款增速快于收入增速 → 回款风险（传导机制：大客户议价延长账期→应收膨胀→坏账风险上升→经营现金流恶化→可能需要垫资维持→现金流危机）

## 8. 财务分析重点

### 8.1 利润表重点
毛收入和净收入区别、服务费率稳定性、媒介和达人成本占比、人效变化、项目制收入波动性

### 8.2 资产负债表重点
应收账款及账龄、合同资产、预付款和媒介垫资、现金储备、商誉

### 8.3 现金流量表重点
经营现金流与利润匹配度、回款周期变化、垫资是否吞噬现金流、大客户结算周期风险

## 9. 市场空间测算

- **TAM**：广告主在品牌/效果/内容/媒介/MarTech上的总预算
- **SAM**：公司覆盖行业/区域/媒介/客户层级对应的可服务预算
- **SOM**：公司中短期可获取的客户预算份额

测算公式：客户预算法=目标广告主数x年均预算；服务费率法=广告投放总额x可抽取费率

注意：预算空间不等于收入空间；毛收入大不代表利润大；平台直采趋势压缩中间层

## 10. 快速分析卡

- **一句话本质**：通过流量、内容、媒介、数据和策略能力帮广告主高效完成传播或转化，从广告预算中获得可持续的服务费、差价或技术收入
- **核心收入公式**：收入 = 客户数 x 单客户预算 x 服务费率
- **核心成本公式**：成本 = 媒介/达人/制作成本 + 客户服务人工 + 销售成本 + 技术管理成本 + 坏账
- **核心判断三要素**：1)能否持续拿到并留住客户预算 2)能否证明效果并形成稳定毛利 3)是否具备标准化交付或技术/资源壁垒
- **最重要指标**（3个）：净收入毛利率、客户续约率、人均净收入
- **最大风险**（3个）：平台依赖、回款拖延与垫资、客户集中度
- **一句话结论模板**：传媒广告核心不是做大毛收入，而是能否在客户预算中占据稳定份额，用可验证效果和可复制交付形成健康净收入和稳定现金流
