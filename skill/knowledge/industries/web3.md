# Web3/加密经济行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
基于区块链和智能合约构建去中心化价值传输与可编程金融生态，通过交易手续费、储备利差、协议收入和代币增值实现商业化。本质不是"做互联网"也不是"做金融"，而是用去中心化信任机制降低价值流转的中介成本和准入门槛，同时通过代币经济实现网络效应的内部化。

### 1.2 与普通行业的核心差异

| 差异维度 | Web3/加密经济 | 传统互联网/金融 |
|---------|-------------|---------------|
| 监管约束 | 极端分化：全面禁止（中国内地）到积极拥抱（香港/新加坡/阿联酋） | 相对稳定和可预期 |
| 资产属性 | 原生数字资产，私钥=产权，无中介可追回 | 账户余额，可挂失冻结 |
| 收入与代币关系 | 代币既是融资工具也是收入来源，估值逻辑与传统不同 | 股权融资和收入分离 |
| 周期性 | 4年减半周期叠加监管周期，波动率是传统市场10x+ | 温和周期 |
| 合规与非法边界 | 同一业务在不同法域定性完全不同 | 跨法域差异相对温和 |
| 用户行为 | 匿名/伪匿名，链上数据全公开但身份隐匿 | 实名制，数据由平台控制 |

### 1.3 分析总框架
区块链基础设施 → 智能合约可编程层 → 金融中间层（交易所/稳定币/做市）→ 应用层（DeFi/NFT/RWA/GameFi）→ 终端用户
核心驱动：流动性、信任（或合规替代信任）、网络效应和代币经济共同决定规模和可持续性

## 2. 价值链与商业模式

### 2.1 价值创造链条
交易所型：用户注册/KYC → 法币入金(C2C) → 交易(现货/合约) → 手续费+资金费率 → 用户资产沉淀 → 理财/借贷利差 → 生态绑定(Launchpad/平台币) → 更多交易
稳定币型：用户存入法币 → 铸造稳定币 → 储备金投资(美债) → 利差收入 → 规模扩大 → 更低成本 → 更多需求
DeFi协议型：用户存入资产(TVL) → 协议提供金融服务(借贷/交易/衍生品) → 协议手续费 → 代币激励分配 → 治理和生态发展

### 2.2 核心飞轮
交易所：更多用户和交易量 → 更深流动性 → 更低滑点 → 吸引大额/机构交易者 → 更多资产沉淀 → 生态产品(钱包/公链/支付)提高粘性 → 更多交易
稳定币：更大发行量 → 更多使用场景和流动性 → 更低合规边际成本 → 更高利差利润 → 更多储备投入合规 → 更多机构信任 → 更大发行量

### 2.3 商业模式分类
- **交易手续费**：收费对象=交易用户，公式=交易量×费率，CEX现货0.05-0.1%，合约0.02-0.05%
- **资金费率**：收费对象=合约持仓者，公式=持仓量×费率×频次，每8小时结算
- **储备利差**：收费对象=稳定币持有者（隐性），公式=发行量×储备收益率
- **上币费/IEO**：收费对象=项目方，公式=项目$50-500万+代币份额
- **理财利差**：收费对象=存币用户，公式=存币规模×(放贷利率-用户利率)
- **协议手续费**：收费对象=DeFi用户，公式=TVL×费率，部分分给LP
- **代币增值/通胀**：收费对象=生态参与者，公式=代币市值×通胀释放-销毁

## 3. 收入与成本模型

### 3.1 收入模型
- CEX收入 = 衍生品交易费(~45%) + 现货交易费(~25%) + 上币费/Launchpad(~10%) + 理财利差(~8%) + 其他(~12%)
- 稳定币收入 = 发行量 × 储备收益率 - 合规成本 - 赎回成本
- DeFi协议收入 = TVL × 协议费率 - 代币激励支出
- 矿机/基础设施收入 = 销量×单价 或 算力×单位收益

### 3.2 成本模型
固定成本：技术平台、合规与法务、安全审计、核心团队
变动成本：做市成本、Gas费(链上操作)、代币激励、获客成本(空投/返佣)、风险拨备

### 3.3 单位经济
- CEX：单用户LTV = 月均手续费$50-200 × 平均生命周期月数，CAC=$10-100
- 稳定币：边际成本≈0，利差随美联储利率波动
- DeFi：代币激励/收入比 <1为健康，>1则入不敷出
- 矿机：盈亏平衡点 = 币价/(电费+折旧)

### 3.4 利润率特征
- CEX毛利率：60-80% [适用：头部交易所] [局限：中小交易所因流动性不足费用更高]
- 稳定币毛利率：95%+ [适用：Tether/Circle] [局限：合规成本随监管趋严上升]
- 矿机制造毛利率：30-50% [适用：比特大陆等] [局限：强周期性，熊市可转亏]
- DeFi协议毛利率：波动大 [适用：成熟协议] [局限：多数代币激励>收入，实际亏损]

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 中心化交易所(CEX) | 托管式加密资产交易平台 | 交易用户/机构 | 手续费+资金费率+上币费+理财利差 | 交易量、TVL、市占率 |
| 去中心化交易所(DEX) | 非托管链上交易平台 | 链上用户 | 协议手续费(部分分LP) | TVL、交易量、独立地址数 |
| 稳定币发行 | 锚定法币的加密货币发行 | 全行业基础设施 | 储备利差 | 发行量、储备透明度 |
| DeFi借贷 | 链上去中心化借贷协议 | 存借用户 | 存贷利差/协议费 | TVL、借款利用率、清算率 |
| 公链/L1 | 区块链底层协议 | 开发者/验证者 | Gas费+代币增发 | TVL、TPS、开发者数 |
| 钱包/入口 | 链上资产管理和DApp访问 | 终端用户 | Swap手续费+聚合差价 | MAU、Swap量 |
| NFT/数字藏品 | 非同质化代币和数字资产 | 收藏者/创作者 | 交易佣金+铸造费 | 交易量、活跃钱包数 |
| RWA | 现实资产代币化 | 传统金融机构/投资者 | 发行费+管理费 | 代币化规模、合规牌照 |
| 矿机/算力 | 加密货币挖矿硬件和运营 | 矿工/矿场 | 硬件销售+算力租赁 | 算力、能效比、成本 |

## 5. 核心指标体系

- **规模指标**：TVL(协议锁仓量)、日交易量、CEX托管资产规模、稳定币发行量、市值/FDV、活跃地址数
- **增长指标**：TVL增速、交易量增速、新增地址数、新协议数量、链上日活增长率
- **变现指标**：协议收入(P/S)、手续费率、资金费率、ARPU(活跃用户月均手续费)、Mcap/TVL
- **效率指标**：Gas费/交易、清算率、滑点、MEV提取量、做市价差
- **安全指标**：被黑金额、漏洞修复响应时间、审计覆盖率、多签比例
- **生态指标**：开发者数量、DApp数量、GitHub commits、跨链桥TVL
- **链上专属指标**：TVL/市值、Fees/Revenue区分、Earnings(Revenue-激励-成本)、代币激励/收入比、解锁抛压
- **交易所专属指标**：市占率、合约持仓比(健康<5:1)、OTC溢价、平台币表现
- **稳定币专属指标**：发行量、储备构成、脱锚频率、链上流通速度

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
CEX极度集中(HHI指数5352)，币安+OKX占据衍生品市场~50%；稳定币Tether占~65%市占率；DeFi协议同质化严重，TVL流动性高(随时可撤)；公链竞争激烈但以太坊生态优势明显；钱包赛道正在从工具向"入口+交易"转型

### 6.2 常见壁垒类型
流动性壁垒(交易所核心)、网络效应(流动性吸引流动性)、合规/牌照壁垒(交易所和稳定币)、品牌与信任(FTX后更关键)、代币锁定效应(平台币/Launchpad)、技术壁垒(智能合约安全/公链性能)、数据壁垒(链上标签/地址画像)

### 6.3 替代风险
DEX替代CEX(长期趋势但短期体验差距大)、CBDC替代稳定币(政策驱动)、传统金融入场替代RWA/DeFi、AI Agent替代手动交易

## 7. 行业风险

### 7.1 通用风险项
监管禁止(中国内地全面禁止交易/挖矿/发行)、智能合约漏洞(被黑)、市场周期性(4年减半周期)、流动性危机(挤兑/脱锚)、跨链桥安全(历史被黑超$20亿)、代币解锁抛压、女巫攻击(撸毛党刷量)、MEV攻击

### 7.2 行业特有风险
合规二元化（同一业务中国非法但香港合法）、稳定币储备透明度(Tether审计争议)、交易所挪用用户资产(FTX教训)、代币经济不可持续(通胀补贴>真实收入)、预言机失效导致DeFi系统性风险、私钥丢失不可恢复

### 7.3 风险信号
合约持仓量/现货交易量>5:1（过度杠杆化，极端行情连环爆仓）、OTC出金溢价>3%（法币流出压力，熊市前兆）、代币激励/协议收入>1（入不敷出，不可持续）、稳定币脱锚频次增加（储备信任危机）、新币上线频率明显加快+上线即暴跌>50%（交易所创收压力/撸毛党主导）、平台代币月跌幅>30%（信任危机/运营困难）

## 8. 财务分析重点

### 8.1 利润表重点
交易费收入结构(现货/合约/上币费)、代币激励支出(DeFi关键)、风险拨备、合规成本、Gas费支出

### 8.2 资产负债表重点
用户托管资产(CEX)、储备资产构成(稳定币)、代币库存和解锁节奏、链上TVL、跨链桥锁定资产

### 8.3 现金流量表重点
经营现金流是否匹配链上收入、储备金赎回压力、代币质押/解锁现金流、资本开支(矿机/节点)

## 9. 市场空间测算

- **TAM**：全球加密经济总市值(~$3万亿)、全球DeFi TVL(~$850亿)、稳定币总发行量(~$2000亿)
- **SAM**：特定赛道可服务市场(如CEX交易量、RWA代币化规模)
- **SOM**：目标项目可获取的链上份额或交易量份额

测算方法：
- 交易量法：收入空间 = 目标市场交易量 × 可实现费率
- TVL法：DeFi收入空间 = 目标TVL × 协议费率 × 资金周转率
- 稳定币法：利差收入空间 = 目标发行量 × 储备收益率 - 合规成本

注意：加密市场波动率极高，TAM随周期变化2-5x；中国内地市场在法律层面接近零（但OTC地下市场存在）；合规市场(香港/新加坡)增速快但基数小

## 10. 快速分析卡

- **一句话本质**：用去中心化信任机制降低价值流转中介成本，通过交易手续费、储备利差和代币经济实现商业化
- **核心收入公式**：CEX收入 = 交易量×费率；稳定币收入 = 发行量×储备收益率；DeFi收入 = TVL×费率-代币激励
- **核心成本公式**：成本 = 合规成本 + 安全成本 + 获客成本(空投/返佣) + 代币激励 + 风险拨备
- **核心判断三要素**：1)合法性边界是否清晰 2)收入是否来自真实需求而非通胀补贴 3)信任/合规是否可持续
- **最重要指标**（3个）：TVL/交易量、协议收入vs代币激励比、合规牌照状态
- **最大风险**（3个）：监管禁止、智能合约安全、代币经济不可持续
- **一句话结论模板**：该Web3项目的核心价值在于[流动性/信任基础设施/合规路径]，关键风险是[监管合法性/资产安全/代币经济可持续性]，长期取决于[能否在合规框架下把交易/协议/信任做深且不依赖通胀补贴]
- **中国内地特别提示**：境内涉及虚拟货币发行、交易、兑换的业务均为非法金融活动；合法路径仅限联盟链技术、RWA备案(证监会1号令)、香港持牌通道
