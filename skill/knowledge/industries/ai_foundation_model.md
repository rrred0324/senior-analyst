# 大模型公司商业建模知识库

> 适用场景：一级市场投资研究、AI 公司分析、行业商业建模、技术型项目尽调、赛道比较
> 覆盖范围：基础大模型、多模态模型、开源模型公司、API 模型平台、企业大模型解决方案
> 行业特征：强技术驱动、高资本投入、算力约束显著、商业化路径仍在演化、上游资源依赖强

---

## 1. 行业总论

### 商业本质

大模型公司的本质是：将通用或行业专用的模型能力，转化为可调用、可部署、可嵌入业务流程的智能能力，并通过 API、企业服务、应用产品或生态能力实现商业化。

它不是传统软件公司，也不完全是云服务公司，更不是单纯科研组织。它同时涉及：

- 模型研发能力
- 数据处理能力
- 算力组织能力
- 平台化交付能力
- 应用产品化能力
- 场景落地能力

### 行业核心矛盾

1）模型能力 vs 商业化能力：模型强不代表有人付费，商业上更重要的是客户是否愿意持续用、持续付费。

2）收入增长 vs 推理成本：调用量增长带来收入，但也会拉高推理成本。如果单位毛利始终不改善，增长质量会很差。

3）通用能力 vs 行业场景：通用模型更有天花板，但行业模型更容易先形成付费闭环。

4）开源扩散 vs 商业壁垒：开源有助于生态扩张，但也可能压缩收费空间。必须回答：开源之后，真正可收费的部分在哪里？

### 分析总框架

```
行业本质（模型能力平台化、服务化、产品化）
  → 商业模式分类（API/企业服务/应用/开源商业化）
    → 收入成本模型（调用量×单价 + 企业服务 + 订阅）
      → 核心指标体系（技术/商业/成本/战略四维）
        → 经营机制与竞争（数据飞轮 + 场景壁垒）
```

## 2. 商业模式分类

### 2.1 按商业化路径划分

| 模式 | 描述 | 核心收入来源 | 关键能力 |
|---|---|---|---|
| API 模型服务 | 向开发者/企业提供模型调用 | Token/调用收费 | 模型效果、稳定性、推理成本 |
| 企业私有化部署 | 向企业输出模型及部署能力 | 项目费、部署费、年费 | 企业销售、交付、定制能力 |
| 行业解决方案 | 面向垂直行业提供模型+工作流方案 | 合同额、订阅费、运维费 | 场景理解、方案复制能力 |
| 模型+应用一体化 | 自己做终端产品 | 订阅费、席位费、增值费 | 产品能力、分发能力 |
| 开源模型商业化 | 开源底座 + 托管/增值服务 | 企业版、托管、工具链收费 | 社区影响力、商业转化能力 |

### 2.2 按能力栈划分

| 类型 | 描述 | 投资视角重点 |
|---|---|---|
| 基础模型公司 | 强调底层模型训练与迭代 | 技术壁垒、算力组织、资本效率 |
| 多模态模型公司 | 文本、图像、语音、视频统一建模 | 产品应用范围、差异化能力 |
| 行业大模型公司 | 医疗、金融、教育、法律等专用模型 | 行业数据壁垒、落地深度 |
| 模型平台公司 | 模型调度、托管、部署、评测 | 平台粘性、开发者生态 |
| 应用型模型公司 | 模型嵌入具体产品 | 留存、付费、工作流嵌入 |

## 3. 收入与成本模型

### 3.1 收入模型

**API 服务**
```
收入 = Token 调用量 × 单位价格
```

**企业解决方案**
```
收入 = 部署项目费 + 年度订阅费 + 推理服务费 + 运维费
```

**模型+应用**
```
收入 = 付费用户数 × ARPU
或
收入 = 企业客户数 × ACV
```

**综合模型**
```
总收入 = API 收入 + 企业服务收入 + 应用产品收入 + 生态增值收入
```

### 3.2 成本模型

主要成本包括：

+ 模型训练成本
+ 推理成本
+ GPU/算力租赁或折旧成本
+ 数据清洗与标注成本
+ 研发成本
+ 销售与解决方案交付成本
+ 安全/合规/内容审核成本
+ 云资源与带宽成本

**利润模型**
```
利润 = 收入 - 算力成本 - 研发成本 - 数据成本 - 销售交付成本 - 管理费用
```

### 3.3 单位经济模型

**API 模型**
```
单次调用毛利 = 单次调用收入 - 单次推理成本
```

**企业客户模型**
```
单客户利润 = 客户年度收入 - 售前/交付成本 - 推理成本 - 客服与运维成本
```

**应用模型**
```
单用户利润 = ARPU - 模型调用成本 - 获客成本分摊 - 服务成本
```

## 5. 经营机制

### 5.1 核心飞轮
```
模型能力提升
→ 更多开发者/客户接入
→ 更多使用数据与反馈
→ 模型进一步优化
→ 应用效果更好
→ 商业化收入增长
→ 进一步投入算力与研发
```

### 5.2 核心判断逻辑

1）是否具备真正的模型能力？需区分：自研底座模型 / 基于开源模型微调 / 套壳式应用封装

2）商业化路径是否清晰？如果公司只讲"模型很强"，但没有明确客户、收费方式、交付模式、毛利改善路径，则商业建模不成立。

3）成本曲线是否改善？长期竞争力很大程度取决于：推理成本下降速度、GPU 资源组织能力、算法优化带来的性价比提升

4）是否有可持续壁垒？可持续壁垒可能来自：自研模型架构、数据来源、行业场景 know-how、工具链生态、客户工作流嵌入、开发者生态

## 6. 细分赛道分析

### 6.1 基础模型公司
本质：提供底层通用智能能力
核心变量：模型性能、训练资本消耗、推理毛利、上游 GPU 获取能力、开发者生态
风险：成本极高、商业化周期长、模型同质化、巨头竞争挤压

### 6.2 行业大模型公司
本质：把模型能力垂直嵌入高价值行业任务
核心变量：行业数据资源、客户付费意愿、行业合规、解决方案复制能力
风险：项目制过重、标准化不足、行业扩张慢

### 6.3 开源模型公司
本质：通过开源建立生态，再从企业服务中变现
核心变量：社区活跃度、企业线索转化率、托管与部署服务收入、企业版付费能力
风险：商业化难转化、免费替代多、定价权弱

## 7. 财务分析重点

### 7.1 利润表
+ 收入构成是 API、项目还是产品订阅
+ 毛利率是否随推理优化提升
+ 研发费用高是否形成真实壁垒
+ 销售费用是否对应可复制的客户增长

### 7.2 资产负债表
+ 预付款是否与算力采购相关
+ 是否存在大额设备资本化
+ 应收账款是否反映项目制交付压力
+ 无形资产或资本化研发比例

### 7.3 现金流量表
+ 融资现金流依赖程度
+ 经营现金流是否能支撑模型服务业务
+ 若利润差但现金流更差，通常说明商业化尚不健康

---

## 8. 常见风险信号

+ 收入增长主要靠项目制，非标准化
+ API 调用量增长，但毛利不改善
+ 客户试点多，正式付费少
+ 企业订单一次性强，续费差
+ 研发投入大，但产品化弱
+ 过度依赖单一上游模型或 GPU 资源
+ 开源热度高，但商业收入转化弱

## 9. 市场空间分析模板

### 自上而下
```
TAM = 企业软件/智能化支出 × AI 渗透率 × 可服务模型份额
```

### 自下而上
```
市场空间 = 目标客户数 × 单客户年模型支出
```

## 11. 快速分析卡

### 一句话本质
大模型公司本质上是：将模型能力平台化、服务化、产品化的智能基础设施公司

### 核心公式
```
收入 = 调用量 × 单价 + 企业服务费 + 订阅收入
```

### 核心判断
+ 模型能力是否真实
+ 商业化路径是否清晰
+ 推理成本是否持续下降
+ 客户是否持续付费

### 最大风险
+ 高投入低变现
+ 模型同质化
+ 毛利难改善
+ 被巨头基础能力压制
