# 消费行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
围绕消费者的日常需求、情绪价值或身份表达，提供标准化商品或品牌体验，并通过产品溢价、渠道效率和复购实现持续收入与利润。本质不是"卖货"，而是以产品力、品牌力和渠道力影响消费者选择，并在持续复购中实现规模和利润累积。

### 1.2 与普通行业的核心差异

| 差异维度 | 消费行业 | 制造业/科技行业 |
|---------|---------|---------------|
| 核心壁垒 | 品牌心智 + 渠道效率 + 复购 | 技术专利 + 规模效应 |
| 需求特征 | 高频复购驱动，消费决策感性 | 低频大宗，决策理性 |
| 路径依赖 | 从单品到品牌到品类矩阵 | 从技术到产品到生态 |
| 毛利来源 | 品牌溢价 + 规模采购议价 | 技术壁垒 + 供应链效率 |
| 关键变量 | 复购率、渠道动销、品牌搜索量 | 研发投入、良率、客户集中度 |

### 1.3 分析总框架
产品力验证 → 品牌心智建立 → 渠道铺设与动销 → 复购与口碑沉淀 → SKU扩展与客单提升 → 供应链与组织能力支撑

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 国潮消费兴起 | 李宁/花西子等国产品牌崛起，消费者对国货认同感提升 |
| 2020 | 疫情改变消费结构 | 必选消费韧性强，可选消费受冲击，线上渗透率跳升 |
| 2021 | 新消费品牌批量涌现/退潮 | 资本涌入新消费，但大量品牌烧钱换增长后难以为继 |
| 2022 | 消费降级趋势初显 | 拼多多/折扣零售崛起，消费者更重性价比 |
| 2023 | 消费K型分化 | 高端消费韧性与大众消费降级并存，品牌需明确客群定位 |
| 2024-25 | 出海+下沉双线展开 | 新消费品牌出海东南亚，低线市场成增量来源 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
洞察需求 → 产品定义 → 研发/打样/供应链生产 → 品牌与内容传播 → 渠道铺设 → 消费者购买 → 使用体验 → 复购/推荐 → SKU扩展 → 收入与利润积累

### 2.2 核心飞轮
更好的产品和体验 → 更高复购和口碑 → 更强品牌认知 → 更高渠道效率和更低获客成本 → 更大销售规模 → 更强供应链议价和研发投入 → 更好的产品和体验

核心驱动：产品被复购，品牌被记住，渠道愿意推，最终形成稳定心智和利润结构。

### 2.3 商业模式分类

| 模式 | 收费对象 | 收费方式 | 公式 |
|-----|---------|---------|------|
| 商品销售 | 消费者/渠道商 | 按件销售 | 收入 = 销量 x 单价 |
| 品牌溢价 | 消费者 | 高于白牌的价格实现高毛利 | 毛利 = 收入 - 商品成本 |
| 渠道分销 | 经销商/零售终端 | 经销供货、批发 | 分销收入 = 出货量 x 出厂价 |
| DTC直销 | 终端消费者 | 电商、私域、门店直营 | DTC收入 = 购买用户数 x 购买频次 x 客单价 |
| 会员/衍生品 | 消费者 | 会员、礼盒、联名、订阅 | 增值收入 = 增值购买人数 x 客均增值消费 |

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 主商品收入 + 新SKU收入 + 渠道收入 + 会员/增值收入 + 其他收入

DTC品牌：收入 = 购买用户数 x 购买频次 x 客单价
分销型品牌：收入 = 渠道终端数量 x 单终端动销 x 出厂价
品牌扩张：收入增长 = 用户增长 + 复购提升 + 提价 + SKU扩展 + 渠道扩张

### 3.2 成本模型
- 固定成本：品牌建设、组织管理、基础研发、部分渠道准入费用
- 变动成本：原料、包材、生产、履约、广告投放、平台佣金、销售返利、促销折扣

### 3.3 单位经济
单用户模型：LTV = 用户生命周期购买次数 x 平均订单毛利；CAC = 获客总成本 / 新增购买用户数
单件模型：单件毛利 = 售价 - 生产成本 - 包材成本 - 平台扣点/渠道费用

### 3.4 利润率特征
- 食品饮料：毛利率40-60% [适用：大众食饮/饮料] [局限：高端零食可达65%+，低端白牌仅30-35%]，净利率8-15% [适用：成熟品牌] [局限：新品牌扩张期常为负]
- 美妆个护：毛利率60-80% [适用：品牌美妆] [局限：白牌/代工仅30-50%]，净利率10-20% [适用：头部品牌] [局限：高投流期可降至5%以下]
- 服饰鞋包：毛利率50-70% [适用：品牌服饰] [局限：快时尚/白牌仅30-45%]，净利率5-12%（库存压力大） [适用：正常库存周转] [局限：滞销减值期可为负]
- 宠物消费：毛利率40-60% [适用：宠物食品/用品] [局限：医疗类宠物服务毛利率更高]，净利率8-15% [适用：成熟品牌] [局限：渠道建设期利润承压]
- 功能型消费：毛利率50-70% [适用：功能零食/保健品] [局限：普通功效产品仅40-50%]，净利率10-18% [适用：头部品牌] [局限：同质化竞争期净利率压缩]

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 食品饮料 | 满足日常食用和饮用需求 | 大众消费者 | 商品销售 | 复购率、渠道渗透、毛利率 |
| 美妆个护 | 满足护肤、清洁、颜值提升 | 女性/年轻消费者 | 商品销售 | 复购率、客单价、投流ROI |
| 服饰鞋包 | 满足穿搭与审美表达 | 泛消费人群 | 商品销售 | 售罄率、退货率、库存周转 |
| 宠物消费 | 满足宠物食品和用品 | 养宠人群 | 商品销售 | 复购率、用户生命周期 |
| 母婴消费 | 面向婴幼儿和家庭需求 | 家庭用户 | 商品销售 | 渠道渗透、复购、客群留存 |

赛道差异：食饮更看复购、渠道和供应链；美妆更看品牌心智、内容种草和毛利；服饰更看上新能力、库存和趋势判断；宠物更看长期陪伴型复购；母婴更看信任和渠道稳定性。

## 5. 核心指标体系

- **规模指标**：收入、销量、购买用户数、门店数/渠道点位数、SKU数、市占率
- **增长指标**：收入增速、新增用户数、新渠道数、新品收入占比、新区域收入占比
- **转化指标**：曝光转化率、进店转化率、下单转化率、私域转化率、试吃/试用转化率
- **留存/复购指标**：次月复购率、90日复购率、年复购率、会员续费率、老客贡献收入占比、回流率
- **变现指标**：客单价、ARPU、单件售价、毛利率、渠道加价率、会员渗透率
- **供给指标**：产能利用率、供货稳定性、缺货率、动销率、售罄率、渠道覆盖率
- **效率指标**：CAC、LTV、LTV/CAC、投流ROI、库存周转、渠道人效、上新成功率
- **财务指标**：毛利率、费用率、销售费用率、净利率、存货周转、经营现金流、应收应付周转
- **风控指标**：退货率、客诉率、食安/质量事件、渠道压货率、滞销率、爆品依赖度、单渠道依赖度

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
多数消费赛道参与者多、竞争分散；头部品牌逐步建立心智和渠道优势；白牌、代工、低价替代普遍存在；渠道变化会重塑竞争格局；新媒体时代品牌崛起快但淘汰也快。

### 6.2 常见壁垒类型
产品壁垒（口感/配方/功效/设计/品质稳定性）、品牌壁垒（认知/信任/心智）、渠道壁垒（终端铺货/分销网络/KA关系/私域沉淀）、供应链壁垒（产能/品控/交付稳定性）、组织壁垒（上新/投放/渠道/运营协同能力）、用户复购壁垒（习惯形成和偏好沉淀）。

### 6.3 替代风险
白牌低价替代、大品牌价格下探、渠道切换导致品牌势能减弱、内容流量衰减、爆品生命周期结束。

## 7. 行业风险

### 7.1 通用风险项
爆品依赖、复购不足、渠道压货、投流ROI下滑、供应链不稳定、品控与食安风险、库存积压、大单品老化、价格战、渠道集中度高。

### 7.2 行业特有风险
- 投流能拉来首单不代表生意成立，若复购弱品牌价值往往不稳
- 若毛利不足，营销放大会把利润吃掉
- 若渠道铺得快但动销弱，容易形成库存风险
- 过度依赖创始人IP或单主播，稳定性差

### 7.3 风险信号
- 收入增长快但老客复购不提升 → 品牌力未建立（传导机制：靠投流拉新而非复购驱动→老客不认可产品→获客成本无法摊薄→利润被投放吞噬）
- 流量投放增加但自然搜索和品牌词不增长 → 品牌心智未形成（传导机制：投放仅驱动短期转化→用户未形成品牌认知→停投即停增长→长期无法建立壁垒）
- 渠道扩张快但终端动销变弱 → 渠道压货风险（传导机制：铺货过快超出终端消化能力→库存积压→退货/返利增加→渠道关系恶化→收入虚高利润实降）
- 毛利率被折扣和返利持续侵蚀 → 价格体系崩塌（传导机制：竞争加剧或需求不足→频繁打折→消费者形成折扣预期→正价销售困难→品牌溢价消失）
- 库存周转恶化 → 现金流与减值风险（传导机制：存货积压→占用营运资金→被迫清仓减值→利润和现金流双重恶化）
- 新品成功率持续下降 → 创新瓶颈（传导机制：团队上新能力不足或市场饱和→新品无法替代老品→爆品依赖加剧→增长天花板显现）

## 8. 财务分析重点

### 8.1 利润表重点
毛利率、销售费用率、促销和返利影响、渠道费用结构、净利率、新品对利润的贡献。

### 8.2 资产负债表重点
现金、存货、应收账款、应付账款、预付款、渠道返利与费用计提、有息负债。

### 8.3 现金流量表重点
库存是否吞噬现金、渠道压货是否带来虚高经营表现、经营现金流是否与利润一致、投流扩张是否导致现金压力上升。

## 9. 市场空间测算

- **TAM**：目标品类消费总支出
- **SAM**：公司目标人群、目标价格带、目标渠道对应的可服务市场
- **SOM**：公司当前和中短期可实际获取的份额

测算公式：
- 人群法：市场空间 = 目标消费者人数 x 年购买频次 x 客单价
- 品类法：市场空间 = 品类总体消费额 x 目标价格带占比 x 可触达渠道占比
- 渠道法：市场空间 = 可覆盖终端数 x 单终端年动销额

注意：品类大不代表新品牌能轻易切入；价格带、渠道和消费心智决定真实可得市场；高复购和低复购赛道不能同口径比较；爆品型市场空间不等于品牌长期空间。

## 10. 快速分析卡

- **一句话本质**：围绕消费者需求和品牌认知，通过产品力、渠道力和复购实现长期收入与利润积累
- **核心收入公式**：收入 = 购买用户数 x 购买频次 x 客单价（或 渠道点位数 x 单点位动销 x 出厂价）
- **核心成本公式**：成本 = 商品成本 + 渠道费用 + 流量投放 + 仓配售后 + 管理费用
- **核心判断三要素**：1)产品是否能复购 2)品牌是否在形成心智 3)渠道和供应链是否高效
- **最重要指标**（3个）：复购率、毛利率、投流ROI
- **最大风险**（3个）：爆品不可持续、过度依赖投流、渠道压货
- **一句话结论模板**：该品牌在[品类/渠道]已验证[复购/心智/动销]，但需关注[爆品依赖/渠道库存/白牌替代]风险，长期看能否从单品扩展为可持续品牌
