# 出海行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
在不同国家和地区找到可复制的需求与供给匹配方式，通过产品适配、渠道获取、本地履约与合规经营，把本土能力转化为全球化收入和利润。核心不是"把国内产品卖到国外"，而是"跨区域可复制的商业闭环"。

### 1.2 与普通行业的核心差异

| 差异维度 | 出海行业 | 纯国内业务 |
|---------|---------|----------|
| 市场边界 | 多国市场，文化/监管差异大 | 单一市场，规则统一 |
| 增长逻辑 | 单市场验证→多市场复制 | 单市场渗透和深耕 |
| 风险维度 | 汇率、地缘、合规、物流跨国 | 主要为国内经营风险 |
| 组织要求 | 全球化组织、本地化团队 | 本土组织即可 |
| 单位经济 | 需按国家分别验证 | 统一单位经济 |

### 1.3 分析总框架
本土能力验证 → 目标市场需求验证 → 本地化适配 → 渠道获客与履约 → 单国单位经济跑通 → 多国复制扩张

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 工具出海红利期 | 中国开发者在海外靠工具类App获大量用户，但变现能力有限 |
| 2020 | 疫情加速线上化+TikTok全球化 | TikTok海外用户激增，中国互联网产品出海进入品牌化阶段 |
| 2021 | 游戏出海成必选项 | 国内版号收紧+防沉迷，游戏公司出海从选项变成生存策略 |
| 2022 | 电商出海爆发 | SHEIN/TEMU验证中国供应链+全球电商模式，跨境物流基建加速 |
| 2023 | 地缘政治风险上升 | 印度封禁中国App、美国数据安全审查趋严，合规成本显著增加 |
| 2024-25 | 出海本地化深耕 | 从"产品出海"转向"运营本地化"，海外建仓/本地团队/合规成关键 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
跨境电商/品牌出海：识别海外需求 → 产品定义与供应链组织 → 渠道投放与获客 → 跨境物流与履约 → 复购与品牌沉淀
应用/游戏出海：产品研发 → 海外买量 → 用户注册与活跃 → 广告/订阅/内购变现 → 多区域扩张
SaaS出海：定位海外需求 → 产品国际化 → 海外获客销售 → 客户上线续费 → 扩模块扩区域

### 2.2 核心飞轮
更适配的产品与本地化 → 更高转化和用户口碑 → 更强收入和现金流 → 投入更多国家和品牌 → 更强规模与供应链优势
核心驱动：产品竞争力、本地化能力、渠道效率、履约能力和全球组织能力的复合飞轮。

### 2.3 商业模式分类

| 模式 | 收费对象 | 收费方式 | 公式 |
|------|---------|---------|------|
| 商品销售 | 海外消费者/渠道 | 按件或批量 | 收入 = 销量 × ASP |
| 订阅收费 | 海外个人/企业 | 按月/年/Seat | 收入 = 付费用户数 × ARPU |
| 广告/内购 | 用户/广告主 | 广告展示、道具购买 | 收入 = 活跃用户数 × ARPU |
| 平台佣金 | 商家/服务方 | 按交易额抽成 | 收入 = GMV × 抽成率 |

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 商品销售 + 订阅 + 广告 + 内购 + 佣金 + 服务收入

商品出海：收入 = 流量 × 转化率 × 客单价
应用/游戏：收入 = 活跃用户数 × 付费率 × ARPPU + 广告收入
SaaS出海：ARR = 客户数 × ARPA
工业品出海：收入 = 客户数 × 平均订单额 × 复购频次

### 3.2 成本模型
固定成本：核心研发、品牌建设、海外组织搭建、管理与合规体系、本地仓与基础设施
变动成本：商品采购、物流费用、广告投放、支付手续费、售后退货、渠道返佣

### 3.3 单位经济
跨境电商：单订单毛利 = 销售价 - 采购成本 - 国际物流 - 平台佣金 - 支付手续费 - 售后退货
应用/游戏：单用户LTV = 生命周期总收入 - 分摊服务成本；CAC回收周期 = 获客成本 / 月贡献毛利
SaaS：单客户年毛利 = 年订阅收入 - 云成本 - 客户支持成本

### 3.4 利润率特征
品牌出海/跨境电商毛利率40-60% [适用：品牌型出海] [局限：铺货型/白牌通常20-35%]，净利率5-15% [适用：成熟品牌] [局限：新进入市场通常为负]；SaaS出海毛利率60-80% [适用：纯SaaS产品] [局限：含大量实施服务的SaaS通常40-60%]，净利率10-25% [适用：已过扩张期的SaaS] [局限：扩张期通常为负]；应用/游戏毛利率60-80% [适用：自主研发应用/游戏] [局限：代理发行通常30-50%]，净利率15-30% [适用：爆款应用/游戏] [局限：非爆款通常5-10%甚至亏损]。高投放增长若缺乏留存和复购，价值质量较低。

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 跨境电商 | 平台或独立站卖货到海外 | 海外消费者 | 商品销售 | GMV、转化率、复购 |
| 品牌出海 | 自有品牌海外销售 | 海外消费者/渠道 | 销售+复购 | 收入、毛利率、品牌复购 |
| 应用出海 | 工具/社交/效率应用 | 海外用户 | 订阅/广告/IAP | DAU、订阅率、LTV |
| 游戏出海 | 面向海外发行游戏 | 玩家 | IAP+广告 | 留存、ARPU、ROI |
| SaaS出海 | 面向海外企业软件服务 | 海外企业 | 订阅 | ARR、NDR、CAC |
| 工业品出海 | 工业设备销往海外 | 海外企业/渠道 | 销售+售后 | 订单额、渠道数、复购 |
| 平台型出海 | 连接海外供需的平台 | 双边用户 | 佣金/服务费 | GMV、抽成率、活跃度 |

## 5. 核心指标体系

- **规模指标**：海外收入、海外GMV/ARR、海外用户数、订单量、国家数/区域数、渠道数
- **增长指标**：海外收入增速、海外用户增速、国家扩张速度、新渠道增长、老客复购增长
- **转化指标**：广告点击转化率、落地页转化率、下单转化率、订阅转化率、试用到付费转化率
- **留存/复购指标**：次月留存、90天留存、复购率、订阅续费率、NDR（SaaS）、渠道续约率
- **变现指标**：AOV、ARPU、ARPPU、ASP、广告eCPM、品牌溢价率
- **供给指标**：本地化完成度、海外仓覆盖度、本地服务团队数
- **效率指标**：CAC、LTV/CAC、投放ROI/ROAS、回本周期、库存周转、人均海外收入
- **财务指标**：毛利率、销售费用率、经营现金流、汇兑损益、区域利润率、退货率
- **风控指标**：合规事件数、支付拒付率、账号封禁率、税务风险、渠道依赖度、单一国家收入占比

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
跨境电商和应用出海竞争极其激烈；品牌出海可形成长期壁垒；SaaS出海受产品力和本地化程度影响大；工业品出海慢热但客户黏性强；平台型出海赢家通吃。

### 6.2 常见壁垒类型
供应链和成本壁垒、品牌壁垒、本地化运营壁垒、渠道壁垒、合规和认证壁垒、数据和投放优化壁垒、全球化组织能力壁垒。

### 6.3 替代风险
本土竞争者替代、国际巨头降维打击、平台规则变化、流量成本上升、贸易壁垒和地缘政治变化。

## 7. 行业风险

### 7.1 通用风险项
汇率波动、地缘政治风险、平台封店/封号、税务和海关风险、投放成本上升、本地化失败、物流中断、支付风险、知识产权风险、单一市场依赖过高。

### 7.2 行业特有风险
地缘政治突变导致市场关闭、平台政策调整一夜封号、跨境税务合规漏洞被追缴、本地化表面化导致水土不服。

### 7.3 风险信号
海外收入增长但复购恶化 → 增长不可持续（传导机制：投放驱动首购→本地化不足致复购差→单位经济不成立→规模越大亏损越大）；投放增长但LTV/CAC持续下滑 → 获客效率枯竭（传导机制：竞争加剧→竞价推高CAC→但留存和复购未提升→LTV覆盖不了CAC→增长越快亏损越多）；单一国家收入占比过高 → 集中度风险（传导机制：单一国家政策/汇率/地缘突变→收入和利润大幅波动→无法通过多国分散对冲→业务韧性极差）；平台流量占比过大 → 渠道依赖风险（传导机制：平台政策/算法调整→流量和销量骤降→无自主流量蓄水池→被动受制于人）；退货率和客诉率持续上升 → 产品/履约问题（传导机制：产品不适配本地需求或物流质量差→退货增加→履约成本攀升→口碑恶化→转化率下降→需更多投放弥补）；合规与税务问题频发 → 合规风险积累（传导机制：合规漏洞→罚款/关店/追缴→直接经济损失+品牌信誉受损→业务可能被迫退出该市场）。

## 8. 财务分析重点

### 8.1 利润表重点
海外收入结构、区域收入拆分、投放成本占比、物流和履约成本占比、汇兑损益、区域利润率差异。

### 8.2 资产负债表重点
存货、海外仓资产、应收账款、现金与受限资金、递延收入（订阅型）、税务准备。

### 8.3 现金流量表重点
海外扩张是否显著消耗现金；投放与库存是否吞噬现金流；不同国家回款周期差异。

## 9. 市场空间测算

- **TAM**：全球范围内目标用户/客户对该类产品/服务的总支出空间
- **SAM**：公司当前可进入区域、语言、渠道与合规约束下可服务市场
- **SOM**：公司中短期可实际获取的海外收入和市场份额

测算公式：目标国家用户法 = 目标国家用户数 × 年均消费；渠道渗透法 = 目标渠道流量 × 转化率 × 客单价；区域复制法 = 单一成熟市场收入 × 可复制市场数 × 调整系数

注意：海外市场不能简单线性相加；不同国家文化、监管和支付差异很大；单一区域成功不代表可全球扩张。

## 10. 快速分析卡

- **一句话本质**：把本土产品、供应链、品牌或技术能力复制到海外市场，通过本地化和全球化组织能力获取新增收入与利润
- **核心收入公式**：收入 = 海外用户数 × ARPU 或 订单量 × 客单价 或 ARR = 海外客户数 × ARPA
- **核心成本公式**：成本 = 采购/研发 + 国际物流 + 投放成本 + 渠道佣金 + 支付税费 + 本地团队成本
- **核心判断三要素**：1)单位经济是否成立 2)单市场模型是否可复制 3)本地化与合规能力是否支撑长期扩张
- **最重要指标**：海外收入增速、LTV/CAC、复购率/留存率、区域利润率、单一国家收入占比
- **最大风险**：地缘与政策风险、汇率和税务风险、单一市场/平台依赖、投放成本失控、本地化失败
- **一句话结论模板**：长期价值取决于多市场复制能力、品牌沉淀和全球化组织能力，而非短期海外收入规模
