# 游戏行业商业建模知识库

---

## 1. 行业总论

### 商业本质

游戏行业的本质是 **内容产品 + 流量获取 + 生命周期运营** 的综合体。它不是单纯的"互联网流量生意"，而是三个环节的耦合：

- **内容创作**：游戏首先是内容产品，创意质量决定天花板
- **精准投放**：买量获客是核心能力，投放效率决定增长速度
- **长线运营**：服务型游戏（GaaS）模式下，运营质量决定生命周期价值

一个完整的游戏商业闭环：**创意生产 → 产品上线 → 买量获客 → 留存运营 → 变现回收 → 再投入**

### 与普通行业的核心差异

| 差异维度 | 游戏行业 | 普通消费品/互联网行业 |
|----------|----------|----------------------|
| 产品属性 | 内容+服务的混合体，非标准化 | 标准化产品或标准化服务 |
| 供给逻辑 | 创意驱动，爆款概率不可控；"制造"不等于"卖出" | 产能与需求可相对预测 |
| 收入确认 | 递延收入占比高，道具/通行证需分期确认 | 收入确认相对直接 |
| 生命周期 | 单品有明确衰退曲线，需持续更新延长 | 产品生命周期可管理但波动较小 |
| 获客方式 | 买量为主，CAC持续上升；社交裂变为辅 | 品牌驱动、渠道驱动、口碑驱动更多元 |
| 渠道分成 | 苹果/谷歌抽成30%，硬性约束 | 渠道费用比例更灵活 |
| 政策约束 | 版号制度构成供给侧硬约束 | 行业监管通常不直接限制产品供给数量 |
| 人才依赖 | 核心创意人才流失=项目风险 | 个人依赖度通常低于游戏 |

### 分析总框架

分析一家游戏公司，核心回答四个问题：

1. **产品力**：能否持续产出高留存、高变现的产品？（看研发能力、品类积累、人才储备）
2. **获客力**：买量效率是否优于同行？是否有非买量增长来源？（看CAC、ROAS、自然量占比）
3. **运营力**：已上线产品能否长线运营、延缓衰退？（看D30留存、LTV曲线、更新频率）
4. **组合力**：是否构建了足够的产品矩阵来对冲单品风险？（看收入集中度、管线深度）

## 2. 商业模式分类

### 模式分类

| 模式 | 核心逻辑 | 收入来源 | 典型品类 | 代表公司 |
|------|----------|----------|----------|----------|
| **IAP（内购付费）** | 免费游玩+道具/内容付费 | 虚拟道具、皮肤、赛季通行证、抽卡、订阅 | MMORPG、MOBA、二次元、SLG | 腾讯、网易、米哈游 |
| **IAA（广告变现）** | 免费游玩+广告展示收入 | 激励视频广告、插屏广告、Banner广告 | 休闲游戏、超休闲游戏 | Voodoo、SayGames |
| **混合变现（IAP+IAA）** | 内购+广告双轮驱动 | 道具付费 + 广告收入 | 中度游戏、模拟经营、部分休闲 | Playrix、King |
| **买断制（Premium）** | 一次性购买 | 游戏本体销售、DLC | 主机/PC单机大作 | 任天堂、索尼第一方 |
| **订阅制（Subscription）** | 月费/年费畅玩 | 会员订阅费 | 游戏平台/订阅服务 | Xbox Game Pass、苹果Arcade |

**趋势判断**：纯IAA模式利润率受广告市场波动影响大，纯IAP模式获客成本持续上升，混合变现是中期趋势。买断制在移动端式微但在主机/PC端仍有生命力。

### 收入来源详解

| 收入类型 | 变现机制 | 用户心理 | 留存影响 | 典型ARPU |
|----------|----------|----------|----------|----------|
| 道具购买 | 功能性道具提升游戏体验 | 效率驱动、竞争驱动 | 正向（提升参与度） | 中 |
| 皮肤/外观 | 纯视觉差异化 | 社交展示、个性化 | 中性或正向 | 中低（高频） |
| 赛季通行证 | 预付+任务解锁 | 沉没成本+目标感 | 强正向（提升留存和活跃） | 中 |
| 抽卡/开箱 | 随机获取稀有角色/道具 | 赌博心理、收集欲 | 复杂（可能短期高收入但长期损害信任） | 高（付费用户） |
| 激励视频广告 | 观看广告换取游戏内奖励 | 用时间换资源 | 正向（非付费用户的参与通道） | 低（但覆盖广） |

## 3. 收入与成本模型

### 收入公式

**IAP游戏收入公式**：
```
收入 = DAU × 付费率 × ARPPU
     = DAU × ARPU
```

**IAA游戏收入公式**：
```
收入 = DAU × 人均广告展示次数 × eCPM / 1000
```

**综合收入公式（生命周期视角）**：
```
收入 = 新增玩家数 × 玩家生命周期价值(LTV)
```

**收入驱动因素拆解**：

| 变量 | 影响因素 | 可干预性 |
|------|----------|----------|
| DAU | 存量用户规模 × 留存率 + 新增用户 | 运营+投放 |
| 付费率 | 游戏设计、付费点设置、用户质量 | 产品设计+运营 |
| ARPPU | 付费深度设计、大R生态、内容更新节奏 | 产品设计 |
| 人均广告展示次数 | 游戏时长、广告位设计、激励频率 | 产品设计 |
| eCPM | 广告形式、用户画像、地区、广告市场景气度 | 有限可控 |
| LTV | 留存曲线形状 + 变现深度 | 留存运营+产品设计 |
| 新增玩家数 | 买量规模 × 买量效率 + 自然量 | 投放+产品口碑 |

### 成本结构

| 成本项 | 典型占比 | 固定/变动 | 说明 |
|--------|----------|-----------|------|
| 研发成本 | 20-35% | 固定为主 | 人工(60%+)、美术外包、引擎授权、服务器 |
| 买量成本(CAC) | 20-40% | 变动 | CPI/CPA按量计费，竞争加剧则持续上升 |
| 渠道分成 | 25-35% | 变动 | 苹果/谷歌30%，国内安卓50%+渠道可谈 |
| 服务器/带宽 | 3-8% | 半变动 | 随用户规模增长但边际递减 |
| 运营团队 | 5-10% | 固定 | 客服、社区、活动策划、本地化 |
| IP授权/分成 | 0-15% | 变动 | 如使用外部IP，需支付分成 |

**注意**：渠道分成通常由平台直接扣减（如苹果App Store），报表收入已经是扣除渠道分成后的净额。

### 单位经济模型

**核心公式**：
```
LTV / CAC = 回报倍数
回本周期 = CAC / (月ARPU × 付费率 + 月广告ARPU)
```

| 健康度 | LTV/CAC | 回本周期 | 含义 |
|--------|---------|----------|------|
| 优秀 | > 5 | < 60天 | 强产品力+高效获客 |
| 健康 | 3-5 | 60-180天 | 可持续增长 |
| 警惕 | 2-3 | 180-365天 | 买量效率恶化，需优化 |
| 危险 | < 2 | > 365天 | 单位经济不成立，规模越大亏越多 |

**关键认知**：老游戏的长线运营价值常被低估。一款D30留存20%+、运营3年以上的游戏，其LTV曲线尾部面积巨大，新增获客的边际LTV远高于新游戏。老游戏的买量ROI通常优于新游戏。

## 4. 核心指标体系

### 结果指标（北极星指标）

| 指标 | 定义 | 行业基准 | 说明 |
|------|------|----------|------|
| LTV | 玩家生命周期总价值 | IAP游戏$5-50+；IAA游戏$0.5-3 | 最核心指标，所有经营决策的终极参考 |
| 总收入 | 日/月/年维度收入 | — | 财务结果的直接映射 |
| 净利润率 | (收入-成本)/收入 | 15-30%（成熟公司） | 盈利质量 |

### 过程指标（可干预的经营指标）

| 指标 | 定义 | 行业基准 | 驱动关系 |
|------|------|----------|----------|
| D1留存 | 次日留存率 | 35-50%（中度以上） | LTV的早期预测器 |
| D7留存 | 7日留存率 | 15-25% | 决定是否值得继续买量 |
| D30留存 | 30日留存率 | 8-15% | 长线运营能力的核心标志 |
| DAU/MAU | 日活/月活比 | 0.3-0.5 | 用户黏性的直接度量 |
| 付费率 | 付费用户/总用户 | 2-8%（IAP游戏） | 变现深度指标 |
| ARPPU | 每付费用户平均收入 | 差异极大，$10-200+/月 | 付费设计效率 |
| ARPU | 每用户平均收入 | $0.5-5/天（IAP） | 变现能力综合指标 |
| 人均广告展示次数 | 每用户每日广告展示数 | 3-10次（IAA游戏） | 广告变现效率 |
| eCPM | 每千次广告展示收入 | $5-30（激励视频） | 广告市场+用户质量 |
| CAC | 获客成本 | $1-20（CPI），差异极大 | 买量效率 |
| ROAS | 广告支出回报率 | D7 ROAS > 20%, D30 > 60% | 买量决策核心依据 |
| 游戏生命周期 | DAU降至峰值10%的时间 | 6个月-5年+ | 资源配置参考 |

### 护栏指标（防副作用）

| 指标 | 风险场景 | 健康阈值 |
|------|----------|----------|
| 评分/评分趋势 | 强变现导致口碑崩塌 | App Store评分 > 4.0且不快速下降 |
| 退款率 | 诱导消费/未成年人付费 | < 2% |
| 用户投诉率 | 运营事故/平衡性问题 | 无突发跳升 |
| 单款游戏收入占比 | 爆款依赖风险 | < 50%（公司层面） |
| 大R贡献占比 | 付费结构过于集中 | Top 10%付费用户贡献 < 60% |
| 版号获取节奏 | 国内市场准入 | 管线中始终有待审批产品 |

## 5. 经营杠杆与竞争格局

### 竞争优势来源

| 优势来源 | 在游戏行业的表现 | 强弱 |
|----------|------------------|------|
| **规模效应（供给侧）** | 研发基础设施复用（引擎、工具链、美术中台）；用户数据驱动投放优化 | 中等，研发规模效应有限 |
| **规模效应（需求侧）** | 社交关系链留存（微信/QQ游戏）；玩家社区网络效应 | 仅腾讯等平台型公司强 |
| **品牌心智** | IP品牌（原神、王者）降低获客成本；公司品牌吸引人才 | 中强，但IP有生命周期 |
| **技术壁垒** | 引擎技术（米哈游）；大规模同步技术；AI内容生成 | 中等，技术可被追赶 |
| **数据飞轮** | 积累的用户行为数据优化投放、优化产品 | 中强，先发者优势明显 |
| **转换成本** | 社交关系、资产积累、时间投入 | 强（重度游戏），弱（休闲游戏） |
| **牌照/合规** | 版号构成国内市场准入壁垒 | 强约束（国内市场） |

### 规模效应类型与边界

游戏行业呈现 **有限的供给侧规模效应 + 条件性的需求侧规模效应**：

- **供给侧**：引擎、中台、数据分析基础设施可复用，但核心创意不可规模化——增加人手不等于增加爆款概率
- **需求侧**：社交型游戏（MOBA、MMO）存在网络效应，但单机/弱社交游戏不具备
- **边界**：研发团队超过一定规模后管理效率下降；多项目并行管理难度非线性增长

### 龙头对比

| 维度 | 腾讯游戏 | 网易游戏 | 米哈游 | 心动公司 |
|------|----------|----------|--------|----------|
| **核心模式** | 平台+社交裂变+长线运营 | 精品自研+品类深耕 | 技术驱动+全球化+内容壁垒 | 社区(TapTap)+独立游戏 |
| **收入规模** | 1500亿+（2023年） | 300亿+（2023年） | 300亿+（估算） | 30亿级 |
| **代表作** | 王者荣耀、和平精英 | 梦幻西游、永劫无间 | 原神、崩坏 | 香肠派对 |
| **核心优势** | 微信/QQ流量入口；社交关系链留存；投资布局全球 | 品类深耕能力；长线运营（梦幻20年）；稳定研发团队 | 技术壁垒（渲染/开放世界）；内容品质；全球化发行 | TapTap零分成渠道；独立游戏生态 |
| **核心风险** | 自研创新力争议；监管风险 | 爆款依赖；海外突破不足 | 产品管线集中；人才密度维持 | 规模有限；盈利波动 |
| **获客方式** | 社交裂变为主，买量为辅 | 买量为主 | 内容口碑+买量 | TapTap社区分发 |
| **海外占比** | ~25% | ~15% | >50% | 低 |
| **盈利特征** | 高利润率（渠道+平台优势） | 中高利润率 | 高利润率 | 波动，社区投入期 |

## 6. 财务分析映射

### 行业特有财务分析

| 分析维度 | 关键关注点 | 信号含义 |
|----------|------------|----------|
| 递延收入 | 赛季通行证、预付道具、虚拟货币需分期确认 | 递延收入余额=未来收入储备，余额上升是正面信号 |
| 研发资本化 | 自研游戏开发支出是否资本化、资本化比例 | 过高资本化可能虚增资产；关注会计政策一致性 |
| 渠道分成 | 收入确认是否为扣除渠道后的净额 | 通常为净额法，但需确认口径 |
| 商誉/无形资产 | 收购工作室形成的商誉 | 如收购后产品不及预期，减值风险大 |
| 预付款项 | 预付买量费用 | 反映投放力度和节奏 |
| 合同负债 | 玩家预充值未消费部分 | 类似递延收入，余额变化反映消耗节奏 |

### 会计科目与风险

| 科目 | 游戏行业特有风险 | 检查要点 |
|------|------------------|----------|
| 递延收入 | 确认节奏影响利润波动；可能被用于利润调节 | 递延收入余额与DAU/付费趋势是否匹配 |
| 研发支出 | 资本化 vs 费用化的选择影响当期利润 | 资本化比例与同行对比；已资本化项目是否如期上线 |
| 无形资产-游戏IP | 游戏生命周期结束需减值 | 长线游戏是否过度乐观估计寿命 |
| 商誉 | 收购工作室如产品失败需减值 | 被收购工作室核心产品表现 |
| 应收账款 | 渠道商回款周期 | 苹果/谷歌回款通常稳定；国内安卓渠道需关注 |
| 存货 | 实体版游戏、周边商品 | 金额通常不大，关注跌价准备 |

## 7. 风险信号清单

### 红旗信号

| 红旗信号 | 具体表现 | 潜在含义 |
|----------|----------|----------|
| **爆款依赖** | 单款游戏贡献 >50% 收入 | 后续管线如不继，收入断崖风险 |
| **买量ROI恶化** | CAC持续上升，ROAS持续下降；买量收入占比上升 | 行业竞争加剧或产品力不足；单位经济恶化 |
| **留存快速下滑** | D7/D30留存同比显著下降 | 产品老化或运营失误；LTV预期需下调 |
| **版号空窗** | 长期未获新版号 | 国内新产品无法上线，增长受限 |
| **核心人才离职** | 制作人/主策/技术负责人离职 | 在研项目风险；已有产品运营质量可能受影响 |
| **递延收入异常** | 递延收入余额大幅下降但DAU未降 | 可能提前确认收入调节利润 |
| **研发资本化率畸高** | 资本化率远超同行 | 可能虚增当期利润 |
| **评分暴跌** | App Store评分短期下降 >0.5 | 强变现/运营事故/平衡性问题；将影响自然量和留存 |
| **大R流失** | 头部付费用户活跃度/付费下降 | 收入结构脆弱；可能是竞品抢夺 |
| **海外合规风险** | 数据隐私/未成年人保护/抽卡法规 | 下架或罚款风险 |

### 常见误区

| 误区 | 正确认知 |
|------|----------|
| "DAU高=好生意" | DAU只是基数，关键是LTV。高DAU+低留存+低付费=差生意 |
| "爆款=可持续" | 单次爆款不等于持续产出能力。应看管线深度和组织能力 |
| "游戏公司是科技公司" | 游戏本质是内容创意+运营，技术是手段不是壁垒（除少数公司外） |
| "大公司一定赢" | 创意行业有反规模效应；大公司官僚化可能降低创新力 |
| "买量=增长" | 买量是加速器不是发动机；产品力不足的买量是烧钱 |
| "版号放开=利好" | 版号放开后竞争加剧，买量成本上升，小公司反而更难 |
| "老游戏=没价值" | 长线运营的老游戏LTV极高、买量ROI好，是最被低估的资产 |
| "收入增长=健康" | 如果收入增长靠买量驱动而非自然增长，利润可能反降 |
| "海外=蓝海" | 海外竞争同样激烈，本地化、合规、文化差异是硬门槛 |

## 8. 投资尽调问题清单

### 产品与管线

1. 目前在营产品有几款？各自处于生命周期什么阶段（增长/稳定/衰退）？
2. 单款游戏收入占比最高多少？是否有明确的新品替代计划？
3. 在研产品管线有几款？分别处于什么阶段？预计上线时间？
4. 历史产品的成功率（上线/研发中/取消）是多少？
5. 核心产品的D1/D7/D30留存、LTV、ROAS数据是什么趋势？

### 获客与增长

6. 自然量占比是多少？趋势如何？
7. CAC的近年变化趋势？与行业平均对比如何？
8. ROAS回收曲线（D7/D30/D60/D180）是什么形状？
9. 是否有非买量增长来源（社交裂变、品牌IP、社区）？
10. 海外市场的获客效率与国内对比如何？

### 运营能力

11. 旗舰产品运营多少年了？DAU和收入趋势如何？
12. 更新频率和内容消耗速度如何？玩家对更新的反馈？
13. 付费率、ARPPU的趋势？是否有过度变现的信号？
14. 大R用户（Top 1%/5%）的收入贡献占比？

### 研发能力

15. 核心制作人和主策划在职多久？稳定性如何？
16. 研发团队规模和结构？人均产出（收入/研发人数）？
17. 是否有自研引擎或技术中台？复用程度如何？
18. 美术外包占比？核心美术是否内部化？

### 财务质量

19. 递延收入余额和变化趋势？是否与DAU/付费趋势匹配？
20. 研发支出资本化比例？与同行对比如何？
21. 商誉金额？被收购资产的实际表现？
22. 渠道收入确认方式（总额法/净额法）？
23. 经营性现金流与净利润的匹配度？

### 合规与风险

24. 现有产品的版号情况？在申版号有几款？
25. 是否有海外合规风险（GDPR/COPPA/抽卡法规）？
26. 未成年人防沉迷的合规措施和影响？
27. 是否有知识产权纠纷？

### 竞争与战略

28. 所在品类的竞争格局？份额变化趋势？
29. 与腾讯/网易等平台方的合作关系？是否有过度依赖？
30. 海外战略的执行情况？本地化投入和效果？
