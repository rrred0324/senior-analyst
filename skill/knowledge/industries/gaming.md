# 游戏行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质

游戏行业的本质是**内容产品 + 流量获取 + 生命周期运营**——用创意和产品能力制造"成瘾性体验"，通过精细化运营延长生命周期，在有限窗口期内最大化单用户价值。

核心变量不是"做了多少游戏"，而是"单款产品的LTV能否覆盖获取和研发成本，且概率可预期"。

### 1.2 与普通行业的核心差异

| 维度 | 普通行业 | 游戏行业 |
|------|----------|----------|
| 产品形态 | 标准化/可复制 | 创意驱动/高度不确定 |
| 收入模式 | 持续性收入 | 生命周期内一次性变现 |
| 核心约束 | 产能/渠道 | 爆款概率+版号+买量ROI |
| 规模效应 | 规模越大成本越低 | 研发成本刚性，规模主要靠产品矩阵 |
| 生命周期 | 产品长期可用 | 单游戏2-5年，极少数超10年 |
| 监管 | 相对宽松 | 版号审批+内容审查+未成年人限制 |

### 1.3 分析总框架

```
产品能力（研发/创意）
→ 获客能力（买量/自然流量）
→ 运营能力（留存/付费/活动）
→ 生命周期管理（迭代/焕新/停服）
→ 收入与利润释放
→ 再投资（新游戏/新赛道）
```

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 版号暂停审批（3月-12月） | 行业收入增速断崖式下降，中小厂商出清加速 |
| 2019 | 版号恢复但数量收紧 | 年度版号数量从高峰期9000+降至约1500，行业进入存量竞争 |
| 2021 | 防沉迷新规+未成年人限玩 | 未成年人游戏时长和付费大幅受限，DAU短期承压 |
| 2022 | 版号再次阶段性收紧 | 行业收入首次出现同比下滑，出海成为必选项 |
| 2023-24 | 游戏出海加速+小程序游戏爆发 | 出海收入占比持续提升；小游戏重构获客和变现模式 |
| 2025 | AI生成内容进入游戏制作流程 | 美术和文案生产效率提升，但制作门槛降低加剧竞争 |

## 2. 价值链与商业模式

### 2.1 价值创造链条

```
创意策划 + 研发
→ 版号审批
→ 上线发行（自研自发/代理发行）
→ 买量获客 + 自然流量
→ 用户留存与付费转化
→ 活动运营与内容更新
→ 生命周期衰减或焕新
→ 收入确认（IAP/IAA）
→ 利润释放
```

### 2.2 核心飞轮

```
更好的产品体验
→ 更高的自然留存
→ 更低的买量成本（口碑传播）
→ 更多的收入
→ 更多的研发投入
→ 更好的产品体验
```

### 2.3 商业模式分类

**模式一：内购付费（IAP）**
- 名称：In-App Purchase
- 收费对象：付费玩家
- 收费方式：虚拟道具/通行证/抽卡
- 公式：收入 = DAU × 付费率 × ARPPU

**模式二：广告变现（IAA）**
- 名称：In-App Advertising
- 收费对象：广告主
- 收费方式：激励视频/插屏/Banner
- 公式：收入 = DAU × 广告展示次数 × eCPM

**模式三：混合变现**
- 名称：IAP + IAA
- 收费对象：付费玩家 + 广告主
- 公式：收入 = DAU × 付费率 × ARPPU + DAU × 广告展示 × eCPM

## 3. 收入与成本模型

### 3.1 收入模型

**流水口径**（行业通用衡量标准，反映用户实际消费规模）：
```
总流水 = Σ(各游戏 DAU × 付费率 × ARPPU) + 广告流水
```

**确认收入口径**（财务报表口径，反映可确认收入）：
```
总收入 = 总流水 × (1 - 渠道分成比例) - 递延调整 ± 预付变动
```
- 渠道分成：苹果 30%、安卓 CP 50%（国内安卓渠道）
- 递延调整：玩家预充值/通行证等需按服务期分摊确认

驱动因子：
- DAU：日活用户，受留存和新增影响
- 付费率：通常1-5% [适用：中重度IAP游戏；局限：休闲IAA游戏不适用此指标]，重度游戏可达10%+
- ARPPU：单付费用户日均消费，重度游戏50-200元，休闲游戏5-20元
- LTV：单用户生命周期价值，通常 = 首日ARPU × 30日留存系数 [适用：上线3个月以上、留存稳定的游戏；局限：新游首月波动大，此估算偏差大]

### 3.2 成本模型

**固定成本**：研发团队薪酬、服务器/带宽、办公成本
**变动成本**：买量成本（UA）、渠道分成（30%苹果/50%安卓CP）、版号申请成本、运营活动成本

### 3.3 单位经济

```
单位经济 = LTV - CAC - 渠道分成 - 服务器成本
```

- LTV/CAC > 3 为健康 [适用：IAP中重度游戏，上线6个月以上] [局限：IAA休闲游戏因ARPU低，LTV/CAC通常<2但可通过广告频次补偿]
- CAC回收周期 < 60天 为优秀 [适用：中重度IAP游戏] [局限：SLG等长线游戏回收周期可达90-180天]
- 渠道分成占收入 30-50% 是行业硬成本

### 3.4 利润率特征

- 研发+自发：毛利率 60-80%，但研发成本前置
- 代理发行：毛利率 20-40%
- 纯IAA休闲游戏：毛利率 40-60%，但ARPU低
- 行业净利率差异极大：爆款可达30%+，中小厂商经常亏损

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|--------|------|---------|---------|---------|
| MMORPG | 大型多人在线角色扮演 | 重度玩家 | IAP为主 | ARPPU、留存、DAU |
| SLG | 策略类游戏 | 中重度玩家 | IAP | LTV、付费率、买量ROI |
| 休闲/超休闲 | 轻度消遣游戏 | 泛用户 | IAA为主 | eCPM、留存、次留 |

| 小程序/H5游戏 | 即点即玩 | 微信/抖音用户 | IAA+IAP | 获客成本、裂变系数 |
| 电竞/竞技 | 对抗型游戏 | 竞技玩家 | IAP+赛事+广告 | DAU、赛事生态 |

## 5. 核心指标体系

**规模指标**：DAU/MAU、流水（GMV）、收入、同时在线人数
**增长指标**：新增用户、买量CPA、自然流量占比
**留存指标**：次留、7留、30留、长留（D90/D180）
**付费指标**：付费率、ARPPU、ARPU、LTV
**运营指标**：活动参与率、返场率、流失率、召回率
**效率指标**：LTV/CAC、CAC回收周期、买量ROI（ROAS）
**财务指标**：毛利率、研发费用率、销售费用率（买量占比）
**风控指标**：退款率、投诉率、版号合规、未成年人时长占比

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
- 头部集中：TOP10公司占行业收入50%+（腾讯、网易、米哈游等）
- 中小厂商靠细分赛道和创意突围
- 买量成本持续上升，中小厂商利润被压缩
- 出海成为新增量

### 6.2 常见壁垒类型
- **IP壁垒**：自有IP形成用户粘性和跨产品协同
- **技术壁垒**：引擎自研、美术管线、服务端架构
- **数据壁垒**：用户行为数据和模型积累
- **渠道壁垒**：自有流量（微信/抖音生态）
- **品牌壁垒**：玩家社区和口碑

### 6.3 替代风险
- 短视频/直播争夺用户时长
- AI生成内容降低游戏制作门槛，但同时也加剧竞争
- 跨端竞争（云游戏/小程序）

## 7. 行业风险

### 7.1 通用风险项
- 爆款不确定性：研发投入大但成功率低
- 买量ROI恶化：CPI持续上涨
- 用户时长被短视频挤压

### 7.2 行业特有风险
- **版号风险**：国内版号审批节奏不确定，是最大的政策变量
- **生命周期衰减**：单游戏收入不可逆下滑，需持续推新
- **未成年人监管**：防沉迷政策收紧影响部分品类
- **渠道依赖**：苹果/安卓渠道分成高且政策多变
- **人才流失**：核心策划/制作人出走

### 7.3 风险信号
- 买量ROI持续低于1 → 获客模型不成立（传导机制：CPI上涨→单用户获客成本超过首日收入→买量越多亏越多→现金流被吞噬）
- 次留<30%且7留<10% → 产品力不足 [适用：中重度IAP游戏；局限：超休闲游戏次留基准为40-50%，7留5-10%即可接受]
- 连续3个季度无新品上线 → 产品线断裂（传导机制：老游戏自然衰减→无新品接替→收入断崖→研发团队流失加速恶化）
- 销售费用率>50% → 买量驱动不可持续（传导机制：买量占比过高→单用户利润被压缩→一旦流量成本上涨或效果衰减即无法维持）
- 递延收入持续下降 → 老游戏衰退且无新爆款接替（传导机制：玩家预充值减少→未来可确认收入减少→收入确认加速下滑）

## 8. 财务分析重点

### 8.1 利润表重点
- 收入确认口径（总额法vs净额法）
- 递延收入变化（反映玩家预充值趋势）
- 研发费用率（通常15-30%）
- 销售费用率（买量占比，通常20-40%）
- 渠道分成比例

### 8.2 资产负债表重点
- 递延收入（核心指标，反映未来可确认收入）
- 预付账款（买量预付）
- 商誉（并购游戏公司产生）
- 无形资产（IP/游戏资产资本化）

### 8.3 现金流量表重点
- 经营现金流与利润匹配度
- 买量支出是否导致现金流紧张
- 研发投入现金流出节奏

## 9. 市场空间测算

- **用户规模法**：游戏用户数 × ARPU
- **时长法**：总娱乐时长 × 游戏占比 × 变现率
- **品类法**：细分品类用户数 × 品类ARPU × 渗透率

## 10. 快速分析卡

- **一句话本质**：游戏是"爆款概率+生命周期变现"生意，核心不是做了多少游戏，而是单产品LTV能否覆盖成本且概率可预期
- **核心收入公式**：流水 = DAU × 付费率 × ARPPU + DAU × 广告展示 × eCPM（流水口径）；收入 = 流水 × (1-渠道分成) - 递延调整（确认收入口径）
- **核心成本公式**：成本 = 研发成本 + 买量成本 + 渠道分成（30-50%）+ 服务器成本
- **核心判断三要素**：1）产品力（留存是否够硬） 2）获客效率（LTV/CAC是否>3） 3）产品线厚度（能否持续推新）
- **最重要指标**：1）次留/7留/30留 2）LTV/CAC 3）递延收入趋势
- **最大风险**：1）版号政策不确定 2）爆款失败率 3）买量ROI持续恶化
- **一句话结论模板**：游戏公司的核心不是流水规模，而是爆款概率和生命周期变现能力；长期胜负手不是谁买量最多，而是谁能以更高概率做出高留存产品并持续迭代
