# 工业自动化行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
用标准化或半标准化的自动化能力，帮助工业客户降低单位成本、提升良率、提高节拍、降低人工依赖，并增强生产确定性。核心不是"卖设备"，而是"可靠产品+工艺理解+客户信任"的长期服务关系。

### 1.2 与普通行业的核心差异

| 差异维度 | 工业自动化 | 普通B2B行业 |
|---------|----------|-----------|
| 销售周期 | 认证→导入→量产，6-24个月 [适用：汽车/锂电等大客户] [局限：标准品中小客户可缩短至2-6个月] | 通常1-6个月 |
| 客户粘性 | 切换成本极高 | 切换成本中等 |
| 收入结构 | 设备+软件+维保+备件+升级多元 | 以单次销售为主 |
| 壁垒类型 | 技术+认证+工艺know-how+案例 | 主要是价格和关系 |
| 周期性 | 强周期，跟随制造业CAPEX波动 | 周期性较弱 |

### 1.3 分析总框架
产品能力验证 → 客户认证与导入 → 场景理解深化 → 复购与扩线 → 从单品到方案/软件延伸

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 中美贸易摩擦推动国产替代 | 外资品牌供应不确定性增加，国产自动化设备验证加速 |
| 2020 | 疫情催生"无人工厂"需求 | 劳动力短缺+防疫要求，工业自动化投资意愿提升 |
| 2021 | 专精特新政策支持 | 中小工业自动化企业获政策扶持，细分领域国产化率提升 |
| 2022 | 新能源产线投资高峰 | 锂电/光伏产线设备需求爆发，自动化设备商订单激增 |
| 2023 | 产能过剩+资本开支回落 | 新能源扩产放缓，设备商订单回调，行业进入分化期 |
| 2024-25 | 人形机器人+AI工业视觉 | 人形机器人进入工厂试点，AI视觉检测替代人工质检 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
标准品设备型：研发控制/驱动/感知产品 → 建立渠道或直销 → 进入客户产线 → 批量复制 → 设备、备件和服务持续变现
解决方案型：理解客户工艺 → 方案设计与验证 → 设备交付集成 → 调试验收 → 售后维保与二次扩产
工业软件型：采集生产数据 → 构建监控/分析系统 → 提升决策效率 → 形成续费和增购

### 2.2 核心飞轮
更多客户项目 → 更多场景理解和工艺know-how → 产品和交付能力增强 → 更高成功率和ROI → 赢得更多客户项目
核心驱动：产品可靠性、工艺理解、客户案例、交付能力和售后服务持续增强。

### 2.3 商业模式分类

| 模式 | 收费对象 | 收费方式 | 公式 |
|------|---------|---------|------|
| 设备销售 | OEM/工厂/集成商 | 按台/套/项目 | 收入 = 出货量 × ASP |
| 软件授权与订阅 | 工业客户 | 一次性授权/模块/年费 | 收入 = 客户数 × ARPU |
| 系统集成 | 工厂客户 | 按项目合同额 | 收入 = 项目数量 × 平均合同额 |
| 售后维保与升级 | 存量客户 | 维保合同/备件/升级 | 收入 = 存量装机客户数 × 服务ARPU |

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 设备销售 + 软件收入 + 系统集成 + 维保收入 + 备件耗材 + 升级改造收入

标准品：收入 = 出货量 × ASP
软件：收入 = 客户数 × 客单价 × 续费率
项目制：收入 = 项目数 × 平均项目金额
存量服务型：收入 = 存量装机量 × 服务渗透率 × 服务ARPU

### 3.2 成本模型
固定成本：研发团队、产品平台开发、工厂固定资产、管理费用、测试认证体系
变动成本：元器件采购、生产制造、项目实施、渠道返利、售后维保、物流运输

### 3.3 单位经济
标准硬件：单台毛利 = ASP - BOM成本 - 制造成本 - 渠道返利
机器人/设备：单机毛利 = 设备售价 - 硬件成本 - 装配调试 - 售后预提
项目制方案：单项目毛利 = 合同额 - 设备成本 - 实施成本 - 调试验收成本
软件型：单客户毛利 = 授权/订阅收入 - 实施交付成本 - 客户成功成本

### 3.4 利润率特征
标准品毛利率40-60% [适用：PLC/伺服/变频器等控制类标准品] [局限：低端标准品竞争激烈可降至30-40%]（PLC/伺服偏高 [适用：中高端产品线] [局限：入门级产品30-40%]），机器人25-40% [适用：国产工业机器人本体] [局限：高端外资品牌通常40-55%]，系统集成15-30% [适用：产线集成项目] [局限：纯人工密集型集成可低至10-15%]，软件60-80% [适用：标准化MES/SCADA等] [局限：含大量定制实施的项目制软件通常35-50%]。产品型公司净利率8-20% [适用：标准化产品为主的公司] [局限：产品线单一或竞争激烈通常5-10%]，集成型3-10% [适用：有一定规模效应的集成商] [局限：小型集成商通常1-5%]。标准化产品毛利和估值质量优于重项目集成。

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| PLC/控制器 | 工业控制核心单元 | OEM、终端工厂 | 设备销售+服务 | 出货量、毛利率、客户数 |
| 伺服/变频器 | 驱动电机及运动控制 | 设备厂、工厂 | 设备销售 | 出货量、ASP、渠道覆盖 |
| 工业机器人 | 搬运/焊接/装配自动执行 | 汽车、锂电、3C | 设备+集成+维保 | 装机量、单机毛利 |
| 机器视觉 | 检测/定位/识别 | 电子、半导体、食品 | 设备/软件/方案 | 检测精度、项目数、复购 |
| MES/工业软件 | 生产执行与数据管理 | 中大型制造企业 | 授权+实施+维保 | 合同额、续费率、客单价 |
| 系统集成 | 产线自动化整体交付 | 工厂客户 | 项目制收入 | 项目毛利率、交付周期 |

## 5. 核心指标体系

- **规模指标**：收入、新签订单、在手订单、出货量、装机量、活跃客户数、海外收入占比
- **增长指标**：收入增速、订单增速、装机量增速、客户数增长、新行业突破数、新品收入占比
- **转化指标**：线索到商机转化率、样机到量产转化率、项目中标率、认证通过率、试点到批量转化率
- **留存/复购指标**：客户复购率、存量客户扩线率、软件续费率、维保续签率、渠道留存率
- **变现指标**：ASP、客单价、单客户生命周期价值、软件ARPU、服务ARPU
- **供给指标**：交期、产能利用率、准时交付率、返修率、故障率、项目交付周期
- **效率指标**：人均收入、研发投入产出比、销售费用率、库存周转、应收周转、项目毛利率
- **财务指标**：毛利率、净利率、经营现金流、研发费用率、存货周转天数、应收账款周转天数、ROIC
- **风控指标**：客诉率、质量事故数、项目延期率、坏账率、单一客户依赖度、核心器件断供风险

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
高端市场由国际龙头占据；中端和细分场景国产替代机会大；项目型集成市场分散；工业软件和控制核心环节壁垒高；下游景气行业吸引新进入者。

### 6.2 常见壁垒类型
核心技术和算法壁垒、产品可靠性壁垒、工艺know-how壁垒、客户认证壁垒、渠道与服务网络壁垒、软硬件一体化壁垒、生态兼容性壁垒。

### 6.3 替代风险
国际厂商价格下探、客户自研或自集成、下游景气下行导致CAPEX缩减、核心零部件被卡脖子、新技术路线替代旧架构。

## 7. 行业风险

### 7.1 通用风险项
制造业CAPEX周期波动、大客户依赖、交付延期、质量事故、应收账款高、核心器件断供、下游景气反转、国产替代不及预期。

### 7.2 行业特有风险
核心元器件（芯片/编码器/减速机）被卡脖子、下游单一行业CAPEX断崖下降、认证周期过长导致商机流失、项目制扩张带来管理和回款失控。

### 7.3 风险信号
订单增长但回款恶化 → 现金流风险（传导机制：为抢订单放宽账期→应收账款膨胀→坏账风险上升→经营现金流与利润脱节→可能表面盈利实则现金流枯竭）；收入增长但毛利率持续下滑 → 竞争力或定价权下降（传导机制：竞争加剧被迫降价→或项目制中低毛利部分占比提升→单位经济恶化→长期盈利能力受损）；新签项目多但延期验收增加 → 交付能力不足（传导机制：项目过多超交付能力→验收推迟→收入确认延迟+成本前置→现金流和利润双压）；大客户收入占比持续提高 → 集中度风险（传导机制：依赖大客户→客户议价权增强→毛利被压缩+如果客户切换供应商则收入断崖）；库存和应收同步上升 → 运营效率恶化（传导机制：备货增加+回款变慢→资金占用→可能需加杠杆→财务费用上升→利润被侵蚀）。

## 8. 财务分析重点

### 8.1 利润表重点
收入结构、产品毛利率vs项目毛利率、研发费用率、销售费用率、服务收入占比、净利率。

### 8.2 资产负债表重点
存货、应收账款、合同资产/合同负债、固定资产、在建工程、现金和有息负债。

### 8.3 现金流量表重点
收入增长是否伴随经营现金流改善；项目型业务是否拉长现金回收周期；扩产是否占用大量资本开支。

## 9. 市场空间测算

- **TAM**：工业制造自动化和数字化总投入市场
- **SAM**：公司当前产品品类、技术能力和客户行业覆盖下可服务市场
- **SOM**：公司中短期可实际获得的订单、装机和客户份额

测算公式：设备渗透率法 = 目标行业设备数 × 自动化渗透率 × 单设备价值量；产线投资法 = 新增/改造产线数 × 单产线投资额；客户数法 = 可触达客户数 × 平均客单价

注意：TAM大不代表单家公司可切份额大；需区分周期性扩产需求与长期结构性升级需求。

## 10. 快速分析卡

- **一句话本质**：通过控制、感知、执行和软件系统提升工业生产效率、良率和确定性，并通过设备、软件、项目和服务变现
- **核心收入公式**：收入 = 出货量 × ASP + 软件/服务收入 + 项目收入
- **核心成本公式**：成本 = BOM/制造成本 + 实施交付成本 + 销售渠道成本 + 研发成本 + 售后维保成本
- **核心判断三要素**：1)是否具备可复制的产品和场景能力 2)毛利与现金流是否匹配 3)客户认证、复购和扩线逻辑是否成立
- **最重要指标**：新签订单、在手订单、出货量/装机量、毛利率、客户复购率
- **最大风险**：下游CAPEX波动、交付与回款风险、质量事故、核心器件断供、大客户依赖
- **一句话结论模板**：长期价值取决于标准化能力、复购能力、毛利质量和穿越制造周期的能力，而非短期订单高低
