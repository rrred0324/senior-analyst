# 互联网广告行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质

互联网广告的本质不是"卖广告位"，而是**将用户注意力精准匹配给广告主，让广告主获得可衡量的回报**。其商业逻辑可拆解为三层：

| 层次 | 核心能力 | 本质 |
|------|---------|------|
| 流量层 | 聚集用户注意力 | 用户产品能力——DAU、时长、粘性 |
| 匹配层 | 精准连接供需 | 算法与数据能力——定向、竞价、排序 |
| 变现层 | 广告主获得可衡量回报 | 效果衡量能力——ROI/ROAS可量化 |

三者的关系：**流量是基础，匹配是乘数，变现是结果**。没有流量就没有广告库存；匹配效率决定单位流量价值；变现效果决定广告主是否持续投入。

### 1.2 与普通行业核心差异

| 维度 | 传统行业 | 互联网广告行业 |
|------|---------|--------------|
| 边际成本 | 每多生产一件产品有明确边际成本 | 广告展示的边际成本趋近于零 |
| 库存属性 | 库存可存储、可调拨 | 广告库存即逝（用户走了，展示机会就没了） |
| 定价机制 | 成本加成或市场定价 | 实时竞价（RTB），价格由供需即时决定 |
| 效果衡量 | 品牌曝光难量化 | 可追踪到点击、转化、ROI |
| 双边市场 | 通常是单边 | 典型双边：用户侧（免费）+ 广告主侧（付费） |
| 规模效应 | 生产和渠道的规模效应 | 数据飞轮：更多用户→更好数据→更准匹配→更高eCPM→更多广告主→更多收入→投入产品→更多用户 |

### 1.3 分析总框架

```
                    ┌──────────────┐
                    │   用户侧     │
                    │ DAU/时长/粘性 │
                    └──────┬───────┘
                           │ 流量供给
                           ▼
                    ┌──────────────┐
                    │   匹配侧     │
                    │ 算法/数据/竞价 │
                    └──────┬───────┘
                           │ 匹配效率
                           ▼
                    ┌──────────────┐
                    │   变现侧     │
                    │ eCPM/ROI/留存 │
                    └──────┬───────┘
                           │ 广告主回报
                           ▼
                    ┌──────────────┐
                    │   广告主侧   │
                    │ 预算/结构/集中度│
                    └──────────────┘
```

**分析一条主线**：从用户→流量→匹配→变现→广告主，看每个环节的效率和质量。

**三个核心问题**：
1. 流量从哪来、能否持续？（用户侧）
2. 匹配效率多高、有无技术壁垒？（匹配侧）
3. 广告主为什么愿意持续花钱？（变现侧）

## 2. 商业模式分类

### 2.1 模式分类

| 模式 | 典型场景 | 核心逻辑 | 代表公司 | 特点 |
|------|---------|---------|---------|------|
| **搜索广告** | 搜索引擎关键词竞价 | 用户主动表达意图，意图明确→转化率高 | 百度、Google、360搜索 | eCPM最高，意图信号最强，效果广告为主 |
| **信息流广告** | 社交/资讯/短视频信息流 | 以内容形式原生呈现，算法推荐定向 | 字节(抖音/头条)、腾讯(朋友圈/QQ)、小红书 | 体验原生，兼顾品牌与效果，依赖推荐算法 |
| **视频广告** | 长视频贴片/短视频激励/直播 | 强视觉冲击，品牌+效果兼顾 | 爱奇艺/优酷(贴片)、快手(激励视频)、B站 | 贴片品牌为主，激励视频效果为主，制作成本高 |
| **程序化广告** | ADX/DSP/DMP/SSP技术链路 | 技术驱动的自动化买卖，实时竞价 | 穿山甲、优量汇、SMAATO | 长尾流量变现，技术壁垒在数据与算法 |
| **电商广告** | 搜索/推荐/直播电商 | 购买意图强，离转化最近 | 阿里(直通车/引力魔方)、拼多多、京东 | ROI最可衡量，广告即交易，闭环最短 |
| **开屏广告** | App启动全屏展示 | 强曝光，品牌为主 | 各大App开屏 | CPM最高之一，但频次有限，库存有限 |

### 2.2 收入来源

| 收入来源 | 说明 | 占比趋势 |
|---------|------|---------|
| **效果广告(CPC/CPA/oCPM)** | 按点击或转化计费，广告主为结果买单 | 持续提升，已超70% |
| **品牌广告(CPM/CPT)** | 按展示或时间计费，注重曝光和品牌建设 | 占比下降，但大客户仍需 |
| **程序化广告技术服务** | ADX/DSP/SSP平台抽佣 | 独立DSP萎缩，大厂自建为主 |
| **广告增值服务** | 创意制作、数据洞察、投放优化 | 边际收入，对中小平台意义有限 |
| **联盟/广告网络分成** | 第三方流量接入，平台抽成 | 穿山甲/优量汇模式，扩展流量池 |

## 3. 收入与成本模型

### 3.1 收入公式

**核心收入公式**：

```
广告收入 = 流量 × 广告加载率 × 填充率 × eCPM

其中：
  流量 = DAU × 人均使用时长 × 单位时长展示次数
  广告加载率 = 广告展示占内容展示的比例
  填充率 = 有广告填充的请求占比
  eCPM = 每千次广告展示的收入（= CPM竞价均值）
```

**展开变形**：

```
广告收入 = DAU × ARPU(广告)
         = DAU × 人均日广告展示次数 × 每1000次展示收入 / 1000
         = 广告请求量 × 填充率 × eCPM / 1000
```

**各因子驱动因素**：

| 因子 | 驱动因素 | 提升路径 | 天花板/约束 |
|------|---------|---------|-----------|
| DAU | 用户产品力、内容生态、网络效应 | 产品迭代、内容投入、社交裂变 | 人口与品类天花板 |
| 人均时长 | 内容吸引力、使用场景丰富度 | 短视频/直播/社交提升时长 | 用户时间总量有限(24h) |
| 广告加载率 | 内容与广告比例 | 增加广告位、提高频次 | **用户体验红线**——过高则用户流失 |
| 填充率 | 广告主数量与预算、匹配效率 | 拓展广告主、程序化填充 | 受广告主预算周期影响 |
| eCPM | 竞价激烈程度、定向精度、转化效果 | 提升算法精度、丰富用户画像 | 受宏观经济和行业景气度影响 |

### 3.2 成本结构

| 成本项目 | 说明 | 占收入比(典型) | 属性 |
|---------|------|--------------|------|
| **流量获取成本(TAC)** | 获客投放、渠道分成、预装 | 10-25% | 变动成本，决定性 |
| **分成成本** | 联盟/创作者/流量方分成 | 15-40%（有分成业务时） | 变动成本 |
| **带宽与服务器** | 内容分发、数据存储、计算 | 5-15% | 半固定，随规模递减 |
| **研发投入** | 算法、推荐、广告系统 | 10-20% | 固定+变动，核心投入 |
| **内容成本** | 采购/自制/UGC激励 | 10-30%（内容平台） | 固定+变动 |
| **销售费用** | 广告主拓展、客户服务 | 5-15% | 变动，大客户销售驱动 |
| **管理费用** | 日常运营 | 5-10% | 固定 |

**关键洞察**：广告平台的核心成本不在"生产"而在"流量获取"和"分成"。毛利率看似高（60-80%），但如果考虑流量获取和分成，真实经营杠杆要看**扣除TAC和分成后的毛利率**。

### 3.3 单位经济模型

| 指标 | 公式 | 健康标准 | 说明 |
|------|------|---------|------|
| **单用户广告价值** | ARPU(广告) = 广告收入 / DAU | 因平台而异，抖音>1元/天，百度~0.5元/天 | 核心变现指标 |
| **获客成本(CAC)** | 总获客费用 / 新增用户 | ARPU×LTV > CAC×3 | 互联网广告行业CAC是关键门槛 |
| **LTV/CAC** | 用户生命周期价值 / 获客成本 | > 3为健康 | 决定能否持续增长 |
| **每分钟时长变现效率** | ARPU / 人均日使用分钟数 | 越高越好 | 衡量时间变现效率 |
| **扣除TAC后毛利率** | (收入-TAC-分成) / 收入 | > 40% | 真实经营杠杆指标 |
| **单广告主ARPA** | 广告收入 / 活跃广告主数 | 趋势向上 | 广告主预算深度 |

## 4. 核心指标体系

### 4.1 结果指标

| 指标 | 定义 | 计算方式 | 行业基准(参考) |
|------|------|---------|--------------|
| **广告收入** | 总变现规模 | 流量×加载率×填充率×eCPM/1000 | — |
| **eCPM** | 千次展示收益 | 广告收入/展示次数×1000 | 搜索>80元，信息流30-80元，视频15-40元 |
| **ARPU** | 单用户日均/月均广告收入 | 广告收入/DAU(或MAU) | 抖音>1元/天，快手~0.5元/天 |
| **广告收入占比** | 广告收入/总收入 | 反映商业模式依赖度 | 纯广告平台100%，混合平台30-70% |

### 4.2 过程指标

| 指标 | 定义 | 重要性 | 说明 |
|------|------|-------|------|
| **DAU/MAU** | 日/月活跃用户 | 极高 | 流量基础，广告收入的起点 |
| **人均使用时长** | 日均单用户使用分钟数 | 极高 | 决定可展示广告的库存量 |
| **广告加载率(Ad Load)** | 广告展示占内容展示的比例 | 极高 | 核心杠杆，但有用户体验上限 |
| **填充率(Fill Rate)** | 有广告填充的请求占比 | 高 | 反映广告主供给和匹配效率 |
| **CTR** | 点击率=点击次数/展示次数 | 高 | 间接反映广告相关性和用户兴趣 |
| **CVR** | 转化率=转化次数/点击次数 | 高 | 衡量广告实际效果，影响广告主留存 |
| **竞价深度** | 每次竞价参与出价的广告主数 | 高 | 影响eCPM，反映竞争激烈度 |
| **广告主留存率** | 续投广告主占比 | 极高 | 广告主LTV的决定因素，比新客更重要 |
| **ROI/ROAS** | 广告主投入产出比 | 极高 | 广告主是否继续投放的终极判断依据 |
| **用户留存率** | 次日/7日/30日留存 | 高 | 用户体验的代理指标，广告过载会降低留存 |

### 4.3 护栏指标

| 指标 | 定义 | 预警阈值 | 说明 |
|------|------|---------|------|
| **用户留存率** | 次日/7日留存 | 次日留存连续2周下降 | 广告过载的最早信号 |
| **人均使用时长** | 日均使用分钟 | 同比下降>10% | 用户体验恶化的量化指标 |
| **广告主集中度** | Top10广告主收入占比 | > 50% | 行业风险集中，一损俱损 |
| **单行业广告收入占比** | 某行业广告主收入占比 | > 30% | 行业政策/景气波动风险 |
| **ARPU与留存背离** | ARPU上升但留存下降 | 连续出现 | 杀鸡取卵——短期变现牺牲长期 |
| **填充率下降** | 有广告填充的请求比例 | 连续2月下降 | 广告主预算萎缩的信号 |
| **eCPM同比下降** | 同比口径 | 降幅>15% | 竞争加剧或需求萎缩 |

## 5. 经营杠杆与竞争格局

### 5.1 竞争优势来源

| 竞争优势 | 说明 | 持久性 |
|---------|------|-------|
| **数据飞轮** | 更多用户→更丰富数据→更精准匹配→更高eCPM→更多广告主→更多收入→再投入产品 | 极强，越滚越快 |
| **算法壁垒** | 推荐算法、竞价算法、创意生成算法的持续迭代 | 强，但可被追赶 |
| **网络效应** | 用户侧网络效应(社交) + 广告主侧网络效应(预算聚集) | 社交网络效应更强 |
| **用户心智与场景** | 搜索场景=主动意图，社交场景=关系推荐，短视频=沉浸消费 | 中等，用户可迁移 |
| **生态闭环** | 广告→内容→交易→数据的闭环 | 强，增加切换成本 |
| **品牌信任** | 大广告主对平台品牌和效果稳定性的信任 | 中等 |

### 5.2 规模效应

| 环节 | 是否有规模效应 | 机制 |
|------|--------------|------|
| 流量获取 | 弱-中 | 小平台CAC更高，大平台有品牌和自然流量 |
| 算法训练 | **极强** | 数据量级决定模型精度，小平台无法竞争 |
| 广告主获取 | 中 | 大平台广告主基数大，竞价更深，eCPM更高 |
| 带宽/基础设施 | 中 | 规模越大单位成本越低 |
| 内容成本 | 弱 | 内容成本通常随规模线性增长甚至超线性 |
| 销售与服务 | 弱 | 大客户需要定制化服务，人效有天花板 |

**关键结论**：互联网广告行业的规模效应**不在基础设施，而在数据与算法**。数据飞轮是最核心的竞争壁垒。

### 5.3 龙头对比

| 维度 | 字节跳动 | 腾讯 | 百度 | 快手 | 小红书 |
|------|---------|------|------|------|-------|
| **核心场景** | 短视频+资讯+全域 | 社交+视频号+小程序 | 搜索+信息流+AI | 短视频+直播电商 | 种草+社区+电商 |
| **流量规模(DAU)** | 抖音~7亿(国内) | 微信~13亿 | ~6亿 | ~4亿 | ~1亿 |
| **核心优势** | 算法+短视频+全域流量 | 社交关系+私域+视频号红利 | 搜索意图+AI | 下沉市场+直播电商闭环 | 种草心智+高价值用户 |
| **eCPM水平** | 行业最高之一 | 中高(视频号提升中) | 搜索高但信息流低 | 中等 | 高(用户购买意图强) |
| **广告收入(估)** | >4000亿/年(国内) | >1000亿/年 | ~800亿/年 | ~600亿/年 | ~300亿/年(快速增长) |
| **广告主结构** | 全行业覆盖 | 游戏+电商+品牌 | 医疗+教育+本地 | 电商+品牌+本地 | 美妆+服饰+生活方式 |
| **增长动力** | 全域(搜索+电商+本地) | 视频号商业化加速 | AI驱动搜索重构 | 电商广告闭环 | 商业化加速+电商闭环 |
| **风险** | 国内流量见顶、海外不确定性 | 广告商业化与用户体验平衡 | 搜索被瓜分、AI变现不确定 | 电商广告竞争激烈 | 社区氛围与商业化冲突 |

## 6. 财务分析映射

### 6.1 行业特有财务分析

| 分析维度 | 关键指标 | 分析要点 |
|---------|---------|---------|
| **变现效率** | 广告收入/MAU、广告收入/总时长 | 同一流量池下，谁变现效率更高 |
| **增长质量** | 广告收入增速 vs DAU增速 vs ARPU增速 | 区分增长来源：量(用户)还是价(变现效率) |
| **经营杠杆** | 毛利率、扣除TAC后毛利率、OPM | 规模扩大后经营杠杆是否释放 |
| **广告主健康** | 广告主数量增速、ARPA增速、留存率 | 广告主是"可持续付费"还是"一锤子买卖" |
| **季节性** | Q1淡季、Q2回暖、Q3平稳、Q4旺季 | 广告收入有强季节性，需同比而非环比 |
| **宏观经济敏感度** | 广告收入增速 vs GDP增速弹性 | 广告是"经济晴雨表"，下行期先被砍预算 |

### 6.2 会计科目与风险

| 会计科目 | 关注点 | 风险信号 |
|---------|-------|---------|
| **收入确认** | 广告展示完成vs点击vs转化确认时点 | 收入确认政策变更、异常冲回 |
| **应收账款** | 广告主账期、回款周期 | 应收账款周转天数大幅增加 |
| **流量获取成本(TAC)** | 是否资本化vs费用化 | TAC占收入比异常上升 |
| **无形资产/商誉** | 并购广告技术公司的商誉 | 大额商誉减值风险 |
| **递延收入** | 广告主预充值未消耗部分 | 大幅下降=广告主预算萎缩 |
| **关联交易** | 集团内广告/流量交易定价 | 关联交易占比过高，定价不公允 |
| **研发费用** | 算法和广告系统投入 | 研发费用率持续下降(竞争力削弱) |

## 7. 风险信号清单

### 7.1 红旗信号

| 信号 | 含义 | 严重程度 |
|------|------|---------|
| ARPU提升但用户留存下降 | 以牺牲用户体验换取短期变现，不可持续 | 🔴 致命 |
| Top3行业广告主贡献>50%收入 | 行业集中风险极高，政策/景气波动可重创收入 | 🔴 致命 |
| 广告加载率超过行业合理水平 | 信息流>15%、视频>20%通常已触及用户容忍上限 | 🔴 高危 |
| eCPM连续2季度同比下降 | 广告主需求萎缩或竞争格局恶化 | 🔴 高危 |
| 填充率持续低于70% | 广告主供给不足，库存闲置 | 🟡 警示 |
| 广告主留存率<60% | 广告主效果不达预期，LTV低 | 🟡 警示 |
| 管理层强调"提升变现效率"但不说"用户体验" | 可能走上杀鸡取卵的道路 | 🟡 警示 |
| 流量获取成本增速>收入增速 | 增长不经济，获客效率恶化 | 🟡 警示 |

### 7.2 常见误区

| 误区 | 正确理解 |
|------|---------|
| 只看eCPM不看用户体验 | eCPM是结果指标，如果以牺牲用户留存为代价，短期eCPM越高长期收入越低 |
| 忽视广告主结构风险 | 游戏版号、教育双减、医疗监管都曾重创对应平台广告收入 |
| 把流量增长等同于广告收入增长 | 流量→广告收入需要经历"加载率×填充率×eCPM"三层衰减，量不等于价 |
| 认为广告收入只跟宏观经济有关 | 平台自身因素(算法迭代、场景拓展、广告主结构)同样重要 |
| 忽视隐私政策冲击 | IDFA/ATT政策使iOS定向精度下降30-50%，eCPM直接受损 |
| 高估新场景的变现速度 | 视频号、小红书等新场景从有流量到高eCPM通常需要2-3年 |
| 把程序化广告当万能药 | 程序化解决的是效率问题，不能凭空创造广告主需求 |
| 只看CPM不看CVR | 高CPM但低CVR的平台，广告主ROI差，长期不可持续 |

## 8. 投资尽调问题清单

### 流量侧

1. DAU/MAU趋势？环比/同比增速？用户增长来源(自然/付费)？
2. 人均使用时长趋势？与竞品对比？
3. 用户画像(年龄、城市、消费力)？是否与高价值广告主目标人群匹配？
4. 用户留存率趋势？次日/7日/30日留存是否稳定？
5. 流量获取成本(TAC)占收入比？趋势如何？

### 变现侧

6. 广告加载率当前水平？是否有提升空间？用户体验反馈如何？
7. eCPM趋势？同比/环比变化？不同广告位eCPM差异？
8. 填充率水平？是否存在大量库存闲置？
9. ARPU趋势？与同行业对比？提升来源(加载率 vs eCPM)？
10. 广告收入增速拆分：DAU贡献 vs ARPU贡献？

### 广告主侧

11. 活跃广告主数量与增速？大客户vs中小客户占比？
12. 广告主留存率？新广告主获取成本？
13. 广告主行业分布？Top3行业占比？是否有政策风险集中？
14. 广告主ARPA趋势？广告主预算是否在增长？
15. 广告主ROI/ROAS水平？是否有第三方验证？

### 竞争与壁垒

16. 核心算法/推荐系统是否有差异化优势？迭代速度如何？
17. 数据飞轮是否在运转？用户数据→算法→eCPM→广告主的闭环是否通畅？
18. 新竞争者进入门槛？是否面临跨界竞争(如电商/社交平台做广告)？
19. 广告技术链路(DSP/ADX/DMP)是否自建？对第三方的依赖度？

### 风险与合规

20. 隐私政策(IDFA/个人信息保护法)对定向精度和eCPM的实际影响？
21. 广告法/互联网广告管理办法合规成本？
22. 广告主行业政策风险(游戏版号、教育、医疗、金融)？
23. 广告内容审核机制？是否有品牌安全风险？
24. 关联交易占比？定价是否公允？
25. 季节性波动规律？Q4旺季与Q1淡季的波动幅度？

## 9. 行业快速分析卡

| 项目 | 内容 |
|------|------|
| **行业** | 互联网广告 |
| **商业本质** | 用户注意力精准匹配广告主，广告主获得可衡量回报 |
| **核心公式** | 收入 = 流量(DAU×时长) × 广告加载率 × 填充率 × eCPM |
| **核心矛盾** | 用户体验 vs 广告负载 vs 变现效率——三者必须平衡 |
| **单位经济** | DAU × ARPU(广告) vs CAC；LTV/CAC > 3 |
| **第一指标** | eCPM(千次展示收益) + 用户留存率(护栏) |
| **关键壁垒** | 数据飞轮：用户→数据→算法→匹配→eCPM→广告主→收入→产品→用户 |
| **最大风险** | ①流量见顶 ②广告主行业集中 ③隐私政策限制 ④用户体验过载 |
| **最大误区** | 只看eCPM不看留存；把流量增长等同于广告收入增长 |
| **竞争格局** | 字节(算法+全域) > 腾讯(社交+视频号) > 百度(搜索+AI) > 快手(下沉+电商) > 小红书(种草) |
| **宏观敏感度** | 高——广告是经济晴雨表，下行期最先被砍预算 |
| **季节性** | Q1淡→Q2回暖→Q3稳→Q4旺(双十一+年末) |
| **估值核心** | 广告收入增速、ARPU提升空间、扣除TAC后经营杠杆、广告主结构健康度 |
| **一句话判断** | 看一家广告平台，先看用户是否还在增长/留存，再看eCPM是否有提升空间，最后看广告主结构是否健康——三者缺一不可 |
