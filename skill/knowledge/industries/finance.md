# 金融行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质

金融行业的本质是三件事的组合：**风险定价 + 杠杆经营 + 资金期限管理**。

- **风险定价**：金融的核心能力是对风险进行识别、量化、定价和转移。谁能更准地定价风险，谁就能在同样的风险暴露下获得更高收益，或在同样的收益水平下承担更低风险。
- **杠杆经营**：金融机构用相对少的自有资本撬动数倍至数十倍的外部资金（存款、保费、债券等）来经营。杠杆是利润放大器，也是风险放大器。理解一家金融机构，首先要理解它的杠杆结构。
- **资金期限管理**：负债端（存款、保单、拆借）和资产端（贷款、投资、持有到期资产）的期限匹配是金融机构的命门。期限错配是利润来源之一，也是系统性风险的根源。

因此，分析金融机构时，核心追问不是"利润多少"，而是：

1. **收益从哪来？** — 利息收入、手续费、承保利润还是投资收益？
2. **承担了什么风险？** — 信用风险、市场风险、流动性风险还是操作风险？
3. **资本够不够支撑？** — 资本充足率、偿付能力是否达标？
4. **盈利可持续吗？** — 当期利润是否隐含了未来的风险暴露？

### 1.2 与普通行业的核心差异

金融行业与普通行业存在结构性差异，直接套用普通行业的分析框架会导致严重误判。

| 维度 | 普通行业 | 金融行业 |
|------|----------|----------|
| 核心收入 | 卖产品/服务的收入 | 利息/手续费/承保/投资收益 |
| 核心成本 | 原材料+制造+销售+管理 | 资金成本+风险成本+运营成本 |
| 关键约束 | 产能/渠道/需求 | 监管资本/偿付能力/风险敞口 |
| 杠杆 | 低（1-3x） | 高（10-30x 银行，5-15x 保险） |
| 资产性质 | 固定资产、存货为主 | 金融资产为主，价值受市场波动影响 |
| 负债含义 | 欠款/借款 | 存款/保单责任准备金，是经营的基础而非负担 |
| 风险暴露 | 经营风险、市场风险 | 信用风险+市场风险+流动性风险+操作风险+合规风险 |
| 监管约束 | 相对宽松 | 极强（资本充足率、偿付能力、准备金、集中度等） |
| 利润质量 | 看毛利率/净利率/周转 | 看风险调整后收益、拨备是否充分、资本回报 |
| 表外风险 | 较少 | 大量（担保、承诺、衍生品、SPV） |
| 周期性 | 需求周期 | 信用周期+利率周期，且自身会放大周期 |

**最容易犯的错误**：把金融机构的负债当"欠款"，把金融资产当"普通资产"，用普通行业的毛利率/净利率框架分析金融公司，忽视监管资本约束和风险敞口。

### 1.3 分析总框架

对任何金融机构，遵循以下分析逻辑链：

```
商业模式 → 收入成本结构 → 核心经营指标 → 资产质量与风险 → 资本与偿付能力 → 盈利可持续性 → 估值与投资判断
```

**分层分析要点**：

| 层级 | 核心问题 | 关键输出 |
|------|----------|----------|
| 行业层 | 监管环境、信用周期位置、利率环境、竞争格局 | 行业约束条件 |
| 模式层 | 收入来自利息/承保/投资/手续费？各占多少？ | 收入结构拆分 |
| 经营层 | 核心经营指标是否健康？单位经济是否成立？ | 指标诊断 |
| 风险层 | 资产质量如何？拨备是否充分？风险敞口多大？ | 风险评估 |
| 资本层 | 资本充足率/偿付能力是否达标？有无资本压力？ | 资本约束判断 |
| 财务层 | 利润是否真实？盈利能否持续？ROE 拆解？ | 盈利质量判断 |
| 估值层 | 用什么估值方法？隐含什么假设？安全边际多大？ | 投资决策 |

## 2. 商业模式分类

金融行业内部分化极大，不同子行业的商业模式、收入来源、核心指标、风险特征截然不同，**绝不能混在一起分析**。

### 2.1 子行业拆分

| 子行业 | 核心功能 | 赚钱逻辑 | 代表公司 |
|--------|----------|----------|----------|
| **银行** | 信用中介+支付中介 | 吸储放贷赚息差，中间业务赚手续费 | 工商银行、招商银行、摩根大通 |
| **保险（寿险）** | 风险转移+长期储蓄 | 承保端赚死差/费差，投资端赚利差 | 中国平安、中国人寿、友邦保险 |
| **保险（财险）** | 风险转移 | 承保利润+投资收益，承保端追求综合成本率<100% | 人保财险、平安产险 |
| **证券/券商** | 资本中介+交易服务 | 经纪佣金+投行费+自营投资+资管费 | 中信证券、高盛 |
| **信贷/消费金融** | 信用下沉放贷 | 放款规模×综合收益率-资金成本-风险成本-运营成本 | 捷信、马上消费 |
| **助贷/联合贷** | 获客+风控+导流 | 服务费/分润，不直接承担信用风险或部分承担 | 360数科、乐信 |
| **信托/资管** | 受托理财 | 管理费+超额业绩报酬 | 中信信托、黑石 |
| **金融科技** | 技术赋能金融 | SaaS 订阅费/交易抽成/技术服务费 | 蚂蚁集团、Stripe |
| **支付** | 资金流转 | 手续费/通道费/备付金利息 | 支付宝、微信支付、PayPal |
| **租赁** | 融资+融物 | 租金收入-资金成本-资产折旧-风险成本 | 远东宏信 |

### 2.2 各模式收入与利润来源详解

#### 银行

**业务链**：吸收负债（存款/同业/发债） → 配置生息资产（贷款/债券/同业） → 利息收入+中间收入 → 扣减信用减值+运营成本 → 净利润

**收入来源**：

| 收入类型 | 来源 | 驱动因素 |
|----------|------|----------|
| 净利息收入 | 生息资产收益率 - 付息负债成本率 | 资产规模、NIM、资产配置结构 |
| 手续费及佣金 | 银行卡、结算、代理、托管、理财 | 客户数、AUM、交易量 |
| 投资收益 | 债券投资、交易性金融资产 | 投资规模、市场行情、投资能力 |
| 其他 | 汇兑损益、公允价值变动 | 市场波动 |

**利润来源拆解（三差模型）**：

| 利差来源 | 含义 | 可持续性 |
|----------|------|----------|
| 信用利差 | 承担信用风险获得的额外收益 | 取决于风控能力，周期波动大 |
| 期限利差 | 期限错配（短借长投）获得的收益 | 取决于利率环境，利率倒挂时为负 |
| 流动性利差 | 牺牲流动性获得的收益 | 稳定但有限 |

#### 保险

**必须拆开承保端和投资端看**，这是保险分析的核心原则。

**寿险利润来源（三差）**：

| 利差来源 | 含义 | 备注 |
|----------|------|------|
| 死差 | 实际死亡率低于定价假设 | 长期较稳定 |
| 费差 | 实际费用低于定价假设 | 依赖运营效率 |
| 利差 | 实际投资收益率高于定价利率 | 最大波动来源，也是最大利润/亏损来源 |

**财险利润来源**：

| 利润来源 | 含义 | 备注 |
|----------|------|------|
| 承保利润 | 保费收入-赔付-费用，综合成本率<100% | 好的财险公司承保端能盈利 |
| 投资收益 | 准备金的投资收益 | 承保盈利时投资收益是锦上添花 |

**收入公式**：
- 寿险：收入 = 新单保费 × 新业务价值率 + 续期保费 + 投资收益
- 财险：收入 = 已赚保费 + 投资收益

#### 信贷/消费金融/助贷

**收入公式**：收入 = 放款规模 × 综合收益率（年化）

**综合收益率构成**：

| 收益来源 | 典型范围 | 说明 |
|----------|----------|------|
| 利息收入 | 10%-36% | 受监管利率上限约束 |
| 服务费/手续费 | 1%-5% | 贷款服务费、账户管理费等 |
| 罚息/滞纳金 | 取决于逾期 | 逾期产生的额外收入（不可依赖） |

**三种模式对比**：

| 维度 | 自营放贷 | 联合贷 | 助贷 |
|------|----------|--------|------|
| 资金来源 | 自有+外部融资 | 与银行按比例出资 | 银行全额出资 |
| 风险承担 | 全额承担 | 按出资比例承担 | 不承担/部分兜底 |
| 收入 | 全额利差 | 按比例分润 | 服务费/导流费 |
| 资本消耗 | 高 | 中 | 低/无 |
| 监管约束 | 牌照+杠杆+利率 | 牌照+联合贷比例 | 获客+数据合规 |
| 关键能力 | 风控+资金 | 风控+资金+银行合作 | 获客+风控模型 |
| 代表 | 消费金融公司 | 蚂蚁借呗（早期模式） | 360数科、乐信 |

## 3. 收入与成本模型

### 3.1 银行收入公式与变量拆解

```
净利息收入 = 生息资产平均余额 × 净息差(NIM)

其中：
  生息资产 = 贷款 + 债券投资 + 同业资产 + 其他
  NIM = (利息收入 - 利息支出) / 生息资产平均余额
      = 生息资产收益率 - 付息负债成本率 × (付息负债/生息资产)

净息差驱动因素：
  资产端：贷款占比、贷款定价（风险偏好）、债券收益率
  负债端：存款结构（活期/定期）、存款成本、同业负债成本
  结构端：资产负债期限匹配、存贷比
```

**非息收入公式**：

```
非息收入 = 手续费及佣金净收入 + 投资收益 + 其他

其中手续费拆分：
  手续费 = 银行卡手续费 + 结算手续费 + 代理业务手续费 + 托管费 + 理财手续费 + ...
```

### 3.2 银行成本结构

| 成本项 | 公式/含义 | 占营收典型比 | 性质 |
|--------|-----------|-------------|------|
| 利息支出 | 付息负债 × 付息成本率 | 40%-55% | 变动（但相对刚性） |
| 信用减值损失 | 贷款 × 不良生成率 × 拨备计提比例 | 10%-30% | 变动（周期波动大） |
| 业务及管理费 | 员工薪酬+网点+IT+营销 | 20%-30% | 半固定 |
| 税金及附加 | - | 1%-2% | 变动 |

**关键成本率指标**：

| 指标 | 公式 | 含义 |
|------|------|------|
| 成本收入比 | 业务及管理费 / 营业收入 | 运营效率，越低越好，通常 25%-35% |
| 信用成本 | 信用减值损失 / 平均贷款 | 风险定价是否覆盖风险成本 |
| 拨备覆盖率 | 贷款减值准备余额 / 不良贷款余额 | 拨备是否充分 |

### 3.3 保险收入公式与变量拆解

**寿险**：

```
新业务价值(NBV) = 新单保费 × 新业务价值率(新业务利润率)
内含价值(EV) = 调整后净资产 + 有效业务价值
有效业务价值 = 现有保单未来利润的折现值

收入 = 新单保费 + 续期保费 + 投资收益
新单保费 = 代理人人数 × 人均产能 × 件均保费
         = 银保渠道新单 + 个险新单 + 其他渠道新单
```

**财险**：

```
已赚保费 = 签单保费 - 未到期责任准备金提转差
承保利润 = 已赚保费 - 赔付支出 - 手续费 - 业务管理费 - 营业税
综合成本率 = 赔付率 + 费用率
  赔付率 = 赔付支出 / 已赚保费
  费用率 = (手续费 + 业务管理费 + 营业税) / 已赚保费
```

### 3.4 保险成本结构

**寿险成本**：

| 成本项 | 含义 | 占比特征 |
|--------|------|----------|
| 退保金 | 保单退保支付的金额 | 随产品结构波动 |
| 赔付支出 | 死亡给付、满期给付、年金给付 | 长期较稳定，短期受产品设计影响 |
| 提取保险责任准备金 | 为未来赔付计提的准备金增加额 | 占比最高，体现未来负债 |
| 手续费及佣金 | 获取保单的成本（代理人佣金、银保手续费） | 获取成本高，是新业务利润率的核心压制因素 |
| 业务及管理费 | 运营成本 | 相对稳定 |

**财险成本**：

| 成本项 | 占已赚保费典型比 | 说明 |
|--------|-------------------|------|
| 赔付支出 | 55%-70% | 核心成本，受自然灾害和大案影响波动大 |
| 手续费 | 10%-20% | 渠道成本，竞争越激烈越高 |
| 业务管理费 | 10%-15% | 运营成本 |
| 营业税及附加 | 3%-5% | |

### 3.5 信贷/消费金融收入公式与变量拆解

```
收入 = 月均在贷余额 × 综合收益率(年化) / 12
    = 放款规模 × 平均放款期限 × 综合收益率

更精确的拆分：
  月收入 = 期初在贷余额 × 综合收益率(月) + 新增放款 × 综合收益率(月) × 当月存续比例
```

**放款规模驱动因素**：

```
放款规模 = 获客量 × 授信通过率 × 授信额度 × 提款率 × 复借率 × 平均放款期限
```

### 3.6 信贷/消费金融成本结构（三段拆分）

| 成本段 | 内容 | 占收入典型比 | 关键驱动 |
|--------|------|-------------|----------|
| **资金成本** | 银行借款/ABS/发债/股东借款的利息 | 15%-30% | 信用评级、资金渠道、市场利率 |
| **风险成本** | 信用减值损失=在贷余额×不良生成率 | 10%-40% | 客群质量、风控能力、经济周期 |
| **运营成本** | 获客+IT+人力+催收+办公 | 15%-30% | 获客效率、自动化程度、规模 |

**单位经济模型**：

```
单客 LTV = 客户生命周期内贡献的收入
         = 月均放款额 × 综合收益率(月) × 平均存续月数
         = 首次放款额 × 复借次数 × 综合收益率 × 平均放款期限

单客 CAC = 获客成本 + 风险成本分摊 + 运营成本分摊

单位经济成立条件：LTV / CAC > 3，或单客净贡献 > 0
```

**关键单位经济指标**：

| 指标 | 公式 | 健康基准 |
|------|------|----------|
| 单客获客成本(CAC) | 营销费用 / 新增授信客户数 | 行业差异大，关键是与 LTV 匹配 |
| 单客 LTV | 生命周期总贡献收入 | CAC 的 3 倍以上 |
| LTV/CAC | - | > 3 |
| 回本周期 | CAC / 月均单客净贡献 | 6-12 个月（消费金融） |
| 复借率 | 老客再次借款比例 | > 50%（消费金融通常 60%-80%） |

## 4. 核心指标体系

### 4.1 银行核心指标

| 指标类型 | 指标 | 公式/含义 | 基准值/健康范围 |
|----------|------|-----------|-----------------|
| **结果指标** | ROE | 净利润/净资产 | > 10%（优秀银行 12%-15%） |
| | ROA | 净利润/总资产 | > 0.8% |
| | 净利润增速 | - | GDP 增速+3-5pct |
| **过程指标** | 净息差(NIM) | 净利息收入/生息资产均值 | 1.5%-2.5%（因市场而异） |
| | 生息资产增速 | - | 名义 GDP 增速附近 |
| | 非息收入占比 | 非息收入/营业收入 | > 25%（越高越轻） |
| | 成本收入比 | 业务管理费/营业收入 | 25%-35% |
| | 贷款增速 | - | 与经济增速匹配 |
| **护栏指标** | 不良贷款率(NPL) | 不良贷款/贷款总额 | < 1.5% |
| | 拨备覆盖率 | 贷款减值准备/不良贷款 | > 150% |
| | 逾期90+/贷款 | 逾期90天以上贷款/贷款总额 | < NPL |
| | 关注类贷款占比 | 关注类贷款/贷款总额 | 趋势比绝对值重要 |
| **行业特有指标** | 资本充足率(CAR) | 资本/风险加权资产 | > 10.5%（系统性重要银行>11.5%） |
| | 一级资本充足率 | 一级资本/风险加权资产 | > 8.5% |
| | 核心一级资本充足率 | 核心一级资本/风险加权资产 | > 7.5% |
| | 存贷比 | 贷款/存款 | 70%-90% |
| | 流动性覆盖率(LCR) | HQLA/30天净现金流出 | > 100% |
| | 拨贷比 | 贷款减值准备/贷款总额 | > 1.5%-2.5% |

### 4.2 保险核心指标

#### 寿险核心指标

| 指标类型 | 指标 | 公式/含义 | 基准值/健康范围 |

### 4.4 Vintage 分析详解

Vintage 分析是信贷行业最核心的风控分析工具，必须理解其原理和应用。

**定义**：按放款月份（Vintage）分组，追踪每一批放款从放款时点开始，在不同账龄（MOB, Month on Book）的逾期率表现。

**核心价值**：
1. **区分放款质量**：不同月份放款的客群风险是否变化
2. **识别风险趋势**：近期放款的风险是否在恶化
3. **排除季节干扰**：避免总量逾期率被规模增长稀释
4. **评估风控调整效果**：风控策略调整后，新 Vintage 表现是否改善

**分析方法**：

| 分析维度 | 方法 | 判断标准 |
|----------|------|----------|
| 横向比较 | 同一 MOB 下不同 Vintage 的逾期率 | 越低越好，趋势恶化是强预警 |
| 纵向比较 | 同一 Vintage 随 MOB 增长的逾期曲线 | 正常应逐步收敛趋稳 |
| 峰值判断 | 逾期率在哪个 MOB 达到峰值 | 峰值后移可能是风险信号 |
| 与预期对比 | 实际 Vintage vs 定价时的风险假设 | 持续高于预期=定价不足 |

**典型 Vintage 逾期率曲线形态**：

```
逾期率
  │        ╱──╲  (恶化: 峰值后移或持续上升)
  │       ╱    ╲
  │      ╱      ╲───  (正常: MOB6-9 达峰后趋稳)
  │     ╱
  │    ╱  ────────  (优秀: 低且平稳)
  │   ╱
  └───────────────── MOB
     3  6  9  12  15  18
```

## 5. 经营杠杆与竞争格局

### 5.1 竞争优势来源

| 优势来源 | 在金融行业的体现 | 强度 | 代表 |
|----------|-----------------|------|------|
| **牌照壁垒** | 银行、保险、券商、消费金融牌照稀缺 | 强，但逐步松动 | 银行牌照、保险牌照 |
| **客户基础** | 存款基础、保单客户、用户数 | 极强，切换成本高 | 招行(零售客户)、平安(综合金融) |
| **资金成本** | 低成本负债来源（活期存款、保单浮存金） | 核心优势，难以逾越 | 招行(活期占比高)、四大行 |
| **风控能力** | 更低的不良率、更精准的风险定价 | 长期核心壁垒 | 招行、优秀消费金融公司 |
| **渠道网络** | 网点、代理人队伍、线上流量 | 有价值但边际递减 | 代理人渠道、银保渠道 |
| **数据飞轮** | 更多客户→更多数据→更好风控→更低成本 | 在信贷领域显著 | 头部消费金融、互联网银行 |
| **品牌信任** | 金融机构的品牌即信用 | 强 | 大行、平安 |
| **综合金融** | 交叉销售、集团协同 | 中等，执行难度大 | 平安集团 |
| **科技能力** | 效率提升、成本下降、体验优化 | 越来越重要 | 微众银行、网商银行 |

### 5.2 规模效应类型

| 子行业 | 规模效应类型 | 表现 | 边界 |
|--------|-------------|------|------|
| 银行 | 供给侧+需求侧 | 资金成本下降、网点分摊、数据积累、品牌增强 | 规模大到一定程度后管理成本上升、大而不倒的监管成本 |
| 保险(寿险) | 需求侧弱 | 大数法则分散风险、品牌增强 | 代理人管理规模不经济、利差受投资能力约束 |
| 保险(财险) | 供给侧 | 数据积累改善定价、运营分摊 | 巨灾风险无法靠规模分散、费率竞争 |
| 信贷/消费金融 | 数据飞轮 | 更多数据→更准风控→更低损失→更高利润→更多放款 | 客群下沉到一定程度后风险非线性上升 |
| 支付 | 双边网络效应 | 用户越多商户越多→商户越多用户越多 | 政策限制（反垄断、费率管制） |

## 6. 财务分析映射

### 6.1 行业特有财务分析要点

**金融机构财务分析的核心原则：不能只看利润表，必须同时看资产负债表和风险指标**。

| 信号 | 严重度 | 含义 |
|------|--------|------|
| NBV 连续负增长 | 极高 | 新业务价值在萎缩，增长逻辑断裂 |
| 偿付能力充足率逼近120% | 极高 | 资本生命线告急，可能限制新业务 |
| 综合成本率(财险)>105% | 高 | 承保端严重亏损 |
| 退保率异常上升 | 高 | 可能是产品设计问题或销售误导 |
| 继续率持续下降 | 高 | 产品竞争力不足或客户满意度低 |
| 投资收益率长期低于负债成本 | 极高 | 利差损，寿险最致命风险 |
| 非标/不动产投资占比过高 | 中 | 流动性风险+信用风险 |
| 准备金假设频繁调整 | 中 | 可能通过调假设做利润 |
| 代理人人数大幅下降且产能未提升 | 中高 | 渠道转型阵痛，新单承压 |
| 再保分出异常增加 | 中 | 可能通过再保粉饰偿付能力 |
| 万能险/投连险占比过高 | 中 | 保障成分低，更像理财产品，受市场波动影响大 |

#### 信贷/消费金融红旗信号

| 信号 | 严重度 | 含义 |
|------|--------|------|
| 新 Vintage 逾期率持续高于老 Vintage | 极高 | 风控在恶化，可能为规模牺牲风险 |
| 90+逾期率加速上升 | 极高 | 风险暴露加速 |
| M1→M2 迁徙率上升 | 高 | 早期逾期转化恶化，催收效果下降 |
| 风险调整后收益率<资金成本 | 极高 | 做一单亏一单，单位经济不成立 |
| 放款增速远超行业但风控标准不变 | 高 | 可能通过降标准冲量 |
| 获客成本持续上升且复借率下降 | 高 | 客群质量在下降 |
| 核销率大幅上升 | 中高 | 以前的风险在暴露 |
| 资金成本上升（评级下调/渠道收紧） | 中高 | 流动性风险信号 |
| 单一渠道依赖过高 | 中 | 渠道政策变化风险 |
| 监管处罚或合规问题 | 中高 | 可能导致业务受限 |

### 7.2 常见分析误区

| 误区 | 为什么错 | 正确做法 |
|------|----------|----------|
| 拿普通行业财务指标套金融公司 | 金融的资产/负债性质完全不同，毛利率、净利率含义不同 | 用行业特有指标：NIM、COR、综合收益率等 |
| 只看利润增长，不看资本约束 | 利润增长可能消耗资本，资本不够时增长不可持续 | 同时看 ROE 和资本充足率/偿付能力 |
| 忽视拨备/准备金对利润的影响 | 拨备是利润的"调节器"，少提拨备=虚增利润 | 看拨备覆盖率变化、信用成本趋势 |
| 不看风险成本只看收益率 | 高收益可能来自高风险，风险调整后才是真实收益 | 算风险调整后收益率=综合收益率-风险成本 |
| 忽视监管约束 | 监管是硬约束，可改变商业模式和盈利能力 | 追踪监管政策变化，评估影响 |
| 拿 NPL 绝对值跨行比较 | 不同银行不良认定标准不同 | 看逾期90+/不良偏离度，看趋势而非绝对值 |
| 把保险投资收益当经常性收入 | 投资收益波动大，尤其是公允价值变动 | 区分净投资收益(利息+股息)和总投资收益(含浮盈) |
| 不看 Vintage 只看整体逾期率 | 整体逾期率会被规模增长稀释，掩盖风险恶化 | 用 Vintage 分析看不同批次放款的风险趋势 |
| 忽视期限错配风险 | 期限错配是利润来源也是风险来源 | 看资产负债期限缺口、流动性指标 |
| 把 EV 绝对值当估值锚 | EV 的假设(投资收益率、风险贴现率)可调整 | 看假设是否合理、偏差方向、敏感性分析 |
| 忽视金融的周期性 | 信用周期和利率周期深刻影响金融公司盈利 | 判断当前所处的周期位置 |
| 不区分承保利润和投资利润(保险) | 两者的性质、可持续性、驱动因素完全不同 | 拆开看承保端和投资端 |

## 8. 投资尽调问题清单

### 8.1 银行尽调核心问题

**行业与定位**
1. 银行在区域/全国的市场份额和排名？竞争格局如何？
2. 区域经济结构如何？主要产业和增长动力？
3. 监管环境最近有何变化？对银行的影响？

**商业模式与收入**
4. 资产结构如何？贷款/债券/同业占比？
5. 贷款结构如何？零售/对公、行业分布、期限分布？
6. 负债结构如何？存款/同业/发债占比？活期/定期？
7. NIM 水平和趋势？主要驱动因素？
8. 非息收入占比和构成？增长驱动力？

**资产质量与风险**
9. NPL 水平和趋势？不良认定标准是否严格？逾期90+/不良偏离度？
10. 关注类贷款占比和趋势？
11. 拨备覆盖率和拨贷比？是否充分？
12. 信用成本趋势？是否与不良生成匹配？
13. 行业和客户集中度？是否有大额风险暴露？
14. 表外项目规模和风险？

**资本与盈利**
15. 资本充足率水平？内生资本补充能力？有无融资需求？
16. ROE 拆解？利润增长来源？
17. 成本收入比？运营效率如何？
18. 利润增长有多少来自拨备少提？

**估值与风险**
19. 当前 PB 和 PE 水平？历史分位数？
20. 隐含的不良率预期是多少？
21. 最坏情况下资本充足率会怎样？
22. 利率变动对 NIM 和债券投资的影响？

### 8.2 保险尽调核心问题

**行业与定位**
1. 寿险/财险市场格局？公司市场地位？
2. 监管政策变化？对产品设计/渠道/资本的影响？
3. 行业阶段？保险深度和密度？

**商业模式与收入**
4. 寿险：NBV 及增速？NBV 利润率？趋势？
5. 寿险：新单保费中，期交占比？趸交占比？
6. 寿险：渠道结构？代理人/银保/线上占比及变化？
7. 寿险：代理人人数和产能趋势？
8. 财险：综合成本率及趋势？赔付率和费用率拆分？
9. 财险：车险/非车险占比？非车险盈利情况？
10. 续期保费占比和继续率？

**投资端**
11. 投资资产结构？债券/股票/非标/不动产占比？
12. 净投资收益率和总投资收益率？趋势？
13. 投资收益率假设是否合理？与实际偏差方向？
14. 是否存在利差损风险？

**资本与偿付能力**
15. 偿付能力充足率？趋势？
16. 内含价值(EV)及增速？EV 假设是否合理？
17. 经验偏差方向？正偏差还是负偏差？
18. 是否需要补充资本？渠道和成本？

**估值与风险**
19. 寿险：PEV 水平？历史分位数？
20. 财险：PB 水平？承保利润估值？
21. 最坏情况下偿付能力能否维持？
22. 利率下行对投资端和准备金的影响？

### 8.3 信贷/消费金融尽调核心问题

**行业与定位**
1. 目标客群画像？与银行客群的差异？
2. 市场竞争格局？主要竞争对手和策略差异？
3. 监管政策变化？利率上限、数据合规、催收规范？

**商业模式与收入**
4. 自营/联合贷/助贷模式占比？趋势？
5. 放款规模和增速？增长来源（新客/老客）？
6. 综合收益率水平？与监管上限的距离？
7. 资金成本和资金渠道？稳定性如何？
8. 收入结构中利息/服务费/其他占比？

**风控与资产质量**
9. Vintage 逾期曲线？近期 Vintage 是否恶化？
10. 30+/90+ 逾期率？M1→M2 迁徙率？趋势？
11. 核销率和核销后回收率？
12. 客群结构变化？新客 vs 老客的风险差异？
13. 风控模型迭代频率和效果？
14. 风险调整后收益率？趋势？

**运营与单位经济**
15. 获客成本(CAC)和趋势？各渠道 CAC 差异？
16. 单客 LTV？LTV/CAC 比率？
17. 复借率？趋势？
18. 运营成本占比？自动化程度？

**资本与估值**
19. 注册资本和杠杆倍数？是否需要补充资本？
20. ROE 水平和趋势？
21. 估值方法？P/E 还是 P/B 还是 DCF？
22. 最坏情况下（逾期率翻倍）能否维持正利润？

## 9. 行业快速分析卡

### 银行快速分析卡

| 维度 | 内容 |
|------|------|
| **商业本质** | 风险定价+杠杆经营+期限管理；吸收负债→配置资产→赚息差+手续费 |
| **收入公式** | 净利息收入=生息资产×NIM；+ 非息收入(手续费+投资) |
| **成本结构** | 利息支出(40-55%) + 信用减值(10-30%) + 运营成本(20-30%) |
| **核心指标** | 结果:ROE/ROA/NIM; 过程:贷款增速/非息占比/成本收入比; 护栏:NPL/拨备覆盖/逾期90+; 特有:CAR/LCR/存贷比 |
| **竞争优势** | 牌照+客户基础+资金成本+风控能力+品牌 |
| **核心风险** | 信用风险暴露/利率风险/流动性危机/监管收紧 |
| **风险信号** | NPL升+拨备降 / 逾期90+偏离度高 / 关注类占比升 / NIM持续收窄 / 资本逼近红线 |
| **估值方法** | PB 为主(0.3-1.5x)；ROE 决定 PB 中枢；隐含不良率是关键 |
| **常见误区** | 只看利润不看拨备 / NPL 跨行直接比较 / 忽视资本约束 / 忽视周期 |

### 保险快速分析卡

| 维度 | 内容 |
|------|------|
| **商业本质** | 风险转移+杠杆经营；承保端(死差/费差)+投资端(利差)双轮驱动 |
| **收入公式** | 寿险:NBV=新单保费×NBV利润率;+续期保费+投资收益; 财险:已赚保费+投资收益 |
| **成本结构** | 寿险:退保+赔付+准备金提取+手续费+管理费; 财险:赔付(55-70%)+手续费(10-20%)+管理费(10-15%) |
| **核心指标** | 寿险:NBV增速/NBV利润率/EV增速/继续率/投资收益率; 财险:COR/赔付率/费用率 |
| **竞争优势** | 牌照+渠道(代理人)+品牌+投资能力+产品定价 |
| **核心风险** | 利差损/偿付能力不足/退保率上升/投资亏损/巨灾(财险) |
| **风险信号** | NBV连负 / 偿付能力逼近120% / COR>105%(财险) / 退保率升 / 投资收益<负债成本 |
| **估值方法** | 寿险:PEV(0.3-1.5x); 财险:PB(0.5-2x)+承保利润PE |
| **常见误区** | 不拆承保和投资 / EV 假设当事实 / 忽视利差损风险 / 拿保费增速当增长质量 |

### 信贷/消费金融快速分析卡

| 维度 | 内容 |
|------|------|
| **商业本质** | 风险定价+杠杆经营；放款×综合收益率-资金成本-风险成本-运营成本 |
| **收入公式** | 收入=月均在贷余额×综合收益率; 风险调整后收入=综合收益率-风险成本率 |
| **成本结构** | 资金成本(15-30%) + 风险成本(10-40%) + 运营成本(15-30%) |
| **核心指标** | 结果:ROE/净利润; 过程:放款增速/综合收益率/复借率; 护栏:Vintage/30+/90+/迁徙率; 特有:LTV/CAC/风险调整后收益 |
| **竞争优势** | 风控能力+获客效率+资金成本+数据积累+牌照 |
| **核心风险** | 客群下沉风险/流动性风险/监管收紧(利率上限/数据合规)/资金链断裂 |
| **风险信号** | 新Vintage恶化 / 90+加速上升 / 风险调整后收益<0 / CAC升+复借率降 / 资金成本上升 |
| **估值方法** | PE(8-20x)为主；关注周期性和风险调整后盈利 |
| **常见误区** | 只看整体逾期不看Vintage / 不算风险调整后收益 / 把规模增长当增长质量 / 忽视监管风险 |

## 附录：金融行业分析检查清单

对任何金融公司做分析时，按此清单逐项检查：

- [ ] 明确了子行业类型（银行/保险/信贷/其他）
- [ ] 拆解了收入来源及占比
- [ ] 明确了核心成本结构（资金+风险+运营）
- [ ] 检查了资产质量指标和趋势
- [ ] 验证了拨备/准备金是否充分
- [ ] 检查了资本充足率/偿付能力
- [ ] 评估了风险调整后收益
- [ ] 识别了监管约束和政策变化影响
- [ ] 判断了当前信用周期/利率周期位置
- [ ] 检查了红旗信号清单
- [ ] 区分了利润的可持续部分和不可持续部分
- [ ] 评估了最坏情况下的资本和偿付能力
- [ ] 验证了关键假设的合理性（保险 EV 假设、信贷 Vintage 假设）
- [ ] 完成了财务-业务指标的交叉验证
