# 金融行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质

金融行业的本质是**风险定价 + 杠杆经营 + 资金期限管理**三件事的组合。

- **风险定价**：对风险进行识别、量化、定价和转移。谁能更准地定价风险，谁就能在同样风险暴露下获得更高收益
- **杠杆经营**：用相对少的自有资本撬动数倍至数十倍的外部资金来经营。杠杆是利润放大器，也是风险放大器
- **资金期限管理**：负债端和资产端的期限匹配是命门。期限错配是利润来源之一，也是系统性风险的根源

### 1.2 与普通行业的核心差异

| 维度 | 普通行业 | 金融行业 |
|------|----------|----------|
| 核心收入 | 卖产品/服务收入 | 利息/手续费/承保/投资收益 |
| 核心成本 | 原材料+制造+销售 | 资金成本+风险成本+运营成本 |
| 关键约束 | 产能/渠道/需求 | 监管资本/偿付能力/风险敞口 |
| 杠杆 | 低（1-3x） | 高（银行10-30x，保险5-15x） |
| 负债含义 | 欠款/借款 | 存款/保单责任准备金，是经营基础 |
| 利润质量 | 看毛利率/净利率 | 看风险调整后收益、拨备充分性 |

### 1.3 分析总框架

```
监管环境 → 风险定价能力 → 资本约束 → 资产质量 → 盈利可持续性 → 估值判断
```

**核心追问不是"利润多少"，而是**：收益从哪来？承担了什么风险？资本够不够支撑？盈利可持续吗？

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2017 | 金融监管体制改革，设立金稳委 | 金融监管从分业走向统筹，强化穿透式监管 |
| 2018 | 资管新规落地 | 打破刚性兑付，非标转标，影子银行压缩 |
| 2020 | 银行理财转型，理财子公司批量设立 | 银行理财从表内转向表外独立运营 |
| 2021 | 互联网平台金融业务整改 | 平台金融业务纳入持牌监管，助贷模式受限 |
| 2022 | 房地产信用风险暴露 | 开发贷不良率上升，银行资产质量承压 |
| 2023 | LPR多次下调 | 银行NIM持续收窄，净利息收入承压 |

## 2. 价值链与商业模式

### 2.1 价值创造链条

```
资金获取（存款/保费/拆借）
→ 风险识别与定价
→ 资金配置（贷款/投资/承保）
→ 期限匹配与流动性管理
→ 风险转移与对冲
→ 收入确认（利息/手续费/投资收益）
→ 风险拨备与利润释放
```

### 2.2 核心飞轮

```
更准的风险定价
→ 更低的实际风险成本
→ 更高的风险调整后收益
→ 更强的资本积累
→ 更大的业务规模
→ 更多的数据和经验
→ 更准的风险定价
```

### 2.3 商业模式分类

**模式一：银行**
- 名称：存贷汇
- 收费对象：存款人、借款人
- 收费方式：存贷利差 + 手续费
- 公式：收入 = 生息资产 × NIM + 手续费收入

**模式二：保险**
- 名称：承保 + 投资
- 收费对象：投保人
- 收费方式：保费 + 投资收益
- 公式：收入 = 保费收入 + 投资收益 - 赔付支出

**模式三：信贷/消费金融**
- 名称：放贷 + 风控
- 收费对象：借款人
- 收费方式：利息 + 服务费
- 公式：收入 = 放款余额 × 综合收益率 - 信用损失

## 3. 收入与成本模型

### 3.1 收入模型

**银行**：总收入 = 净利息收入 + 手续费及佣金收入 + 投资收益 + 其他
- 净利息收入 = 生息资产 × NIM
- 手续费收入 = 中间业务规模 × 费率

**保险**：总收入 = 已赚保费 + 投资收益 + 其他
- 已赚保费 = 保费收入 - 分出保费 - 提取未到期责任准备金
- 投资收益 = 投资资产 × 综合投资收益率

**信贷**：总收入 = 放款余额 × 综合收益率
- 综合收益率 = 利率 + 服务费率 + 其他费率

### 3.2 成本模型

**固定成本**：网点/职场成本、系统IT成本、合规团队成本、管理人员薪酬
**变动成本**：资金成本（利息支出）、风险成本（拨备/赔付）、获客成本、催收成本

### 3.3 单位经济

- 银行：单位贷款利润 = 贷款利率 - 资金成本 - 风险成本 - 运营成本
- 保险：单位保单利润 = 保费 - 赔付 - 获取成本 - 运营成本 + 投资收益
- 信贷：单位放款利润 = 综合收益率 - 资金成本 - 信用损失率 - 获客成本 - 运营成本

### 3.4 利润率特征

- 银行：净息差 1.5-2.5% [适用：中国商业银行] [局限：海外银行/互联网银行差异大]，ROE 8-15% [适用：中国上市银行] [局限：中小银行波动更大]，ROA 0.8-1.5% [适用：中国上市银行] [局限：高杠杆银行ROA偏低]
- 保险：综合成本率 95-105% [适用：中国财险行业] [局限：寿险不适用此指标]（<100%即承保盈利），投资收益率 4-6% [适用：中国保险业长期假设] [局限：低利率环境下趋降]
- 信贷：风险调整后收益率 8-20% [适用：消费金融/小贷] [局限：银行信贷利差远低于此]，逾期率是核心变量

### 保险综合利润判断框架

保险公司的利润 = 承保利润 + 投资收益，两者必须联合判断：

```
综合利润 = 已赚保费 × (1 - 综合成本率) + 投资资产 × 综合投资收益率
```

**判断逻辑**：
| 承保状态 | 投资收益能否覆盖 | 判断 |
|---------|----------------|------|
| 承保盈利（综合成本率<100% [适用：财险] [局限：寿险承保盈利标准不同]） | 是 | 优质，双轮驱动 |
| 承保盈利 | 否 | 承保利润被投资亏损抵消，需排查投资策略 |
| 承保亏损（综合成本率>100% [适用：财险] [局限：寿险常见承保亏损]） | 能覆盖且有盈余 | 可接受，投资能力是核心优势（常见于财险） |
| 承保亏损 | 不能覆盖 | 危险，持续亏损将侵蚀资本 |

**关键约束**：
- 寿险：承保亏损较常见（费率竞争+准备金计提），投资收益必须稳定覆盖
- 财险：承保盈利是硬指标，综合成本率>105% [适用：中国财险] [局限：车险/非车险差异大]且投资收益率<4% [适用：中国保险业] [局限：低利率环境下4%可能偏高]通常不可持续
- 监管底线：综合成本率持续>110% [适用：中国财险] [局限：不同险种监管容忍度不同]可能触发监管干预

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|--------|------|---------|---------|---------|
| 商业银行 | 吸储放贷+中间业务 | 企业+个人 | 利差+手续费 | NIM、NPL、资本充足率 |
| 保险（寿险） | 长期保障+储蓄 | 个人 | 保费+投资收益 | 新业务价值、综合成本率 |
| 保险（财险） | 短期风险保障 | 企业+个人 | 保费 | 综合成本率、赔付率 |
| 消费金融 | 个人信贷 | 个人 | 利息+服务费 | 逾期率、放款增速 |
| 互联网支付 | 支付通道+账户 | 商户+个人 | 手续费+备付金 | TPV、take rate |
| 财富管理 | 资产配置+顾问 | 高净值+机构 | 管理费+业绩报酬 | AUM、费率、留存率 |

## 5. 核心指标体系

**规模指标**：总资产、贷款余额、保费收入、AUM、存款规模
**增长指标**：贷款增速、保费增速、AUM增速、客户数增速
**风险指标**：不良率（NPL）、关注类贷款占比、逾期率、拨备覆盖率、综合成本率
**效率指标**：成本收入比、人均利润、单网点产出、NIM
**资本指标**：资本充足率、核心一级资本充足率、偿付能力充足率
**流动性指标**：流动性覆盖率（LCR）、净稳定资金比率（NSFR）、存贷比
**盈利指标**：ROE、ROA、净息差、风险调整后资本回报（RAROC）
**资产质量**：Vintage曲线、迁徙率、核销率、回收率

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
- 银行：高集中度，国有大行+股份行+城商行三层格局
- 保险：寡头竞争，前5家市占率>50% [适用：中国保险业] [局限：细分险种集中度差异大]
- 信贷：分散，持牌机构+互联网平台并存
- 支付：双寡头（支付宝+微信支付），侧翼有银联+网联

### 6.2 常见壁垒类型
- **牌照壁垒**：银行、保险、支付牌照是硬门槛
- **资本壁垒**：资本充足率要求限制了规模扩张速度
- **数据壁垒**：风控模型和数据积累形成差异化
- **渠道壁垒**：线下网点和代理人队伍
- **信任壁垒**：品牌和安全性认知

### 6.3 替代风险
- 金融脱媒：优质客户直接发债替代贷款
- 互联网平台替代传统金融服务
- 开放银行/API经济重构服务入口
- AI 替代传统风控和投顾

## 7. 行业风险

### 7.1 通用风险项
- 信用风险：借款人违约
- 市场风险：利率、汇率、资产价格波动
- 流动性风险：资金错配导致挤兑或无法变现
- 操作风险：内部流程、人员、系统失误

### 7.2 行业特有风险
- **监管风险**：政策变化（利率管制、资本要求、业务限制）
- **信用周期风险**：经济下行期不良率系统性上升
- **期限错配风险**：短借长投导致流动性危机
- **影子银行风险**：表外业务实质风险未充分反映
- **偿付能力风险**（保险）：准备金不足或投资亏损

### 7.3 风险信号
- NPL连续2个季度上升 → 信用风险恶化（传导机制：经济下行/行业风险暴露→借款人还款能力下降→逾期增加→拨备计提增加→利润被侵蚀→资本充足率下降→扩张受限）
- NIM持续收窄且无改善路径 → 盈利能力恶化 [适用：银行] [局限：非息收入占比高的银行NIM下降影响较小]（传导机制：资产端收益率下行/LPR下调→息差压缩→净利息收入减少→若无法通过中间业务补偿则利润持续下滑）
- 拨备覆盖率<150% [适用：中国商业银行监管要求] [局限：不同国家/银行类型监管标准不同] → 风险缓冲不足（传导机制：不良增加但拨备不充足→未来需大幅补提拨备→利润大幅波动→资本充足率承压）
- 资本充足率接近监管红线 → 扩张受限（传导机制：风险资产增长→资本消耗→资本充足率逼近红线→被迫缩表或增资→增长受限）
- 经营现金流与利润持续背离 → 利润质量存疑（传导机制：利润含非现金收入（如应计利息）→经营现金流弱于利润→实际造血能力不足→依赖外部融资维持）

## 8. 财务分析重点

### 8.1 利润表重点
- 利息收入 vs 非息收入结构
- NIM趋势及归因
- 拨备计提充足性（拨备覆盖率、拨贷比）
- 手续费收入增速及质量

### 8.2 资产负债表重点
- 资产结构（贷款/投资/同业占比）
- 负债结构（存款/同业/发债占比）
- 资本充足率（核心一级/一级/总资本）
- 表外项目（担保、承诺、衍生品）

### 8.3 现金流量表重点
- 经营现金流是否与净利润匹配
- 存款增长是否健康
- 同业负债波动是否异常
- 投资现金流方向（扩张or收缩）

## 9. 市场空间测算

- **银行**：信贷余额 × 增速 + 中间业务渗透率提升
- **保险**：人口 × 保险深度（保费/GDP）× 提升空间
- **信贷**：目标人群 × 人均信贷余额 × 渗透率
- **支付**：TPV × take rate × 增值服务渗透

## 10. 快速分析卡

- **一句话本质**：金融的本质是风险定价+杠杆经营+期限管理，核心不是"做了多大"，而是"承担了什么风险、资本够不够、利润是否可持续"
- **核心收入公式**：银行=生息资产×NIM+手续费；保险=保费+投资收益-赔付；信贷=放款×综合收益率-信用损失
- **核心成本公式**：资金成本+风险成本（拨备/赔付）+运营成本
- **核心判断三要素**：1）风险定价能力是否足够准 2）资本约束下增长空间多大 3）当前利润是否隐含未来风险暴露
- **最重要指标**：1）NPL/逾期率（资产质量） 2）NIM/综合收益率（盈利能力） 3）资本充足率（扩张能力）
- **最大风险**：1）信用周期系统性恶化 2）监管政策收紧 3）流动性危机
- **一句话结论模板**：该金融机构的核心不是规模排名，而是风险定价能力和资本效率；长期胜负手不是谁放贷最多，而是谁在周期波动中拨备最充分、资本最扎实
