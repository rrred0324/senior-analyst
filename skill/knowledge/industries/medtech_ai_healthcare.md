# 医疗科技与AI医疗商业建模知识库

> 适用场景：医疗器械、数字医疗、AI 医疗项目分析，一级市场投资与商业建模
> 覆盖范围：AI 辅助诊断、数字疗法、医疗 SaaS、智能器械、院内信息化、医疗机器人
> 行业特征：强监管、证据导向、付费链条复杂、销售周期长、临床验证重要

---

## 1. 行业总论

### 商业本质

医疗科技与 AI 医疗行业的本质是：通过软件、器械、数据和算法提高医疗效率、改善诊疗质量、降低误诊漏诊或优化院内运营，并通过器械销售、软件收费、服务费或医保/院方付费实现商业化。

### 行业核心特点

- 医疗不是单纯 IT 行业，必须面对临床有效性
- 监管、认证、准入决定商业化节奏
- 医院端付费链条复杂，销售周期长
- 产品价值需要临床证据支持
- AI 医疗往往不是直接替代医生，而是辅助与增效

### 分析总框架

```
行业本质（技术能力 → 临床/运营价值 → 付费变现）
  → 商业模式（AI诊断/器械/SaaS/服务/解决方案）
    → 收入成本模型（医院×ACV / 销量×ASP）
      → 核心指标（注册证 × 客户数 × 续费率 × 回款周期）
        → 经营机制（注册 → 入院 → 数据积累 → 扩展）
```

## 2. 商业模式分类

| 模式 | 描述 | 收入来源 | 核心能力 |
|---|---|---|---|
| AI 辅助诊断 | 影像/病理/筛查辅助 | 软件费、项目费 | 算法效果、临床证据 |
| 医疗器械 | 智能设备/耗材 | 设备销售、耗材 | 注册认证、渠道 |
| 医疗 SaaS | 医院/诊所软件系统 | 订阅费、服务费 | 系统集成、客户关系 |
| 数字医疗服务 | 线上诊疗/管理 | 服务费、会员费 | 服务运营、合规 |
| AI 医疗解决方案 | 软硬一体方案 | 合同额、运维费 | 临床落地、院内集成 |

## 3. 收入与成本模型

### 3.1 收入模型

**医疗器械**
```
收入 = 销量 × ASP + 耗材复购收入
```

**医疗 SaaS / AI 软件**
```
收入 = 医院客户数 × ACV
```

**医疗服务**
```
收入 = 用户数 × 付费率 × ARPU
```

### 3.2 成本模型

+ 研发成本
+ 临床验证成本
+ 注册合规成本
+ 销售与渠道成本
+ 交付与培训成本
+ 器械制造成本

### 3.3 单位经济模型

```
单医院利润 = 年收入 - 销售获客成本 - 部署成本 - 客户支持成本
```

## 4. 核心指标体系

+ 医院客户数
+ 科室覆盖数
+ 产品注册证数量
+ 单院收入
+ 续费率
+ 临床准确率 / 灵敏度 / 特异度
+ 渗透率
+ 渠道覆盖率
+ 回款周期
+ 毛利率

---

## 5. 经营机制

### 核心飞轮
```
完成注册/临床验证
→ 进入医院或场景
→ 积累病例与使用数据
→ 提升模型与产品效果
→ 扩展更多医院/科室
```

### 核心判断逻辑

1. 产品是否真正改善临床或运营？
2. 监管准入是否清晰？
3. 谁来付钱，预算归属哪里？
4. 是项目制还是可复制产品制？

---

## 6. 细分赛道分析

### 6.1 AI 辅助诊断
重点看：临床准确率、注册进度、医院采购意愿、是否融入工作流

### 6.2 医疗器械
重点看：注册认证、渠道能力、耗材模式、设备装机量

### 6.3 数字医疗 / 院内 SaaS
重点看：院方付费能力、续费率、科室扩张、系统集成复杂度

---

## 7. 财务分析重点

+ 销售费用高是否对应医院拓展
+ 应收账款与回款周期
+ 收入是否依赖少数大医院
+ 器械业务看存货和渠道压货
+ 软件业务看续费和合同负债

---

## 8. 常见风险信号

+ 临床效果好，但采购转化弱
+ 监管推进慢
+ 医院预算不明确
+ 回款周期过长
+ 项目制过重，难以标准化
+ 销售驱动强于产品驱动

---

## 9. 市场空间分析模板

```
市场空间 = 目标医院/机构数量 × 单机构年支出 × 渗透率
```

---

## 10. 尽调问题清单

1. 产品解决的是临床问题还是运营问题？
2. 是否具备注册证与准入资质？
3. 谁是付费方？预算来自哪里？
4. 销售周期多长？回款周期多长？
5. 模型效果是否有真实临床证据？
6. 是否可以跨医院、跨科室复制？

## 11. 快速分析卡

### 一句话本质
医疗科技本质上是：在强监管和强证据约束下，把技术能力转化为临床或运营价值的生意

### 核心公式
```
收入 = 客户数 × 单客户价值
或
收入 = 销量 × ASP
```

### 核心判断
+ 是否有临床或运营价值
+ 监管准入是否明确
+ 付费链条是否成立
+ 回款是否健康

### 最大风险
+ 临床价值存在但采购转化弱
+ 注册推进慢
+ 回款周期长
+ 销售驱动强于产品驱动
