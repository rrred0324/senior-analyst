# 工业智能与机器视觉商业建模知识库

> 适用场景：工业 AI、机器视觉、工业自动化项目研究，一级市场投资分析，产业数字化商业建模
> 覆盖范围：视觉检测、工业质检、工业软件+AI、边缘智能、制造场景智能化
> 行业特征：强场景、强交付、ROI 导向、工业 know-how 壁垒高、标准化与项目制并存

---

## 1. 行业总论

### 商业本质

工业智能与机器视觉行业的本质是：用视觉、算法、软件和工业控制能力，替代人工检测、提升生产效率、降低缺陷率和运营成本，并从设备、软件、项目交付或持续服务中收费。

### 行业核心特点

- 客户购买逻辑以 ROI 为核心
- 工业场景复杂，非单纯软件逻辑
- 标准化难度高，但一旦打入产线粘性强
- 常见模式为"硬件 + 软件 + 集成 + 服务"
- 项目制较多，规模化能力是核心分水岭

### 分析总框架

```
行业本质（AI+视觉+工业控制 → 提升产线效率）
  → 商业模式（设备/软件/项目/服务）
    → 收入成本模型（项目数×合同额 / 部署点位×单点价值）
      → 核心指标（检出率 × 客户数 × 复购率 × 毛利率）
        → 经营机制（标杆客户 → 行业案例 → 模板化 → 降交付成本）
```

## 2. 商业模式分类

| 模式 | 描述 | 收入来源 | 核心能力 |
|---|---|---|---|
| 视觉检测设备 | 卖设备和系统 | 设备销售 | 硬件集成、识别能力 |
| 软件授权 | 视觉算法/平台授权 | License/订阅费 | 算法和平台能力 |
| 项目解决方案 | 产线改造、检测方案交付 | 项目合同额 | 集成能力、行业理解 |
| 持续服务 | 运维、模型迭代、升级 | 年服务费 | 客户成功、持续优化 |

---

## 3. 收入与成本模型

### 3.1 收入模型

```
收入 = 项目数量 × 平均合同额
或
收入 = 部署点位数 × 单点位价格
```

### 3.2 成本模型

+ 硬件成本
+ 算法研发成本
+ 项目实施成本
+ 售后运维成本
+ 销售成本

### 3.3 单位经济模型

```
单项目利润 = 项目收入 - 硬件与实施成本 - 售后成本
```

## 4. 核心指标体系

+ 客户数
+ 产线渗透率
+ 单项目金额
+ 毛利率
+ 缺陷检出率
+ 漏检率
+ 部署周期
+ 复购率
+ 软件收入占比

---

## 5. 经营机制

### 核心飞轮
```
拿下标杆客户
→ 形成行业案例
→ 提升模型效果与场景模板化
→ 降低交付成本
→ 扩展更多工厂/产线
```

### 核心判断逻辑

1. 是否真正进入生产环节？
2. ROI 是否足够清晰？
3. 标准化程度能否逐步提高？
4. 软件收入占比能否提升？

---

## 6. 财务分析重点

+ 项目制收入占比高不高
+ 毛利率是否因标准化提升而改善
+ 应收账款与回款周期
+ 存货与交付压力
+ 客户集中度

---

## 7. 常见风险信号

+ 只能做定制项目
+ 复购率低
+ 销售周期过长
+ 验收周期长导致回款差
+ 算法效果依赖单一场景
+ 标杆案例无法复制

---

## 8. 市场空间分析模板

```
市场空间 = 目标行业产线数量 × 单产线可部署点位 × 单点位价值
```

---

## 9. 尽调问题清单

1. 客户 ROI 多久能回本？
2. 是卖设备、卖软件还是卖解决方案？
3. 是否具备跨工厂复制能力？
4. 漏检率/误检率表现如何？
5. 项目制向产品制转化程度如何？
6. 软件订阅收入能否持续增长？

## 10. 快速分析卡

### 一句话本质
工业智能本质上是：用 AI 提高产线效率和质控水平的工业工具生意

### 核心公式
```
收入 = 部署规模 × 单点位价值
```

### 核心判断
+ 是否进入核心产线
+ ROI 是否清晰
+ 标准化能力如何
+ 回款质量是否健康

### 最大风险
+ 定制化过重
+ 标杆案例不可复制
+ 回款周期长
+ 缺乏产品化能力
