# 半导体行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
通过先进设计、制造、封装和材料设备能力，将电路功能集成到芯片中，为下游电子系统提供算力、控制、连接、感知和电能转换能力，在高技术门槛、高资本投入和长周期验证中实现商业回报。本质不是"卖芯片"，而是在性能、成本、功耗、可靠性和可量产性之间找最优解。

### 1.2 与普通行业的核心差异

| 差异维度 | 半导体行业 | 普通制造业 |
|---------|----------|----------|
| 研发周期 | 流片到量产3-5年，验证周期极长 | 产品迭代周期短 |
| 资本投入 | 极高CAPEX（先进制程单厂超百亿美元） | 资本投入相对可控 |
| 客户验证 | 客户导入需1-3年，且一旦进入粘性极强 | 客户切换成本较低 |
| 周期性 | 受库存周期和资本开支周期双重影响 | 周期性相对温和 |
| 失败代价 | 流片失败/良率不达标直接损失巨大 | 试错成本相对可控 |

### 1.3 分析总框架
下游需求 → 产品定义/技术路线 → 流片验证 → 客户导入 → 量产爬坡 → 良率/产能优化 → 规模化出货

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 中兴禁运事件 | 国产替代意识觉醒，但实际差距仍巨大 |
| 2019 | 华为被列入实体清单 | 供应链自主可控上升为国家战略，国内设备/材料加速验证 |
| 2020 | 疫情+芯片荒 | 全球缺芯暴露供应链脆弱性，车规/消费芯片价格暴涨 |
| 2022 | 美国对华芯片出口管制升级 | 先进制程设备/EDA被限制，国产替代从"选项"变为"必选项" |
| 2023 | 成熟制程扩产潮 | 28nm及以上制程国产产线密集投产，但产能过剩隐现 |
| 2024-25 | AI算力需求爆发 | HBM/先进封装需求激增，国产GPU和算力芯片加速追赶 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
Fabless设计：市场需求定义 → 芯片架构与设计 → 流片 → 验证与测试 → 客户导入 → 量产爬坡 → 持续出货
Foundry制造：工艺开发 → 客户导入 → 晶圆生产 → 良率提升 → 产能利用率优化 → 稳定交付
设备/材料：研发 → 客户验证 → 产线导入 → 小批量试用 → 大规模采购 → 存量产线持续消耗/替换

### 2.2 核心飞轮
产品性能/良率/可靠性提升 → 客户导入与信任增强 → 更多量产订单 → 更高出货规模 → 更强研发摊薄和工艺迭代能力 → 产品性能/良率/可靠性继续提升
核心驱动：技术迭代、客户验证、量产能力和供应链协同共同形成的正循环

### 2.3 商业模式分类
- **芯片销售**：收费对象=系统厂商/模组厂/渠道商，收费方式=按颗/按片/按模组，公式=出货量×ASP
- **晶圆代工**：收费对象=Fabless/IDM，收费方式=按晶圆片数/工艺节点，公式=投片量×单片价格
- **封测服务**：收费对象=设计公司/制造厂，收费方式=按封装测试数量，公式=封测量×单位封测价格
- **设备/材料销售**：收费对象=晶圆厂/封测厂，收费方式=一次性设备采购+持续材料消耗，公式=销量×单价
- **EDA/IP授权**：收费对象=设计公司/IDM，收费方式=授权费/订阅费/版税，公式=授权客户数×客均合同额+版税收入

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 芯片销售收入 + 代工收入 + 封测收入 + 设备收入 + 材料收入 + EDA/IP收入 + 其他收入
- 芯片设计：收入 = 出货量 × ASP = 客户数 × 单客户出货量 × ASP
- 晶圆厂：收入 = 产能 × 产能利用率 × 单位产出价格
- 设备材料：收入 = 导入客户数 × 单客户采购量 × ASP
- EDA/IP：收入 = 新签授权收入 + 续费收入 + 版税收入

### 3.2 成本模型
固定成本：研发团队、工艺开发、厂房与设备折旧、管理团队、EDA工具和设计平台投入
变动成本：晶圆采购、封测、原材料消耗、按出货增长的测试与物流成本、渠道返利

### 3.3 单位经济
- Fabless型：单颗毛利 = ASP - 晶圆成本分摊 - 封测成本 - 测试成本 - 渠道成本
- Foundry型：单片毛利 = 单片收入 - 材料成本 - 制造变动成本 - 折旧分摊
- 设备型：单台设备毛利 = 设备售价 - BOM成本 - 制造装配成本 - 售后安装成本
- 材料型：单客户生命周期价值 = 材料导入后持续采购毛利 - 前期认证与导入成本

### 3.4 利润率特征
- Fabless设计毛利率：45-65%（模拟/功率偏高） [适用：成熟制程数字芯片] [局限：模拟/功率芯片可达55-70%，低端消费芯片仅35-45%]，净利率：10-25% [适用：量产稳定期] [局限：研发投入期常为负]
- Foundry毛利率：35-55%（先进制程高） [适用：7nm及以下先进制程] [局限：成熟制程竞争激烈仅25-40%]，净利率：20-40% [适用：高利用率先进制程] [局限：稼动率不足时净利率可降至10%以下]
- OSAT封测毛利率：15-30% [适用：先进封装] [局限：传统封测仅10-20%]，净利率：5-15% [适用：规模效应期] [局限：价格竞争期仅3-8%]
- 设备毛利率：40-55% [适用：前道核心设备] [局限：后道/成熟设备仅30-40%]，净利率：15-25% [适用：已验证量产设备] [局限：新设备研发期常为负]
- EDA/IP毛利率：70-90% [适用：头部EDA厂商] [局限：新兴EDA工具仅50-65%]，净利率：20-35% [适用：成熟EDA/IP] [局限：追赶期投入大净利率低]

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| Fabless设计 | 无晶圆厂芯片设计公司 | 系统厂商/模组厂 | 芯片销售 | ASP、出货量、毛利率 |
| Foundry | 晶圆代工厂 | 设计公司/IDM | 代工收入 | 产能利用率、良率、ASP |

## 5. 核心指标体系

- **规模指标**：收入、出货量、投片量、产能、装机量、导入客户数、在手订单
- **增长指标**：收入增速、出货增速、新客户数、新产品收入占比、新行业收入占比
- **转化指标**：样品到量产转化率、设计Win数、客户验证通过率、设备试用转采购率
- **留存/复购指标**：客户复购率、客户续约率（EDA/IP）、存量客户收入占比、大客户净收入留存
- **变现指标**：ASP、单客户年收入、单产品收入、单片收入、版税收入占比
- **供给指标**：良率、产能利用率、稼动率、交期、报废率、研发tape-out数量
- **效率指标**：R&D/Revenue、FAE支持效率、新产品导入周期、客户认证周期、库存周转
- **财务指标**：毛利率、研发费用率、销售费用率、EBITDA Margin、净利率、经营现金流、ROIC、折旧占比
- **风控指标**：失效率、退货率、良率波动、供应链集中度、单一客户收入占比、质量事故数、合规与出口管制风险

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
先进制程制造集中度极高；模拟、功率、MCU既有国际龙头也有区域替代机会；设备和材料验证门槛高、客户粘性强；EDA/IP头部效应显著；国产替代、地缘政治和供应链安全重塑格局

### 6.2 常见壁垒类型
技术与设计壁垒、工艺与良率壁垒、客户验证壁垒、资本投入壁垒、供应链与产能壁垒、生态兼容与软件工具壁垒、品牌与可靠性壁垒、专利与知识产权壁垒

### 6.3 替代风险
被国际大厂降价或升级替代、工艺路线变化导致旧产品失效、下游客户自研、供应链受限导致交付风险、需求下行导致价格和库存双杀

## 7. 行业风险

### 7.1 通用风险项
技术迭代风险、客户验证不通过、量产爬坡不及预期、良率不达标、大客户依赖、晶圆产能受限、行业周期下行、高研发投入长期无法变现、出口管制和地缘风险、存货减值风险

### 7.2 行业特有风险
流片失败导致巨额沉没成本、先进制程追赶中的技术代差风险、地缘政治导致供应链断裂、CAPEX重资产模式下的稼动率不足风险、国产替代逻辑从情绪到验证的落差

### 7.3 风险信号
- 流片成功但迟迟没有量产客户 → 产品定义与市场需求脱节（传导机制：技术驱动而非需求驱动→产品参数不匹配客户系统需求→无法通过客户验证→研发投入无法变现）
- 收入增长依赖单一客户或单一产品 → 集中度风险（传导机制：大客户砍单或换供应商→收入断崖→产能利用率骤降→固定成本摊薄困难→利润急剧恶化）
- 良率长期低于行业水平 → 量产能力不足（传导机制：工艺不成熟→良率低→成本高→交期不稳→客户信任下降→订单流失→恶性循环）
- 存货和应收快速增加 → 周期下行信号（传导机制：下游需求减弱→库存积压+客户付款延迟→跌价准备+坏账风险→利润和现金流双重恶化）
- CAPEX大幅投入但稼动率不升 → 资本效率恶化（传导机制：扩产快于需求增长→产能利用率低→固定折旧摊薄单位利润→ROIC下降→资金压力增大）
- 研发费用高企但新产品放量滞后 → 研发转化低效（传导机制：研发方向偏离市场→Tape-out延迟或客户导入慢→研发投入无法转化为收入→长期亏损风险）

## 8. 财务分析重点

### 8.1 利润表重点
收入结构、毛利率、研发费用率、折旧摊销、销售与FAE成本、净利率

### 8.2 资产负债表重点
现金、存货、应收账款、固定资产、在建工程、无形资产/IP、有息负债

### 8.3 现金流量表重点
经营现金流是否匹配收入增长、CAPEX是否过重、存货和应收是否占用大量现金、大规模扩产是否带来融资压力

## 9. 市场空间测算

- **TAM**：对应芯片、器件、设备、材料或设计工具的全球/区域总体市场
- **SAM**：公司所在工艺、应用场景、区域和客户类型对应的可服务市场
- **SOM**：公司当前和中短期能够拿下的客户份额与出货规模

测算公式：
- 终端需求倒推法：市场空间 = 下游终端出货量 × 单机芯片价值量
- 客户采购法：市场空间 = 目标客户数 × 客均采购额
- 产能法：市场空间 = 目标产能 × 单位产出价格

注意：市场大不等于公司能导入客户；半导体最核心不是TAM而是验证通过率和量产能力；替代空间大但进入节奏取决于认证和供应链切换；周期下行时市场空间和价格可能同步收缩

## 10. 快速分析卡

- **一句话本质**：用技术、工艺和供应链能力，在性能、成本、功耗、可靠性和量产之间做最优平衡，服务下游系统需求
- **核心收入公式**：收入 = 出货量/投片量 × ASP
- **核心成本公式**：成本 = 晶圆/材料/制造成本 + 研发成本 + 封测测试成本 + 销售与FAE成本 + 折旧摊销
- **核心判断三要素**：1)技术和产品是否真正成立 2)客户验证和量产是否真实推进 3)放量后单位经济和供应链是否可持续
- **最重要指标**（3个）：出货量/ASP、良率、毛利率
- **最大风险**（3个）：技术失败/客户验证不通过、量产与良率不及预期、周期下行与存货压力
- **一句话结论模板**：该半导体项目的核心价值在于[产品竞争力/客户验证/量产能力]，关键风险是[技术路线/良率/周期性]，长期取决于[能否完成从技术验证到客户导入再到稳定量产的完整闭环]
