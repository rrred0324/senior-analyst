# 半导体行业商业建模知识库

> 适用场景：芯片设计、设备材料、EDA、制造链项目分析，一级市场与产业投资研究
> 覆盖范围：IC 设计、Fabless、IDM、半导体设备、材料、EDA、封测
> 行业特征：强技术壁垒、研发周期长、资本开支高、产业链协同深、周期性明显

---

## 1. 行业总论

### 商业本质

半导体行业的本质是：通过高难度芯片设计、制造、封装测试及配套设备材料能力，提供信息处理与控制的核心器件，并从性能提升、系统适配和供给能力中获得商业价值。

### 行业结构

```
EDA / IP
→ 芯片设计
→ 晶圆制造
→ 封装测试
→ 模组/系统客户
```

设备材料贯穿制造链。

### 分析总框架

```
行业本质（高壁垒技术+供应链协同 → 核心算力/控制器件）
  → 产业链环节（设计/制造/封测/设备材料/EDA）
    → 收入成本模型（出货量×ASP）
      → 核心指标（良率 × 客户导入 × 出货量 × 毛利率）
        → 经营机制（研发 → 导入 → 量产 → 迭代）
```

## 2. 商业模式分类

| 模式 | 描述 | 收入来源 | 核心能力 |
|---|---|---|---|
| Fabless | 只做设计 | 芯片销售 | 架构、产品定义、客户资源 |
| IDM | 设计+制造 | 芯片销售 | 全链条能力 |
| 设备公司 | 提供制造设备 | 设备销售、服务收入 | 工艺适配、客户认证 |
| 材料公司 | 提供耗材/材料 | 材料销售 | 配方工艺、认证周期 |
| EDA/IP | 提供工具和 IP | 授权费、订阅费 | 技术壁垒、生态绑定 |

## 3. 收入与成本模型

### 3.1 收入模型

**芯片设计**
```
收入 = 出货量 × ASP
```

**EDA/IP**
```
收入 = 授权客户数 × 合同金额
```

**设备材料**
```
收入 = 客户采购量 × 单价
```

### 3.2 成本模型

+ 流片成本
+ 晶圆代工成本
+ 封测成本
+ 研发成本
+ 客户认证成本
+ 销售支持成本

### 3.3 单位经济模型

```
单芯片毛利 = ASP - 晶圆成本 - 封测成本 - 分摊费用
```

## 5. 经营机制

### 核心飞轮
```
研发成功
→ 客户导入
→ 量产放量
→ 毛利改善
→ 持续迭代下一代产品
```

### 核心判断逻辑

1. 技术是否领先或足够替代？
2. 客户导入周期多长？
3. 是否具有量产能力和供应链协同？
4. 周期下行时是否仍有竞争力？

---

## 6. 细分赛道分析

### 6.1 芯片设计
重点看：产品定义、客户导入、ASP 与毛利、迭代节奏

### 6.2 设备材料
重点看：国产替代空间、认证周期、客户粘性、售后服务能力

### 6.3 EDA / IP
重点看：授权模式、续费率、客户绑定深度、生态壁垒

---

## 7. 财务分析重点

+ 收入是否依赖单一大客户
+ 存货与在制品风险
+ 毛利率波动是否受代工产能影响
+ 高研发投入是否形成持续产品线
+ Capex 对设备厂影响

---

## 8. 常见风险信号

+ 流片失败或量产良率不稳定
+ 客户验证时间过长
+ 芯片价格下滑快于成本下降
+ 过度依赖单一晶圆厂或客户
+ 库存积压
+ 周期下行冲击大

---

## 9. 市场空间分析模板

```
市场空间 = 目标应用出货量 × 单机芯片数量 × 单芯片价值量
```
