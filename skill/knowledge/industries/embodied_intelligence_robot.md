# 具身智能与人形机器人商业建模知识库

> 适用场景：机器人行业研究、一级市场投资尽调、具身智能商业模式分析、硬科技项目建模
> 覆盖范围：人形机器人、通用机器人、专用作业机器人、机器人平台、RaaS 模式
> 行业特征：软硬一体、研发周期长、量产难、场景导向强、商业化节奏与技术叙事常错配

---

## 1. 行业总论

### 商业本质

具身智能与人形机器人的本质是：把感知、决策、控制、运动和执行集成为可在真实物理环境中工作的智能系统，并通过整机销售、解决方案交付、软件订阅或服务化运营获得收入。

真正的商业价值不在"像人"，而在于：
- 能否完成任务
- 是否稳定
- ROI 是否清晰
- 是否可规模复制
- 总拥有成本是否可接受

### 行业核心矛盾

1）技术演示 vs 可交付产品：很多公司 demo 很强，但离量产交付很远。

2）通用性 vs 商业化落地：通用能力令人兴奋，但最早付费的常常是特定高价值场景。

3）软硬件一体化 vs 成本控制：智能能力提升往往带来 BOM、研发、维护成本上升。

4）卖设备 vs 卖服务：卖设备回款快，但持续收入弱；卖服务长期价值高，但资金占用和运营压力更大。

### 分析总框架

```
行业本质（感知+决策+控制+执行+系统集成）
  → 商业模式（整机/软件附加/RaaS/解决方案/平台）
    → 收入成本模型（销量×ASP / 在服台数×服务费）
      → 核心指标（稳定性 × 单台economics × 场景ROI）
        → 经营机制（场景验证 → 数据积累 → 成本下降 → 规模复制）
```

## 2. 商业模式分类

| 模式 | 描述 | 收入来源 | 核心能力 |
|---|---|---|---|
| 整机销售 | 销售机器人本体 | ASP × 销量 | 量产、供应链、产品稳定性 |
| 机器人+软件 | 硬件 + 控制/调度/管理软件 | 硬件收入 + 订阅费 | 软件 attach rate、平台能力 |
| 场景解决方案 | 面向工厂、仓储、巡检等场景交付 | 项目费、系统费、运维费 | 系统集成与行业 know-how |
| RaaS | 机器人按月/按年服务收费 | 服务费 | 利用率、维护成本、回本周期 |
| 机器人平台 | 提供底盘、控制、算法平台 | 平台授权、模组收入 | 平台化能力、生态合作 |

## 3. 收入与成本模型

### 3.1 收入模型

**整机销售**
```
收入 = 销量 × ASP
```

**软件附加**
```
收入 = 部署台数 × 软件订阅费
```

**RaaS**
```
收入 = 在服台数 × 月服务费 × 服务月数
```

**解决方案**
```
收入 = 项目数量 × 平均合同金额
```

### 3.2 成本模型

主要成本：
+ BOM 成本
+ 制造与组装成本
+ 核心零部件采购成本
+ 研发成本
+ 测试验证成本
+ 售后维护成本
+ 部署与交付成本
+ 供应链管理成本

**利润模型**
```
利润 = 收入 - 硬件成本 - 研发成本 - 售后运维成本 - 销售管理费用
```

### 3.3 单位经济模型

**单台销售模型**
```
单台毛利 = ASP - BOM - 制造成本 - 交付成本
```

**单台生命周期模型**
```
单台 LTV = 硬件毛利 + 软件/服务累计收入 - 售后与维护成本
```

**RaaS 回本模型**
```
回本周期 = 单台投入成本 / 单台月毛利
```

## 5. 经营机制

### 5.1 核心飞轮
```
在高价值场景部署成功
→ 数据与控制策略积累
→ 产品稳定性提升
→ 交付效率和成本改善
→ 客户 ROI 更清晰
→ 更多复制部署
→ 规模化降低成本
```

### 5.2 核心判断逻辑

1）先专用场景，还是一开始追求通用？更现实的路径通常是：先切入明确场景、做出 ROI、再逐步扩展任务边界。

2）客户是否真的买单？不要只看合作公告，要看是否形成正式订单、是否完成验收、是否有复购、是否进入量产采购。

3）单位经济是否成立？技术叙事不能代替单台 economics。必须拆：单台成本、单台售价、单台售后、单台利用率、回本周期。

4）软硬件壁垒是否协同？机器人公司若只有算法或只有硬件，壁垒通常不完整。更强的公司会形成：控制算法 + 系统集成 + 供应链 + 场景数据闭环。

## 6. 细分赛道分析

### 6.1 人形机器人
本质：追求更高通用性的人机环境适配能力
重点看：量产节奏、核心零部件自研程度、动作稳定性、场景切入点、BOM 下降路径
风险：技术成熟度不足、成本极高、商业落地慢

### 6.2 专用作业机器人
本质：围绕单一或少量高价值任务实现自动化替代
重点看：ROI 清晰度、场景标准化程度、客户复购、部署与维护难度
优势：通常比人形机器人更快商业化

### 6.3 RaaS 模式机器人
本质：客户买的是"任务完成能力"，而不是设备所有权
重点看：利用率、折旧、售后运维、回本周期、合同稳定性

## 7. 财务分析重点

### 7.1 利润表
+ 收入是整机型还是服务型
+ 毛利率能否随着量产上升
+ 研发费用是否合理反映产品化进展
+ 销售费用是否转化为真实订单

### 7.2 资产负债表
+ 存货和在产品质量
+ 固定资产和产线投入
+ 预付款与核心零部件锁产
+ 应收账款与验收周期

### 7.3 现金流量表
+ 制造类硬科技企业通常现金流压力较大
+ 若收入确认快于回款，需警惕应收风险
+ RaaS 模式会加重前期资金占用

---

## 8. 常见风险信号

+ demo 强，量产弱
+ 订单多为意向，不是正式采购
+ BOM 高企、毛利倒挂
+ 过度依赖单一客户或单一场景
+ 售后成本过高
+ 交付周期拉长
+ 软硬件团队协同差
+ "通用叙事"掩盖商业化不足

---

## 9. 市场空间分析模板

### 自上而下
```
TAM = 可自动化替代的人力成本总额 × 机器人渗透率
```

### 自下而上
```
市场空间 = 可服务场景数量 × 单场景部署台数 × ASP/年服务费
```

## 11. 快速分析卡

### 一句话本质
具身智能本质上是：把智能能力变成真实世界可交付、可复制、可回本的作业系统

### 核心公式
```
收入 = 销量 × ASP
或
收入 = 在服台数 × 服务费
```

### 核心判断
+ 场景 ROI 是否清晰
+ 单台 economics 是否成立
+ 量产交付是否真实
+ 复购与复制能力如何

### 最大风险
+ 商业化慢于预期
+ 成本高企
+ 量产困难
+ 叙事强于订单
