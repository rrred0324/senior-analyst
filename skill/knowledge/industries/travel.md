# 旅游行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
围绕"出行与目的地体验"组织供给、匹配需求、完成交易与履约，通过佣金、差价、服务费和增值服务变现。本质不是"卖票"或"卖酒店"，而是在用户有限决策时间和复杂供给环境下，帮助其更低成本、更高确定性地完成出行决策与履约体验。

### 1.2 与普通行业的核心差异

| 差异维度 | 旅游行业 | 普通零售/电商 |
|---------|---------|-------------|
| 需求频率 | 低频（年2-5次 [适用：休闲旅游人群] [局限：商旅用户可达10-20次/年]），强季节性 | 中高频，需求相对均匀 |
| 供给特征 | 高度分散、实时变动、不可存储 | 标准化、可存储、可提前备货 |
| 履约复杂度 | 跨地域、多环节、退改频繁 | 相对标准化履约 |
| 价格机制 | 动态定价（航司/酒店实时变价） | 相对固定定价 |
| 风险类型 | 不可抗力冲击大（疫情/天气/政策） | 需求波动但无极端外部冲击 |

### 1.3 分析总框架
流量获取能力 → 供给整合与议价 → 交易转化效率 → 履约与售后保障 → 复购与交叉销售 → 品牌信任沉淀

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 在线旅游渗透率提升 | OTA平台从"订票工具"转向"旅行决策入口"，内容化战略启动 |
| 2020 | 疫情重创旅游行业 | 出境游归零，国内游大幅萎缩，OTA和旅行社现金流承压 |
| 2021 | 周边游/微度假兴起 | 长途旅行受限，露营/民宿/城市微度假成为新消费热点 |
| 2023 | 出境游恢复但不及预期 | 国际航班/签证逐步恢复，但出境游客恢复至疫情前约60% |
| 2024 | 免签政策扩围+入境游增长 | 中国对多国免签，入境游成为行业新增量 |
| 2025 | AI行程规划+超个性化 | AI驱动的行程定制成为OTA新卖点，从标准化产品走向个性化服务 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
获取流量 → 聚合机酒景点等供给 → 搜索比价与推荐 → 完成在线预订 → 提供履约和售后 → 复购与交叉销售

### 2.2 核心飞轮
更多用户订单 → 更丰富供给与价格优势 → 更高转化率和用户信任 → 更强口碑与流量获取能力 → 更多用户订单

核心驱动：流量能力、供给整合能力、履约保障能力和品牌信任共同推动的复利增长。

### 2.3 商业模式分类

| 模式 | 收费对象 | 收费方式 | 公式 |
|-----|---------|---------|------|
| 佣金抽成 | 酒店/航司/景区/供应商 | 按成交额抽佣 | 收入 = GMV x Take Rate |
| 差价模式 | 终端游客 | 低买高卖 | 收入 = 销售价 - 采购成本 |
| 服务费 | 游客/企业客户 | 按单/按人次/年费 | 收入 = 服务量 x 单次服务费 |
| 广告变现 | 酒店/景区/旅行品牌 | CPC/CPA/展示 | 收入 = 流量 x 变现率 |
| 订阅/SaaS | B端商家 | 年费/模块费 | 收入 = 客户数 x ARPU |

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 佣金收入 + 差价收入 + 服务费收入 + 广告收入 + 订阅收入 + 其他增值收入

OTA拆法：收入 = GMV x Take Rate
订单拆法：GMV = 订单量 x 客单价
度假游拆法：收入 = 成交人数 x 人均客单价
商旅拆法：收入 = 企业客户数 x 单客户年交易额 x 抽佣率 + 管理费

### 3.2 成本模型
- 固定成本：核心技术团队、产品系统开发、管理团队、品牌建设、基础客服体系
- 变动成本：流量投放、订单履约、支付手续费、渠道返佣、售后赔付、供应链采购波动

### 3.3 单位经济
OTA单订单：单订单毛利 = 订单GMV x Take Rate - 流量成本 - 支付手续费 - 客服售后成本
度假单游客：单游客毛利 = 销售价 - 采购成本 - 履约成本 - 获客成本 - 售后成本
酒店单间夜：单间夜毛利 = 每间夜收入 - 酒店采购成本 - 渠道成本 - 服务成本

### 3.4 利润率特征
- OTA平台：毛利率60-80% [适用：佣金模式轻资产OTA] [局限：含自营产品的OTA通常40-60%]（佣金模式轻资产），净利率10-20% [适用：成熟期龙头OTA] [局限：扩张期OTA通常为负或微利]（成熟期）
- 度假/跟团游：毛利率15-30% [适用：标准化跟团游] [局限：定制游/高端游可35-50%]，净利率3-8% [适用：规模运营商] [局限：小型旅行社通常1-3%]
- 酒店分销：毛利率20-40% [适用：聚合分销平台] [局限：直销/直签酒店通常10-20%]
- 商旅服务：毛利率30-50% [适用：企业商旅管理] [局限：纯代订服务通常15-25%]，净利率8-15% [适用：成熟商旅服务商] [局限：新进入者通常3-8%]

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| OTA | 在线聚合机酒景点等供给并交易 | 大众游客 | 佣金+广告 | GMV、Take Rate、转化率 |
| 酒店分销 | 酒店库存销售与分发 | 出行用户、企业 | 佣金/差价 | ADR、间夜数、佣金率 |
| 机票分销 | 航空票务在线预订 | 出行用户、商旅 | 佣金/服务费 | 客单价、出票量、退改率 |
| 度假游 | 跟团、自由行、套餐产品 | 家庭/休闲客群 | 差价+服务费 | 客单价、毛利率、复购 |
| 本地玩乐 | 门票、演艺、体验项目 | 目的地游客 | 佣金/差价 | 订单量、核销率 |
| 商旅服务 | 企业差旅管理和系统服务 | 企业客户 | 服务费+佣金 | 客户数、续约率、TPV |
| 定制游 | 个性化行程设计和履约 | 高净值用户 | 服务费+差价 | 客单价、转化率、满意度 |
| 旅游SaaS | 给景区/酒店/旅行社提供系统 | B端商家 | 订阅+实施 | ARR、客户数、续费率 |

## 5. 核心指标体系

- **规模指标**：GMV、收入、订单量、出行人次、间夜数、出票量、企业客户数、供应商数量
- **增长指标**：GMV增速、收入增速、订单量增速、新用户增长、老用户复购增长、企业客户增长
- **转化指标**：UV到下单转化率、搜索到预订转化率、咨询到成交转化率、核销率、支付成功率
- **留存/复购指标**：月复购率、季度复购率、年复购率、会员续费率、商旅客户续约率
- **变现指标**：Take Rate、客单价、AOV、ADR、每订单收入、每用户年收入、增值服务渗透率
- **供给指标**：目的地覆盖数、供应商数量、可售库存丰富度、房态/票态实时性
- **效率指标**：CAC、LTV、LTV/CAC、回本周期、人均订单处理量、客服响应时长
- **财务指标**：毛利率、贡献毛利率、销售费用率、经营现金流、预收款/递延收入、旺季利润贡献占比
- **风控指标**：退改率、客诉率、履约成功率、退款时效、不可抗力损失率、单一流量平台依赖度

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
OTA头部集中，流量和品牌效应强；度假和定制游更分散，服务和口碑重要；商旅看系统能力和企业客户关系；本地玩乐依赖目的地资源和渠道能力。

### 6.2 常见壁垒类型
流量和品牌壁垒、供给整合壁垒、价格和库存系统壁垒、履约和客服体系壁垒、企业客户销售与续约壁垒、会员体系和用户数据壁垒、目的地资源壁垒。

### 6.3 替代风险
供应商直销官网分流、内容平台和超级App抢流量、价格战、用户自行拼装行程、平台规则变化、不可抗力导致需求骤降。

## 7. 行业风险

### 7.1 通用风险项
宏观消费波动、不可抗力（疫情/天气/灾害）、政策和签证变化、流量成本上升、退改损耗、客诉和履约事故、供应商违约、淡旺季波动大。

### 7.2 行业特有风险
- 旺季需求集中但供给价格波动大，淡季固定成本摊薄困难
- 退改签链条长，赔付和客诉成本容易被低估
- 供应商直销趋势削弱平台议价权
- 不可抗力可能导致全年盈利格局被打破

### 7.3 风险信号
GMV增长但Take Rate下滑 → 供给议价权减弱或低毛利业务占比提升（传导机制：供应商直销能力增强→平台被迫降佣→或补贴低价品拉GMV→单位经济恶化→规模增长但利润不增）；订单增长依赖补贴和低价 → 增长质量低（传导机制：补贴拉单→用户为低价而来非为平台价值→补贴停止则订单骤降→长期亏损换短期规模→不可持续）；退改率和赔付率快速上升 → 履约风险（传导机制：退改率上升→赔付成本攀升+运营资源消耗→利润被侵蚀+用户体验恶化→复购下降）；复购率下降 → 用户粘性减弱（传导机制：服务体验下降或竞品分流→老客不再复购→依赖拉新维持增长→获客成本攀升→利润恶化）；单一平台流量依赖过高 → 渠道风险（传导机制：流量平台规则/算法变化→流量成本上升或获取量骤降→无自有流量池对冲→被动受制）；旺季收入好看但全年现金流变差 → 季节性现金流陷阱（传导机制：旺季收入覆盖全年成本→淡季固定成本持续消耗→旺季利润被淡季亏损吞噬→全年现金流恶化）。

## 8. 财务分析重点

### 8.1 利润表重点
GMV与收入匹配关系、佣金率/毛利率变化、流量成本占比、履约和售后成本占比、旺季/淡季利润差异、广告与增值服务收入占比。

### 8.2 资产负债表重点
预收款/合同负债、应收应付款、客户退款准备、现金储备、对供应商押金或保证金、存货（打包资源预采）。

### 8.3 现金流量表重点
预收与退款节奏、淡旺季现金流波动、大促和假期前后资金变化、是否依赖平台账期或供应商账期。

## 9. 市场空间测算

- **TAM**：居民和企业在机酒、门票、度假、商旅及相关旅游服务上的总支出
- **SAM**：公司当前可服务品类、区域、客户类型和渠道下的可服务市场
- **SOM**：公司中短期可实际获得的GMV、收入和市场份额

测算公式：
- 人次法：市场空间 = 年出行人次 x 人均旅游消费
- 品类拆分法：市场空间 = 机票市场 + 酒店市场 + 门票市场 + 度假市场 + 商旅市场
- 客户数法（商旅/SaaS）：市场空间 = 目标企业客户数 x 年客单价
- 线上渗透法：在线市场空间 = 总旅游消费 x 线上渗透率 x 公司可覆盖份额

注意：旅游总盘子大但赛道间毛利和壁垒差异大；GMV大不等于收入质量高；季节性和政策因素影响显著。

## 10. 快速分析卡

- **一句话本质**：组织分散的出行和目的地供给，帮助用户完成更低决策成本、更高确定性的预订与履约，通过佣金、差价和服务费变现
- **核心收入公式**：收入 = GMV x Take Rate（或 订单量 x 每单收入）
- **核心成本公式**：成本 = 流量获取 + 采购与履约 + 支付渠道 + 客服售后 + 技术与管理
- **核心判断三要素**：1)流量获取效率是否健康 2)供给和履约能力是否稳定 3)复购、会员和交叉销售能力是否足够强
- **最重要指标**（3个）：Take Rate、复购率、贡献毛利率
- **最大风险**（3个）：不可抗力冲击、流量成本上涨、供给不稳定
- **一句话结论模板**：该公司核心价值在于[流量/供给/履约]能力，但需关注[Take Rate/退改率/季节性]风险，长期看[品牌信任/复购体系/交叉销售]能否支撑可持续盈利
