# 汽车出行行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
围绕"人和货的移动需求"，通过车辆、能源、软件、网络和运营体系，提供更高效、更安全、更低成本的交通工具与出行服务。本质不是"卖车"或"撮合订单"，而是通过车辆供给、调度能力、能源补给、数字化系统和服务网络，降低单位出行成本、提升通行效率和服务体验，并在高频出行场景中建立持续交易或资产回报能力。

### 1.2 与普通行业的核心差异

| 差异维度 | 汽车出行 | 电商平台 |
|---------|---------|---------|
| 资产属性 | 重资产（车辆/产能/网点），折旧大 | 轻资产为主，边际成本低 |
| 安全要求 | 极高，事故和合规风险大 | 相对低，退货/赔付为主 |
| 政策敏感度 | 极高（牌照/补贴/安全/数据） | 中等，监管相对成熟 |
| 收入结构 | 销售+佣金+服务+软件多元 | 佣金+广告为主 |
| 网络效应 | 强（供给端规模+密度+调度） | 中等（用户端规模效应为主） |

### 1.3 分析总框架
产品力/运力供给 → 用户获取与需求匹配 → 交易/订单完成 → 履约与安全服务 → 后市场与软件增值 → 全生命周期价值挖掘 → 数据驱动效率提升

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 股比放开+关税下调 | 外资品牌加速在华布局，自主品牌竞争压力增大 |
| 2020 | 新能源车补贴退坡过渡 | 政策驱动减弱，市场驱动初显，比亚迪等头部企业胜出 |
| 2021 | 芯片短缺+智能驾驶升温 | 供应链危机暴露国产替代需求，NOA/城市智驾成新卖点 |
| 2022 | 新能源车购置税延续 | 政策利好延续，渗透率加速突破30% |
| 2023 | 价格战全面爆发 | 特斯拉降价引发连锁反应，车企利润率承压，行业洗牌加速 |
| 2024-25 | 出口超越日本成全球第一 | 中国汽车出口超500万辆，新能源出海成第二增长曲线 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
整车销售型：产品研发与制造 → 建立品牌/渠道/交付体系 → 销售车辆 → 提供售后/金融/保险/软件升级 → 增加全生命周期价值
平台撮合型：获取乘客需求 → 组织司机和运力供给 → 算法调度撮合订单 → 提升履约效率和用户体验 → 平台抽成与增值服务变现
车队运营型：采购/租赁车辆 → 管理司机与车队 → 优化排班/补能/保养和利用率 → 提升单车收入和降低单车成本 → 实现资产回报
智能化服务型：通过车联网和软件接入车辆 → 采集运行与用户数据 → 提供导航/娱乐/辅助驾驶/车队管理 → 软件订阅/服务收费

### 2.2 核心飞轮
更优产品/更高运力效率 → 更好用户体验与更低成本 → 更高销量/更高订单量 → 更多数据与更强网络效应 → 更强调度、研发和服务能力 → 更优产品/更高运力效率

核心驱动：产品力、运营效率、服务网络、用户规模和数据能力之间的正循环，而不是单次销量或短期补贴。

### 2.3 商业模式分类

| 模式 | 收费对象 | 收费方式 | 公式 |
|-----|---------|---------|------|
| 整车销售 | 个人用户/企业客户/经销商 | 按辆销售 | 收入 = 销量 x ASP |
| 平台佣金/抽成 | 司机/乘客/商户 | 按订单抽成 | 收入 = GMV x 抽成率 |
| 资产运营收益 | 乘客/企业客户 | 运费、租金、包月 | 收入 = 单车收入 x 车队规模 |
| 软件与订阅 | 车主/车队/OEM | 功能订阅、SaaS | 收入 = 付费车辆数 x ARPU |
| 后市场与增值服务 | 车主/司机/企业 | 维保/保险/金融/充电 | 收入 = 服务用户数 x 客单价 |

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 整车销售收入 + 平台佣金收入 + 资产运营收入 + 软件订阅收入 + 后市场收入 + 金融保险收入 + 数据服务收入

整车厂：收入 = 销量 x ASP
网约车平台：收入 = 订单量 x 平均客单价 x 抽成率
共享出行/车队：收入 = 车队规模 x 单车日收入 x 运营天数
软件服务：收入 = 连接车辆数 x 付费率 x ARPU
后市场：收入 = 活跃车主数 x 到店频次 x 客单价

### 3.2 成本模型
- 固定成本：研发、工厂与产能、平台技术系统、品牌建设、直营网点和服务网络基础设施
- 变动成本：单车BOM、物流交付、司机补贴、能源成本、维修保养、保险、支付手续费、履约成本

### 3.3 单位经济
整车厂：单车毛利 = ASP - 单车BOM - 制造与交付成本 - 渠道成本
网约车平台：单订单毛利 = 客单价 x 抽成率 - 补贴 - 支付成本 - 客服/运营分摊
车队运营：单车月毛利 = 单车月收入 - 折旧/租赁 - 能源 - 维保 - 保险 - 停车/运营成本
后市场：单用户毛利 = 单用户年收入 - 流量成本 - 履约/门店服务成本
软件服务：单车软件毛利 = ARPU - 云服务成本 - 客服支持成本

### 3.4 利润率特征
- 整车销售（新能源）：毛利率10-25%（头部） [适用：头部新能源车企] [局限：新势力/价格战期可降至5%以下，特斯拉等规模效应可达25%+]，净利率5-10% [适用：成熟车企] [局限：扩张期多为负]
- 网约车平台：毛利率15-30% [适用：成熟市场/头部平台] [局限：竞争激烈的新兴市场仅10-15%]，净利率5-15%（成熟市场） [适用：已实现垄断/寡头的市场] [局限：补贴竞争期常为负]
- 车队运营：毛利率10-20% [适用：稳定运营车队] [局限：新能源车队因能源成本低毛利率略高]，净利率3-8% [适用：规模化车队] [局限：小车队管理效率低仅1-3%]
- 车联网/SaaS：毛利率50-70% [适用：纯软件/SaaS] [局限：含硬件部署的综合方案仅30-45%]，净利率15-25% [适用：成熟SaaS] [局限：早期投入期常为负]
- 后市场服务：毛利率30-50% [适用：维保/保险/配件] [局限：标准化快修仅25-35%]，净利率8-15% [适用：连锁化运营] [局限：单店/小规模仅5-8%]

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 新能源整车 | 销售新能源乘用/商用车 | 个人/企业 | 整车销售+软件+服务 | 销量、ASP、毛利率 |
| 智能汽车 | 提供智能座舱/辅助驾驶 | 个人/企业 | 整车+软件订阅 | 激活率、付费率 |
| 网约车平台 | 撮合司机与乘客订单 | 乘客/司机 | 抽成+广告+增值服务 | 订单量、抽成率、履约率 |
| 共享汽车 | 短租分时用车 | 城市用户 | 租金+会员费 | 单车日均订单、利用率 |
| 车队运营 | 车队管理和运力运营 | 企业/司机 | 运费收入/管理费 | 单车收入、车队利用率 |
| 汽车后市场 | 维保、保险、配件、洗美 | 车主/车队 | 服务费+配件毛利 | 到店频次、客单价、复购 |
| 车联网/车管平台 | 连接车辆并提供服务 | 车主/车队/OEM | SaaS+订阅+硬件 | 连接车辆数、ARPU |
| 自动驾驶出行 | 无人驾驶运力服务 | 乘客/企业 | 订单收入/服务费 | 单车收入、接管率、安全里程 |

赛道差异：整车更看产品力、供应链和品牌；出行平台更看供需匹配、调度算法和补贴效率；车队运营更看单车模型和资产回报；后市场更看复购、门店网络和服务标准化；车联网更看连接规模和软件变现；自动驾驶更看技术成熟度、政策和商业化节奏。

## 5. 核心指标体系

- **规模指标**：销量、交付量、订单量、GMV、活跃用户数、活跃司机数、连接车辆数、车队规模、门店数/服务网点数
- **增长指标**：收入增速、销量增速、订单量增速、活跃用户增长、司机增长、单车收入增长、软件激活车辆增长、海外市场增长
- **转化指标**：试驾到下单转化率、线索到购车转化率、注册到叫车转化率、叫车到成单转化率、司机注册到完单转化率、软件功能开通率、金融/保险附加率
- **留存/复购指标**：车主复购率、平台月活留存、司机留存率、用户复叫率、车队续签率、维保复购率、软件续费率
- **变现指标**：ASP、抽成率、客单价、单车日收入、单用户ARPU、金融渗透率、保险附加率、软件付费率
- **供给与运营指标**：运力在线率、接单率、履约率、平均接驾时长、车辆利用率、单车周转率、能耗水平、事故率
- **效率指标**：CAC、LTV、LTV/CAC、单车回本周期、单订单贡献利润、司机获客成本、门店坪效/人效
- **财务指标**：毛利率、单车毛利、单订单毛利、销售费用率、研发费用率、折旧占比、经营现金流、ROIC/ROA
- **风控指标**：事故率、安全投诉率、司机违规率、车辆故障率、召回率、补贴依赖度、大客户依赖度、政策合规事件数

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
整车市场通常品牌集中度较高；新能源与智能汽车竞争激烈，技术与价格战并存；网约车平台头部集中明显；后市场相对分散但可连锁化整合；自动驾驶出行仍处于技术与政策博弈阶段。

### 6.2 常见壁垒类型
品牌和渠道壁垒、制造与供应链壁垒、调度算法和网络效应壁垒、服务网络壁垒、数据和软件能力壁垒、合规与牌照壁垒、资金和资产运营能力壁垒。

### 6.3 替代风险
公共交通改善分流需求、价格战压缩利润、新技术路线替代旧车型、地方监管变化、用户和司机多平台切换、自动驾驶成熟后重塑现有平台逻辑。

## 7. 行业风险

### 7.1 通用风险项
原材料价格波动、价格战、补贴退坡、供应链中断、库存积压、安全事故、司机流失、政策监管变化、充电补能基础设施不足、自动驾驶落地不及预期。

### 7.2 行业特有风险
- 重资产运营导致资本开支和折旧压力巨大
- 补贴退坡后需求和盈利结构可能被重塑
- 安全事故对品牌和监管的影响远大于其他行业
- 自动驾驶等新技术商业化节奏高度不确定
- 平台模式高度依赖供需双边补贴平衡

### 7.3 风险信号
- 销量增长但单车毛利持续下滑 → 量增利减（传导机制：价格战或产品老化→降价促销→单车毛利被压缩→销量增长无法转化为利润→长期盈利能力恶化）
- 订单增长但补贴占比不降反升 → 补贴依赖（传导机制：补贴驱动而非自然需求→用户对价格敏感→补贴退坡即需求萎缩→平台可持续性存疑）
- 司机规模增长但留存恶化 → 供给侧不稳定（传导机制：低门槛招募→司机收入下降→高流失率→服务质量和供给稳定性下降→用户体验恶化）
- 单车利用率下降 → 资产效率恶化（传导机制：车队规模扩张快于需求增长→车辆空置时间增加→单车收入下降→资产回报率降低→CAPEX回收延长）
- 库存天数和应收同步上升 → 现金流压力（传导机制：渠道压货+回款变慢→库存和应收双增→经营现金流恶化→可能需额外融资支撑）
- 软件激活率低于预期 → 软件变现受阻（传导机制：用户付费意愿低→软件收入增长不及预期→难以从硬件销售延展到服务收入→估值逻辑受损）

## 8. 财务分析重点

### 8.1 利润表重点
收入结构、单车毛利/单订单毛利、补贴与促销占比、软件与服务收入占比、销售费用率、研发费用率。

### 8.2 资产负债表重点
存货、应收账款、固定资产、车辆资产、现金、有息负债、合同负债/预收款。

### 8.3 现金流量表重点
是否依赖持续融资扩张、库存和车辆采购是否吞噬现金、经营现金流与收入增长是否匹配、重资产运营是否导致资本开支压力过大。

## 9. 市场空间测算

- **TAM**：对应整车消费、城市出行交易、企业车队运营、后市场服务和车联网服务的总市场空间
- **SAM**：公司当前产品品类、区域覆盖、客户定位和政策许可范围内可服务市场
- **SOM**：公司中短期可实际获取的销量、订单量、车队规模和服务收入份额

测算公式：
- 车辆销售法：市场空间 = 目标购车用户数 x ASP
- 出行交易法：市场空间 = 目标城市出行次数 x 平均客单价 x 平台可渗透率
- 车队运营法：市场空间 = 可运营车辆数 x 单车年收入
- 存量车服务法：市场空间 = 保有量车辆数 x 单车年服务价值

注意：市场大不等于利润高，关键看补贴、资产效率和服务成本；需区分高增长但低毛利环节与高粘性高利润环节；不同城市和区域政策差异巨大；自动驾驶等新业务应谨慎估算商业化节奏。

## 10. 快速分析卡

- **一句话本质**：围绕人和货的移动需求，通过车辆、能源、软件和运营网络提升出行效率与体验，转化为销售、佣金、运营和服务收入
- **核心收入公式**：收入 = 销量 x ASP（或 订单量 x 客单价 x 抽成率，或 车队规模 x 单车收入）
- **核心成本公式**：成本 = 制造/车辆成本 + 补贴/运力成本 + 能源/维保/保险 + 研发销售管理费用
- **核心判断三要素**：1)单位经济是否清晰 2)资产或平台效率是否持续改善 3)是否能从单次交易延展到长期服务收入
- **最重要指标**（3个）：单车/单订单毛利、车辆利用率、经营现金流
- **最大风险**（3个）：价格战和补贴依赖、安全和政策风险、重资产扩张现金流压力
- **一句话结论模板**：该公司在[整车/平台/运营]模式中已建立[产品力/网络密度/资产效率]优势，但需关注[补贴依赖/单车回本/政策风险]压力，长期看能否将一次性交易延展为全生命周期服务收入
