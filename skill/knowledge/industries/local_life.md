# 本地生活行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
围绕"本地供给 + 本地需求 + 本地履约/到店消费"，通过流量分发、交易撮合、履约服务和商户数字化，提升本地服务交易效率并从中变现。本质不是"发优惠券"或"做配送"，而是在有限地理半径内，把分散的本地供给与即时或近即时需求高效匹配，并尽可能降低获客成本、履约成本和交易摩擦。

### 1.2 与普通行业的核心差异

| 差异维度 | 本地生活 | 全国性电商 |
|---------|---------|----------|
| 供给特征 | 本地分散、非标、无法跨区调度 | 集中仓配、标准化、全国流转 |
| 履约方式 | 到店核销/即时配送，时效敏感 | 快递物流，1-3天可接受 |
| 网络效应 | 强局部网络效应（城市/区域级） | 全国规模效应为主 |
| 商户关系 | 双边市场，需同时运营用户和商户 | 以用户端为主，商户为辅 |
| 盈利结构 | 佣金+广告+配送费+会员+SaaS多元 | 佣金+广告为主 |

### 1.3 分析总框架
高频需求场景渗透 → 城市订单密度提升 → 商户供给丰富度 → 履约效率优化 → 综合变现率提升 → 商户数字化粘性增强

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 美团上市+到店外卖双引擎 | 本地生活从"千团大战"走向寡头竞争，美团确立领先地位 |
| 2020 | 疫情重塑消费习惯 | 到店骤降但外卖/即时零售爆发，社区团购成为新战场 |
| 2021 | 抖音切入本地生活 | 短视频平台进入到店/酒旅，美团流量护城河被挑战 |
| 2022 | 即时零售从应急到日常 | 30分钟达从生鲜扩展至全品类，美团闪购/京东到家快速起量 |
| 2023 | 抖音美团正面交锋 | 抖音加大补贴抢商户，本地生活进入双寡头竞争，佣金和广告成核心变现 |
| 2024-25 | 到店酒旅恢复+AI调度 | 线下消费恢复，AI优化骑手调度和供给匹配，效率进一步提升 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
获取用户流量 → 引入商户供给 → 内容展示/搜索推荐 → 促成下单 → 到店核销或履约完成 → 抽佣/广告变现

### 2.2 核心飞轮
更多用户 → 更强订单密度 → 吸引更多商户和服务者 → 供给更丰富/履约更高效 → 用户体验更好 → 更多用户

核心驱动：用户流量、订单密度、商户供给、履约网络和商户经营工具之间相互增强，持续降低边际履约成本并提升交易效率。

### 2.3 商业模式分类

| 模式 | 收费对象 | 收费方式 | 公式 |
|-----|---------|---------|------|
| 交易佣金 | 商户/服务提供者 | 按成交订单抽佣 | 收入 = GMV x 佣金率 |
| 广告流量推广 | 商户 | CPC/CPM/排名位 | 收入 = 广告主数 x 客均投放额 |
| 配送履约费 | 消费者/商户 | 按单/按距离/按时段 | 收入 = 订单量 x 单均履约收费 |
| 会员收入 | 消费者 | 月费/年费 | 收入 = 会员数 x 会员单价 |
| 商户数字化服务 | 商户 | 订阅费/按门店/增值服务 | 收入 = 商户数 x ARPU |

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 交易佣金收入 + 广告收入 + 配送/履约收入 + 会员收入 + 商户SaaS收入 + 其他增值收入

平台拆法：收入 = GMV x 综合变现率
外卖/即时零售：收入 = 订单量 x 单均收入
商户服务型：收入 = 商户数 x ARPU
会员型：收入 = 会员数 x 会员客单价

### 3.2 成本模型
- 固定成本：平台研发、中后台管理、核心运营团队、城市管理团队、品牌投入
- 变动成本：配送成本、流量投放、补贴、商户激励、客服、支付手续费

### 3.3 单位经济
团购/到店：单笔毛利 = 单笔交易抽佣 + 广告分摊收入 - 补贴 - 支付成本 - 客服成本
外卖/到家：单笔毛利 = 单笔佣金收入 + 配送收入 - 骑手履约成本 - 补贴 - 支付成本
家政/上门：单单毛利 = 服务费或抽佣 - 服务者补贴 - 客服售后 - 保险及履约支持成本
商户SaaS：单商户毛利 = 订阅收入 + 增值服务收入 - 销售服务成本 - 交付成本

### 3.4 利润率特征
- 到店团购：毛利率50-70% [适用：成熟平台型到店业务] [局限：新进入者/低线城市场均可能更低]，净利率15-25%（成熟平台） [适用：头部平台到店业务] [局限：扩张期/区域平台不适用]
- 外卖/到家：毛利率20-35% [适用：头部外卖平台] [局限：新平台/低密度城市更低]，单均贡献利润低，靠规模摊薄
- 商户SaaS：毛利率60-80% [适用：标准化SaaS产品] [局限：含实施/定制服务时毛利率偏低]，净利率20-30%（规模化后） [适用：成熟期商户SaaS] [局限：早期亏损]
- 即时零售：毛利率15-25% [适用：成熟即时零售] [局限：冷链/高时效要求品类更低]，履约成本占比高

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 到店餐饮团购 | 到店消费券、套餐和线上获客 | 餐饮商户、消费者 | 佣金+广告 | GMV、核销率、商户数 |
| 酒旅 | 酒店、门票、周边游 | 酒店/景区/用户 | 佣金+广告 | 间夜量、客单价、复购 |
| 外卖/到家 | 餐食或商品即时配送 | 餐饮商户、用户 | 佣金+配送费 | 订单量、履约成本、客单价 |
| 即时零售 | 本地商超、便利店、药店配送 | 零售商户、用户 | 佣金+配送费 | 订单密度、SKU、履约时长 |
| 家政/维修 | 上门服务撮合或自营履约 | 服务者、家庭用户 | 抽佣/服务费 | 订单数、复购率、满意度 |
| 美业/休娱 | 美甲、美发、按摩、KTV、健身 | 门店商户、用户 | 佣金+广告+SaaS | 到店率、复购率、预约率 |
| 商户SaaS | 会员、收银、营销、经营管理 | 本地商户 | 订阅费+增值服务 | 续费率、ARPU、渗透率 |

## 5. 核心指标体系

- **规模指标**：GMV、订单量、商户数、活跃用户数、活跃骑手/服务者数、城市覆盖数、门店覆盖数
- **增长指标**：GMV增速、订单量增速、活跃用户增速、商户增长、新城市扩张速度、新品类收入占比、会员增长
- **转化指标**：浏览到下单转化率、领券到核销转化率、访问到预约转化率、商户签约转化率、会员购买转化率
- **留存/复购指标**：用户复购率、次月留存/季度留存、下单频次、商户续约率、商户广告复投率、SaaS续费率、会员续费率
- **变现指标**：综合变现率、佣金率、广告收入占比、单均收入、ARPU、商户ARPU、会员ARPU
- **供给指标**：商户覆盖密度、SKU/套餐丰富度、骑手/服务者在线率、接单率、履约时长、取消率
- **效率指标**：CAC、LTV、LTV/CAC、单均履约成本、订单密度、城市盈亏平衡周期
- **财务指标**：毛利率、贡献利润率、履约成本率、营销费用率、EBITDA Margin、经营现金流
- **风控指标**：客诉率、食安/服务事故率、退款率、虚假交易率、商户作弊率、运力事故率、合规处罚次数

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
综合平台具备流量、订单密度和多品类协同优势；垂直平台在细分类目和服务质量上可能更强；内容平台正加强"种草到交易"闭环；商户SaaS可能从工具切入交易。

### 6.2 常见壁垒类型
用户心智与流量壁垒、城市订单密度壁垒、履约网络壁垒、商户供给与BD壁垒、内容与推荐分发壁垒、会员体系壁垒、商户数字化与系统嵌入壁垒。

### 6.3 替代风险
流量平台切入交易闭环、商户私域经营削弱平台价值、大型综合平台价格战、履约服务被第三方平台替代、商户自建外卖/会员/预约体系、监管政策收紧。

## 7. 行业风险

### 7.1 通用风险项
补贴战、履约成本高企、用户忠诚度低、商户抽佣敏感、食安与服务事故、区域拓展失败、内容流量成本上升、骑手/服务者管理与合规风险、低毛利高运营杠杆。

### 7.2 行业特有风险
- 网络效应具城市/区域局部性，不一定天然全国通用
- 到家业务重履约，管理难度远高于到店
- 上门服务标准化难度大，质量波动影响信任
- 商户端ROI恶化后可能导致投放和续费大幅下滑

### 7.3 风险信号
GMV增长但贡献利润持续恶化（传导机制：补贴/让利驱动GMV增长→但每单贡献利润为负→规模越大亏损越大→无法通过规模效应扭转单位经济）；新城市扩张快但订单密度不足（传导机制：快速开城→但用户和商户渗透率不足→订单密度低→履约成本无法摊薄→城市级持续亏损→拖累整体利润）；用户留存靠补贴维持（传导机制：用户因补贴而来→补贴停止后无价格/服务优势→用户流失→CAC无法回收→留存率虚高）；商户数量增长但活跃商户占比下降（传导机制：大量签约商户→但实际经营/投放意愿低→僵尸商户占比上升→平台供给质量下降→用户体感变差→交易转化率下降）；履约时长和客诉率同步上升（传导机制：订单量增长但骑手/运力不足→履约时长增加→用户体验下降→客诉增加→复购率下降→口碑受损）；广告收入增长建立在商户ROI恶化之上（传导机制：广告费率上升→商户投放成本增加→但交易转化未同步提升→商户ROI下降→商户减少投放或离开→广告收入不可持续）。

## 8. 财务分析重点

### 8.1 利润表重点
收入结构、佣金率和综合变现率、广告收入占比、履约成本率、补贴率、销售与营销费用率、EBITDA Margin。

### 8.2 资产负债表重点
现金、应收应付结构、预收款/递延收入、合同负债、补贴和营销应付款、有息负债。

### 8.3 现金流量表重点
经营现金流是否随规模提升改善、城市拓展是否消耗过多现金、骑手/服务者补贴是否造成持续现金压力、商户SaaS是否提供更高质量现金流。

## 9. 市场空间测算

- **TAM**：本地生活相关消费总盘子，包括餐饮、休娱、酒旅、到家零售和生活服务
- **SAM**：公司当前可覆盖城市、品类、客群和履约能力范围内可服务市场
- **SOM**：公司中短期能实际获得的GMV、订单和商户份额

测算公式：
- 消费支出法：市场空间 = 目标城市人群数 x 人均本地生活消费 x 平台渗透率
- 订单法：市场空间 = 潜在订单量 x 平均客单价
- 商户法：市场空间 = 可服务商户数 x 单商户年收入

注意：市场大不代表平台都能盈利；不同品类利润结构差异大；高客单低频和高频低客单运营逻辑不同；须结合城市密度与履约半径分析真实可得市场。

## 10. 快速分析卡

- **一句话本质**：在有限地理范围内，把本地供给和本地需求通过流量、交易和履约高效连接，通过佣金、广告、履约和商户服务变现
- **核心收入公式**：收入 = GMV x 综合变现率（或 订单量 x 单均收入 + 商户服务收入）
- **核心成本公式**：成本 = 补贴 + 履约 + 获客 + 商户拓展 + 运营与研发
- **核心判断三要素**：1)是否具备稳定高频需求和订单密度 2)单位经济是否随规模提升而改善 3)商户和用户两端关系是否可持续
- **最重要指标**（3个）：综合变现率、单均履约成本、用户复购率
- **最大风险**（3个）：补贴战、履约成本失控、用户忠诚度弱
- **一句话结论模板**：该公司在[城市/品类]已建立[订单密度/商户粘性/履约效率]优势，但需关注[补贴效率/变现率/跨城复制]风险，长期看能否从交易关系走向商户经营关系
