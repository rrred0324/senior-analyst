# AI基础设施与算力服务商业建模知识库

> 适用场景：AI Infra 投资研究、算力服务公司分析、GPU 云项目尽调、一级市场商业建模
> 覆盖范围：GPU 云、推理服务、模型托管、训练平台、MLOps、模型评测、部署中间层
> 行业特征：重资源组织、技术基础设施属性强、上游资源依赖高、利用率决定盈利能力

---

## 1. 行业总论

### 商业本质

AI 基础设施与算力服务行业的本质是：把算力、模型部署能力、训练/推理工具链、监控评测和平台能力组织起来，以更高效率服务模型开发者和企业客户，并从资源使用和平台服务中变现。

它本质上类似于云计算、开发者工具、AI 时代的"卖水人"，但又叠加了 AI 时代特有变量：
- GPU 稀缺
- 推理优化
- 模型生命周期管理
- 多模型调度
- 安全与合规要求

### 分析总框架

```
行业本质（算力资源组织 + 平台工具链服务）
  → 商业模式（GPU云/推理服务/模型平台/一体化）
    → 收入成本模型（资源使用量×单价 + 平台订阅）
      → 核心指标（利用率 × 单卡毛利 × 平台粘性）
        → 经营机制与竞争（资源调度能力 × 平台壁垒）
```

## 3. 收入与成本模型

### 3.1 收入模型

**GPU 云**
```
收入 = GPU 使用时长 × 单价
```

**推理服务**
```
收入 = 调用量 × 单次收费
或
收入 = 实例数 × 实例单价
```

**平台订阅**
```
收入 = 企业客户数 × ACV
```

**综合平台**
```
总收入 = 算力收入 + 推理服务收入 + 平台软件收入 + 企业服务收入
```

### 3.2 成本模型

主要成本：
+ GPU 采购/租赁成本
+ IDC / 电力 / 带宽成本
+ 折旧与运维成本
+ 集群调度与平台研发成本
+ 销售与客户支持成本
+ 安全合规成本

**利润模型**
```
利润 = 收入 - 资源成本 - 运维成本 - 研发成本 - 销售管理费用
```

### 3.3 单位经济模型

**GPU 单卡模型**
```
单卡毛利 = 单卡收入 - 单卡资源成本 - 单卡运维分摊
```

**推理服务模型**
```
单次推理毛利 = 单次收费 - 单次推理资源成本
```

**企业平台模型**
```
单客户利润 = ACV - 客户支持成本 - 云资源成本 - 销售成本分摊
```

## 5. 经营机制

### 5.1 核心飞轮
```
获得更多优质 GPU/资源
→ 吸引更多模型客户接入
→ 提升资源利用率
→ 单位成本下降
→ 提升定价竞争力和毛利
→ 进一步扩展客户与资源规模
```

### 5.2 核心判断逻辑

1）本质是资源转售，还是平台型基础设施？如果只是简单"倒卖 GPU"，壁垒较弱。真正更有价值的是：调度能力、推理优化、多租户平台能力、企业工具链、客户粘性。

2）利用率是否足够高？算力服务的关键不是"买到卡"，而是能否持续卖出去、能否高利用率运行、是否能控制空置损失。

3）客户结构是否健康？如果过度依赖少数头部客户，波动很大。如果客户集中于训练而非推理，也可能导致收入不稳定。

4）Capex 与现金流是否匹配？这一类公司容易出现收入增长快但资本开支更快、现金流承压严重的问题。

## 6. 细分赛道分析

### 6.1 GPU 云
本质：组织稀缺算力资源并进行时长销售
重点看：GPU 获取能力、利用率、单卡收入、大客户续约、折旧与回本周期

### 6.2 推理服务
本质：帮助客户更便宜、更稳定地部署模型推理
重点看：调用量、单次推理毛利、延迟表现、稳定性、平台切换成本

### 6.3 MLOps / 模型平台
本质：为企业管理模型开发、部署、监控和迭代流程
重点看：企业客户数、NRR、使用深度、平台嵌入程度

## 7. 财务分析重点

### 7.1 利润表
+ 收入是资源型还是软件型
+ 毛利率是否随利用率上升而改善
+ 研发费用是否形成平台壁垒
+ 销售费用是否对应高质量客户获取

### 7.2 资产负债表
+ 固定资产与设备折旧压力
+ 预付款是否与 GPU 锁定有关
+ 租赁负债、IDC 合同
+ 应收账款周转

### 7.3 现金流量表
+ 重视经营现金流与 Capex 的匹配
+ 自由现金流是否显著为负
+ 收入增长是否依赖持续融资扩产

---

## 8. 常见风险信号

+ GPU 多但利用率低
+ 收入增长主要靠短期资源溢价
+ 毛利率随供给改善快速下滑
+ 客户集中度过高
+ Capex 过重导致现金流持续承压
+ 缺少平台化能力，仅为资源转售
+ 上游供给不稳定


## 11. 快速分析卡

### 一句话本质
AI Infra 本质上是：把稀缺算力和模型工具链组织成可规模化交付的基础设施服务

### 核心公式
```
收入 = 资源使用量 × 单价 + 平台订阅收入
```

### 核心判断
+ 利用率高不高
+ 平台能力强不强
+ 毛利率是否改善
+ 现金流是否撑得住扩张

### 最大风险
+ 资源型生意壁垒弱
+ Capex 过重
+ 上游依赖强
+ 周期性供需波动大
