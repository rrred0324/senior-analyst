# 电商行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
电商的本质是用更高效率的供需匹配、更低交易摩擦和更强履约能力，重构商品流通与消费路径，通过差价、佣金、广告和服务费变现。核心是"供需匹配+交易变现+履约闭环"。

### 1.2 与普通行业的核心差异

| 差异维度 | 电商 | 传统零售 |
|---------|------|---------|
| 变现方式 | 佣金+广告+差价+服务费 | 商品差价为主 |
| 增长引擎 | 流量×转化×复购×变现率 | 选址×客流×坪效 |
| 规模效应 | 双边网络效应，规模加速 | 单边规模，线性改善 |
| 履约模式 | 仓配+快递，需构建物流网络 | 门店即履约，即时交付 |

### 1.3 分析总框架
供给是否强 → 流量是否可持续 → 转化效率是否高 → 复购是否健康 → 变现率是否可提升 → 单位经济是否成立

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2017 | 社交电商崛起 | 拼多多靠微信裂变快速起量，传统货架电商流量逻辑被挑战 |
| 2019 | 直播电商爆发 | 李佳琦/薇娅带货模式验证，淘宝直播/抖音电商重构人货场 |
| 2020 | 社区团购大战 | 互联网巨头入场社区团购，补贴大战后行业整合、美团多多领先 |
| 2021 | 反垄断监管收紧 | 阿里被罚182亿，平台"二选一"被禁，电商竞争格局重新打开 |
| 2023 | 低价战略回归 | 京东/淘宝/拼多多全面卷低价，利润率承压，平台从GMV转向用户留存 |
| 2024-25 | 出海电商加速 | TEMU/SHEIN/TikTok Shop全球扩张，跨境电商成新增量 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
组织供给 → 获取流量 → 展示商品 → 浏览与转化 → 下单支付 → 仓配发货 → 签收售后 → 复购/续投 → 收入确认

### 2.2 核心飞轮
更多供给 → 更好体验 → 更多订单 → 更高GMV → 更强变现 → 更多投入流量/履约/工具 → 更多供给

核心驱动：供给丰富度、流量效率、履约体验和复购率构成闭环。

### 2.3 商业模式分类
1. **平台佣金**：商家 / 按成交额抽佣 / 佣金收入 = GMV × take rate
2. **广告收入**：商家/品牌 / 按点击、曝光、成交 / 广告收入 = 流量 × 广告加载率 × eCPM
3. **自营差价**：消费者 / 商品采购价与售价差额 / 商品毛利 = 销售收入 - 采购成本

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 佣金 + 广告 + 自营销售 + 商家服务 + 物流/金融增值

平台核心拆法：收入 = GMV × 综合变现率；GMV = 购买用户数 × 购买频次 × 客单价

### 3.2 成本模型
- 固定成本：技术研发、平台运维、管理费用、核心仓网（部分）
- 变动成本：流量投放、配送、商家激励、退款售后、主播佣金、支付通道
- 前端成本：买量、补贴、市场营销、招商
- 后端成本：仓配、客服、退换货、供应链管理

### 3.3 单位经济
平台单订单经济 = 单订单变现 - 单订单补贴 - 履约成本 - 支付/售后成本
自营单订单毛利 = 客单价 - 采购成本 - 履约成本 - 售后成本
关键判断：复购差则买量吞噬利润；补贴停后GMV下滑则增长质量弱

### 3.4 利润率特征
平台毛利率50%-70%（轻资产） [适用：成熟平台型电商] [局限：自营模式不适用]；自营毛利率15%-30%（重采购） [适用：自营电商] [局限：奢侈品/高溢价品类可能更高]；take rate是变现效率核心指标

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 平台电商 | 连接商家与消费者的交易平台 | 商家+消费者 | 佣金+广告 | GMV、take rate、商家数 |
| 自营电商 | 自采自销线上零售商 | 消费者 | 商品差价 | 收入、毛利率、库存周转 |
| 内容/直播电商 | 内容或主播种草转化 | 消费者、品牌商 | 佣金+广告+服务费 | GMV、转化率、复购率 |
| 跨境电商 | 跨国交易线上零售/平台 | 海外消费者、卖家 | 差价/佣金/服务费 | GMV、物流时效、退货率 |
| B2B电商 | 企业采购和批发交易 | 企业采购方 | 服务费/佣金/金融 | 采购额、客户数、复购率 |

## 5. 核心指标体系

- **规模**：GMV、收入、订单量、购买用户数、活跃商家数、SKU数
- **增长**：GMV增速、收入增速、新增购买用户、新增商家数
- **转化**：流量到购买转化率、加购率、支付转化率、直播间下单率
- **留存/复购**：30日/90日留存、复购率、月购买频次、商家留存率
- **变现**：客单价、take rate、广告率、ARPU、单商家收入
- **供给**：活跃商家数、SKU丰富度、价格竞争力、库存周转
- **效率**：CAC、LTV/CAC、履约时效、订单密度、仓配成本率
- **财务**：毛利率、贡献利润率、履约费用率、销售费用率、经营现金流
- **风控**：退款率、退货率、客诉率、假货率、履约超时率、商家违规率

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
头部平台集中度高；流量入口变化快；品类间竞争结构差异大；新平台从低价、内容、细分供给切入。

### 6.2 常见壁垒类型
流量壁垒、供给壁垒、履约网络壁垒、低价供应链壁垒、商家生态壁垒、推荐算法壁垒、用户心智壁垒。

### 6.3 替代风险
被超级平台流量挤压；被品牌DTC替代；被即时零售替代部分场景；被内容平台吞掉交易入口。

## 7. 行业风险

### 7.1 通用风险项
流量成本上升、复购率不足、补贴依赖、履约成本高、库存风险（自营）、假货治理、内容合规、反垄断监管。

### 7.2 行业特有风险
平台反垄断监管趋严；内容电商过度依赖头部达人；跨境电商受物流关税冲击；自营库存和现金流压力。

### 7.3 风险信号
GMV大但变现率上不去（传导机制：平台流量转化效率低/商家付费意愿弱→广告和佣金收入无法随GMV增长→规模不经济）；收入增长快但补贴更快（传导机制：依赖补贴驱动GMV→补贴增速超过收入增速→单位经济为负→规模越大亏损越大）；库存周转恶化 [适用：自营电商] [局限：平台型无此风险]（传导机制：滞销品增加→库存积压→资金占用→需打折清仓→毛利压缩）；停补贴后留存差（传导机制：用户因补贴而来→无补贴后价格无优势→用户转向竞品→GMV断崖下滑）；广告收入过度挤压商家ROI（传导机制：广告费率持续上升→商家利润被压缩→商家减少投放或离开平台→广告收入不可持续）。

## 8. 财务分析重点

### 8.1 利润表重点
平台vs自营收入结构；毛利率与贡献利润率；补贴和营销费用率；履约费用率；广告收入占比。

### 8.2 资产负债表重点
现金储备；存货（自营）；应付账款；预收款/商家保证金；供应链金融风险敞口。

### 8.3 现金流量表重点
经营现金流与利润匹配；存货变化是否吞噬现金流；是否通过延长账期支撑表观现金流。

## 9. 市场空间测算

- **TAM**：线上可转移的商品零售或采购总额
- **SAM**：公司当前品类、区域、人群下可服务市场
- **SOM**：公司中短期可获取的实际份额

测算：1) 零售支出法 = 目标人群品类支出 × 在线化率 × 份额；2) 用户法 = 潜在用户数 × 年购买频次 × 客单价

注意：不能把社会零售总额直接当电商市场；不同品类线上化率差异大。

## 10. 快速分析卡

- **一句话本质**：电商是用更高效率供需匹配和履约能力完成线上交易，通过交易、广告和服务变现
- **核心收入公式**：平台收入 = GMV × 综合变现率；GMV = 购买用户数 × 频次 × 客单价
- **核心成本公式**：成本 = 流量成本 + 补贴 + 采购（自营） + 履约 + 售后 + 运营
- **核心判断三要素**：供给是否强、复购是否好、单位经济是否成立
- **最重要指标**（3个）：GMV、复购率、take rate/广告率
- **最大风险**（3个）：过度依赖补贴低价、履约或库存吞噬利润、被平台流量和价格战压制
- **一句话结论模板**：电商的核心不是交易额多大，而是是否可高质量变现、复购是否稳定、履约是否高效。决定长期价值的是供给效率、用户复购和单位经济。
