# 家居家装行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
在高决策成本、长交付链条、强非标和低频消费场景中，帮助用户完成从空间规划到最终入住的复杂交付，以信任、效率和品质管理实现变现。核心不是"卖方案"，而是"完成复杂交付"。

### 1.2 与普通行业的核心差异

| 差异维度 | 家居家装 | 普通消费品 |
|---------|---------|----------|
| 决策复杂度 | 高，设计/施工/材料/安装多环节 | 低，单品决策 |
| 交付链条 | 长，1-6个月 [适用：整装/全案] [局限：局部改造通常2-4周]，多环节协同 | 短，即买即用 |
| 标准化程度 | 强非标，每户不同 | 高度标准化 |
| 复购频率 | 极低，5-10年 [适用：全屋装修] [局限：局部改造/软装替换周期2-5年] 一次装修 | 高频复购 |
| 纠纷风险 | 高，增项/延期/质量争议频繁 | 低 |

### 1.3 分析总框架
获客能力 → 签单转化 → 交付能力与工期 → 供应链整合 → 客诉返工控制 → 口碑转介绍 → 整单价值提升

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 精装房政策推进 | 精装交付比例提升，B端家装建材需求增长，C端零售受挤压 |
| 2020 | 疫情推动线上家居消费 | 直播卖家具/线上设计工具兴起，但大件物流和体验仍是瓶颈 |
| 2021 | 房地产下行传导至家居 | 新房销售下滑直接影响家居需求，行业从增量市场转入存量竞争 |
| 2022 | 定制家居价格战 | 欧派/索菲亚等头部品牌降价获客，中小品牌利润承压 |
| 2023 | 旧改和局装成为新增长点 | 二手房交易+旧房翻新带动局改需求，整装模式快速扩张 |
| 2024-25 | AI设计+智能制造 | AI户型设计和全屋智能方案落地，生产端柔性制造提升效率 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
整装型：获取线索 → 量房设计 → 报价签单 → 材料选配施工 → 交付验收 → 售后与转介绍
零售型：流量获取 → 门店展示 → 导购成交 → 仓配安装 → 售后 → 连带销售
定制型：获取需求 → 设计方案 → 复尺下单 → 工厂生产 → 配送安装 → 验收尾款

### 2.2 核心飞轮
更好设计与交付能力 → 更高满意度口碑 → 更高签单转化转介绍 → 更高订单规模和供应链议价 → 更好设计与交付能力

### 2.3 商业模式分类
- **设计施工**：业主/企业客户，设计+施工+套餐费，公式=签单数 x 平均单值
- **材料/产品销售**：消费者/渠道商，零售/分销/整装配套，公式=销量 x ASP
- **定制生产交付**：家庭/项目客户，按面积/延米/套系，公式=定制订单数 x 单均客单价
- **平台撮合**：商家/消费者，线索费/佣金，公式=有效线索数 x 单线索收入

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 设计施工 + 材料销售 + 定制家居 + 家具零售 + 平台收入 + SaaS + 后市场
家装公司：收入 = 到店客户数 x 签约转化率 x 平均合同额
门店零售：收入 = 进店客流 x 成交转化率 x 客单价
定制家居：收入 = 下单客户数 x 单均定制面积 x 单价

### 3.2 成本模型
固定：门店租金、管理层薪酬、核心设计团队、工厂折旧、数字化系统
变动：材料成本、工人工资、安装配送、销售提成、售后维修返工

### 3.3 单位经济
单装修订单：合同收入 - 材料成本 - 人工施工 - 获客成本 - 返工售后分摊
单门店：单店收入 - 房租 - 人员薪酬 - 营销 - 管理分摊

### 3.4 利润率特征
家装毛利25-40% [适用：中高端整装公司] [局限：低价套餐/游击队通常15-25%]、定制30-45% [适用：全屋定制品牌] [局限：小厂本地定制通常20-30%]、家具零售40-60% [适用：品牌成品家具] [局限：线上电商/白牌通常25-40%]；净利率家装2-8% [适用：规模化运营的家装公司] [局限：小型公司管理粗放通常0-3%]、定制5-12% [适用：头部定制品牌] [局限：中小定制厂通常3-6%]、零售3-10% [适用：成熟品牌门店] [局限：新开店爬坡期通常为负]。签单大不代表利润高，增项失控和返工侵蚀真实利润

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 家装设计施工 | 设计与施工交付 | 新房/二手房业主 | 设计+施工+材料差价 | 签单率、工期、客诉率 |
| 整装/全案 | 一体化设计材料和施工 | 改善型家庭 | 套餐/整单收入 | 客单价、毛利率 |
| 局改/旧改 | 局部改造和旧房翻新 | 存量房业主 | 按项目收费 | 周期、转介绍率 |
| 全屋定制 | 柜类木作按需生产安装 | 中高客单家庭 | 产品销售 | 客单价、出厂毛利 |
| 成品家具零售 | 沙发/床/餐桌零售 | 家庭消费者 | 零售收入 | 同店增长、客单价 |
| 建材辅材零售 | 瓷砖/卫浴/五金/涂料 | 业主/家装公司 | 零售/分销 | 周转率、坪效 |
| 家装平台 | 聚合流量撮合需求 | 装修用户/商家 | 线索费/佣金 | 线索转化率、ARPU |
| 后市场服务 | 维修/保养/焕新/安装 | 存量房家庭 | 按单收费 | 复购率、响应时效 |

## 5. 核心指标体系

- **规模**：收入、签单额/GMV、在施工地数、门店数、设计师数、定制订单数
- **增长**：收入增速、签单额增速、到店线索增长、同店增长、整装/定制渗透率
- **转化**：线索到到店转化率、到店到签单转化率、定制下单转化率、软装配套率
- **留存/复购**：转介绍率、售后满意度、老客户复购率、后市场服务复购率
- **变现**：客单价、单均合同额、单设计师产出、单店收入、单户整单价值
- **供给**：设计师数、项目经理数、施工队产能、工厂产能利用率
- **效率**：CAC、回本周期、工期达成率、返工率、客诉率、库存周转天数
- **财务**：毛利率、销售费用率、履约成本率、经营现金流、预收款占比、尾款回收率
- **风控**：客诉率、返工率、延期交付率、安全事故率、坏账率、Top渠道收入占比

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
家装长期分散、区域性强、标准化难；定制家居和家具零售头部化相对更高；存量房时代旧改局改机会增加

### 6.2 常见壁垒类型
品牌信任、本地化服务与门店网络、设计与交付标准化、供应链整合、工厂柔性交付、口碑转介绍

### 6.3 替代风险
平台低价撮合替代传统获客；游击队低价替代正规公司；电商新零售挤压门店；工厂直连压缩经销利润

## 7. 行业风险

### 7.1 通用风险项
获客成本上升、签单率下降、工期延误、材料涨价、客诉返工、尾款回收困难、地产周期下行

### 7.2 行业特有风险
增项失控：低价签单后增项，满意度崩塌；返工链式反应：影响工期成本排期；尾款回收：完工后业主拒付拖延

### 7.3 风险信号
线索增长但签单转化下滑 → 获客效率恶化（传导机制：流量成本上升→线索质量下降→签单率下滑→单位获客成本攀升→利润被侵蚀）；签单额增长但毛利率下降 → 盈利质量恶化（传导机制：低价签单抢量→增项失控/材料涨价→履约成本超预期→实际毛利远低于合同毛利）；工期持续拉长 → 交付能力不足（传导机制：人手不足/供应链延迟→工期延长→客户不满→尾款回收困难+客诉赔付→现金流恶化）；客诉返工退款上升 → 质量失控（传导机制：施工质量波动→返工增加→成本和工期双重恶化→口碑受损→转介绍率下降→获客更依赖投放）；新店快但单店模型未跑通 → 扩张风险（传导机制：快速开店→新店亏损期叠加→固定成本无法摊薄→整体现金流被拖垮）

## 8. 财务分析重点

### 8.1 利润表重点
收入结构、毛利率和履约成本率、销售费用率与获客成本率、售后返工成本、高毛利配套占比

### 8.2 资产负债表重点
现金、应收和尾款、预收款/合同负债、存货和库龄、固定资产、坏账准备

### 8.3 现金流量表重点
预收模式是否支撑现金流、尾款回收是否恶化、工厂Capex和门店扩张压力、返工赔付影响

## 9. 市场空间测算

- **TAM**：新房装修+存量翻新+家具建材+后市场总支出
- **SAM**：公司区域/品类/价格带/渠道下可服务市场
- **SOM**：公司中短期可获取的签单额或零售额

测算公式：新房交付法=年交付套数x单套装修支出；存量翻新法=可翻新存量房x翻新渗透率x客单价；整单价值法=目标客户数x整单客单价

注意：市场大不等于易复制；需区分新房和存量驱动；平台型和交付型应分别建模

## 10. 快速分析卡

- **一句话本质**：在强非标、长链条、低频决策场景中，帮用户完成空间设计、产品配置与交付履约，通过供应链整合、交付管理和口碑复购实现商业价值
- **核心收入公式**：家装收入 = 到店客户数 x 签约转化率 x 平均合同额
- **核心成本公式**：成本 = 材料/制造成本 + 人工施工成本 + 获客成本 + 门店履约成本 + 售后返工成本
- **核心判断三要素**：1)获客签单模型是否健康 2)交付售后能力是否可控 3)供应链整单提升能否支撑利润
- **最重要指标**（3个）：签单转化率、毛利率、返工率/客诉率
- **最大风险**（3个）：获客成本上升、交付延期与客诉返工、尾款回收恶化
- **一句话结论模板**：家居家装核心不是签了多少单，而是能否以可控获客成本拿到订单，通过稳定交付和供应链整合把低频装修转化为可持续的整单价值
