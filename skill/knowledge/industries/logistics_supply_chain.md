# 物流供应链行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
物流供应链的本质是在复杂网络下，以可控成本、可预测时效和可验证服务质量完成货物流转与供应链协同。核心不是"送货"，而是"网络密度×运营效率×服务质量"的持续优化。

### 1.2 与普通行业的核心差异

| 差异维度 | 物流供应链 | 普通服务行业 |
|---------|-----------|------------|
| 规模效应 | 网络密度效应强，规模越大单位成本越低 | 规模效应有限 |
| 资产特征 | 重资产（仓网+运力+设备） | 轻资产为主 |
| 服务质量 | 时效+破损+丢件可量化 | 偏主观 |
| 竞争壁垒 | 网络密度+仓网布局+运营体系 | 品牌+渠道 |

### 1.3 分析总框架
网络和履约效率是否持续优化 → 客户结构和留存是否健康 → 扩张是否带来更好单位经济 → 资本开支和现金流是否可控

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2017 | 供应链创新上升为国家战略 | 政策推动物流降本增效，数字化和智能化成为行业方向 |
| 2019 | 快递价格战加剧 | 极兔入局引发价格战，单票收入持续下降，中小快递出清 |
| 2020 | 疫情暴露供应链韧性不足 | 全球供应链中断，企业从"效率优先"转向"安全+效率"双目标 |
| 2021 | 跨境物流需求爆发 | 跨境电商带动国际物流增长，海外仓布局加速 |
| 2023 | 快递行业格局趋稳 | 极兔收购百世，价格战缓和，行业从规模竞争转向质量和服务竞争 |
| 2024-25 | AI+自动化仓配 | AGV/分拣机器人规模化部署，AI路径优化降本，行业进入智能物流阶段 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
快递/快运型：揽收 → 分拨 → 干线运输 → 中转 → 末端派送 → 签收 → 收入确认

仓配一体型：客户签约 → 入仓 → 库存管理 → 订单接入 → 拣货打包 → 发运配送 → 签收/退货

供应链管理型：需求预测 → 采购补货计划 → 仓网运输计划 → 执行监控 → 异常处理 → 履约优化

### 2.2 核心飞轮
更多订单与客户 → 更高网络密度和仓运协同 → 更低单位履约成本 → 更好时效与服务 → 更强留存与口碑 → 更多订单

核心驱动：网络密度、运营效率、客户结构和数字化能力一起提升，形成履约成本和服务质量的双优化。

### 2.3 商业模式分类
1. **运输收费**：按票/重量/里程 / 收入 = 运量 × 单位运价
2. **仓储收费**：按面积/托盘/天数 / 收入 = 仓储占用量 × 单位仓储费
3. **履约收费**：按订单/件数 / 收入 = 订单量 × 单位履约服务费

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 运输 + 仓储 + 履约操作 + 管理/项目 + 平台/增值服务

快递拆法：收入 = 票量 × 单价；仓配拆法：收入 = 仓储收入 + 履约量 × 操作费；供应链拆法：收入 = 客户数 × 客均合同额

### 3.2 成本模型
- 固定成本：仓库租赁（部分）、干线/分拨基础设施、系统研发、自动化设备折旧
- 变动成本：运力采购、末端派送、分拣包装、人工操作、油电路桥费、赔付成本
- 前端成本：销售BD、大客户拓展、渠道合作
- 后端成本：仓运配执行、调度客服、质控异常处理

### 3.3 单位经济
快递型：单票利润 = 单票收入 - 干线 - 分拨 - 末端派送 - 异常赔付
同城型：单单利润 = 单单收入 - 骑手成本 - 调度 - 补贴 - 异常
仓配型：单订单利润 = 履约收入 + 分摊仓储 - 拣选/包装/出库 - 配送 - 售后
判断要点：规模增长若未带来网络密度提升利润未必改善；大客户收入高但议价压力大

### 3.4 利润率特征
快递净利率3%-8%（规模效应后） [适用：中国头部快递企业] [局限：中小快递/新进入者通常亏损]；仓配毛利率20%-35% [适用：成熟仓配一体服务商] [局限：新仓/低利用率时毛利率更低]；冷链15%-25% [适用：标准化冷链物流] [局限：医药冷链因合规要求成本更高]；供应链SaaS 60%-75% [适用：标准化SaaS产品] [局限：含实施/定制服务时毛利率偏低]

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 快递 | 标准小件高频寄递网络 | 电商/个人 | 单票收入 | 单票收入、单票成本、票量 |
| 快运/零担 | 中大件B端货物运输 | 企业客户 | 运费 | 吨收入、装载率、时效 |
| 同城配送 | 城市内即时履约 | 餐饮/零售/平台 | 按单收费 | 单量、履约时长、骑手效率 |
| 仓储/仓配 | 仓储与订单履约 | 电商/品牌商 | 仓租+操作费 | 坪效、人效、履约成本 |
| 冷链物流 | 温控运输与仓储 | 食品/医药 | 运费+仓储费 | 温控达标率、损耗率 |
| 跨境物流 | 国际运输、清关和履约 | 跨境商家 | 运费+服务费 | 时效、妥投率 |
| 供应链SaaS | WMS/TMS/OMS系统 | 企业客户 | 软件费/实施费 | 客单价、续费率 |

## 5. 核心指标体系

- **规模**：收入、订单量/票量/吨量、仓储面积、客户数
- **增长**：收入增速、订单量增速、新增客户数、新增仓网
- **转化**：线索转签约率、报价转合作率
- **留存/复购**：客户续约率、复购频次、大客户净收入留存、月活跃发货客户
- **变现**：单票收入、单单收入、单客户年收入、单仓收入
- **供给**：运力覆盖率、车队利用率、仓库利用率、装载率
- **效率**：单票成本、履约时效、准时率、妥投率
- **财务**：毛利率、履约成本率、销售费用率、资本开支强度、经营现金流、应收周转
- **风控**：破损率、丢件率、赔付率、温控达标率、安全事故率、单一客户占比

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
快递标准件头部集中；仓配区域和行业差异明显；同城配送竞争激烈平台属性强；跨境冷链专业化分层。

### 6.2 常见壁垒类型
网络密度壁垒、仓网布局壁垒、大客户与行业解决方案壁垒、运营管理壁垒、系统与数据壁垒、冷链/跨境资质壁垒。

### 6.3 替代风险
客户自建物流；被综合平台压价；被更低价区域玩家替代；自动化不足导致效率落后。

## 7. 行业风险

### 7.1 通用风险项
价格战、油价波动、人工成本上升、大客户压价、产能错配、高CAPEX、应收和现金流压力、服务质量事故。

### 7.2 行业特有风险
网络扩张错配（仓网运力布局错误拉低单位经济）；大客户依赖（议价强毛利被压缩）；服务质量事故（破损丢件安全事故致命影响品牌）；冷链/跨境合规风险。

### 7.3 风险信号
订单量增但单票利润降（传导机制：价格战/大客户压价→单票收入下降→但固定成本已摊薄→单票利润仍被压缩→规模增长无法改善盈利→规模不经济）；大客户占比升高且毛利被压缩（传导机制：大客户占比上升→议价能力增强→要求更低价格→毛利被压缩→大客户流失时收入断崖→风险集中）；仓网扩张快但利用率不足 [适用：仓配/供应链企业] [局限：快递型不适用]（传导机制：仓网快速扩张→但订单量未跟上→仓库利用率低→固定成本无法摊薄→持续亏损→拖累整体利润）；时效承诺提升但赔付异常同步上升（传导机制：缩短时效承诺→但运营能力未跟上→延误增加→赔付成本上升→客户信任下降→续约率降低）；应收增加经营现金流转弱（传导机制：大客户账期延长→应收账款增加→现金流被占用→坏账风险上升→经营现金流弱于利润→资金链压力增大）。

## 8. 财务分析重点

### 8.1 利润表重点
运输与仓储收入结构；毛利率变化；履约成本率；人工与运力成本；赔付与异常成本。

### 8.2 资产负债表重点
现金；应收账款；固定资产与设备；使用权资产/租赁负债；有息负债。

### 8.3 现金流量表重点
经营现金流是否随规模扩大改善；CAPEX是否过重；应收账款占用是否恶化。

## 9. 市场空间测算

- **TAM**：货运、仓储、配送、跨境、冷链等全行业物流支出规模
- **SAM**：公司所在区域、行业、品类和服务环节下可服务市场
- **SOM**：中短期可获得的订单、客户和网络份额

测算：1) 物流支出法 = 目标客户商品交易规模 × 物流成本占比；2) 订单量法 = 订单量 × 单均物流收入；3) 客户法 = 可服务客户数 × 客均年合同额

注意：市场大不等于利润厚；重资产扩张赛道重点看资本效率。

## 10. 快速分析卡

- **一句话本质**：物流供应链是在复杂网络中以更低成本、更高时效和更稳定服务完成货物流转与供应链协同的行业
- **核心收入公式**：收入 = 运量/订单量 × 单位收入 + 仓储/履约/增值服务收入
- **核心成本公式**：成本 = 运输 + 仓储操作 + 人工 + 系统设备 + 销售 + 异常赔付
- **核心判断三要素**：网络履约效率是否持续优化、客户结构和留存是否健康、扩张是否带来更好单位经济
- **最重要指标**（3个）：订单量/票量、单位成本、准时率/妥投率
- **最大风险**（3个）：价格战、大客户压价、资本开支过重
- **一句话结论模板**：物流供应链的核心不是把订单量做大，而是把网络密度、履约效率、客户结构和资金周转做优。决定长期价值的是单位经济、服务稳定性、客户粘性和资本效率。
