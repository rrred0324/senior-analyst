# 金融科技行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
用技术重构支付、融资、理财、保险和风控等金融服务流程，以更低成本、更高效率和更强可得性连接资金、资产、用户和金融机构，并通过手续费、利差分成、技术服务费和增值服务实现商业化。本质不是"做金融"也不是"做软件"，而是用技术降低金融交易与风控成本。

### 1.2 与普通行业的核心差异

| 差异维度 | 金融科技 | 普通科技/SaaS |
|---------|---------|-------------|
| 监管约束 | 极强，牌照/合规决定业务边界 | 相对温和 |
| 风险属性 | 承担或间接承担信用/欺诈/流动性风险 | 风险敞口有限 |
| 收入与风险关联 | 规模增长可能伴随坏账恶化 | 规模增长通常改善单位经济 |
| 机构合作依赖 | 高度依赖持牌机构和资金方合作 | 客户关系相对直接 |
| 合规成本 | 持续且高昂，决定业务可持续性 | 合规成本相对可控 |

### 1.3 分析总框架
用户/商户需求 → 交易/金融服务 → 数据沉淀 → 风控/推荐优化 → 机构信任增强 → 更多产品/资金接入 → 更大交易规模

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2017 | 网联成立+支付断直连 | 第三方支付纳入集中清算，支付行业利润空间压缩 |
| 2018 | P2P爆雷潮 | 网贷平台大面积暴雷，互联网金融强监管时代开启 |
| 2020 | 蚂蚁集团暂缓上市 | 平台金融整改信号明确，金融科技从"创新优先"转向"合规优先" |
| 2021 | 平台金融业务整改 | 助贷业务纳入持牌监管，联合贷出资比例限制，平台金融业务缩表 |
| 2023 | 助贷新规+利率红线 | 贷款利率上限进一步明确，助贷平台利润空间持续压缩 |
| 2024-25 | AI+金融深化 | 大模型应用于风控/投顾/客服，金融SaaS和嵌入式金融成为新增长点 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
支付型：获取商户/用户 → 接入支付通道 → 完成交易处理 → 清结算 → 数据沉淀 → 增值服务（风控/营销/融资）→ 收入确认
信贷科技型：获取借款需求 → 身份识别与反欺诈 → 风控建模 → 匹配资金方 → 放款 → 贷后管理 → 回收与分润 → 数据迭代优化
财富/保险科技型：获取用户 → 风险测评/需求识别 → 产品推荐 → 完成购买 → 持有/理赔/复购 → 分销或服务收入

### 2.2 核心飞轮
更多交易与用户 → 更多数据沉淀 → 更好的风控与推荐能力 → 更高转化率和更低坏账/欺诈 → 更强合作机构信任 → 更多产品和资金接入 → 更多交易与用户
核心驱动：数据、风控、合规和渠道能力共同增强，形成交易效率和资产质量的双重复利

### 2.3 商业模式分类
- **手续费**：收费对象=商户/用户/机构，收费方式=按交易额或笔数，公式=交易规模×费率
- **导流与撮合费**：收费对象=资金方/金融机构，收费方式=按成功转化或放款规模，公式=放款规模×分润率
- **技术服务费**：收费对象=银行/保险/券商/商户，收费方式=系统部署/订阅/调用量/项目制，公式=客户数×客均服务费
- **利差/分润**：收费对象=金融合作机构，收费方式=按资产收益/管理费/利差分成，公式=资产规模×分润率
- **增值服务费**：收费对象=商户/用户/机构，收费方式=账户管理/营销/风控/数据/SaaS，公式=付费客户数×客均增值服务费

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 手续费收入 + 技术服务收入 + 导流撮合收入 + 利差/分润收入 + 增值服务收入
- 支付科技：收入 = TPV × 综合费率
- 信贷科技：收入 = 放款规模 × 技术/分润费率 = 流量规模 × 转化率 × 客均放款额 × 变现率
- 财富科技：收入 = AUM × 综合货币化率
- 保险科技：收入 = 保费规模 × 佣金率

### 3.2 成本模型
固定成本：技术平台研发、合规与法务、核心管理团队、基础系统与安全投入
变动成本：通道费、数据调用费、导流成本、风险补偿、客服成本、分润成本

### 3.3 单位经济
- 支付型：单笔交易利润 = 单笔收入 - 通道成本 - 风控/技术成本 - 客服成本
- 信贷科技型：单客利润 = 单客变现收入 - 获客成本 - 风控成本 - 贷后成本 - 风险补偿成本
- 财富/保险科技型：单用户LTV = 生命周期内分销/服务收入 - 获客与服务成本

### 3.4 利润率特征
- 支付科技毛利率：30-50% [适用：成熟支付平台] [局限：新进入者或低利润率市场可能更低]，净利率：5-15% [适用：规模化支付公司] [局限：初创期通常亏损]
- 信贷科技毛利率：40-60%（轻资产模式） [适用：助贷/导流模式] [局限：自营资金模式毛利率更高但风险也更高]，净利率：10-25% [适用：轻资产信贷科技] [局限：重资产/联合贷模式净利率更低]
- 财富/保险科技毛利率：50-70% [适用：代销/分销模式] [局限：自研产品模式不同]，净利率：10-20% [适用：规模化公司] [局限：获客期可能亏损]
- 金融SaaS毛利率：55-75% [适用：标准化金融SaaS] [局限：含实施服务的产品毛利率偏低]，净利率：10-20% [适用：成熟期] [局限：成长期研发投入大]

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 支付科技 | 支付受理、结算和商户服务 | 商户/消费者 | 手续费+商户服务费 | TPV、费率、商户数 |
| 信贷科技 | 借贷撮合、风控和运营技术 | 个人/小微/金融机构 | 导流费+技术费+分润 | 放款额、通过率、不良率 |
| 财富科技 | 理财产品分销和投顾服务 | 个人用户 | 代销费+管理费分成 | AUM、付费率、留存 |
| 保险科技 | 保险销售、核保、理赔数字化 | 消费者/企业/保险公司 | 佣金+服务费 | 保费规模、续保率、赔付率 |
| 风控科技 | 反欺诈、评分、决策引擎 | 金融机构/平台 | API调用费/服务费 | 识别率、误杀率、调用量 |

## 5. 核心指标体系

- **规模指标**：TPV/支付笔数、放款规模、保费规模、AUM、收入、活跃用户数、商户数、机构客户数
- **增长指标**：TPV增速、放款额增速、AUM增速、收入增速、新增商户数、新增机构客户数
- **转化指标**：注册转化率、授信通过率、放款转化率、投保转化率、理财购买转化率、商户签约转化率
- **留存/复购指标**：用户留存率、商户留存率、续借率、续保率、AUM留存率、复投率、月活跃率
- **变现指标**：综合费率、ARPU、商户ARPU、佣金率、利差/分润率、增值服务渗透率
- **供给指标**：合作银行数、合作保险公司数、支付通道覆盖数、资金合作额度、风控模型覆盖场景数
- **效率指标**：CAC、LTV、LTV/CAC、CAC回收周期、审批时效、放款时效、清算时效
- **财务指标**：毛利率、净利率、销售费用率、研发费用率、风险成本率、经营现金流、坏账率/逾期率
- **风控指标**：欺诈率、坏账率、逾期率、误杀率、系统可用性、投诉率、合规处罚次数、单一资金方依赖度

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
支付领域头部集中；信贷科技受监管和牌照环境影响大；财富和保险科技既竞争流量也竞争信任与产品供给；风控科技更依赖模型效果与场景适配；大平台、银行科技子公司、持牌机构深度参与竞争

### 6.2 常见壁垒类型
合规壁垒、数据壁垒、风控模型壁垒、交易规模壁垒、机构合作壁垒、商户网络壁垒、系统稳定性和安全壁垒、品牌与信任壁垒

### 6.3 替代风险
被持牌机构自建替代、被大平台流量入口挤压、被通用支付/金融基础设施替代、监管变化导致模式失效、风控优势被数据或算法同质化削弱

## 7. 行业风险

### 7.1 通用风险项
强监管风险、合规边界不清、牌照依赖、坏账和欺诈上升、资金方合作不稳定、通道成本上升、流量成本上升、大客户或大机构依赖、技术系统故障、声誉风险

### 7.2 行业特有风险
业务表述是科技但收入本质来自高风险金融敞口、合规罚单导致业务暂停、资金方集中度风险（一家机构退出影响巨大）、风控放松换规模导致资产质量恶化

### 7.3 风险信号
交易量增长但坏账率同步恶化（传导机制：放松风控标准→通过率和放款额上升→但高风险客户占比增加→逾期和坏账率滞后上升→拨备/代偿吞噬利润→规模增长不可持续）、收入增长过度依赖某单一机构或渠道（传导机制：单一资金方/渠道占比过高→该机构政策/策略变化→业务量断崖下降→缺乏替代来源→收入大幅波动）、合规罚单频发（传导机制：合规缺陷→监管处罚→业务整改/暂停→客户和机构信任下降→合作方退出→收入萎缩）、通过率提升主要靠放松风控（传导机制：为冲规模降低风控阈值→高风险客户进入→短期放款额上升→但逾期率滞后爆发→坏账远超预期利润→亏损扩大）、单用户利润下降但公司继续冲规模（传导机制：获客成本上升/变现效率下降→单用户利润持续走低→但公司仍加大投放→单位经济恶化→规模越大亏损越大→烧钱不可持续）、业务表述是科技但收入本质来自高风险金融敞口（传导机制：名义技术服务费→实质承担信用风险→经济下行时风险集中暴露→科技估值逻辑无法支撑→估值回归金融属性）

## 8. 财务分析重点

### 8.1 利润表重点
手续费/技术服务费/分润收入结构、通道成本和分润成本、风险成本、销售费用率、研发费用率、合规成本

### 8.2 资产负债表重点
现金、应收/应付款项、备抵和减值、风险准备金、表内外金融敞口、有息负债、合同负债

### 8.3 现金流量表重点
经营现金流是否匹配利润、是否存在回款周期风险、资金沉淀和清结算安排、风险暴露是否消耗现金

## 9. 市场空间测算

- **TAM**：相关金融交易、支付、融资、理财、保险等总市场规模
- **SAM**：公司可服务的人群、商户、机构与场景对应的市场空间
- **SOM**：公司现实可取得的交易份额、资产管理份额或机构覆盖率

测算公式：
- 交易规模法：收入空间 = 行业交易规模 × 可实现费率
- 用户法：市场空间 = 潜在用户数 × 渗透率 × 客均金融服务收入
- 机构客户法：To F市场空间 = 可服务机构数 × 客均合同额

注意：交易空间不等于可得收入空间；可得市场受监管和合作牌照强约束；高增长赛道不一定有高利润率；同样的TPV/放款额，利润质量差异可能极大

## 10. 快速分析卡

- **一句话本质**：用技术提升金融交易、风控和服务效率，在合规前提下连接用户、资产、资金与机构
- **核心收入公式**：收入 = 交易/资产规模 × 综合变现率
- **核心成本公式**：成本 = 获客成本 + 通道/分润成本 + 风控与数据成本 + 技术成本 + 合规成本 + 风险成本
- **核心判断三要素**：1)合规是否清晰 2)风控是否真实有效 3)收入是否可持续且不靠短期套利
- **最重要指标**（3个）：TPV/放款额/AUM、综合费率、坏账率/欺诈率
- **最大风险**（3个）：监管变化、风控失效、大机构依赖
- **一句话结论模板**：该金融科技项目的核心价值在于[交易效率/风控能力/机构合作]，关键风险是[合规边界/资产质量/机构依赖]，长期取决于[能否在合规框架下把交易、风控、资金合作和技术能力做深]
