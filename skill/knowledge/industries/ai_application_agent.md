# AI应用与Agent商业建模知识库

> 适用场景：AI 应用投资研究、Agent 产品分析、一级市场尽调、SaaS 与 AI 融合赛道研究
> 覆盖范围：AI 办公、AI 编程、AI 客服、AI 销售、AI 法务、AI 教育、AI 营销、垂直 Agent
> 行业特征：产品迭代快、场景依赖强、留存分化大、对底层模型依赖明显、分发竞争激烈

---

## 1. 行业总论

### 商业本质

AI 应用与 Agent 的本质是：把大模型能力嵌入具体工作流或消费场景，帮助用户更快、更便宜、更高质量地完成任务，并从中收取订阅费、席位费或结果交付费。

与大模型公司不同，AI 应用公司不一定拥有底层模型，核心在于：

- 场景选择
- 产品体验
- 工作流重构能力
- 用户留存
- 商业化转化
- 成本控制

### AI 应用与传统 SaaS 的差异

| 维度 | 传统 SaaS | AI 应用 / Agent |
|---|---|---|
| 核心价值 | 流程管理、数据记录 | 任务自动完成、内容生成、决策辅助 |
| 用户预期 | 提升效率 | 减少人工操作甚至替代部分岗位 |
| 成本结构 | 研发 + 销售 | 研发 + 模型调用成本 + 销售 |
| 留存逻辑 | 流程嵌入 | 流程嵌入 + 输出质量 |
| 风险 | 替代慢 | 技术迭代快、同质化快 |

### 分析总框架

```
场景选择（高频刚需任务）
  → 产品类型（工具型/结果交付型）
    → 收入模型（订阅/席位/按量/ACV）
      → 核心指标（留存 × 付费 × 毛利）
        → 壁垒评估（工作流嵌入 × 数据闭环 × 切换成本）
```

## 3. 收入与成本模型

### 3.1 收入模型

**C 端**
```
收入 = MAU × 付费率 × ARPPU
```

**企业端**
```
收入 = 客户数 × ACV
```

**席位型**
```
收入 = 企业客户数 × 平均席位数 × 单席位价格
```

**结果交付型**
```
收入 = 任务量 × 单任务收费
```

### 3.2 成本模型

主要成本包括：
+ 模型调用成本
+ 云资源成本
+ 产品研发成本
+ 销售与获客成本
+ 客户成功与实施成本
+ 数据标注与安全审核成本

**利润模型**
```
利润 = 收入 - 模型调用成本 - 获客成本 - 研发及交付费用
```

### 3.3 单位经济模型

**C 端**
```
LTV = ARPU × 毛利率 × 生命周期
CAC = 获客成本 / 新增付费用户数
```

**企业端**
```
单客户利润 = 年收入 - 模型调用成本 - 销售与实施成本 - 客服成本
```

**Agent 任务模型**
```
单任务毛利 = 单任务收费 - 单任务模型与系统成本
```

## 5. 经营机制

### 5.1 核心飞轮
```
产品解决真实任务
→ 用户高频使用
→ 留存改善
→ 数据与反馈积累
→ 输出质量更好
→ 商业化能力增强
→ 更多资金投入产品优化
```

### 5.2 核心判断逻辑

1）是否真正进入工作流？AI 应用是否只是"新奇工具"，还是已经成为：每天都用、不用就低效、已嵌入组织流程。这是投资判断核心。

2）是"提效工具"还是"结果交付"？如果只是辅助工具，天花板通常较低；如果能直接交付结果，则商业价值更高，但责任与复杂度也更高。

3）留存是否真实？AI 应用最大问题之一是：首次体验很强，但复购和留存不一定好。

4）底层模型替代风险大不大？如果底层能力差异不大，应用层壁垒必须来自：工作流设计、数据闭环、品牌与分发、企业集成、组织切换成本。

## 6. 细分赛道分析

### 6.1 AI 办公 / Copilot
本质：帮助用户更快完成文档、表格、会议、协作、知识整理等任务
重点指标：活跃率、使用时长、续费率、与办公系统集成深度

### 6.2 AI 客服 / 销售
本质：用 Agent 提升响应效率、降低人工成本、提高转化率
重点指标：替代人工比例、成交转化率改善、单客户产值、部署周期

### 6.3 AI 编程 / 开发者工具
本质：提升开发效率，甚至承担部分自动编码与测试任务
重点指标：开发者活跃度、使用渗透率、代码接受率、企业版付费率

### 6.4 垂直行业 Agent
本质：在行业专属场景中输出更高价值、更高准确率的自动化能力
重点指标：行业数据壁垒、场景复用率、单客户价值、合规要求

## 7. 财务分析重点

### 7.1 利润表
+ 收入是订阅、席位还是项目
+ 毛利率受模型调用成本影响多大
+ 销售费用投入是否带来高留存客户
+ 研发投入是否推动产品差异化

### 7.2 资产负债表
+ 应收账款反映企业业务账期质量
+ 合同负债反映订阅制收入质量
+ 资本化研发需重点关注

### 7.3 现金流量表
+ 重点看获客投入与经营现金流是否匹配
+ 企业订阅收款通常较好，PoC 型收入现金流不一定稳定

---

## 8. 常见风险信号

+ 用户增长快但留存低
+ 付费率始终上不去
+ 模型成本吞噬毛利
+ 过度依赖投流获客
+ 企业订单多为试点，难转长期合同
+ 产品差异化不足，容易被大厂复制
+ Agent 完成率低，仍严重依赖人工

## 11. 快速分析卡

### 一句话本质
AI 应用与 Agent 本质上是：用模型重构任务流程，并从效率提升或结果交付中收费

### 核心公式
```
收入 = 用户/客户数 × ARPU/ACV
利润 = 收入 - 模型成本 - 获客成本 - 研发交付成本
```

### 核心判断
+ 是否高频刚需
+ 留存是否真实
+ 工作流嵌入是否足够深
+ 毛利率能否改善

### 最大风险
+ 新奇感强、留存弱
+ 模型成本高
+ 同质化严重
+ 被平台型巨头整合
