# 医疗健康行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
在严格合规和专业信任基础上，提升健康服务的可及性、有效性、效率和结果质量。核心不是"卖药"或"看病"，而是通过专业能力、合规能力和支付体系共同作用形成持续服务和规模扩张。

### 1.2 与普通行业的核心差异

| 差异维度 | 医疗健康 | 普通服务 |
|---------|---------|---------|
| 合规与资质 | 强监管，需资质/注册/审批 | 多数无准入限制 |
| 信任壁垒 | 专业信任决定复诊和口碑 | 信任相对易建立 |
| 支付方 | 多方支付(自费/医保/商保) | 用户直接付费 |
| 扩张约束 | 医生供给、资质强约束 | 受限因素少 |
| 事故后果 | 医疗事故伤害极大 | 后果相对可控 |

### 1.3 分析总框架
合规与资质 → 专业能力建设 → 患者获取与信任建立 → 诊疗/产品交付 → 复诊/复购/续费 → 支付闭环与规模复制

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2018 | 仿制药集采启动 | "4+7"带量采购打破高毛利格局，仿制药企利润大幅压缩 |
| 2020 | 疫情暴露基层医疗短板 | 互联网医疗政策松绑，在线问诊和处方流转加速 |
| 2021 | DRG/DIP支付改革推进 | 医院从"按项目付费"转向"按病种付费"，控费和效率成核心 |
| 2022 | 创新药出海受挫 | 多款国产创新药FDA受阻，出海预期回调 |
| 2023 | 医疗反腐风暴 | 医药行业销售模式重塑，合规成本上升 |
| 2024-25 | AI+医疗落地加速 | AI影像/辅助诊断/药物研发进入商业化验证，但支付端尚未打通 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
医疗服务型：患者获取 → 分诊/预约 → 问诊/检查/诊断 → 治疗/手术/康复 → 随访复诊 → 长期健康管理
器械/IVD型：研发/注册 → 渠道准入 → 医院/机构采购 → 临床使用 → 复购 → 售后服务
数字健康型：客户签约 → 系统部署 → 医疗流程数字化 → 数据沉淀 → 效率提升 → 续费/扩容

### 2.2 核心飞轮
更好医疗结果/服务体验 → 更强患者/机构信任 → 更高复诊率/续费率/采购率 → 更大规模与数据积累 → 更强专业能力和运营效率 → 更好医疗结果/服务体验

### 2.3 商业模式分类
- **诊疗服务收费**：患者/支付方，挂号/检查/手术/治疗，公式=就诊人次 x 客均收费
- **药械/耗材销售**：医院/患者/经销商，药品/器械销售，公式=销量 x 单价
- **软件/信息化收费**：医院/机构/政府，项目制/订阅/维护，公式=客户数 x 客均合同额
- **会员和健康管理**：个人/企业，年费/套餐费，公式=付费人数 x 客均年费

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 医疗服务收入 + 药械收入 + 软件/项目收入 + 平台服务收入 + 会员/健康管理收入
医疗服务型：收入 = 患者数 x 年就诊频次 x 客均收费
连锁门诊型：收入 = 门店数 x 单店患者量 x 客均收费
器械/IVD型：收入 = 装机量 x 单机试剂/耗材消耗 x 单价

### 3.2 成本模型
固定：医疗资质合规体系、医生团队、场地设备折旧、系统研发、管理团队
变动：药械耗材采购、检验试剂、按服务量的医护成本、销售提成、渠道返利

### 3.3 单位经济
医疗服务型：单次就诊利润 = 单次收费 - 医护分摊 - 药耗 - 场地设备分摊 - 获客分摊
连锁门诊型：单店模型 = 单店收入 - 医生员工 - 房租 - 药耗 - 营销 - 管理分摊
IVD型：单台设备LTV = 设备毛利 + 耗材持续毛利 - 装机维护成本

### 3.4 利润率特征
医疗服务毛利20-40% [适用：民营综合/专科门诊] [局限：高端私立可达40-50%，公立基本持平或更低]、器械/IVD毛利50-70% [适用：成熟器械/试剂] [局限：集采品种可降至30-40%]、信息化毛利40-60% [适用：标准软件产品] [局限：重实施项目仅25-40%]、健康管理毛利30-50% [适用：体检/会员制] [局限：纯线上管理仅20-30%]；净利率医疗服务5-12% [适用：成熟连锁] [局限：扩张期新店亏损拉低整体]、器械10-20% [适用：有耗材收入的设备型] [局限：纯设备销售仅5-10%]。高收入不代表高利润，器械无耗材收入则设备天花板低

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 医疗服务 | 问诊/手术/治疗/康复 | 患者 | 诊疗收入 | 客单价、复诊率、医生效率 |
| 专科连锁 | 标准化专科诊疗网络 | 患者 | 诊疗+药械 | 单店模型、医生产出 |
| 互联网医疗 | 在线问诊/处方/慢病管理 | 患者/医生 | 问诊费/服务费/药品 | MAU、问诊量、转化率 |
| 器械/IVD | 设备/耗材/检测产品 | 医院/实验室 | 销售收入 | 装机量、试剂消耗、毛利率 |
| 医疗信息化 | 医院系统与数字化 | 医院/机构 | 软件/项目/维护费 | 客单价、续费率、回款周期 |
| 健康管理 | 体检/慢病管理/会员服务 | 个人/企业 | 会员费/服务费 | 续费率、ARPU、渗透率 |

## 5. 核心指标体系

- **规模**：收入、患者数、就诊人次、门店/床位/医生数、装机量、医院客户数
- **增长**：收入增速、患者增速、新增门店/医院、新签客户数、新产品收入占比
- **转化**：到诊转化率、复诊转化率、手术转化率、线上到线下转化率
- **留存/复购**：复诊率、患者留存率、慢病续费率、医院续费率、试剂复购率
- **变现**：客单价、ARPU、单患者年收入、耗材单机年收入、软件客单价
- **供给**：医生数、医生产能利用率、床位使用率、设备开机率、医院覆盖率
- **效率**：CAC、LTV/CAC、回本周期、单店盈亏平衡周期、单医生产出、回款周期
- **财务**：毛利率、销售费用率、研发费用率、净利率、经营现金流、应收周转
- **风控**：医疗差错率、客诉率、合规事件数、患者满意度、药占比/耗占比、单一医生依赖度

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
医疗服务区域性强但连锁化提高中；器械IVD常见技术/注册/渠道竞争；互联网医疗受政策和流量影响大

### 6.2 常见壁垒类型
资质合规、医生与专业能力、临床验证和注册、品牌信任、医院渠道、数据流程、连锁复制管理

### 6.3 替代风险
公立医院替代、更低价器械试剂替代、医生流失削弱能力、政策压缩支付空间、技术迭代致旧产品失效

## 7. 行业风险

### 7.1 通用风险项
强监管合规、医疗事故声誉、医生流失、医保控费、回款周期长、注册审批不及预期、支付方政策变化

### 7.2 行业特有风险
医生依赖：核心医生出走可带走大量患者；合规成本：资质质控合规投入是刚性成本；支付方风险：医保控费/集采直接压缩利润；回款拖累：医院客户回款周期常较长

### 7.3 风险信号
- 患者增长快但复诊率不升 → 品牌信任未建立（传导机制：营销驱动首诊→患者体验或效果未达预期→不复诊→获客成本无法摊薄→长期不可持续）
- 单店扩张快但新店回本变慢 → 扩张失控（传导机制：快速开店→新店医生和患者不足→单店收入爬坡慢→固定成本拖累整体利润→资金链承压）
- 单一明星医生贡献过高 → 医生依赖风险（传导机制：核心医生带走大量患者→该医生离职后收入断崖→品牌和信任受损→重建需极长时间）
- 器械装机增但耗材消耗不增 → 设备天花板逼近（传导机制：装机进入低价值客户→临床使用频率低→试剂/耗材复购不足→单机LTV远低于预期）
- 合规事件投诉明显增加 → 监管与声誉风险（传导机制：合规疏漏→投诉/处罚增加→品牌信任受损→监管收紧→运营受限或罚款）

## 8. 财务分析重点

### 8.1 利润表重点
服务收入vs产品收入结构、毛利率、医护人力成本占比、销售费用率、研发注册费用、质控合规成本

### 8.2 资产负债表重点
现金、应收账款、存货、固定资产设备、无形资产(注册证/软件)、有息负债、合同负债

### 8.3 现金流量表重点
医院客户回款是否拖累现金流、连锁扩张CAPEX是否过重、设备投放现金压力、经营现金流支撑扩张能力

## 9. 市场空间测算

- **TAM**：对应病种/检查/器械/诊疗/健康管理总体市场
- **SAM**：公司所在区域/支付方/专科下可服务市场
- **SOM**：公司中短期可取得的份额

测算公式：患者人群法=目标患者数x年治疗频次x客均支付额；机构采购法=目标医院数x客均采购额；设备耗材法=可装机数x单机年耗材收入

注意：患者总量不等于可支付市场；医保商保支付范围决定真实市场边界；医疗扩张受医生供给和资质强约束

## 10. 快速分析卡

- **一句话本质**：在合规和专业信任基础上，通过服务、产品和数字化能力改善健康结果，实现持续收入与利润
- **核心收入公式**：收入 = 患者数 x 就诊频次 x 客均收费
- **核心成本公式**：成本 = 人力成本 + 药械耗材成本 + 获客成本 + 合规质控成本 + 研发注册成本
- **核心判断三要素**：1)专业能力和合规是否过硬 2)支付与复诊/复购闭环是否成立 3)模式是否可复制扩张
- **最重要指标**（3个）：复诊率/续费率、毛利率、回款周期
- **最大风险**（3个）：政策与合规风险、医生依赖、回款压力
- **一句话结论模板**：医疗健康核心不是短期收入增长，而是在合规专业和信任基础上形成可持续服务能力和支付闭环
