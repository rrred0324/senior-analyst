# AI行业商业建模知识库

---

## 1. 行业总论

### 1.1 商业本质
AI的本质是通过数据、模型、算力和产品化能力，将认知、生成、判断和交互任务规模化自动化，在效率提升、体验提升和新场景创造中实现商业价值。核心是"模型能力嵌入真实工作流，让客户持续为效率/质量/新能力付费"。

### 1.2 与普通行业的核心差异

| 差异维度 | AI | 传统SaaS/软件 |
|---------|------|-------------|
| 价值交付 | 模型能力自动化完成任务 | 软件工具辅助人工 |
| 成本结构 | 推理/算力成本为核心变量 | 云资源成本相对固定 |
| 同质化风险 | 极高，底层模型快速趋同 | 较低，功能壁垒更持久 |
| 迭代速度 | 模型迭代快，产品形态变化快 | 版本迭代相对稳定 |

### 1.3 分析总框架
是否解决高频高价值任务 → 工作流嵌入深度 → 留存是否真实 → 推理成本是否可控 → 单位经济是否可持续 → 差异化能否持续

## 1.4 关键历史里程碑

| 时间 | 事件 | 影响 |
|------|------|------|
| 2017 | Transformer论文发表 | Attention机制奠定大模型基础，AI从特征工程走向预训练范式 |
| 2020 | GPT-3发布 | 大规模语言模型能力跃升，AI应用从感知走向生成 |
| 2022 | ChatGPT发布 | 大模型对话能力引发全球关注，AI商业化元年开启 |
| 2023 | 国产大模型百模大战 | 百度文心/阿里通义/智谱等密集发布，算力和数据成核心竞争要素 |
| 2024 | AI应用商业化探索 | AI搜索/编程/办公助手等场景验证，但PMF和变现仍在早期 |
| 2025 | AI Agent和具身智能 | AI从工具走向Agent，多模态和推理能力提升，行业从模型竞赛转向应用落地 |

## 2. 价值链与商业模式

### 2.1 价值创造链条
AI应用型：识别高价值任务 → 设计AI工作流 → 集成模型能力 → 打磨产品体验 → 获得用户 → 提升留存 → 放大收入

模型/Infra型：获取算力/数据 → 模型训练/优化 → 推理部署 → 开发者接入 → 调用量增长 → 成本优化 → 收入增长

行业方案型：场景选择 → 数据接入 → 模型微调 → 客户试点 → 正式部署 → 增购/续费/复制

### 2.2 核心飞轮
更好产品效果 → 更多使用与数据反馈 → 更好模型调优和工作流优化 → 更高留存 → 更多客户和调用量 → 更低单位成本/更强生态 → 更好效果

核心驱动：模型效果、产品体验、工作流嵌入、数据反馈和成本优化的正循环，不只是"模型参数更大"。

### 2.3 商业模式分类
1. **订阅收费**：企业/个人用户 / 按月年订阅 / 收入 = 付费客户数 × ARPU
2. **按量调用**：开发者/企业 / 按token、请求量 / 收入 = 调用量 × 单位价格
3. **项目制与私有化**：大型企业/政府 / 一次性+部署+维护 / 收入 = 项目数 × 平均合同额

## 3. 收入与成本模型

### 3.1 收入模型
总收入 = 订阅 + 按量调用 + 项目/部署 + 增值服务 + 平台分成

应用拆法：收入 = 用户数 × 付费率 × ARPU；SaaS拆法：收入 = 客户数 × 席位数 × 单价；API拆法：收入 = 调用量 × 单价

### 3.2 成本模型
- 固定成本：核心研发团队、模型训练投入、平台研发、安全与评测体系
- 变动成本：推理token成本、API云资源、第三方模型调用、数据处理、渠道分成
- 前端成本：获客、试用交付、售前方案、实施
- 后端成本：模型推理、质量监控、安全合规、客户成功

### 3.3 单位经济
AI应用：单用户毛利 = ARPU - 推理成本 - 渠道成本
API/Infra：单次调用毛利 = 调用收入 - 推理/带宽/存储成本
判断要点：收入增长但算力吞噬毛利最危险；项目收入大但不可复制则估值质量下降

### 3.4 利润率特征
AI应用毛利率60%-80%（推理可控时） [适用：SaaS化AI应用] [局限：推理成本高的应用毛利率可能降至40%以下]；API/Infra 40%-65% [适用：基础模型API服务] [局限：竞争加剧后毛利率趋降]；项目制30%-50% [适用：定制化AI解决方案] [局限：标准化程度提升后可能改善]
核心关注：推理成本占收入比是AI行业特有核心指标

## 4. 细分赛道

| 子赛道 | 定义 | 核心客户 | 收入模式 | 关键指标 |
|-------|------|---------|---------|---------|
| 基础模型 | 通用模型能力 | 开发者/企业 | API/授权 | 调用量、推理成本、留存 |
| 垂类模型 | 特定行业或任务 | 企业客户 | 订阅/项目 | 场景效果、续费率 |
| AI应用 | 终端用户交付 | C端/B端 | 订阅/席位/增值 | DAU、付费率、留存 |
| AI Agent | 自动完成复杂任务 | 企业/开发者 | 订阅/调用/席位 | 任务成功率、调用深度 |
| AI Infra | 推理、调度、监控 | 开发者/企业 | API/订阅 | QPS、成本、NRR |
| 数据服务 | 清洗、标注、评测 | 模型公司/企业 | 项目/长期服务 | 单项目毛利、复购 |

## 5. 核心指标体系

- **规模**：收入、用户数、企业客户数、API调用量、DAU/MAU
- **增长**：收入增速、用户增速、调用量增速、新增ARR、扩张ARR
- **转化**：注册到激活率、免费到付费率、PoC到正式采购率
- **留存/复购**：用户留存率、NRR、续费率、功能使用深度
- **变现**：ARPU、单席位收入、单次调用收入、增值收入占比
- **供给**：推理成本、单位token成本、模型延迟、QPS、GPU利用率
- **效率**：CAC、LTV/CAC、CAC回收周期、研发效率、部署周期
- **财务**：毛利率、推理成本占收入比、研发费用率、Burn Multiple、Runway
- **风控**：幻觉率、任务完成率、安全事件数、单一模型供应商依赖度

## 6. 竞争格局与壁垒

### 6.1 竞争格局特征
基础模型层头部集中；应用层极度分散变化快；Infra工具层更易形成平台粘性；开源模型降低底层门槛但提升产品层竞争强度。

### 6.2 常见壁垒类型
工作流嵌入壁垒、数据反馈壁垒、算力成本优化壁垒、开发者生态壁垒、行业know-how壁垒、安全合规壁垒。

### 6.3 替代风险
底层模型升级吞噬上层价值；开源替代闭源；大平台进入同类场景；客户自建AI能力。

## 7. 行业风险

### 7.1 通用风险项
技术迭代过快、推理成本失控、留存差、同质化严重、安全合规风险、客户ROI不明显、对单一模型/云厂商依赖。

### 7.2 行业特有风险
底层模型升级吞噬上层价值（wrapper公司失效）；幻觉与安全风险导致信任缺失；推理成本倒挂（收入增毛利降）；PoC陷阱（大量试用但采购少）。

### 7.3 风险信号
用户增长快但留存迅速下滑（传导机制：新用户因噱头/补贴涌入→产品未嵌入真实工作流→用户发现无持续价值→快速流失→获客成本无法回收）；API调用增长但毛利不升反降（传导机制：调用规模增长→推理/算力成本线性上升→但定价被竞争压低→收入增速慢于成本增速→毛利率压缩）；大量PoC但正式采购很少（传导机制：客户好奇尝试PoC→但ROI不明确/安全性存疑/集成复杂→未转化为付费合同→获客成本浪费）；高度依赖第三方模型且无差异化（传导机制：底层模型由第三方提供→模型能力趋同→无法构建壁垒→被价格战或模型升级淘汰）。

## 8. 财务分析重点

### 8.1 利润表重点
收入结构（订阅vs项目vs调用）；毛利率；推理成本占比；研发费用率；净亏损收敛速度。

### 8.2 资产负债表重点
现金；递延收入；资本化研发；服务器/设备投入。

### 8.3 现金流量表重点
经营现金流是否改善；训练与推理投入是否过重；融资现金流依赖程度；Burn Rate。

## 9. 市场空间测算

- **TAM**：目标任务和场景的全球/区域总市场（不是"所有知识工作者"）
- **SAM**：公司能力可服务的具体市场
- **SOM**：中短期可实际获取的规模

测算：1) 任务替代法 = 可替代/增强的任务量 × 单任务价值；2) 席位法 = 目标用户数 × 年收入；3) API调用法 = 调用次数 × 单价

注意：TAM大不等于支付意愿强；重点看高频、高痛点、可量化ROI的场景；SOM往往比TAM更重要。

## 10. 快速分析卡

- **一句话本质**：AI是把模型能力嵌入真实工作流，以更低成本/更高效率完成认知和生成任务的行业
- **核心收入公式**：收入 = 用户/客户数 × 付费率 × ARPU 或 收入 = 调用量 × 单价
- **核心成本公式**：成本 = 算力/推理/云成本 + 研发 + 数据 + 销售与客户成功
- **核心判断三要素**：是否解决高频高价值任务、留存是否真实、推理成本是否可控
- **最重要指标**（3个）：留存率、NRR、推理成本占收入比
- **最大风险**（3个）：同质化、留存差、推理成本过高
- **一句话结论模板**：AI的核心不是用了最先进模型，而是能否嵌入真实场景并持续创造ROI。决定长期价值的是产品高频刚需、工作流嵌入、留存扎实和成本可控。
