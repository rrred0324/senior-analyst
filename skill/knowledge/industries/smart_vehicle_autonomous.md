# 智能汽车与自动驾驶商业建模知识库

> 适用场景：智能驾驶、自动驾驶、汽车智能化供应链研究，一级市场项目分析
> 覆盖范围：L2/L3/L4 自动驾驶、智能座舱、智驾软硬件、域控制器、感知与决策系统
> 行业特征：产业链长、认证周期长、客户集中度高、前装量产导入难、软件定义汽车趋势明显

---

## 1. 行业总论

### 商业本质

智能汽车与自动驾驶行业的本质是：把感知、决策、控制和软硬件系统集成到汽车中，提高安全性、舒适性和自动化水平，并通过软硬件供货、方案授权或持续软件服务实现商业价值。

### 行业核心逻辑

- 汽车是高安全、高认证、高供应链协同产业
- 量产能力和上车能力比 demo 更重要
- 前装定点是关键拐点
- 软件价值提升，但硬件仍是重要基础
- 客户集中于主机厂和 Tier 1

### 分析总框架

```
行业本质（感知+决策+控制 → 上车量产）
  → 商业模式（软硬件供应/软件授权/全栈方案/运营）
    → 收入成本模型（定点车型销量×单车价值量）
      → 核心指标（定点 × SOP × 单车价值量 × 量产毛利）
        → 经营机制（定点 → SOP → 规模出货 → 扩展客户）
```

## 2. 商业模式分类

| 模式 | 描述 | 收入来源 | 核心能力 |
|---|---|---|---|
| 软硬件方案供应商 | 提供感知/决策/域控方案 | 定点项目、量产供货 | 上车能力、可靠性 |
| 软件授权 | 向车企授权算法/系统 | 授权费、维护费 | 算法能力、适配性 |
| 智驾全栈方案 | 提供端到端系统 | 项目费、BOM 收入 | 全栈能力、量产协同 |
| 自动驾驶运营 | Robotaxi / 物流等 | 运力服务费 | 运营能力、车队管理 |

## 3. 收入与成本模型

### 3.1 收入模型

```
收入 = 定点车型销量 × 单车价值量
```

若为软件订阅：

```
收入 = 激活车辆数 × 软件订阅费
```

### 3.2 成本模型

+ 研发成本
+ 测试验证成本
+ 车规认证成本
+ 硬件采购成本
+ 量产导入成本
+ 售后支持成本

### 3.3 单位经济模型

```
单车毛利 = 单车收入 - 单车 BOM - 交付支持成本
```

+ 单车价值量

+ 算法性能
+ 客户集中度

---

## 5. 经营机制

### 核心飞轮
```
获得车厂定点
→ 进入 SOP 量产
→ 规模出货摊薄研发与认证成本
→ 提升车型渗透率
→ 扩展更多客户
```

### 核心判断逻辑

1. 是否拿到真实定点？
2. 定点能否顺利转量产？
3. 单车价值量是否可持续？
4. 算法能力是否转化为前装商业价值？

---

## 6. 财务分析重点

+ 收入确认是否依赖少数定点项目
+ 毛利率是否随量产爬坡提升
+ 研发费用率长期高企是否合理
+ 应收账款与主机厂账期
+ 存货与备货压力

---

## 7. 常见风险信号

+ demo 很强，但没有前装定点
+ 定点多，SOP 少
+ 量产交付不顺
+ 客户集中度过高
+ 硬件成本下降慢
+ 法规推进不及预期

---

## 8. 市场空间分析模板

```
市场空间 = 目标车型销量 × 智驾渗透率 × 单车价值量
```

### 核心公式
```
收入 = 车型销量 × 单车价值量
```

### 核心判断
+ 定点是否真实
+ SOP 是否顺利
+ 单车价值量是否稳定
+ 量产毛利能否改善

+ SOP 延迟
+ 客户集中度高
