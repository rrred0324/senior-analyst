# 投资尽调商业建模框架

适用于 PE/VC、一级市场、战略投资、并购、深度商业分析。

## 三层尽调框架

### 第一层：行业建模（6 问）
1. 行业空间有多大？
2. 行业增速来自哪里？
3. 行业处于哪个阶段？
4. 竞争格局如何？
5. 行业利润池在哪里？
6. 行业未来 3 年主要变量是什么？

1. 公司卖什么？
2. 核心客户是谁？
3. 价值主张是什么？
4. 收入公式怎么拆？
5. 成本公式怎么拆？
6. 单位经济健康吗？
7. 竞争优势在哪里？
8. 规模扩大后是否更强？

### 第三层：财务建模（8 问）
1. 收入增长质量如何？
2. 毛利率是否可持续？
3. 费用率变化说明了什么？

5. 资本开支是否重？
6. 营运资本占用是否恶化？
7. 资产质量是否健康？
8. 是否存在红旗信号？

## 市场空间预测框架

### 三层空间定义
- **TAM**：理论总市场
- **SAM**：当前商业模式可服务市场
- **SOM**：公司实际可获取市场

### 两种测算方法

**自上而下**：
```
行业总人口/总商户数 × 渗透率 × 客单价 × 频次
```

**自下而上**：
```
城市数 × 单城市单日订单 × 年化 × 公司份额
```

投资尽调优先采用"自下而上 + 自上而下交叉验证"。

### 增长驱动拆解

市场空间增长通常来自：
- 渗透率提升
- 客单价提升
- 使用频次提升
- 区域扩张
- 品类扩张
- 替代线下/传统渠道

## 战略退出机制

战略的本质不仅是决定"做什么"，也包括明确"什么时候不做"。

### 常见退出触发信号
- 关键假设连续 N 个周期被证伪
- 核心领先指标持续低于止损线
- 回本周期显著拉长，现金流压力超预期
- 外部环境变化导致市场窗口关闭
- 组织能力长期无法补齐
- 存在更高 ROI 的资源配置方向

### 退出决策原则
1. 先定义止损条件，再投入
2. 退出不是失败，而是资源再配置
3. 探索业务应更强调"阶段验证 + 快速止损"
