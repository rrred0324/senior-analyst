# 三、业务理解

## 3.1 公司到底做什么
1. 公司主营业务是什么？
2. 哪项业务贡献主要收入？
3. 公司处在产业链哪个位置？
4. 目标客户是谁？
5. 核心使用场景是什么？

## 3.2 解决什么问题
1. 客户原来怎么解决这个问题？
2. 为什么现有方案不够好？
3. 公司方案的核心优势是什么？
4. 客户购买决策的核心驱动是什么？

## 3.3 商业模式
1. 收入来源有哪些？
2. 核心收费对象是谁？
3. 收费方式是订阅、抽佣、项目费、广告还是服务费？
4. 商业化链条是否完整？
5. 未来还有哪些新增变现路径？

# 九、财务尽调

## 9.1 收入质量
1. 收入结构是否清晰？
2. 是否过度依赖单一产品、单一客户或单一区域？
3. 收入确认口径是否稳健？
4. 是否存在一次性收入掩盖长期质量问题？

## 9.2 利润质量
1. 毛利率水平及波动原因？
2. 销售费用率、研发费用率、管理费用率如何？
3. 单位经济是否成立？
4. 盈利靠经营改善还是缩减投入？

## 9.3 现金流质量
1. 经营现金流是否匹配利润？
2. 回款周期是否健康？
3. 应收账款和预付账款是否异常？
4. 是否存在表外或代收代付扭曲？

## 9.4 资产负债表风险
重点看：
- 现金
- 应收账款
- 存货
- 合同负债
- 有息负债
- 商誉
- 资本化研发
- 或有负债

3. 核心高管能力是否互补？
4. 是否过度依赖某个关键人物？

## 10.2 组织能力
1. 公司更强在产品、销售、运营还是交付？
2. 能力是否可复制到新区域/新业务？
3. 中层组织是否成型？
4. 数据化管理是否成熟？

## 10.3 激励机制
1. 股权激励是否到位？
2. 销售与交付激励是否合理？
3. 核心人才流失风险如何？

# 十二、风险尽调

## 12.1 业务风险
- 需求波动
- 留存差
- 履约失控
- 供给不足
- 增长依赖买量/补贴
- 大客户流失
- 单一产品风险

## 12.2 财务风险
- 毛利率下滑
- 回款变慢
- 现金流恶化
- 费用刚性过强
- 隐性负债

## 12.3 合规与法律风险
- 牌照问题
- 数据安全
- 用工合规
- 税务问题
- 知识产权风险
- 内容风险
- 政策监管风险
