# 数据分析 Playbook

适用任务：指标异动诊断、归因分析、A/B 测试设计、数据质量检查

## 核心流程

### 指标异动诊断五步法

```
Step 1: 异动确认
    ├─ 数据口径是否一致？
    ├─ 埋点是否稳定？
    ├─ 是否存在延迟/补数？
    └─ 是真异动还是数据问题？

Step 2: 异动量化
    ├─ 变化方向（上升/下降）
    ├─ 变化幅度（绝对值/相对值）
    ├─ 变化时点（突变/渐变）
    └─ 是否持续（点/线/面）

Step 3: 维度拆解
    ├─ 时间维度（同比/环比/特殊时点）
    ├─ 用户维度（新老/活跃度/人群）
    ├─ 渠道维度（各渠道贡献）
    ├─ 地区维度（城市/区域）
    ├─ 产品维度（品类/版本）
    └─ 行为维度（路径/漏斗）

Step 4: 归因定位
    ├─ 结构归因（按维度拆贡献度）
    ├─ 因素归因（量价分解）
    ├─ 漏斗归因（找卡点）
    └─ 同环比归因（季节 vs 结构）

Step 5: 行动建议
    ├─ 立即动作（止损）
    ├─ 短期动作（修复）
    ├─ 长期动作（预防）
    └─ 验证指标（怎么确认有效）
```

## 分析工具选择树

```
问题类型判断：
├─ 是否可随机分流？
│   └─ 是 → A/B 测试（黄金标准）
├─ 有政策/外生冲击？
│   └─ DID / RDD / IV
├─ 有对照样本？
│   └─ PSM（倾向得分匹配）
├─ 单一处理对象？
│   └─ 合成控制法
└─ 纯观察性数据？
    └─ 回归分析 + 控制变量
```

## 数据质量检查清单

在任何分析开始前，先做数据质量检查：

```
□ 口径检查：定义是否一致？
□ 完整性检查：是否有缺失？
□ 时效性检查：数据最新时间？
□ 异常值检查：是否有极端值？
□ 埋点漂移检查：版本变更？
```

## 关键公式

### 最小样本量估算
```
单组样本量 n ≈ 16 × σ² / Δ²

α = 0.05, power = 0.8 时的近似
```

### 贡献度分析
```
各维度贡献度 = (该维度变化量) / (总变化量)

维度 A 贡献 + 维度 B 贡献 + ... = 100%
```

### 量价分解
```
收入变化 = 量变化贡献 + 价变化贡献 + 交叉项

量变化贡献 = Δ量 × 原价
价变化贡献 = Δ价 × 原量
交叉项 = Δ量 × Δ价
```

## 常见误区

| 误区 | 风险 | 应对 |
|------|------|------|
| 单维度归因 | 忽略交叉效应 | 多维度交叉拆解 |
| 把数据问题当业务问题 | 错误干预 | 先做数据质量检查 |
| 相关当因果 | 误导决策 | 标注相关关系+因果验证方法 |
| 偷看 A/B 测试 | 假阳性 | 预设最小实验周期 |
| 忽略基数效应 | 小盘子放大波动 | 绝对值+相对值同看 |
