# 商业分析 Playbook

适用任务：商业模式评估、单位经济分析、渠道 ROI、经营计划、定价策略

## 核心流程

### 商业模式评估五步法

```
Step 1: 商业模式画布梳理
    └─ 9 大构造块，重点识别价值主张与收入来源

Step 2: 收入质量分析
    ├─ 可持续性
    ├─ 复购性
    ├─ 集中度
    ├─ 价格权
    └─ 补贴依赖

Step 3: 单位经济建模
    ├─ LTV 计算（毛利口径）
    ├─ CAC 计算（含所有获客成本）
    ├─ UE = LTV/CAC
    └─ 回本周期

Step 4: 经营杠杆分析
    ├─ 固定成本占比
    ├─ 边际贡献率
    └─ 规模扩大后的利润弹性

Step 5: 增长与利润平衡
    ├─ 当前阶段判断
    ├─ 增长优先 or 利润优先
    └─ 决策依据
```

## 商业模式画布

9 大构造块：
1. 客户细分（CS）
2. 价值主张（VP）
3. 渠道通路（CH）
4. 客户关系（CR）
5. 收入来源（RS）
6. 核心资源（KR）
7. 关键业务（KA）
8. 重要合作（KP）
9. 成本结构（C$）

## 主营收入公式

| 模式 | 公式 | 代表 |
|------|------|------|
| 流量收入 | GMV × 广告变现率 | 抖音 |
| 手续费 | GMV × 抽佣比例 | 美团 |
| 产供销 | 销量 × 单价 − 成本 | 京东自营 |
| 增值服务 | 会员数 × ARPU | 爱奇艺 |

## 单位经济核心公式

### LTV
```
毛利 LTV = LT × ARPU × 毛利率
其中 LT = 1 / churn（流失率稳定时）
```

### CAC
```
CAC = 营销总支出 / 新客数
营销总支出 = 付费投放 + 内容制作 + 人员成本
```

### UE
```
UE = LTV / CAC
健康标准：> 3（互联网/SaaS 经验值 [适用：B2B SaaS/互联网平台，成长期以上] [局限：IAA游戏/低毛利零售不适用此标准]）
```

### 回本周期
```
回本周期 = CAC / 单用户月度毛利贡献
SaaS 标准：< 12 个月 [适用：B2B SaaS，ARR>$1M] [局限：C端产品回本周期通常更长]
```

## 渠道 ROI 分析

### 渠道评级矩阵

| 评级 | LTV/CAC | 回本周期 | D30 留存 | 行动 |
|------|---------|---------|---------|------|
| A | >3 | <12月 | >30% | 加大投入 |
| B | 2-3 | 12-18月 | 20-30% | 维持优化 |
| C | <2 | >18月 | <20% | 评估退出 |

### 渠道组合策略
- A 级：加大投入，注意天花板
- B 级：持续优化
- C 级：测试优化 or 减投
- 品牌渠道：单独评估

## Cohort P&L

```
| 批次 | CAC | M1 | M3累计 | M6累计 | M12累计 | 回本月 |
|------|-----|----|----|----|----|----|
```

诊断信号：
- 新批次 CAC 持续上升 → 渠道天花板
- 新批次 LTV 持续下降 → 用户质量恶化
- 回本周期延长 → 单位经济恶化

## 定价策略

| 方法 | 核心逻辑 | 适用 |
|------|---------|------|
| 成本加成 | 成本+利润率 | 制造业 |
| 价值定价 | 感知价值 | 品牌/SaaS |
| 竞争定价 | 对标竞品 | 标准化产品 |
| 动态定价 | 实时调整 | 出行/酒店 |
| 分层定价 | 套餐分层 | SaaS |

## 经营杠杆

```
边际贡献率 = (收入 − 变动成本) / 收入
经营杠杆系数 = 边际贡献 / 利润
```

- 固定成本高 → 利润弹性大
- 固定成本低 → 利润稳定但规模效应弱

## 增长与利润平衡决策

```
当面临"增长 vs 利润"二选一：

1. 市场还在快速扩大？
   是 → 增长优先
   否 → 利润优先

2. 是否已过规模临界点？
   是 → 可以利润优先
   否 → 增长优先

3. 现金流能支撑亏损吗？
   能 → 可以增长优先
   不能 → 必须利润优先

4. 竞争格局稳定吗？
   稳定 → 利润优先
   激烈 → 增长优先
```
