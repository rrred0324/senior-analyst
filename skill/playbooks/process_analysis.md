# 流程分析 Playbook

适用任务：流程诊断、流程优化、组织治理、SOP 设计

## 核心流程

### 流程诊断五步法

```
Step 1: 明确诊断目标
    └─ 效率/质量/成本/风险

Step 2: 绘制现状流程图
    └─ 实际执行流程（非文档版本）

Step 3: 识别瓶颈与浪费
    ├─ 等待
    ├─ 返工
    ├─ 过度审批
    └─ 信息断层

Step 4: 量化流程绩效
    ├─ 周期时长
    ├─ 一次通过率
    ├─ 单次成本
    └─ 异常率

Step 5: 设计优化方案并验证
    ├─ 改进措施
    ├─ 试点验证
    └─ 前后对比
```

## 流程指标三层模型

```
业务结果指标（Why）
    ↑
流程绩效指标（What）
    ↑
流程活动指标（How）
```

## 流程诊断清单

| 维度 | 检查内容 | 常见问题 |
|------|---------|---------|
| 完整性 | 是否有遗漏/断点 | 信息丢失 |
| 合理性 | 是否有冗余 | 重复审批 |
| 效率 | 是否有瓶颈 | 单点阻塞 |
| 质量 | 是否频繁返工 | 缺少标准 |
| 风险 | 是否缺控制点 | 合规漏洞 |

## 标准工具集

### RACI 矩阵
- R：执行者
- A：负责人（唯一）
- C：被咨询者
- I：被告知者

### SIPOC 模型
- Suppliers
- Inputs
- Process
- Outputs
- Customers

### SLA 设计
- 响应时间
- 处理时间
- 质量标准
- 升级机制

## 流程优化方法

### BPR（流程再造）
根本性重新设计，适用于大幅提升场景

### 精益流程
消除七种浪费：
- 等待、搬运、缺陷、库存、动作、过度加工、过度生产

### DMAIC（六西格玛）
- Define → Measure → Analyze → Improve → Control

## 变更治理

```
变更提案 → 审批评估 → 版本管理 → 培训宣贯 → 灰度试运行 → 收益评估 → 全量生效
```
