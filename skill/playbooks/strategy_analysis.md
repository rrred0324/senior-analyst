# 战略分析 Playbook

适用任务：战略选择、市场分析、资源配置、战略复盘

## 核心流程

### 战略分析五步法

```
Step 1: 市场体量判断
    ├─ TAM（总潜在市场）
    ├─ SAM（可服务市场）
    ├─ SOM（可获取市场）
    └─ 市场增速与天花板

Step 2: 规模效应识别
    ├─ A/B/C/反规模效应类型
    ├─ 规模效应 Scope（全球/全国/城市/蜂窝）
    ├─ 临界质量判断
    └─ 多要素博弈

Step 3: 竞争格局分析
    ├─ 波特五力
    ├─ 核心竞争者定位
    ├─ 护城河类型
    └─ 潜在颠覆者

Step 4: 资源配置决策
    ├─ 三曲线资源分配
    ├─ 预算类型（经营/成长/探索）
    ├─ 关键资源瓶颈
    └─ 机会成本评估

Step 5: 假设与证伪机制
    ├─ 核心战略假设
    ├─ 领先指标
    ├─ 证伪条件
    └─ 复盘周期
```

## 关键框架速查

### TAM/SAM/SOM 估算
- 拟合外推法
- 根本需求法
- 类比法
- 持续校正法

### PEST / PESTEL
- P：政治（监管、补贴、关税）
- E：经济（消费、融资、竞争）
- S：社会（人口、文化、趋势）
- T：技术（创新、数字化）
- E：环境（可持续、碳中和）
- L：法律（合规、知识产权）

### 波特五力
1. 现有竞争强度
2. 新进入者威胁
3. 替代品威胁
4. 供应商议价能力
5. 客户议价能力

### 战略屋（Strategy One）
- 使命愿景
- 战略目标
- 必赢之战
- 落地保障（组织/机制/人才）

## 战略优先级评分

### RICE 评分法
```
RICE 得分 = (Reach × Impact × Confidence) / Effort
```

### ICE 评分法
```
ICE 得分 = (Impact × Confidence × Ease) / 3
```

### 战略举措评分矩阵
维度：战略契合度、预期收益、资源需求、实施难度、风险等级

## 情景规划

当面临高度不确定性时，使用 2×2 情景矩阵：
- 识别 2 个最关键的不确定性
- 构建 4 种情景
- 评估战略在各情景下表现
- 设计韧性战略（no-regret 行动）

## 战略假设管理

每个战略必须明确：

| 假设 | 类型 | 验证指标 | 证伪条件 | 复盘周期 |
|------|------|---------|---------|---------|
| 假设1 | 市场 | ... | ... | 季度 |
| 假设2 | 用户 | ... | ... | 月度 |
| 假设3 | 竞争 | ... | ... | 半年 |

## 常见陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 把策略当战略 | 谈打法不谈方向 | 明确时空与成立前提 |
| 忽视规模效应 Scope | 用错策略类型 | 先识别曲线类型 |
| 忽视反规模效应 | 盲目扩张 | 识别管理瓶颈 |
| 市场体量不校正 | 一次性判断 | 动态评估 |
| 不含证伪机制 | 战略失败而不知 | 明确领先指标 |
