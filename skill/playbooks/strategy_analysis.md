# 战略分析 Playbook

适用任务：战略选择、市场分析、资源配置、战略复盘

## 核心流程

### 战略分析七步法

```
Step 0: 历史纵深
    ├─ 关键里程碑时间线（年份+事件+数据）
    ├─ 战略逻辑的延续与变迁
    ├─ 关键转折点识别
    └─ 当前能力的来源（积累/购买/合作）

Step 1: 当前业务模型拆解
    ├─ 收入来源分解（息差/佣金/技术服务/其他）
    ├─ 各来源的规模、毛利、占比
    ├─ 客户/用户分层（B端/C端/生态内/生态外）
    └─ 当前模型的核心瓶颈

Step 2: 市场体量判断
    ├─ TAM（总潜在市场）
    ├─ SAM（可服务市场）
    ├─ SOM（可获取市场）
    └─ 市场增速与天花板

Step 3: 监管环境分析（中国必做，海外可选）
    ├─ 当前监管状态（牌照/资质/合规要求）
    ├─ 监管趋势方向（收紧/放松/转型）
    ├─ 对业务模型的直接影响（哪些模式被限制、哪些被鼓励）
    └─ 应对策略与合规路径

Step 4: 规模效应识别
    ├─ A/B/C/反规模效应类型
    ├─ 规模效应 Scope（全球/全国/城市/蜂窝）
    ├─ 临界质量判断
    └─ 多要素博弈

Step 5: 竞争格局分析
    ├─ 波特五力
    ├─ 核心竞争者定位（含数据对比表）
    ├─ 护城河类型
    └─ 潜在颠覆者

Step 6: 资源配置决策
    ├─ 三曲线资源分配
    ├─ 预算类型（经营/成长/探索）
    ├─ 关键资源瓶颈
    └─ 机会成本评估

Step 7: 假设与证伪机制
    ├─ 核心战略假设
    ├─ 领先指标
    ├─ 证伪条件
    └─ 复盘周期
```

### 机制解释要求

战略分析中每一个关键判断，都必须解释**为什么**，而不仅仅是**是什么**。具体要求：

| 判断类型 | 最低解释标准 | 示例 |
|---------|------------|------|
| 现象陈述 | 必须给出因果链 | "渗透率低"→ 因果链：出行场景≠金融需求→用户心智=出行工具→金融产品曝光无效 |
| 竞争劣势 | 必须对比机制差异 | "金融渗透率1.8% vs 蚂蚁30%"→ 支付宝=支付工具(金融心智天然) vs 滴滴=出行工具(金融心智缺失) |
| 战略机会 | 必须解释壁垒来源 | "司机经营贷是机会"→ 壁垒来源：平台掌握司机真实收入数据+可直接扣款→银行无法复制 |
| 风险判断 | 必须说明传导路径 | "监管风险"→ 传导：助贷新规→银行自主风控→滴滴风控输出降级→佣金率下降 |

### 关联公司数据策略

当分析对象为非上市公司或数据不透明的业务时，通过关联公司/参股公司的公开数据**反推**分析对象的业务表现：

1. 识别可用的关联公司窗口（如参股消金公司、合资企业、生态内上市公司）
2. 提取关联公司的公开财务数据
3. 基于持股比例和业务关系，推算分析对象的贡献和收益
4. 明确标注推算逻辑和不确定性

## 关键框架速查

### TAM/SAM/SOM 估算
- 拟合外推法
- 根本需求法
- 类比法
- 持续校正法

### PEST / PESTEL
- P：政治（监管、补贴、关税）
- E：经济（消费、融资、竞争）
- S：社会（人口、文化、趋势）
- T：技术（创新、数字化）
- E：环境（可持续、碳中和）
- L：法律（合规、知识产权）

### 波特五力
1. 现有竞争强度
2. 新进入者威胁
3. 替代品威胁
4. 供应商议价能力
5. 客户议价能力

### 战略屋（Strategy One）
- 使命愿景
- 战略目标
- 必赢之战
- 落地保障（组织/机制/人才）

## 战略优先级评分

### RICE 评分法
```
RICE 得分 = (Reach × Impact × Confidence) / Effort
```

### ICE 评分法
```
ICE 得分 = (Impact × Confidence × Ease) / 3
```

### 战略举措评分矩阵
维度：战略契合度、预期收益、资源需求、实施难度、风险等级

## 情景规划

当面临高度不确定性时，使用 2×2 情景矩阵：
- 识别 2 个最关键的不确定性
- 构建 4 种情景
- 评估战略在各情景下表现
- 设计韧性战略（no-regret 行动）

## 战略假设管理

每个战略必须明确：

| 假设 | 类型 | 验证指标 | 证伪条件 | 复盘周期 |
|------|------|---------|---------|---------|
| 假设1 | 市场 | ... | ... | 季度 |
| 假设2 | 用户 | ... | ... | 月度 |
| 假设3 | 竞争 | ... | ... | 半年 |

## 常见陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 把策略当战略 | 谈打法不谈方向 | 明确时空与成立前提 |
| 忽视规模效应 Scope | 用错策略类型 | 先识别曲线类型 |
| 忽视反规模效应 | 盲目扩张 | 识别管理瓶颈 |
| 市场体量不校正 | 一次性判断 | 动态评估 |
| 不含证伪机制 | 战略失败而不知 | 明确领先指标 |
