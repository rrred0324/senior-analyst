# IPO/新上市公司分析 Playbook

适用任务：IPO分析、S-1/F-1招股书分析、新上市公司深度研究、创始人控制型公司评估

## 核心流程

### IPO分析七步法

```
Step 1: 招股书关键数据提取
    ├─ 营收/利润/现金流时间序列（至少3年+最近季度）
    ├─ 业务分部数据（按产品/地域/客户类型）
    ├─ 股权架构（AB股/投票权/期权池）
    ├─ 风险因素清单（逐条映射到估值影响）
    └─ 募集资金用途

Step 2: 基本面估值底线
    ├─ DCF（基于招股书历史数据+趋势延伸）
    ├─ 分部对标Comps（至少3家对标per segment）
    └─ 概率加权估值 = 基本面锚点

Step 3: IPO溢价量化
    ├─ 溢价来源识别：创始人光环/范式变革/FOMO/稀缺性/做空限制
    ├─ 每种溢价估算金额范围
    ├─ 证伪条件定义
    └─ IPO价格 vs 基本面底线 → 溢价占比

Step 4: 投资者回报分析
    ├─ IRR矩阵：IPO价/首日价/回调价 × 3年/5年 × Bull/Base/Bear
    ├─ 概率加权IRR计算
    ├─ 使IRR转正的最低入场价
    └─ 稀释影响建模（如果预期再融资）

Step 5: 治理架构评估
    ├─ 六维度治理评级（独立董事/投票权偏离/关联交易/高管稳定/信披质量/投资者保护）
    ├─ 同行业创始人控制型对标
    ├─ 治理折价建议
    └─ 锁定期到期影响评估

Step 6: 上市后关键观察窗口
    ├─ 首个财报（验证收入确认/成本结构假设）
    ├─ 锁定期到期日（解禁卖压估算）
    ├─ 6个月后的分析师覆盖（卖方vs买方分歧）
    └─ 12个月后的IPO情绪消散期

Step 7: 持续跟踪框架
    ├─ 关键指标看板
    ├─ 证伪触发器
    └─ 季度更新协议
```

## S-1/F-1数据提取模板

| 数据类别 | 关键字段 | 常见陷阱 |
|---------|---------|---------|
| 收入 | 分部营收、ARPU/客单价、增速 | 非GAAP口径调整、并购贡献 vs 有机增长 |
| 盈利 | 毛利/净利/调整后EBITDA | 股票期权费用是否扣除、研发资本化比例 |
| 现金流 | OCF/FCF/Capex | 租赁是否入表、营运资本变动 |
| 资产 | 商誉/无形资产/总资产 | 商誉减值风险、并购溢价 |
| 股权 | AB股比例/期权池/已发行vs储备 | 完全稀释后股数 vs 基本股数 |
| 风险因素 | 逐条映射影响 | 招股书风险因素是法律文件，不是分析——需自行量化 |

## 创始人控制型公司特殊性

| 维度 | 创始人控制型公司 | 分散型公司 |
|------|---------------|----------|
| 决策速度 | 极快，单点决策 | 较慢，董事会共识 |
| 战略一致性 | 高，愿景驱动 | 中，妥协产物 |
| 风险承担 | 愿意all-in（马斯克式） | 偏保守 |
| 少数股东保护 | 低（强制表决权碾压） | 高（多数规则） |
| 关联交易风险 | 高（缺乏制衡） | 低（独立审查） |
| 估值影响 | 需治理折价（通常5-25%） | 无折价 |
