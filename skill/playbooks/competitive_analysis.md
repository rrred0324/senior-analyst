# 竞争对手对比分析 Playbook

适用任务：竞争对手对比、行业对标、差异化分析、竞争格局梳理

## 核心流程

### 竞争对手对比四步法

```
Step 1: 选择对标公司
    ├─ 直接竞争者（同市场、同模式）
    ├─ 商业模式类似（不同市场但模式相似）
    ├─ 发展阶段类似（规模/阶段可比）
    └─ 确保至少 2-3 家对标

Step 2: 多维度对比
    ├─ 财务维度（收入/利润/Take Rate/增速）
    ├─ 运营维度（MAU/订单量/留存率/CAC）
    ├─ 估值维度（P/S/P/E/EV/EBITDA）
    └─ 标注行业中位数

Step 3: 差异归因分析
    ├─ 监管因素差异
    ├─ 竞争格局差异
    ├─ 商业模式差异
    ├─ 发展阶段差异
    └─ 地域差异
    → 判断差异的可持续性

Step 4: 竞争优势识别
    ├─ 哪些指标显著优于对手？（护城河）
    ├─ 哪些指标显著劣于对手？（风险点）
    ├─ 哪些指标趋同？（行业共性）
    └─ 构建竞争优势矩阵
```

## 对标公司选择原则

### 可比性检查
| 维度 | 检查项 |
|------|--------|
| 商业模式 | 收入来源/盈利模式是否相似 |
| 发展阶段 | 规模/成熟度是否可比 |
| 地域市场 | 同一市场或相似市场 |
| 会计口径 | 指标口径是否一致 |

### 常见对标错误
- ❌ 用不同商业模式的公司对比（如京东自营 vs 淘宝平台）
- ❌ 用不同发展阶段的公司对比（如初创 vs 成熟）
- ❌ 不调整口径直接对比
- ❌ 只选弱者对比以显得好看

## 差异归因框架

发现差异 → 归因分析 → 判断可持续性

### 归因维度
1. **监管因素**：政策/合规导致的差异（通常持续）
2. **竞争格局**：市场结构导致的差异（中期持续）
3. **商业模式**：盈利模式导致的差异（长期持续）
4. **发展阶段**：成熟度导致的差异（会随时间改变）
5. **地域差异**：市场特征导致的差异（通常持续）

### 可持续性判断
- 监管限制短期难以改变 → 差异持续
- 但国际业务可能不同 → 差异可能缩小
- 发展阶段差异 → 随时间会收敛

## 竞争优势矩阵

```
         优势程度
           ↑
    强  │ 护城河 │ 继续强化 │
        ├────────┼──────────┤
    弱  │ 需改进 │ 行业共性 │
           →
         重要性
```

- **护城河**（重要且优势强）：核心壁垒，继续强化
- **需改进**（重要但优势弱）：优先投入
- **继续强化**（不重要但优势强）：维持优势
- **行业共性**（不重要且优势弱）：接受现状
