# 情景与敏感性分析 Playbook

适用任务：未来预测、估值分析、风险评估、假设验证、情景推演

## 核心流程

### 情景分析五步法

```
Step 1: 识别关键驱动因素
    ├─ 通过敏感性分析找出影响最大的变量
    ├─ 识别 3-5 个关键驱动因素
    └─ 确保因素之间相对独立

Step 2: 设定三情景假设
    ├─ Bull Case（乐观情景）：关键假设均向有利方向
    ├─ Base Case（基准情景）：当前趋势的合理延伸
    └─ Bear Case（悲观情景）：关键假设均向不利方向
    → 每个情景的假设必须合理且可验证

Step 3: 推演财务结果
    ├─ 每个情景下的收入/利润/现金流预测
    ├─ 对应的估值推算
    └─ 与当前估值对比计算潜在回报

Step 4: 概率加权
    ├─ 为每个情景分配主观概率
    ├─ 计算概率加权期望值
    └─ 概率之和必须为 100%

Step 5: 设定触发条件
    ├─ 每个情景的可观测信号
    ├─ 信号必须可量化
    └─ 验证时点明确（1-2 个季度内可验证）
```

### 敏感性分析三步法

```
Step 1: 单因素敏感性分析
    ├─ 固定其他变量，逐一改变单一变量
    ├─ 观察结果变化幅度
    └─ 识别对结论影响最大的变量

Step 2: 双因素敏感性分析（复杂分析必做）
    ├─ 选择最敏感的两个变量
    ├─ 生成双因素敏感性矩阵
    └─ 判断主次驱动因素

Step 3: 稳健性评估
    ├─ 确定结论的稳健区间
    ├─ 判断在什么条件下结论会反转
    └─ 标注不确定性等级
```

## 情景假设设计规范

### Bull Case 要求
- 不是幻想，假设必须合理
- 基于可实现的乐观条件
- 通常概率 15-25%
- 必须说明哪些有利条件需要同时成立

### Base Case 要求
- 基于当前趋势的合理延伸
- 不做额外乐观或悲观假设
- 通常概率 40-60%
- 必须是最可能发生的情况

### Bear Case 要求
- 不是极端灾难，假设必须可能发生
- 基于可实现的悲观条件
- 通常概率 20-35%
- 必须说明哪些不利条件需要同时成立

### 概率分配原则
- 三情景概率之和 = 100%
- Base Case 通常占比最大
- Bull/Bear 不一定对称
- **必须说明概率分配的逻辑依据**——禁止无锚定主观赋值

### 概率赋值的驱动因子分解法（新增——强制方法）

禁止"我觉得Bull 20% Base 50% Bear 30%"式无锚赋值。概率必须经过以下步骤推导：

```
Step 1: 识别每个情景的关键驱动条件（2-4个）
Step 2: 估计每个驱动条件的独立概率（基于历史频率/行业类比/专家判断）
Step 3: 计算联合概率（Bull需要多个有利条件同时成立，Bear只需任一不利条件触发）
Step 4: 联合概率 → 赋值修正（Bull通常是"大部分满足"，Bear是"任一触发"）
Step 5: 输出：Bull X% / Base Y% / Bear Z%（附驱动因子概率表）
```

**驱动因子概率表（必须输出）**：

| 驱动因子 | Bull需要的条件 | 独立概率 | Bear触发的条件 | 独立概率 |
|---------|--------------|---------|--------------|---------|
| 因子1 | [条件] | X% | [条件] | X% |
| 因子2 | [条件] | X% | [条件] | X% |
| 因子3 | [条件] | X% | [条件] | X% |

→ 联合概率：Bull ≈ X%×X%×X%（大部分满足）≈ XX%
→ Bear ≈ 1-(1-X%)×(1-X%)×(1-X%)（任一触发）≈ XX%

### 隐含概率反推法（新增——市场情绪校准）

在给出自己的概率分布后，必须反向计算当前市场价格隐含的情景分布：

```
当前市值 = Bull终值 × P(bull) + Base终值 × P(base) + Bear终值 × P(bear)
其中 P(bull) + P(base) + P(bear) = 100%
```

解出市场隐含的概率分布，与自己的概率分布对比：

```
| 分布来源           | Bull | Base | Bear |
|-------------------|------|------|------|
| 我的分析           | 20%  | 50%  | 30%  |
| 市场隐含           | 60%  | 30%  | 10%  |
| 差异               | +40pp| -20pp| -20pp|
```

→ **结论**：市场定价远比我的分析乐观，差异40pp意味着我要么低估了X因素，要么市场定价过度。


## 常见陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 情景假设不独立 | Bull 需要 5 个假设同时成立 | 减少关键假设数量 |
| 概率分配无依据 | 随意给 33/33/33 | 基于历史频率或专家判断 |
| 触发条件不可观测 | "市场变好" | 必须量化（如"GTV 增速 >25%"） |
| 只做情景不做敏感性 | 不知道哪个假设最重要 | 两者必须配合使用 |
| Base Case 等于当前 | 忽略趋势变化 | 基于趋势延伸，不是当前快照 |
