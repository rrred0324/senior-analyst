# 情景与敏感性分析 Playbook

适用任务：未来预测、估值分析、风险评估、假设验证、情景推演

## 核心流程

### 情景分析五步法

```
Step 1: 识别关键驱动因素
    ├─ 通过敏感性分析找出影响最大的变量
    ├─ 识别 3-5 个关键驱动因素
    └─ 确保因素之间相对独立

Step 2: 设定三情景假设
    ├─ Bull Case（乐观情景）：关键假设均向有利方向
    ├─ Base Case（基准情景）：当前趋势的合理延伸
    └─ Bear Case（悲观情景）：关键假设均向不利方向
    → 每个情景的假设必须合理且可验证

Step 3: 推演财务结果
    ├─ 每个情景下的收入/利润/现金流预测
    ├─ 对应的估值推算
    └─ 与当前估值对比计算潜在回报

Step 4: 概率加权
    ├─ 为每个情景分配主观概率
    ├─ 计算概率加权期望值
    └─ 概率之和必须为 100%

Step 5: 设定触发条件
    ├─ 每个情景的可观测信号
    ├─ 信号必须可量化
    └─ 验证时点明确（1-2 个季度内可验证）
```

### 敏感性分析三步法

```
Step 1: 单因素敏感性分析
    ├─ 固定其他变量，逐一改变单一变量
    ├─ 观察结果变化幅度
    └─ 识别对结论影响最大的变量

Step 2: 双因素敏感性分析（复杂分析必做）
    ├─ 选择最敏感的两个变量
    ├─ 生成双因素敏感性矩阵
    └─ 判断主次驱动因素

Step 3: 稳健性评估
    ├─ 确定结论的稳健区间
    ├─ 判断在什么条件下结论会反转
    └─ 标注不确定性等级
```

## 情景假设设计规范

### Bull Case 要求
- 不是幻想，假设必须合理
- 基于可实现的乐观条件
- 通常概率 15-25%
- 必须说明哪些有利条件需要同时成立

### Base Case 要求
- 基于当前趋势的合理延伸
- 不做额外乐观或悲观假设
- 通常概率 40-60%
- 必须是最可能发生的情况

### Bear Case 要求
- 不是极端灾难，假设必须可能发生
- 基于可实现的悲观条件
- 通常概率 20-35%
- 必须说明哪些不利条件需要同时成立

### 概率分配原则
- 三情景概率之和 = 100%
- Base Case 通常占比最大
- Bull/Bear 不一定对称
- 必须说明概率分配的逻辑依据

### 单因素敏感性
| 变量值 | 结果 | 变化幅度 |
|--------|------|---------|
| -20% | ... | ... |
| -10% | ... | ... |
| 基准 | ... | 0% |
| +10% | ... | ... |
| +20% | ... | ... |

**结论**：变量 X 每变化 Y%，结果变化 Z% → [高/中/低]敏感

### 双因素敏感性矩阵
```
结果值
变量B →  值1   值2   值3   值4
变量A ↓
  值1    ...   ...   ...   ...
  值2    ...   ...   ...   ...
  值3    ...   ...   ...   ...
  值4    ...   ...   ...   ...
```

**结论**：变量 A 是第 X 驱动因素，变量 B 是第 Y 驱动因素

## 常见陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 情景假设不独立 | Bull 需要 5 个假设同时成立 | 减少关键假设数量 |
| 概率分配无依据 | 随意给 33/33/33 | 基于历史频率或专家判断 |
| 触发条件不可观测 | "市场变好" | 必须量化（如"GTV 增速 >25%"） |
| 只做情景不做敏感性 | 不知道哪个假设最重要 | 两者必须配合使用 |
| Base Case 等于当前 | 忽略趋势变化 | 基于趋势延伸，不是当前快照 |
