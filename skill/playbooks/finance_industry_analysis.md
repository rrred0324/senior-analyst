# 财报与行业分析 Playbook

适用任务：财报分析、财报排雷、行业对标、投资分析

## 核心流程

### 财报分析强制顺序

```
Step 1: 现金流（日子）        ← 不可跳步 ─────────────┐
    ├─ OCF 是否为正？                                    │
    ├─ OCF/净利润比值？                                  │ 强制执行门控：
    └─ 现金流四象限定位                                  │ 数据不可得时留空位
                                                        │ 标注缺口，不可跳步
Step 2: 资产负债（底子）    ← 不可跳步 ─────────────┤
    ├─ 资产负债率                                        │
    ├─ 重点科目风险（含风险等级）                        │
    │   ├─ 应收账款增速 vs 营收增速                     │
    │   ├─ 存货周转天数趋势                             │
    │   ├─ 商誉/总资产比 → >50%为🔴风险                 │
    │   ├─ 在建工程是否长期不转固                        │
    │   └─ [新] 整体商誉减值情景推演（如有重大并购）     │
    └─ [新] 资本支出拆分按业务板块                       │
                                                        │
Step 3: 利润（面子）        ← 不可跳步 ─────────────┤
    ├─ 毛利率                                           │
    ├─ 净利率                                           │
    └─ ROE（杜邦分解）                                   │
                                                        │
Step 4: 勾稽验证           ← 不可跳步 ─────────────┤
    ├─ [新] 验证一：营收增长 vs 现金流匹配度            │
    ├─ [新] 验证二：盈利窗口会计口径检查                │
    ├─ [新] 验证三：应收账款与营收增长匹配度            │
    └─ [新] 验证四：关键比率合理性（vs行业中位数）      │
                                                        │
Step 5: 红旗扫描           ← 不可跳步 ─────────────┘
    ├─ 收入异常
    ├─ 现金流异常
    ├─ 资产异常
    └─ 报表异常
```

> **⚠️ 执行门控规则**：Step 1-5 必须全部执行、全部输出。如果某步数据不可得，在报告中对应章节留出空位并标注「数据缺口：[缺口项] — 影响范围：[对结论的影响] — 建议补充方式：[如何获取]」。**绝对不可跳步后假装该步不存在。**

## 三表核心指标

### 利润表
- 毛利率
- 净利率
- ROE（净利率 × 周转率 × 杠杆）

### 资产负债表
- 资产负债率
- 流动比率 / 速动比率
- 重点科目（应收、存货、商誉、在建）

### 现金流量表
- OCF
- OCF/净利润
- 现金流四象限

## 现金流四象限

| 状态 | OCF | 投资 CF | 含义 |
|------|-----|---------|------|
| 母鸡型 | + | − | 成熟稳定，经营造血、稳健投资，优选 |
| 蛮牛型 | + | + | 扩张期，经营造血同时加大投资，需关注融资支撑 |
| 收缩变现型 | − | + | 经营失血但靠变卖资产或收回投资获取现金。若为短期战略调整可接受；若持续则为危险信号 |
| 失血型 | − | − | 经营和投资两端失血，极度危险 |

> **判断要点**：收缩变现型需区分主动与被动。主动收缩（业务聚焦、剥离非核心资产）是战略选择，OCF 短暂为负但趋势应收敛；被动变卖（因经营失血被迫处置资产维持流动性）才是真正的危险信号。连续2个季度以上 OCF 为负且投资 CF 持续为正，基本可判断为被动收缩。

### 现金流执行模板（新增）

每份财报分析必须在"日子"章节输出以下内容：

```markdown

[公司名] [期间] 现金流向图：

经营现金流入  ──→ +$XX亿
                      │
资本支出      ──→ -$XX亿         净现金流出 ≈ -$XX亿/[期间]
  ├─ 板块A    ──→ -$XX亿 (X%)
  ├─ 板块B    ──→ -$XX亿 (X%)
  └─ 板块C    ──→ -$XX亿 (X%)

```

### 勾稽验证四项检查协议（新增）

**验证一：营收增长 vs 现金流匹配度**
- 比较营收增速、Capex增速、运营利润方向是否一致
- 营收增速放缓+Capex增速翻倍 = "赌注加倍"模式 → 🔴警告

**验证二：盈利窗口会计口径检查**
- 如存在唯一盈利年，检查：①盈利是否来自运营改善②是否受益于收入确认时点③是否受益于资本化vs费用化选择④合并前后口径是否一致
- 唯一盈利年有"窗口盈利"特征 → 🟡标注不宜视为可持续

**验证三：应收账款与营收增长匹配度**
- 应收增速显著快于营收增速 → 可能放宽信用条件冲收入
- 数据不可得时，明确列出缺口

**验证四：关键比率合理性**
- 将公司关键比率（运营利润率、Capex/营收、支出/收入比等）与行业中位数对比
- 偏离>10pp的比率必须解释原因并评估可持续性

## 红旗信号清单

### 收入异常
- [ ] 毛利率显著高于同行（>10% 差距）[适用：同行业同模式对比；局限：部分高毛利新经济公司可能合理偏高]
- [ ] 应收账款增速远超营收
- [ ] 收入集中在期末
- [ ] 客户集中度过高
- [ ] 关联交易占比过高

### 现金流异常
- [ ] 净利润+但 OCF 持续-
- [ ] OCF/净利润 <0.5 [适用：非金融行业；局限：重资本开支行业可能因折旧摊销导致偏低]
- [ ] 存贷双高
- [ ] 利息收入/货币资金 <1%

### 资产异常
- [ ] 商誉/总资产 >50%
- [ ] 在建工程长期不转固
- [ ] 存货周转天数持续上升

### 报表异常
- [ ] 频繁更换审计
- [ ] 审计意见非标

## 投资分析四维框架

```
财务质量 + 竞争优势 + 管理层 + 估值 = 投资决策
```

### 竞争优势（护城河）
- 无形资产（品牌、专利）
- 转换成本
- 网络效应
- 成本优势
- 有效规模

### 管理层评估
- ROIC 长期表现
- 资本配置能力
- 股东回报记录
- 战略一致性

### 公司治理评级（新增——上市公司必做）

凡分析上市公司（包含已上市、IPO后、新上市公司），必须输出治理评级：

| 治理维度 | 评分标准 | 评级 |
|---------|---------|------|
| **独立董事比例** | >2/3独立=A+, 1/2=B, <1/3=D/F | — |
| **投票权与经济权偏离** | 偏离<10%=A, 10-30%=C, >50%=F | — |
| **关联交易披露** | 无重大关联交易=A, 有独立评估=B, 无独立评估=D- | — |
| **高管稳定性** | 核心团队>5年=B+, 频繁更换=D | — |
| **信息披露质量** | 全分部详细披露=A, 关键数据缺失=C/F | — |
| **投资者保护** | 有毒丸/金色降落伞=B, 无保护机制=F | — |

综合评级规则：取六维度中位数 → 对标同行业创始人控制型公司 → 建议治理折价
- A+/A → 无折价
- B+/B → 0-5%折价
- C+/C → 5-10%折价
- D+/D → 10-15%折价
- F → 15-25%折价

### 客户集中度分析（新增——投资分析必做）

| 维度 | 分析要点 | 风险等级 |
|------|---------|---------|
| 前五大客户营收占比 | >30%高集中 | 🟡 |
| 最大单一客户占比 | >15%单客户依赖 | 🔴 |
| 政府/机构客户占比 | >50%为政府依赖型 | 🔴 |
| 创始人关联公司占比 | >5%关联交易风险 | 🟡 |
| 客户集中度趋势 | 集中度上升→风险恶化 | 🟡 |

→ **核心判断**：公司是"商业竞争者"还是"政府依赖型商业化"？如是后者，需在估值中反映政府合同波动风险

### 估值方法

| 方法 | 适用 |
|------|------|
| P/E | 盈利稳定 |
| PEG | 成长股 |
| P/S | 亏损但增长 |
| P/B | 银行/保险 |
| EV/EBITDA | 重资产 |
| DCF | 理论锚点 |

## 行业分析要点

### 制造业
核心：产能利用率、良品率、固定资产周转率

### 零售业
核心：同店增长、坪效、库存周转

### SaaS
核心：NDR、ARR、Magic Number、Rule of 40

### 金融/银行
核心：净息差、不良率、拨备覆盖率

### 房地产
核心：净负债率、预售款占比、三道红线

### 互联网平台
核心：MAU、GMV、Take Rate、CAC

### 医疗健康
核心：研发投入比、专利到期、管线数

### 游戏
核心：流水、付费率、长线留存

### 保险
核心：综合成本率、内含价值、新业务价值

## 造假识别核心原则

> **宁可错杀，不可放过**

- 3-5 个红旗 → 造假概率 15-40%
- 5+ 个核心红旗 → 造假概率 >50%
