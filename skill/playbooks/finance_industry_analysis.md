# 财报与行业分析 Playbook

适用任务：财报分析、财报排雷、行业对标、投资分析

## 核心流程

### 财报分析强制顺序

```
Step 1: 现金流（日子）
    ├─ OCF 是否为正？
    ├─ OCF/净利润比值？
    └─ 现金流四象限定位

Step 2: 资产负债（底子）
    ├─ 资产负债率
    ├─ 重点科目风险
    └─ 商誉/在建工程

Step 3: 利润（面子）
    ├─ 毛利率
    ├─ 净利率
    └─ ROE（杜邦分解）

Step 4: 勾稽验证
    └─ 三表一致性检查

Step 5: 红旗扫描
    ├─ 收入异常
    ├─ 现金流异常
    ├─ 资产异常
    └─ 报表异常
```

## 三表核心指标

### 利润表
- 毛利率
- 净利率
- ROE（净利率 × 周转率 × 杠杆）

### 资产负债表
- 资产负债率
- 流动比率 / 速动比率
- 重点科目（应收、存货、商誉、在建）

### 现金流量表
- OCF
- OCF/净利润
- 现金流四象限

## 现金流四象限

| 状态 | OCF | 投资 CF | 含义 |
|------|-----|---------|------|
| 母鸡型 | + | − | 成熟稳定，经营造血、稳健投资，优选 |
| 蛮牛型 | + | + | 扩张期，经营造血同时加大投资，需关注融资支撑 |
| 收缩变现型 | − | + | 经营失血但靠变卖资产或收回投资获取现金。若为短期战略调整可接受；若持续则为危险信号 |
| 失血型 | − | − | 经营和投资两端失血，极度危险 |

> **判断要点**：收缩变现型需区分主动与被动。主动收缩（业务聚焦、剥离非核心资产）是战略选择，OCF 短暂为负但趋势应收敛；被动变卖（因经营失血被迫处置资产维持流动性）才是真正的危险信号。连续2个季度以上 OCF 为负且投资 CF 持续为正，基本可判断为被动收缩。

## 红旗信号清单

### 收入异常
- [ ] 毛利率显著高于同行（>10% 差距）[适用：同行业同模式对比；局限：部分高毛利新经济公司可能合理偏高]
- [ ] 应收账款增速远超营收
- [ ] 收入集中在期末
- [ ] 客户集中度过高
- [ ] 关联交易占比过高

### 现金流异常
- [ ] 净利润+但 OCF 持续-
- [ ] OCF/净利润 <0.5 [适用：非金融行业；局限：重资本开支行业可能因折旧摊销导致偏低]
- [ ] 存贷双高
- [ ] 利息收入/货币资金 <1%

### 资产异常
- [ ] 商誉/总资产 >50%
- [ ] 在建工程长期不转固
- [ ] 存货周转天数持续上升

### 报表异常
- [ ] 频繁更换审计
- [ ] 审计意见非标

## 投资分析四维框架

```
财务质量 + 竞争优势 + 管理层 + 估值 = 投资决策
```

### 竞争优势（护城河）
- 无形资产（品牌、专利）
- 转换成本
- 网络效应
- 成本优势
- 有效规模

### 管理层评估
- ROIC 长期表现
- 资本配置能力
- 股东回报记录
- 战略一致性

### 估值方法

| 方法 | 适用 |
|------|------|
| P/E | 盈利稳定 |
| PEG | 成长股 |
| P/S | 亏损但增长 |
| P/B | 银行/保险 |
| EV/EBITDA | 重资产 |
| DCF | 理论锚点 |

## 行业分析要点

### 制造业
核心：产能利用率、良品率、固定资产周转率

### 零售业
核心：同店增长、坪效、库存周转

### SaaS
核心：NDR、ARR、Magic Number、Rule of 40

### 金融/银行
核心：净息差、不良率、拨备覆盖率

### 房地产
核心：净负债率、预售款占比、三道红线

### 互联网平台
核心：MAU、GMV、Take Rate、CAC

### 医疗健康
核心：研发投入比、专利到期、管线数

### 游戏
核心：流水、付费率、长线留存

### 保险
核心：综合成本率、内含价值、新业务价值

## 造假识别核心原则

> **宁可错杀，不可放过**

- 3-5 个红旗 → 造假概率 15-40%
- 5+ 个核心红旗 → 造假概率 >50%
