## 一、OKX App 两大核心区域：CEX 与 Web3

### 1.1 一句话区分

打开OKX App，你面对的是**两个完全不同的世界**：

| | CEX（中心化交易所） | Web3（去中心化世界） |
|---|---|---|
| **比喻** | 银行账户 | 自己家的保险柜 |
| **谁控制资产** | OKX 替你保管 | 你自己保管 |
| **登录方式** | 手机号/邮箱+密码 | 助记词/私钥 |
| **操作入口** | App底部"交易" | App底部"Web3" |
| **需要身份认证** | 需要（KYC） | 不需要 |
| **丢了密码** | 找客服重置 | **永远找不回来** |

### 1.2 为什么要同时理解两者？

- **CEX**是你用法币（人民币/美元）买入加密货币的入口
- **Web3**是你持有、使用、投资加密货币的主战场
- 典型流程：CEX买币 → 提币到Web3钱包 → 在DeFi/DEx中使用

### 1.3 OKX App 底部导航栏对应

```
┌──────────────────────────────────────────┐
│  首页  │  交易(CEX)  │  Web3  │  资产    │
│        │  现货/合约   │ 钱包   │          │
│        │  闪兑/杠杆   │ DeFi  │          │
│        │              │ DEX   │          │
│        │              │ NFT   │          │
└──────────────────────────────────────────┘
```

## 二、Web3 钱包：你的链上金库

### 2.1 什么是 Web3 钱包？

Web3钱包不是"装钱的包"，而是**管理你在区块链上资产身份的工具**。它存储的是：
- **助记词**（Mnemonic）：12或24个英文单词，是你钱包的"万能钥匙"
- **私钥**（Private Key）：一串字符，用于签名交易，证明"你是你"
- **公钥/地址**（Address）：类似银行卡号，别人给你转账用的

**核心原则**：谁掌握助记词/私钥，谁就拥有钱包里的资产。OKX Web3钱包是**非托管**的——OKX不存储你的助记词，无法帮你找回，也无法动用你的资产。

### 2.2 创建钱包的步骤

在OKX App中：

```
步骤1：点击底部"Web3"标签
步骤2：选择"创建钱包"
步骤3：设置钱包名称和密码（这是本地密码，保护App内访问）
步骤4：⚠️ 备份助记词（最重要的一步）
       → 手写抄录12/24个单词到纸上
       → 按顺序抄写，不得错漏
       → 存放在安全的离线位置
       → 绝不截图、绝不拍照、绝不发到网上
步骤5：验证助记词（按顺序点选单词确认）
步骤6：钱包创建完成
```

### 2.3 导入已有钱包

如果你之前有钱包（如MetaMask），可以导入：

```
步骤1：点击底部"Web3"标签
步骤2：选择"导入钱包"
步骤3：选择导入方式：
       → 助记词导入（输入12/24个单词）
       → 私钥导入（输入一串字符）
步骤4：设置本地密码
步骤5：导入完成
```

### 2.4 钱包地址详解

一个钱包可以拥有**多条链的地址**，每条链的地址格式不同：

| 区块链 | 地址格式示例 | 特征 |
|--------|-------------|------|
| 以太坊（EVM） | `0x71C7...3bE4` | 以0x开头，42位 |
| 比特币 | `bc1q...w5r4` | 以bc1或1/3开头 |
| Solana | `7xKX...3nVd` | Base58编码 |
| Tron | `TJYe...8kV2` | 以T开头 |

**重要**：给不同链的币转账，必须用对应链的地址。以太坊地址收BTC会丢币！

### 2.5 CEX账户 vs Web3钱包的资产互转

```
CEX账户资金 → "提币" → Web3钱包地址    （从OKX托管转到自己控制）
Web3钱包地址 → "充币" → CEX账户         （从自己控制转到OKX托管）
```

在OKX App中的操作路径：

```
CEX → Web3：资产 → 提币 → 选择币种 → 选择"OKX Web3钱包" → 确认
Web3 → CEX：Web3 → 钱包 → 选择币种 → 转账 → 输入CEX充币地址 → 确认
```

## 三、发送与接收币种

### 3.1 接收（收币）

别人给你转账，你只需要提供**你的钱包地址**：

```
步骤1：打开OKX App → Web3 → 钱包
步骤2：选择你要接收的币种（如USDT）
步骤3：点击"收款"或地址旁边的复制按钮
步骤4：将地址发送给对方（二维码或文字复制）
步骤5：等待对方发起交易，区块链确认后到账
```

**注意点**：
- 确认对方和你使用的是**同一条链**（如都用以太坊ERC-20，或都用Tron TRC-20）
- USDT在多条链上都有发行（ERC-20/TRC-20/BEP-20等），链不同地址不同
- 到账时间取决于区块链网络拥堵程度，通常1-30分钟

### 3.2 发送（转币）

```
步骤1：打开OKX App → Web3 → 钱包
步骤2：选择你要发送的币种
步骤3：点击"转账"或"发送"
步骤4：输入或粘贴对方地址（⚠️ 务必逐字核对）
步骤5：选择网络/链（如ERC-20、TRC-20）
步骤6：输入转账数量
步骤7：确认交易详情：
       → 收款地址
       → 转账金额
       → 网络手续费（Gas费）
       → 预计到账时间
步骤8：输入本地密码确认
步骤9：交易发送，等待区块链确认
```

**关键概念：Gas费（网络手续费）**

Gas费是支付给区块链矿工/验证者的交易处理费：
- 以太坊主网Gas费较高（$1-$50不等，取决于网络拥堵程度）
- Tron/BSC/Solana等链Gas费极低（通常<$0.1）
- Gas费从你的钱包中扣除（需要留足对应链的原生代币：以太坊需ETH、BSC需BNB、Tron需TRX）

### 3.3 常见转账问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 转账长时间不到账 | 网络拥堵/Gas费设太低 | 等待确认或用交易加速器 |
| 转到了错误地址 | 地址复制错误/选错链 | **无法撤回**，联系收款方 |
| "Insufficient gas" | 钱包缺少原生代币付Gas | 先转入一些ETH/TRX等 |
| USDT转账失败 | 合约授权不足 | 先在链上approve授权 |

## 四、CEX 链上充币：从外部钱包转入OKX

**充币**（Deposit）是将数字资产从外部钱包或其他平台转入你的OKX CEX账户。这是你在CEX上进行交易的前提——必须先有币在CEX账户里。

### 4.1 充币前必读：三要素核对法

每一笔充币操作，都必须核对**三个关键要素**，任何一个出错都可能导致**资产丢失且无法撤回**：

```
┌─────────────────────────────────────────────────────┐
│              充币三要素核对清单                        │
│                                                     │
│  1. 币种    ──  你充的是USDT还是USDC？BTC还是BCH？    │
│  2. 网络    ──  你选的是ERC-20还是TRC-20？           │
│  3. 地址+标签 ──  地址是否正确？是否需要填Memo/Tag？  │
│                                                     │
│  ⚠️ 三项全部正确才能到账，任一错误可能丢币！          │
└─────────────────────────────────────────────────────┘
```

### 4.2 选择资产（币种）

**为什么币种选择很重要？**

加密货币世界中存在大量名称相似但完全不同的资产，充错币种是新手最常见的失误之一：

| 易混淆币种 | 实际区别 | 充错后果 |
|-----------|---------|---------|
| USDT vs USDC | 两种不同的稳定币，合约地址完全不同 | 无法自动到账，需人工申诉 |
| BTC vs BCH | 比特币 vs 比特币现金，完全不同的链 | 无法自动到账 |
| ETH vs ETC | 以太坊 vs 以太经典，分叉后的两条链 | 无法自动到账 |
| SOL vs Staked SOL | Solana vs 质押版SOL | 可能无法正确到账 |

**操作规范**：

```
步骤1：在OKX App中打开 资产 → 充币
步骤2：选择你要充入的币种
       → ⚠️ 在搜索框输入币种名称时，仔细确认下拉列表中的选项
       → 不要只看简称，注意全称和图标
步骤3：确认OKX支持该币种的充币（未上架币种无法充值到账）
```

**如何确认OKX支持某个币种？**
- 访问OKX支持币种列表：OKX App → 市场 → 搜索币种
- 如果在充币页面找不到该币种，说明OKX可能不支持其充币
- 有疑问时，先联系OKX客服确认，不要贸然操作

### 4.3 选择网络（最关键的一步）

**为什么网络选择如此重要？**

同一种币（如USDT）可以在多条不同的区块链上发行和流通。每条链上的USDT是**不同的资产**，使用不同的地址格式和智能合约。如果你从以太坊网络转出USDT，但充值时选择了Tron网络，你的资产将无法到账。

```
USDT 的多条链版本示例：

以太坊 (ERC-20) USDT  ──  地址格式: 0x...     ──  合约地址: 0xdAC17F9...
波场 (TRC-20) USDT    ──  地址格式: T...      ──  合约地址: TR7NHqje...
BSC (BEP-20) USDT     ──  地址格式: 0x...     ──  合约地址: 0x55d398...
Solana (SPL) USDT     ──  地址格式: 基于SPL   ──  合约地址: EPjFWdd...

⚠️ 虽然都叫"USDT"，但它们是不同链上的不同代币！
⚠️ BSC网络目前不支持USDT充提，仅支持BNB充提！
```

**选择网络的操作规范**：

```
步骤1：在OKX充币页面，选择币种后，查看"网络"选项
步骤2：OKX会列出该币种支持的所有充币网络
步骤3：⚠️ 你必须选择与转出方（外部钱包）所在链一致的网络
       → 如果你的USDT在以太坊上 → 选择 ERC-20
       → 如果你的USDT在波场上 → 选择 TRC-20
       → 如果不确定 → 去转出方查看该USDT的网络类型
步骤4：确认后，OKX显示对应网络的充币地址
```

**常见币种的网络选择速查**：

| 币种 | 可选网络 | Gas费 | 推荐网络 | 备注 |
|------|---------|-------|---------|------|
| USDT | ERC-20 / TRC-20 / BEP-20 / SPL | ERC高/TRC低/BSC低/SPL极低 | TRC-20 | BSC网络暂不支持USDT充提 |
| BTC | BTC原生 / Lightning | 中 / 极低 | BTC原生 | Lightning适合小额快速 |
| ETH | ERC-20 / Arbitrum / Optimism / Base | 主网高/L2低 | 主网大额/L2日常 | L2上的ETH是wrapped版本 |
| SOL | SPL | 极低 | SPL | Solana原生网络 |

**选择网络时的核心判断逻辑**：

```
                    你要从哪里转出？
                         │
              ┌──────────┼──────────┐
              ▼          ▼          ▼
         另一个CEX    Web3钱包    硬件钱包
              │          │          │
              ▼          ▼          ▼
      查看对方提币    查看钱包中     查看硬件
      页面的网络      币种的链      钱包支持的链
              │          │          │
              └──────────┼──────────┘
                         ▼
              必须选择与转出方一致的网络
                         │
                         ▼
                    ⚠️ 不确定？
              → 先用小额测试（如$1）
              → 确认到账后再转大额
```

### 4.4 标签（Memo/Tag）：最容易忽略的关键项

**什么是标签？**

部分币种（如XRP、EOS、XLM、BNB等）在充值时，除了地址外还需要填写**标签（Memo/Tag）**。标签用于区分同一地址下不同用户的存款——OKX为所有用户共享少数几个充币地址，靠标签区分谁充了多少钱。

```
没有标签的币种（如BTC、ETH、USDT）：
  你的充币地址 = 你的专属地址  →  地址对就行

需要标签的币种（如XRP、EOS、XLM）：
  你的充币地址 = OKX的共享地址  →  地址+标签 才能区分是你充的
```

**忘记填标签或填错标签怎么办？**

这是充币问题中**最常见的类型之一**：
1. 资产会到达OKX的地址，但无法自动分配到你的账户
2. 需要通过OKX自助工具提交申诉：访问 [OKX充币反馈](https://www.okx.com/zh-hans/support-center/ticket/create?formId=1110001594)
3. 提供交易哈希（TxHash）、充值币种、数量、正确的标签等信息
4. OKX核实后可人工入账，但**处理周期较长**（数天到数周）

**操作规范**：

```
⚠️ 充币前先确认该币种是否需要标签：
   → 充币页面如果出现"标签/Memo/Tag"输入框 = 必须填写
   → 没有该输入框 = 不需要填
   → 标签通常是纯数字，复制时注意不要多空格或换行
   → ⚠️ 标签和地址必须同时正确，缺一不可
```

### 4.5 完整充币操作流程

**从外部钱包/其他交易所充值到OKX CEX账户**：

```
第一步：获取OKX充币地址
────────────────────────
  1. 打开OKX App → 资产 → 充币
  2. 选择充币币种（如USDT）
  3. 选择充币网络（⚠️ 必须与转出方一致，如TRC-20）
  4. 复制充币地址（如需要，同时复制标签/Memo）
  5. ⚠️ 确认页面上的最低充值额度

第二步：在转出方发起提币
────────────────────────
  6. 打开转出方（其他交易所或Web3钱包）
  7. 进入提币/转账页面
  8. 粘贴OKX充币地址
  9. ⚠️ 在转出方也选择相同的网络（如TRC-20）
  10. 如需要，粘贴标签/Memo
  11. 输入提币数量
  12. ⚠️ 确认提币数量 ≥ OKX最低充值额度

第三步：确认与等待
────────────────────────
  13. 在转出方确认提币
  14. 等待区块链网络确认（时间视网络而定）
  15. 在OKX资产页面查看是否到账
```

**从OKX Web3钱包充值到CEX账户（App内免手续费）**：

```
  1. 打开OKX App → 资产 → 充币
  2. 选择币种
  3. 网络选择中，选择"OKX Web3钱包"（如果可用）
  4. 系统自动处理，通常秒级到账，免Gas费
  5. 如果没有"OKX Web3钱包"选项，按上面的标准流程操作
```

### 4.6 最低充值额度

OKX对每种币的充值有**最低额度要求**，低于该额度的充值**将无法到账且无法找回**：

```
如何查看最低充值额度：
  OKX App → 资产 → 充币 → 选择币种和网络 → 页面显示"最低充值量"

常见币种最低充值额度（参考值，以页面显示为准）：
  ┌──────────┬──────────────┬──────────────────┐
  │ 币种     │ 网络         │ 最低充值额度(约) │
  ├──────────┼──────────────┼──────────────────┤
  │ BTC      │ BTC原生      │ 0.0005 BTC       │
  │ ETH      │ ERC-20       │ 0.001 ETH        │
  │ USDT     │ TRC-20       │ 1 USDT           │
  │ USDT     │ ERC-20       │ 5 USDT           │
  │ SOL      │ SPL          │ 0.1 SOL          │
  └──────────┴──────────────┴──────────────────┘
```

**低于最低额度怎么办？**
- BTC充值低于最低额度：可通过OKX自助工具提交申请，处理周期较长
- 其他币种低于最低额度：**通常无法找回**，资产永久丢失
- **预防远比补救重要**：充值前务必确认最低额度

### 4.7 充币到账确认数

不同网络需要不同的区块确认数才会到账，这是正常的安全机制：

| 网络 | 确认数要求 | 预计等待时间 |
|------|-----------|------------|
| BTC | 1次确认 | 10-60分钟 |
| ETH (ERC-20) | 12次确认 | 2-5分钟 |
| TRC-20 | 1次确认 | 1-3分钟 |
| BSC (BEP-20) | 1次确认 | 1分钟内 |
| SOL (SPL) | 1次确认 | 几秒-1分钟 |
| Arbitrum/Optimism | 数次确认 | 1-5分钟 |

> ⚠️ 在达到所需确认数之前，OKX资产页面可能显示"确认中"，这属于正常现象。

### 4.8 Travel Rule（国际转账规则）与额外验证

如果你在**受监管地区**使用OKX，充币后可能触发Travel Rule额外验证：

```
触发条件：
  → 来自非OKX平台的大额充币
  → 来自受监管地区以外的充币
  → 触发国际转账规则（Travel Rule）

表现：
  → 充币已到账但被锁定，无法交易/提现
  → 页面提示需要补充信息

处理方式：
  → 按照页面提示填写转出方信息
  → 通常需要提供转出方平台名称、你的身份信息
  → 验证通过后资产自动解锁（通常1-24小时）
```

### 4.9 充币问题完整排查清单

如果充币后长时间未到账，按以下顺序排查：

```
排查步骤                         →    如果是这个问题...
──────────────────────────────────────────────────────
1. 区块链确认是否完成？           →  等待确认，耐心即可
   (用TxHash在区块链浏览器查看)

2. 币种是否正确？                 →  充错币种：提交OKX反馈
   (充的USDT，但选了USDC？)

3. 网络是否匹配？                 →  网络不匹配：提交OKX反馈
   (转出方ERC-20，OKX选TRC-20？)

4. 地址是否正确？                 →  充错地址：联系地址所有方
   (地址是否与OKX充币页面一致？)     (如果是OKX地址但选错网络，提交反馈)

5. 是否需要标签但未填/填错？      →  提交OKX反馈，提供TxHash
   (XRP/EOS/XLM等币种)

6. 是否低于最低充值额度？         →  BTC可尝试申诉，其他币种通常无法找回

7. 是否触发Travel Rule验证？      →  按提示补充信息，等待解锁

8. 是否充值到合约地址？           →  ❌ 勿使用合约地址充币，提交反馈
   (充到了代币合约而非充币地址)

9. OKX是否暂停了该币种充提？     →  关注OKX公告，等待恢复
   (查看OKX公告页面)
```

**提交充币反馈的自助入口**：
- OKX App → 资产 → 充币 → 右上角"充币记录" → 选择问题交易 → 提交反馈
- 或直接访问：[OKX充币反馈表单](https://www.okx.com/zh-hans/support-center/ticket/create?formId=1110001594)

**反馈时需要准备的信息**：
1. 交易哈希（TxHash / TxID）—— 从转出方获取
2. 充值币种和数量
3. 充值网络
4. OKX充币地址
5. 如果涉及标签问题：正确的标签/Memo

### 4.10 充币安全操作十诫

| # | 规则 | 原因 |
|---|------|------|
| 1 | **先小额测试，再大额充值** | 确认流程正确，避免大额损失 |
| 2 | **币种、网络、地址三次核对** | 任一错误可能导致丢币 |

## 五、DeFi 与 DApp：去中心化世界入门

### 5.1 什么是 DApp？

DApp = Decentralized Application（去中心化应用）

与传统App（如微信、淘宝）的区别：

| | 传统App | DApp |
|---|---|---|
| **运行在** | 某公司的服务器 | 区块链（智能合约） |
| **控制者** | 公司可以随时修改/关闭 | 代码部署后不可篡改 |
| **你的数据** | 公司存储和控制 | 你自己控制（链上） |
| **登录方式** | 手机号/微信登录 | 钱包连接 |
| **典型例子** | 支付宝、微信 | Uniswap、Aave、OpenSea |

### 5.2 什么是 DeFi？

DeFi = Decentralized Finance（去中心化金融）

简单说，DeFi就是**用智能合约替代银行/券商等金融中介**，让你直接在链上完成金融操作。

| 传统金融 | DeFi对应 | 说明 |
|---------|---------|------|
| 银行存款 | 质押/流动性挖矿 | 存币生息 |
| 银行贷款 | 借贷协议（Aave/Compound） | 抵押借币 |
| 证券交易所 | DEX（Uniswap/PancakeSwap） | 币币兑换 |
| 理财产品 | 收益聚合器（Yearn） | 自动优化收益 |
| 保险 | 链上保险（Nexus Mutual） | 智能合约保险 |

### 5.3 在OKX中使用DeFi

OKX Web3钱包内置了DeFi聚合入口，你不需要单独访问各种DApp网站：

```
步骤1：打开OKX App → Web3 → "发现"或"DeFi"
步骤2：浏览可用的DeFi项目，按类型筛选：
       → 赚币（存币生息）
       → 借贷（抵押借币/存币放贷）
       → 流动性（做市提供流动性）
       → 质押（Staking）
步骤3：选择感兴趣的项目，查看：
       → 年化收益率（APY/APR）
       → TVL（总锁仓量，衡量规模和安全性的指标）
       → 支持的币种
       → 风险提示
步骤4：点击"参与"或"存入"
步骤5：选择要存入的币种和数量
步骤6：确认交易（App自动处理智能合约交互）
步骤7：等待链上确认，即可开始赚取收益
```

### 5.4 DeFi 风险提示

| 风险类型 | 说明 | 防范方法 |
|---------|------|---------|
| **智能合约风险** | 代码漏洞可能导致资金丢失 | 只用经过审计的大项目 |
| **无常损失** | 流动性提供者因价格波动受损 | 理解原理后再参与 |
| **Rug Pull** | 项目方卷款跑路 | 警惕超高APY，查团队背景 |
| **清算风险** | 借贷抵押率不足被强制清算 | 保持安全抵押率，设置提醒 |
| **钓鱼DApp** | 假冒网站骗取授权 | 只通过OKX内置入口访问 |

## 六、DEX 交易：兑换与专业交易

### 6.1 CEX 交易 vs DEX 交易

| | CEX交易（中心化交易所） | DEX交易（去中心化交易所） |
|---|---|---|
| **比喻** | 菜市场：卖家挂单，买家摘单 | 自动售货机：算法自动定价 |
| **定价机制** | 订单簿（买卖挂单撮合） | AMM（自动做市商算法） |
| **需要注册** | 需要（KYC） | 不需要 |
| **资产控制** | 交易所托管 | 自己控制 |
| **交易对象** | 交易所上架的币对 | 任何链上的代币 |
| **滑点** | 深度好时几乎没有 | 取决于流动性池大小 |
| **费用** | 交易手续费（0.02%-0.1%） | 网络Gas费 + DEX手续费 |

### 6.2 什么是 AMM（自动做市商）？

DEX不用订单簿，而是用**流动性池**：

```
传统交易所（订单簿）：
  买家出价 $100  ←→  卖家要价 $101  →  成交

DEX（AMM流动性池）：
  池子里有 100 ETH + 200,000 USDT
  价格 = 200,000 / 100 = $2,000/ETH
  你买入10 ETH → 池子剩90 ETH + 更多USDT → 价格自动上升
  你卖出10 ETH → 池子剩110 ETH + 更少USDT → 价格自动下降
```

**核心概念：滑点（Slippage）**

你看到的价格和实际成交价格的差异。交易金额越大，或流动性池越浅，滑点越大。

### 6.3 DEX 兑换（快捷模式）

这是最简单的DEX交易方式，类似"闪兑"：

```
步骤1：打开OKX App → Web3 → DEX
步骤2：选择"兑换"标签
步骤3：选择"支付币种"（你持有的，如USDT）
步骤4：选择"获得币种"（你想买的，如ETH）
步骤5：输入支付数量
步骤6：系统自动显示：
       → 预计获得数量
       → 当前汇率
       → 价格影响（滑点）
       → 最少获得数量（Min Received）
       → 网络手续费
       → 路由路径（经哪些DEX和池子）
步骤7：确认交易 → 输入密码 → 等待链上确认
```

**OKX DEX的特别之处**：它是一个**DEX聚合器**，不是单一DEX。它会自动比较多个DEX（Uniswap、PancakeSwap、1inch等）的价格，帮你找到最优路径。

### 6.4 DEX 专业交易（限价单模式）

限价单允许你**设定目标价格**，到达后自动成交：

```
步骤1：打开OKX App → Web3 → DEX
步骤2：选择"限价"标签
步骤3：设置交易参数：
       → 支付币种和数量
       → 获得币种
       → 目标价格（你期望的成交价）
       → 有效期（如24小时/7天/30天）
步骤4：确认委托
步骤5：等待市场价格到达你的目标价时自动成交
```

**适用场景**：
- 你觉得当前价格偏高，想等跌到目标价再买
- 你想在高点卖出但不想一直盯盘
- 你想在睡觉时自动完成交易

### 6.5 DEX 交易的关键参数解读

| 参数 | 含义 | 新手建议 |
|------|------|---------|
| **汇率** | 两种币的兑换比例 | 与CEX对比，差距过大需警惕 |
| **价格影响** | 你的交易对池子价格的影响 | >3%需注意，>5%建议拆分交易 |
| **最少获得** | 考虑滑点后你最少能拿到的数量 | 设置滑点保护（通常1%-3%） |
| **Gas费** | 网络手续费 | 以太坊主网较贵，可考虑Layer2 |
| **路由** | 交易经过的路径 | OKX自动优化，一般无需手动调整 |
| **滑点容忍度** | 你能接受的最大价格偏差 | 常规币设1-2%，小币设3-5% |

### 6.6 网络选择建议

| 网络 | Gas费 | 速度 | 代币丰富度 | 建议场景 |
|------|-------|------|-----------|---------|
| 以太坊主网 | 高（$2-$50） | 较慢(1-5分钟) | 最丰富 | 大额交易、主流币 |
| Arbitrum/Optimism | 低（$0.1-$1） | 快(秒级) | 丰富 | 日常交易、DeFi |
| BSC | 极低（<$0.1） | 快(3秒) | 丰富 | 低成本交易 |
| Solana | 极低（<$0.01） | 极快(400ms) | 中等 | 高频交易 |
| Base | 低（$0.01-$0.5） | 快 | 增长中 | 新兴生态 |

## 七、跨链桥：资产跨链搬运工

### 7.1 什么是跨链桥？

不同区块链之间是**互相隔离**的——以太坊上的ETH无法直接在Solana上使用。跨链桥就是连接不同链的"桥梁"，将资产从一条链转移到另一条链。

```
以太坊上的USDT  ──跨链桥──→  Solana上的USDT
   (ERC-20)                    (SPL)
```

### 7.2 跨链桥的工作原理

**锁定-铸造模式（最常见）**：

```
步骤1：你在以太坊上锁定 100 USDT
步骤2：桥的智能合约验证锁定成功
步骤3：桥在Solana上铸造 100 USDT 给你
步骤4：你赎回时，Solana上的100 USDT 被销毁
步骤5：以太坊上的 100 USDT 被解锁还给你
```

### 7.3 在OKX中使用跨链桥

```
步骤1：打开OKX App → Web3 → DEX → "跨链"标签
步骤2：选择"来源链"（资产当前所在的链，如以太坊）
步骤3：选择"目标链"（你想转到的链，如Arbitrum）
步骤4：选择币种和数量
步骤5：系统显示：
       → 跨链汇率
       → 跨链手续费
       → 预计到账时间
       → 最少获得数量
步骤6：确认交易
步骤7：等待来源链确认 + 目标链铸造完成
```

### 7.4 跨链桥的关键风险

| 风险 | 说明 | 防范方法 |
|------|------|---------|
| **桥被攻击** | 跨链桥是黑客最爱攻击的目标 | 使用大品牌桥，分散风险 |
| **到账延迟** | 部分桥需要较长时间 | 查看预计时间，选择快速桥 |
| **费用较高** | 桥费+双链Gas费 | 对比不同桥的费用 |
| **目标链Gas** | 跨链后需要目标链的原生代币付Gas | 提前准备或选择自动兑换Gas的桥 |

### 7.5 常见跨链桥对比

| 桥 | 支持链 | 费用 | 速度 | 安全性 |
|----|--------|------|------|--------|
| **OKX跨链桥**（内置） | 30+链 | 中低 | 快 | OKX风控审核 |
| **Stargate** | 主流L1/L2 | 低 | 快 | 高（LayerZero协议） |
| **Across** | 以太坊L2生态 | 极低 | 极快(秒级) | 高 |
| **Wormhole** | 多链 | 中 | 中 | 中（曾遭攻击） |
| **官方桥** | 各L2专属 | 视链而定 | L2快/L1慢 | 最高 |

**新手建议**：优先使用OKX内置跨链功能，自动匹配最优路线，省去手动比较的麻烦。

## 八、安全红线：新手必读

### 8.1 绝对不能做的事

| ❌ 禁止行为 | 后果 |
|------------|------|
| 截图/拍照保存助记词 | 手机被黑或泄露后资产被盗 |
| 把助记词发给任何人（包括"客服"） | 钱包被清空 |
| 点击不明链接连接钱包 | 授权被恶意合约掏空 |
| 在多个DApp授权无限额度 | 一个DApp被黑，所有资产危险 |
| 使用公共WiFi操作钱包 | 中间人攻击窃取签名 |
| 向任何人透露本地密码 | 本地防护失效 |

### 8.2 必须做的事

| ✅ 必做事项 | 原因 |
|------------|------|
| 助记词手写抄录，存放在至少两个安全位置 | 灾难恢复保障 |
| 大额资产使用硬件钱包（如Ledger） | 私钥永不触网 |
| 操作前核对地址前后几位和末尾几位 | 防止恶意软件篡改剪贴板地址 |
| 定期撤销不用的DApp授权 | 减少攻击面 |
| 先用小额测试，确认流程后再大额操作 | 避免操作失误导致大额损失 |
| 使用OKX内置安全检测功能 | 自动识别风险合约和地址 |

### 8.3 钱包授权管理

当你使用DApp时，需要授权（Approve）合约访问你的代币。这就像"给某人一把有限权限的钥匙"。

```
查看和管理授权：
OKX App → Web3 → 钱包 → 安全 → 授权管理

操作建议：
1. 只授权你需要的额度（不要选"无限"）
2. 用完后及时撤销授权
3. 看到陌生代币被授权，立即撤销
```

### 8.4 识别常见骗局

| 骗局类型 | 特征 | 防范 |
|---------|------|------|
| **假客服** | 主动联系你，索要助记词/密码 | OKX客服绝不会索要助记词 |
| **空投骗局** | 钱包突然收到陌生代币+引导你去某DApp | 不要交互不明空投代币 |
| **钓鱼网站** | 高仿DApp网站，连接钱包后盗币 | 只通过OKX内置入口访问DApp |
| **高收益陷阱** | 承诺极高APY（>100%） | 天上不会掉馅饼 |
| **假币同名** | 伪造与知名币种同名的代币 | 核对合约地址，不只看币种名称 |
