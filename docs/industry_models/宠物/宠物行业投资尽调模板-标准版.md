# 三、业务理解

## 3.1 公司到底做什么
1. 公司卖的是高频商品、医疗、服务还是内容/平台？
2. 用户为什么选择它，而不是综合电商、社区门店或头部品牌？
3. 公司核心竞争力在品牌、渠道、医生资源、门店还是供应链？
4. 当前收入主要来自哪些品类、服务和地区？

## 3.2 解决什么问题
1. 是否解决了喂养、安全、健康、便利或专业照护问题？
2. 用户选择的核心原因是适口性、品牌、医生信任、价格还是服务体验？
3. 新手养宠用户是否因内容或顾问服务而提高转化？
4. 如果不用该产品/服务，用户会选择什么替代方案？

## 3.3 商业模式
1. 收入来自商品、会员、服务、医疗还是平台佣金？
2. 是否具备高频复购基础 SKU？
3. 是否能从低毛利引流品扩展到高毛利商品或服务？
4. 是否有私域、会员或健康档案作为长期变现基础？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在细分赛道主要受宠物数量增长还是单宠消费升级驱动？
2. 行业是品类普及期还是品牌升级期？
3. 用户更愿意为哪些场景支付溢价？
4. 医疗和服务类空间是否明显大于单纯商品？

## 5.2 行业格局
1. 头部品牌和连锁集中度如何？
2. 综合电商和即时零售是否形成挤压？
3. 垂直宠物平台还有什么差异化空间？
4. 白牌和低价竞争是否明显？

## 5.3 行业趋势
1. 拟人化和情感消费升级是否持续？
2. 主粮高端化、功能粮、保健品趋势是否增强？
3. 医疗和保险渗透率是否提升？
4. 连锁化和社区化服务是否会持续加强？

# 九、财务尽调

## 9.1 收入质量
1. 收入是否建立在高频复购或稳定复诊基础上？
2. 高频刚需品类和高毛利品类结构是否合理？
3. 自有品牌收入增长是否健康？
4. 促销是否透支未来需求？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 流量成本是否持续上升？
3. 私域和会员是否改善利润结构？
4. 医疗、售后和纠纷是否侵蚀利润？

## 9.3 现金流质量
1. 库存是否占用过多现金？
2. 门店/医院扩张是否吞噬现金流？
3. 大促后退货和回款情况如何？
4. 储值型业务是否掩盖真实经营质量？

## 9.4 资产负债表风险
重点看：
- 存货
- 存货跌价准备
- 应收账款
- 预付款
- 现金
- 租赁负债
- 储值负债/递延收入

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否懂宠物消费、零售、医疗或连锁运营？
2. 是否具备质量和合规意识？
3. 是否有私域和会员运营能力？
4. 是否过度依赖单一医生、店长、主播或采购？

## 10.2 组织能力
1. 是否具备稳定供应链和选品能力？
2. 是否具备导购、客服、社群和到店服务体系？
3. 门店或医院标准化能力如何？
4. 是否具备从单品到多品类/多服务扩张能力？

## 10.3 激励机制
1. 销售激励是否导致重促销轻复购？
2. 私域和门店团队是否对长期用户价值负责？
3. 品类和采购团队是否对周转和毛利负责？
4. 医疗和服务团队是否有质量和客诉红线机制？
