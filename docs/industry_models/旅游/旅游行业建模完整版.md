# 一、行业基础定义

## 1.1 行业名称
- 行业名称：旅游
- 英文常用称呼：Travel / Tourism / Online Travel
- 细分赛道：OTA、机票预订、酒店预订、门票预订、度假游、跟团游、自由行、商旅管理、本地玩乐、定制游、旅游供应链服务、旅游 SaaS 等
- 上下游位置：
  - 上游：航司、酒店、民宿、景区、地接社、签证服务商、交通服务商、内容流量平台、支付平台
  - 中游：OTA、旅行社、旅游平台、商旅管理公司、旅游技术服务商
  - 下游：个人游客、家庭用户、企业商旅客户、团体客户、海外游客
- 主要服务对象：To C 为主，部分 To B（商旅、供应链分销、系统服务）

## 1.2 行业一句话定义
> 旅游行业的本质是：围绕“出行与目的地体验”组织供给、匹配需求、完成交易与履约，并通过佣金、差价、服务费和增值服务实现变现的行业。

## 1.3 行业边界

### 覆盖范围
- 机票、酒店、门票、度假产品等旅游产品交易与分销
- 围绕旅游形成的线路设计、打包产品、履约服务和本地服务
- 企业商旅管理和旅游技术平台
- 旅游目的地运营和在线预订服务

### 不覆盖范围
- 单纯交通基础设施运营（如机场、铁路本体）
- 纯餐饮或零售本地消费业务
- 不以旅游出行为核心场景的住宿或交通业务

# 二、行业本质与核心价值

## 2.1 商业本质

旅游行业的本质不是“卖票”或“卖酒店”，而是：

> 在用户有限决策时间和复杂供给环境下，帮助其更低成本、更高确定性地完成出行决策与履约体验。

### 1）客户为什么需要它？
游客或商旅客户需要旅游服务，通常因为：
- 旅游供给分散，信息不透明
- 价格、时间、路线和体验难以自行最优匹配
- 机酒门票等资源需实时确认
- 跨城市 / 跨国家出行安排复杂
- 需要提升预订效率、降低出错率
- 需要售后和行程保障

### 2）企业提供的核心价值是什么？
- 聚合和筛选旅游供给
- 降低用户搜索和决策成本
- 提供价格比较与套餐组合
- 保障交易、支付、退改和履约
- 提供行程服务、客服和售后支持
- 为商旅客户提供管控与结算能力

### 3）企业为什么能赚钱？
旅游企业盈利来源通常包括：
- 机票 / 酒店 / 门票 / 度假产品佣金
- 打包产品差价
- 服务费
- 商旅管理费
- 广告和流量变现收入
- 保险、接送机、签证等增值服务收入
- SaaS / 系统服务费（To B）

## 2.2 价值创造链条

旅游行业典型链路：

### OTA 平台型
```text
获取流量
→ 聚合机酒景点等供给
→ 搜索比价与推荐
→ 完成在线预订
→ 提供履约和售后
→ 复购与交叉销售
```

### 度假 / 跟团 / 定制游型
```latex
设计旅游产品
→ 获取用户咨询
→ 销售转化
→ 组织供应链和地接资源
→ 完成出行履约
→ 用户口碑和复购
```

### 商旅服务型
```latex
签约企业客户
→ 接入差旅政策和审批流程
→ 提供机酒火及报销对接
→ 统一结算与管控
→ 续约与扩客户数
```

## 2.3 行业核心飞轮
```latex
更多用户订单
→ 更丰富供给与价格优势
→ 更高转化率和用户信任
→ 更强口碑与流量获取能力
→ 更多用户订单
```

旅游行业真正强的飞轮是：

> 流量能力、供给整合能力、履约保障能力和品牌信任共同推动的复利增长。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：佣金抽成
+ 名称：Commission
+ 收费对象：酒店、航司、景区、供应商
+ 收费方式：按成交额抽佣
+ 公式：

```latex
收入 = GMV × Take Rate
```

### 模式二：差价模式
+ 名称：Margin / Spread
+ 收费对象：终端游客
+ 收费方式：低买高卖赚差价
+ 公式：

```latex
收入 = 销售价 - 采购成本
```

### 模式三：服务费模式
+ 名称：Service Fee
+ 收费对象：游客 / 企业客户
+ 收费方式：按单、按人次、按企业年费收费
+ 公式：

```latex
收入 = 服务量 × 单次服务费
```

### 模式四：广告与流量变现
+ 名称：Advertising
+ 收费对象：酒店、景区、旅行品牌
+ 收费方式：CPC / CPA / 展示
+ 公式：

```latex
收入 = 流量 × 变现率
```

### 模式五：订阅 / 系统收费
+ 名称：Subscription / SaaS
+ 收费对象：B端商家
+ 收费方式：年费、模块费、实施费
+ 公式：

```latex
收入 = 客户数 × ARPU
```

## 4.2 行业最优商业模式
旅游中高质量模型通常具备：

+ 高复购和较低流量依赖
+ 供给稳定，履约风险可控
+ 品牌信任度高，售后能力强
+ 佣金率或毛利率稳定
+ 淡旺季波动可管理
+ 有交叉销售和增值服务能力

理想模型不是：

> 强依赖短期买量、供给不可控、退改损耗高、旺季赚钱淡季大亏、售后事故频发
>

而是：

> 用稳定流量入口和可信履约能力承接高频基础出行需求，再向高毛利度假、增值服务和商旅等场景延展。
>

## 4.3 从单品类到平台路径
```latex
先切入机票/酒店/门票等高频入口
→ 积累用户和交易数据
→ 扩展套餐、度假、保险等增值服务
→ 建立会员与复购体系
→ 形成综合旅游平台
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 佣金收入 + 差价收入 + 服务费收入 + 广告收入 + 订阅收入 + 其他增值收入
```

## 5.2 拆解驱动因子
### OTA 常见拆法
```latex
收入 = GMV × Take Rate
```

### 订单拆法
```latex
GMV = 订单量 × 客单价
```

### 度假游拆法
```latex
收入 = 成交人数 × 人均客单价
毛利 = 成交人数 × 人均毛利
```

### 商旅拆法
```latex
收入 = 企业客户数 × 单客户年交易额 × 抽佣率 + 管理费
```

### 旅游 SaaS 拆法
```latex
ARR = 客户数 × ARPA
```

## 5.3 收入增长来源
+ 流量增长
+ 转化率提升
+ 客单价提升
+ 供给丰富度提升
+ 佣金率优化
+ 新品类拓展
+ 复购率提升
+ 会员体系渗透
+ 企业客户拓展
+ 海外游客或目的地拓展

# 六、成本模型
## 6.1 主要成本构成
+ 流量获取成本
+ 供应链采购成本
+ 履约成本
+ 客服和售后成本
+ 技术与系统成本
+ 商务 BD 成本
+ 支付和清结算成本
+ 渠道分成成本
+ 人员和管理成本

## 6.2 成本分类方式
### 固定成本
+ 核心技术团队
+ 产品和系统开发
+ 管理团队
+ 品牌建设
+ 基础客服体系

### 可变成本
+ 流量投放
+ 订单履约
+ 支付手续费
+ 渠道返佣
+ 售后和赔付
+ 供应链采购波动成本

### 前端成本
+ 买量获客
+ 内容投放
+ 搜索引擎投放
+ 渠道合作
+ 销售团队（商旅 / 定制游）

### 后端成本
+ 客服
+ 售后退改
+ 地接履约
+ 系统清结算
+ 风控和投诉处理

## 6.3 单位经济模型
### OTA 平台
```latex
单订单毛利 = 订单 GMV × Take Rate - 流量成本 - 支付手续费 - 客服售后成本
```

### 度假游
```latex
单游客毛利 = 销售价 - 采购成本 - 履约成本 - 获客成本 - 售后成本
```

### 酒店分销
```latex
单间夜毛利 = 每间夜收入 - 酒店采购成本 - 渠道成本 - 服务成本
```

### 商旅服务
```latex
单客户年毛利 = 抽佣收入 + 管理费 - 服务交付成本 - 客服支持成本
```

### 核心判断
+ 旅游行业关键不是 GMV 大，而是 Take Rate、履约稳定性和单位经济
+ 退改签、客诉、不可抗力和旺淡季波动会显著影响真实利润
+ 如果流量成本持续上升而复购弱，模式脆弱
+ 高质量旅游公司通常拥有更强品牌信任和供给组织能力

## 6.4 利润公式
```latex
利润 = 各类收入 - 流量成本 - 采购与履约成本 - 支付与渠道成本 - 客服售后成本 - 技术与管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
旅游增长通常来自：

+ 居民出行频次提升
+ 假期制度和消费升级
+ 旅游线上化率提升
+ 机酒门票等供给数字化
+ 本地玩乐和深度游渗透
+ 商旅需求恢复或增长
+ 会员体系增强复购
+ 国际旅游开放和恢复

## 8.2 规模效应
规模扩大后可能带来：

+ 更强的供给议价权
+ 更低的获客成本
+ 更强品牌心智
+ 更完善的客服和售后体系
+ 更多交叉销售机会
+ 更高的系统与运营效率

## 8.3 网络效应
旅游行业网络效应弱于社交和平台型互联网，但在以下方面存在：

+ 用户规模越大，供给商越愿意合作
+ 供给越丰富，用户选择越多，转化越高
+ 评价内容越多，决策效率越高
+ 商旅平台客户越多，系统和服务标准越成熟

## 8.4 淡旺季与供给波动
+ 行业存在明显季节性
+ 节假日、天气、疫情、政策都会影响需求
+ 航班、酒店和景区供给价格动态变化大
+ 优秀公司需要平衡高峰需求承接和淡季成本控制

## 11.1 利润表重点
+ GMV 与收入匹配关系

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
居民和企业在机酒、门票、度假、商旅及相关旅游服务上的总支出空间

### SAM
公司当前可服务品类、区域、客户类型和渠道下的可服务市场

### SOM
公司中短期可实际获得的 GMV、收入和市场份额

## 12.2 通用测算公式
### 方法一：人次法
```latex
市场空间 = 年出行人次 × 人均旅游消费
```

### 方法二：品类拆分法
```latex
市场空间 = 机票市场 + 酒店市场 + 门票市场 + 度假市场 + 商旅市场
```

### 方法三：客户数法（商旅 / SaaS）
```latex
市场空间 = 目标企业客户数 × 年客单价
```

### 方法四：线上渗透法
```latex
在线市场空间 = 总旅游消费 × 线上渗透率 × 公司可覆盖份额
```

## 12.3 市场空间判断注意事项
+ 旅游总盘子大，但赛道间毛利和壁垒差异大
+ GMV 大不等于收入质量高
+ 季节性、政策和地缘因素影响显著
+ 需区分高频入口和低频高客单场景

1. 流量获取效率是否健康

+ 供给不稳定
+ 客诉和退款压力
+ 季节性波动
