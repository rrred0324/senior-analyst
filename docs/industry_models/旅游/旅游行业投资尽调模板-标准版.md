# 三、业务理解

## 3.1 公司到底做什么
1. 公司是平台型、分销型、履约型还是技术型公司？
2. 核心卖的是机票、酒店、门票、套餐、商旅服务还是软件服务？
3. 用户为什么来这里买，而不是去供应商官网或其他平台？
4. 公司最强的是流量、供给、履约还是服务？

## 3.2 解决什么问题
1. 降低了用户搜索成本、价格成本还是履约风险？
2. 提升了供给销售效率还是用户预订效率？
3. 商旅客户看重的是管控、结算还是议价能力？
4. 定制游/度假游客户看重的是省心还是体验差异化？

## 3.3 商业模式
1. 收入来自佣金、差价、服务费、广告还是订阅？
2. 是否存在交叉销售和增值服务？
3. 是否有会员体系和复购逻辑？
4. 收入确认和 GMV 口径是否清晰？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在细分赛道是高频入口还是低频高客单？
2. 线上化率还有多少提升空间？
3. 市场是增量竞争还是存量替代？
4. 海外游、国内游、周边游、商旅等结构变化如何？

## 5.2 行业格局
1. 头部平台是否已形成明显优势？
2. 供应商直销和超级平台是否造成分流？
3. 公司在垂直赛道是否有独特定位？
4. 价格战是否严重？

## 5.3 行业趋势
1. 用户更偏好自由行还是打包产品？
2. 本地玩乐、深度游和即时预订是否增长？
3. 商旅数字化是否提升？
4. 政策、签证和国际开放对行业影响如何？

# 九、财务尽调

## 9.1 收入质量
1. 收入是否高度依赖某一品类或假期旺季？
2. GMV 增长是否伴随 Take Rate 稳定？
3. 是否存在低毛利冲规模问题？
4. 广告、会员、增值服务占比是否上升？

## 9.2 利润质量
1. 流量成本是否可控？
2. 退改、赔付、客服成本是否侵蚀利润？
3. 淡旺季利润波动是否合理？
4. 商旅 / SaaS 等高质量收入占比是否提升？

## 9.3 现金流质量
1. 预收款和退款节奏是否健康？
2. 是否受到平台账期或供应商账期影响？
3. 淡季是否需要额外融资支持？
4. 大促和假期期间现金流是否承压？

## 9.4 资产负债表风险
重点看：
- 现金
- 预收款 / 合同负债
- 应收应付款
- 退款准备
- 供应商保证金
- 有息负债
- 存货或预采资源

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备旅游行业、平台运营或供应链经验？
2. 是否具备流量运营和履约管理双重能力？
3. 是否过度依赖创始人拿资源？
4. 商旅或 To B 团队是否成熟？

## 10.2 组织能力
1. 客服、售后、风控、清结算体系是否完善？
2. 旺季承接能力如何？
3. 供应商管理能力如何？
4. 是否具备跨品类扩张能力？

## 10.3 激励机制
1. 销售和运营激励是否鼓励低价冲量？
2. 客服和售后是否兼顾效率与满意度？
3. 供应链团队是否对毛利和稳定性负责？
4. 是否对复购和会员渗透有清晰 KPI？

# 十二、风险尽调

## 12.1 业务风险
- 流量成本上升
- 供给不稳定
- 客诉和退改压力
- 低频导致复购弱
- 旺季服务承接失败
- 品类扩张失控

## 12.2 财务风险
- Take Rate 下滑
- 高补贴低毛利
- 退款和赔付侵蚀现金流
- 假期后收入回落明显
- 商旅账期拖长

## 12.3 合规与法律风险
- 消费者权益纠纷
- 退改签政策争议
- 数据与支付合规风险
- 资质和旅行社牌照问题
- 跨境旅游监管变化
