# 一、行业基础定义

## 1.1 行业名称
- 行业名称：旅游
- 英文常用称呼：Travel / Tourism / Online Travel
- 细分赛道：OTA、机票预订、酒店预订、门票预订、度假游、跟团游、自由行、商旅管理、本地玩乐、定制游、旅游供应链服务、旅游 SaaS 等
- 上下游位置：
  - 上游：航司、酒店、民宿、景区、地接社、签证服务商、交通服务商、内容流量平台、支付平台
  - 中游：OTA、旅行社、旅游平台、商旅管理公司、旅游技术服务商
  - 下游：个人游客、家庭用户、企业商旅客户、团体客户、海外游客
- 主要服务对象：To C 为主，部分 To B（商旅、供应链分销、系统服务）

## 1.2 行业一句话定义
> 旅游行业的本质是：围绕“出行与目的地体验”组织供给、匹配需求、完成交易与履约，并通过佣金、差价、服务费和增值服务实现变现的行业。

## 1.3 行业边界

### 覆盖范围
- 机票、酒店、门票、度假产品等旅游产品交易与分销
- 围绕旅游形成的线路设计、打包产品、履约服务和本地服务
- 企业商旅管理和旅游技术平台
- 旅游目的地运营和在线预订服务

### 不覆盖范围
- 单纯交通基础设施运营（如机场、铁路本体）
- 纯餐饮或零售本地消费业务
- 不以旅游出行为核心场景的住宿或交通业务

# 二、行业本质与核心价值

## 2.1 商业本质

旅游行业的本质不是“卖票”或“卖酒店”，而是：

> 在用户有限决策时间和复杂供给环境下，帮助其更低成本、更高确定性地完成出行决策与履约体验。

### 1）客户为什么需要它？
游客或商旅客户需要旅游服务，通常因为：
- 旅游供给分散，信息不透明
- 价格、时间、路线和体验难以自行最优匹配
- 机酒门票等资源需实时确认
- 跨城市 / 跨国家出行安排复杂
- 需要提升预订效率、降低出错率
- 需要售后和行程保障

### 2）企业提供的核心价值是什么？
- 聚合和筛选旅游供给
- 降低用户搜索和决策成本
- 提供价格比较与套餐组合
- 保障交易、支付、退改和履约
- 提供行程服务、客服和售后支持
- 为商旅客户提供管控与结算能力

### 3）企业为什么能赚钱？
旅游企业盈利来源通常包括：
- 机票 / 酒店 / 门票 / 度假产品佣金
- 打包产品差价
- 服务费
- 商旅管理费
- 广告和流量变现收入
- 保险、接送机、签证等增值服务收入
- SaaS / 系统服务费（To B）
