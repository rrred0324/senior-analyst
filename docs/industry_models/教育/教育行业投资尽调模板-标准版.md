# 一、行业基础定义

## 1.1 行业名称
- 行业名称：教育
- 细分赛道：职业教育、成人教育、素质教育、语言学习、K12非学科、教育硬件、教育信息化、教育 SaaS、校企合作、国际教育服务等
- 上下游位置：
  - 上游：内容研发、师资供给、教材教辅、技术平台、流量渠道
  - 中游：教育机构、平台、学校服务商、培训与课程服务商
  - 下游：学生、家长、企业客户、学校、政府
- 主要服务对象：To C、To B、To G、To S（学校）

## 1.2 行业一句话定义
> 教育行业的本质是：围绕知识、技能、能力和成长结果，提供内容、教学、服务和工具，并通过学习效果、交付体验和持续服务实现收入与长期价值。

## 1.3 行业边界

### 覆盖范围
- 提供课程、培训、教学服务或教育工具的业务
- 面向个人、学校、企业或政府的教育与培训解决方案
- 具备持续内容供给、教学交付或教育数字化能力的公司

### 不覆盖范围
- 纯流量导购平台且不承担教育交付
- 无教学内容和交付能力的泛知识内容号
- 一次性咨询型业务且无法复制
- 与教育弱相关的文娱内容业务

# 二、行业本质与核心价值

## 2.1 商业本质

教育行业的本质不是“卖课”，而是：

> 帮助学习者提升认知、技能、成绩或职业结果，并在可验证的学习效果与服务体验基础上形成持续信任和收入。

### 1）客户为什么需要它？
学生、家长、企业和学校需要教育服务，通常是因为：
- 提升成绩、技能或考试通过率
- 获得职业能力和就业机会
- 获得素质提升和兴趣培养
- 提高教学效率和学校管理能力
- 降低学习路径选择成本
- 获得更好的教育资源可及性

### 2）企业提供的核心价值是什么？
- 提供系统化内容和课程体系
- 提供教学服务与学习陪伴
- 提升学习效率和完成率
- 帮助用户达成考试、升学、就业或能力提升结果
- 为学校和企业提供数字化教学与培训工具

### 3）企业为什么能赚钱？
教育公司的盈利来源通常包括：
- 课程付费收入
- 学费或培训服务费
- 会员订阅收入
- 教材/硬件销售收入
- 企业培训项目收入
- 学校信息化项目收入
- 增值服务收入

## 2.2 价值创造链条

教育行业典型链路：

### To C 教培型
```text
用户获取
→ 试听/体验
→ 报名转化
→ 教学交付
→ 学习反馈与服务
→ 续费/转介绍
→ 收入确认
