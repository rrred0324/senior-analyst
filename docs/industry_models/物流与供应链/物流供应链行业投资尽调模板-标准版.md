# 三、业务理解

## 3.1 公司到底做什么
1. 公司做运输、仓储、履约，还是供应链管理与系统？
2. 服务的是哪类货物、哪类客户、哪个环节？
3. 核心收入来自单票、单吨、仓储还是项目服务？
4. 公司是重运营服务商、平台型公司还是科技型公司？
5. 在客户价值链中承担的是成本中心还是关键履约能力？

## 3.2 解决什么问题
1. 客户为什么选择外包给该公司？
2. 公司帮助客户提升了什么：时效、成本、库存、异常率还是可视化？
3. 相比竞品，优势是价格、网络、服务质量还是系统能力？
4. 没有该公司时，客户会如何替代？

## 3.3 商业模式
1. 收入来自运输费、仓储费、履约费、管理费还是技术费？
2. 是否具备长期合同和高复购特征？
3. 是否有增值服务变现空间？
4. 模式是否对订单量、密度和资源利用率高度敏感？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在细分物流市场有多大？

3. 公司可服务市场是否受区域、品类或资质限制？
4. 是否能从单环节切入扩展至更多环节？

## 5.2 行业格局
1. 头部玩家是谁？
2. 竞争焦点在价格、网络、仓网、运力还是系统？
3. 行业集中度如何？
4. 公司在细分市场处于什么位置？

## 5.3 行业趋势
1. 电商、即时零售、制造业升级是否带来增量？
2. 自动化、无人化、算法调度是否重塑行业？
3. 客户是否从单点物流采购转向综合供应链采购？
4. 政策、交通与环保要求是否影响经营？

# 九、财务尽调

## 9.1 收入质量
1. 收入来自高频复购还是一次性项目？
2. 是否依赖单一大客户？
3. 单位单价是否被持续压缩？
4. 增值服务收入占比是否提升？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 网络扩张是否摊薄成本还是加重负担？
3. 人工、运力、仓租成本是否可控？
4. 赔付和异常成本是否被低估？

## 9.3 现金流质量
1. 应收账款是否显著占用现金？
2. CAPEX 是否过重？
3. 经营现金流是否随规模增长改善？
4. 大客户账期是否压缩现金流？

## 9.4 资产负债表风险
重点看：
- 现金
- 应收账款
- 固定资产
- 使用权资产
- 租赁负债
- 有息负债
- 设备折旧压力

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备物流、供应链、系统、行业客户经验？
2. 是否有复杂网络管理能力？
3. 是否过度依赖少数关键运营负责人？
4. 是否具备跨区域复制能力？

## 10.2 组织能力
1. 公司更强在销售、大客户服务、网络运营还是系统建设？
2. 中后台调度与数据分析能力如何？
3. 质控、安全、赔付和客服体系是否成熟？
4. 是否具备从执行层升级到解决方案层的能力？

## 10.3 激励机制
1. 是否过度激励抢单，忽视利润和质量？
2. 运营团队是否对成本和时效同时负责？
3. 核心管理和一线节点稳定性如何？

## 11.2 公司壁垒
1. 壁垒来自网络、仓网、客户关系、系统还是行业 Know-how？

3. 客户是否对公司形成深度流程依赖？

## 11.3 替代风险
1. 大客户是否会自建替代？
2. 低价竞争者是否容易切入？
3. 平台和上游客户是否具备强议价权？
4. 自动化不足是否导致长期竞争力下降？

- 应收账款上升
- 现金流承压

- 资产周转下降

## 12.3 合规与法律风险
- 交通运输合规
- 劳务与用工合规
- 冷链/医药/跨境资质合规
- 安全生产责任
- 货损与赔付纠纷
- 数据与系统安全合规
