# 一、行业基础定义

## 1.1 行业名称
- 行业名称：物流供应链
- 细分赛道：快递、快运、同城配送、整车/零担、仓储、冷链、跨境物流、国际货代、供应链管理、履约服务、物流科技、供应链金融协同服务等
- 上下游位置：
  - 上游：制造商、品牌商、贸易商、农产品供应方、运力提供方、仓储资源方、港口/机场/铁路等基础设施
  - 中游：物流服务商、仓配一体化平台、货代公司、供应链解决方案公司、数字化平台
  - 下游：电商平台、零售商、企业客户、终端消费者、医院、餐饮等
- 主要服务对象：To B、To C、To G

## 1.2 行业一句话定义
> 物流供应链行业的本质是：通过运输、仓储、分拣、配送、计划和协同管理，在时间和空间上高效匹配货物、信息与资源，以更低成本、更高时效和更稳定履约支撑商品流通与供应链运转。

## 1.3 行业边界

### 覆盖范围
- 与货物流通、仓配履约、供应链协同管理相关的服务与系统
- 连接生产、仓储、运输、配送、终端交付的经营活动
- 提供物流执行能力或供应链数字化能力的公司

### 不覆盖范围
- 单纯商品贸易但不承担物流或供应链能力的业务
- 纯车辆销售、纯仓库地产持有且无运营服务的业务
- 无履约能力的泛信息撮合平台
- 与物流弱相关的纯 ERP、OA 软件

# 二、行业本质与核心价值

## 2.1 商业本质

物流供应链行业的本质不是“送货”，而是：

> 在复杂网络下，以可控成本、可预测时效和可验证服务质量完成货物流转与供应链协同。

### 1）客户为什么需要它？
企业和消费者需要物流供应链服务，通常是因为：
- 商品需要跨区域和跨环节流转
- 自建物流成本高且复杂
- 对时效、稳定性、库存效率有更高要求
- 多仓、多渠道、多平台履约复杂
- 跨境、冷链、B2B 履约需要专业能力
- 供应链协同和可视化越来越重要

### 2）企业提供的核心价值是什么？
- 提供运输、仓储、配送和履约能力
- 提高订单交付效率
- 降低库存与物流总成本
- 提高供应链可视化和计划能力
- 提升异常处理与服务稳定性
- 支撑多渠道、多区域经营扩张

### 3）企业为什么能赚钱？
物流供应链公司的盈利来源通常来自：
- 运费收入
- 仓储服务费
- 分拣包装费
- 履约服务费
- 项目管理费
- 平台撮合或技术服务费
- 增值服务收入（代收、保险、逆向物流、关务等）

## 2.2 价值创造链条

物流供应链行业典型链路：

### 快递/快运型
```text
揽收
→ 分拨
→ 干线运输
→ 中转
→ 末端派送
→ 签收
→ 收入确认
```

### 仓配一体型
```latex
客户签约
→ 入仓
→ 库存管理
→ 订单接入
→ 拣货/打包
→ 发运配送
→ 签收/退货处理
→ 收入确认
```

### 供应链管理型
```latex
需求预测
→ 采购/补货计划
→ 仓网与运输计划
→ 执行监控
→ 异常处理
→ 库存与履约优化
→ 管理费/系统费确认
```

## 2.3 行业核心飞轮
```latex
更多订单与客户
→ 更高网络密度和仓运协同
→ 更低单位履约成本
→ 更好时效与服务质量
→ 更强客户留存与口碑
→ 更多订单与客户
```

物流供应链真正强的飞轮是：

> 网络密度、运营效率、客户结构和数字化能力一起提升，形成履约成本和服务质量的双优化。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：运输收费
+ 名称：Transportation Fee
+ 收费对象：个人 / 商家 / 企业客户
+ 收费方式：按票、按重量、按体积、按里程、按车型收费
+ 公式：

```latex
收入 = 运量 × 单位运价
```

### 模式二：仓储收费
+ 名称：Warehousing Fee
+ 收费对象：商家 / 品牌商 / 企业
+ 收费方式：按面积、托盘、库位、天数收费
+ 公式：

```latex
收入 = 仓储资源占用量 × 单位仓储费
```

### 模式三：操作与履约收费
+ 名称：Fulfillment Fee
+ 收费对象：电商商家 / 品牌商 / 平台
+ 收费方式：按订单、件数、出入库、分拣、包装收费
+ 公式：

```latex
收入 = 订单量 × 单位履约服务费
```

### 模式四：管理与解决方案收费
+ 名称：Management / Solution Fee
+ 收费对象：企业客户
+ 收费方式：项目制、管理费、咨询费、系统服务费
+ 公式：

```latex
收入 = 客户数 × 客均合同额
```

### 模式五：平台与增值服务收费
+ 名称：Platform / Value-added Fee
+ 收费对象：货主 / 承运商 / 商家
+ 收费方式：撮合佣金、保险、代收货款、逆向物流、关务等
+ 公式：

```latex
收入 = 交易量 × 费率 + 增值服务付费量 × 单价
```

## 4.2 行业最优商业模式
物流供应链中高质量模型通常具备：

+ 高复购、高留存客户结构
+ 网络密度足够高
+ 单位履约成本持续下降
+ 服务质量稳定可控
+ 数字化管理能力强
+ 具备一定议价能力
+ 资本开支与扩张节奏匹配

理想模型不是：

> 靠低价抢量但越做越亏
>

而是：

> 通过密度、调度、仓网和系统能力提升，持续优化单位经济并增强客户粘性。
>

## 4.3 从单点履约到综合供应链服务路径
```latex
先做运输/仓储单点服务
→ 切入客户日常履约链路
→ 提供仓配一体与系统协同
→ 承接计划、库存、逆向、关务等更多环节
→ 成为综合供应链服务商
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 运输收入 + 仓储收入 + 履约操作收入 + 管理/项目收入 + 平台/增值服务收入 + 其他收入
```

## 5.2 拆解驱动因子
### 快递/快运常见拆法
```latex
收入 = 票量或吨量 × 单位单价
```

### 同城配送常见拆法
```latex
收入 = 订单量 × 单均收入
```

### 仓配型常见拆法
```latex
收入 = 仓储收入 + 订单履约量 × 单位操作费
```

### 供应链管理/To B 型常见拆法
```latex
收入 = 客户数 × 客均合同额 + 增购收入 + 续约收入
```

## 5.3 收入增长来源
+ 订单量增长
+ 网络覆盖扩张
+ 仓网扩张
+ 客单价提升
+ 大客户拓展
+ 新行业场景拓展
+ 增值服务渗透
+ 客户复购与续约
+ 从单环节服务升级为多环节服务

# 六、成本模型
## 6.1 主要成本构成
+ 干线运输成本
+ 末端配送成本
+ 仓租和仓储运营成本
+ 人工分拣与操作成本

+ 设备折旧
+ 平台与系统投入
+ 销售与客户维护成本
+ 管理费用
+ 赔付与异常成本

## 6.2 成本分类方式
### 固定成本
+ 仓库租赁（部分）
+ 干线/分拨基础设施
+ 系统研发投入
+ 管理团队
+ 自动化设备折旧

### 可变成本
+ 运力采购
+ 末端派送
+ 分拣包装
+ 人工操作
+ 油电和路桥费
+ 赔付成本

### 前端成本
+ 销售 BD
+ 大客户拓展
+ 渠道合作
+ 市场费用

### 后端成本
+ 仓运配执行
+ 调度与客服
+ 质控与异常处理
+ IT 运维与系统支持

## 6.3 单位经济模型
### 快递型
```latex
单票利润 = 单票收入 - 单票干线成本 - 单票分拨成本 - 单票末端派送成本 - 单票异常赔付成本
```

### 同城配送型
```latex
单单利润 = 单单收入 - 骑手履约成本 - 调度成本 - 补贴 - 客服异常成本
```

### 仓配型
```latex
单订单利润 = 单订单履约收入 + 分摊仓储收入 - 拣选/包装/出库成本 - 配送成本 - 售后逆向成本
```

### 供应链 SaaS 型
```latex
单客户LTV = 软件订阅毛利 + 实施/增购毛利 - 获客成本 - 交付成本
```

### 核心判断
+ 规模增长若没有带来网络密度提升，利润未必改善
+ 大客户收入高，但议价压力和集中度风险也高
+ 冷链和跨境的毛利可能更高，但合规与异常成本也更高
+ 仓网和运力布局错误，会显著拉低单位经济

## 6.4 利润公式
```latex
利润 = 收入 - 运输成本 - 仓储与操作成本 - 人工成本 - 系统与设备成本 - 销售费用 - 赔付异常成本 - 管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
物流供应链增长通常来自：

+ 更多订单量
+ 更高客户留存
+ 更广区域覆盖
+ 更深客户渗透
+ 更高单客户服务环节数
+ 更高附加值场景扩张

## 8.2 规模效应
规模扩大后可能带来：

+ 网络更密集
+ 路由更优化
+ 装载率提升
+ 单位仓运成本下降
+ 采购和运力议价能力增强
+ 系统和中后台投入被摊薄

## 8.3 网络效应
物流供应链存在一定网络效应和密度效应：

+ 更多订单 → 更高线路密度 → 更低单位成本
+ 更多客户 → 更稳定仓网布局 → 更优时效与服务
+ 更多节点与数据 → 更优调度与预测能力

## 8.4 标准化与人力依赖程度
+ 快递和标准仓配标准化程度较高
+ 冷链、跨境、项目物流复杂度更高
+ 同城即时配送对人力调度依赖强
+ 供应链 SaaS 更接近软件服务模式

---

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 快递和标准件市场头部集中
+ 仓配和供应链服务区域和行业差异明显
+ 同城配送竞争激烈，平台属性强
+ 跨境与冷链常呈现专业化分层
+ 物流科技和 SaaS 更看产品和落地能力

## 9.2 常见壁垒类型
+ 网络密度壁垒
+ 仓网布局壁垒
+ 大客户与行业解决方案壁垒
+ 运营管理壁垒
+ 系统与数据壁垒
+ 冷链/跨境资质与资源壁垒
+ 品牌与服务稳定性壁垒
+ 资本投入壁垒

## 9.3 替代风险
+ 客户自建物流替代
+ 被综合平台压价
+ 被更低价区域玩家替代
+ 技术和自动化不足导致效率落后
+ 单一模式无法适应客户多场景需求

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
对应货运、仓储、配送、跨境、冷链等全行业流通规模或物流支出规模

### SAM
公司所在区域、行业、品类和服务环节下可服务市场

### SOM
公司当前和中短期可获得的订单、客户和网络份额

## 12.2 通用测算公式
### 方法一：物流支出法
```latex
市场空间 = 目标客户群商品交易规模 × 物流成本占比
```

### 方法二：订单量法
```latex
市场空间 = 订单量 × 单均物流收入
```

### 方法三：客户数法
```latex
市场空间 = 可服务客户数 × 客均年合同额
```

## 12.3 市场空间判断注意事项
+ 市场大不等于利润厚
+ 物流空间受价格竞争和行业周期影响大
+ 重资产扩张赛道需重点看资本效率
+ 高时效和高复杂度赛道通常更容易形成溢价，但交付门槛也更高

# 十四、快速分析卡
## 一句话本质
> 物流供应链行业本质上是在复杂网络中，以更低成本、更高时效和更稳定服务完成货物流转与供应链协同的行业。
>

## 核心收入公式
```latex
收入 = 运量/订单量 × 单位收入 + 仓储/履约/增值服务收入
```

## 核心成本公式
```latex
成本 = 运输成本 + 仓储操作成本 + 人工成本 + 系统设备成本 + 销售费用 + 异常赔付成本
```

## 核心判断三要素
1. 网络和履约效率是否持续优化
2. 客户结构和留存是否健康
3. 扩张是否带来更好单位经济而不是更重负担

## 最重要指标
+ 订单量 / 票量 / 吨量
+ 单位收入
+ 单位成本
+ 装载率 / 仓库利用率
+ 准时率 / 妥投率
+ 客户留存率
+ 经营现金流

## 最大风险
+ 价格战
+ 大客户压价
+ 资本开支过重
+ 质量事故
+ 现金流与应收压力

## 最终结论模板
> 物流供应链行业的核心不是把订单量做大，而是把网络密度、履约效率、客户结构和资金周转做优。真正决定长期价值的不是短期规模，而是单位经济、服务稳定性、客户粘性和资本效率。
