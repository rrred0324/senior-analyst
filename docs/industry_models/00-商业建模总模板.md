# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 主收入A + 主收入B + 增值收入C + 其他收入D
```

## 5.2 拆解驱动因子
每个收入来源都要继续拆：

### 通用拆法一：用户规模驱动
```latex
收入 = 用户数 × 付费率 × ARPU / ARPPU
```

### 通用拆法二：交易规模驱动
```latex
收入 = GMV / TPV / 流水 × take rate
```

### 通用拆法三：企业客户驱动
```latex
收入 = 客户数 × ACV × 续费率
```

### 通用拆法四：广告驱动
```latex
收入 = 流量规模 × 广告加载率 × eCPM
```

### 通用拆法五：项目驱动
```latex
收入 = 项目数 × 平均合同额
```

## 5.3 收入增长来源
分析未来增长由哪些因素贡献：

+ 用户数增长
+ 使用频次提升
+ 客单价提升
+ 付费率提升
+ take rate 提升
+ 扩品类
+ 扩区域
+ 扩客群
+ 增值服务渗透

# 十、行业风险分析
## 10.1 通用风险项
+ 需求波动风险
+ 获客成本上升
+ 供给不足
+ 留存不足
+ 价格竞争
+ 毛利率下滑
+ 交付失控
+ 回款变差
+ 合规与监管风险
+ 数据安全风险
+ 大客户依赖
+ 单产品依赖
+ 单城市 / 单渠道依赖

## 10.2 风险信号模板
看到下列情况需要警惕：

+ 增长主要靠补贴 / 买量 / 低价
+ 收入增长但现金流恶化
+ 客户增长但留存差
+ GMV 很大但 take rate 提不上去
+ 收入很高但毛利率不断下滑
+ 项目很多但回款很慢
+ 商业化加强后留存恶化
+ 高增长来自单一大客户或单一产品
+ 核心指标和行业规律不匹配

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
行业理论总市场规模

### SAM
公司当前产品能力可服务市场

### SOM
公司中短期可获得市场份额

## 12.2 通用测算公式
### 方法一：用户规模法
```latex
市场空间 = 潜在用户数 × 渗透率 × 年均ARPU
```

### 方法二：企业客户法
```latex
市场空间 = 目标客户数 × 年均 ACV
```

### 方法三：交易法
```latex
市场空间 = 行业交易总额 × 在线化率 × 平台渗透率 × take rate
```

### 方法四：支出法
```latex
市场空间 = 客户年度相关支出 × 产品渗透率 × 可得份额
```

## 12.3 市场空间判断注意事项
+ 不要只看大盘，不看可服务市场
+ 不要把全行业支出都当可得收入
+ 要区分 GMV、TPV 与公司收入
+ 要考虑监管和替代限制
