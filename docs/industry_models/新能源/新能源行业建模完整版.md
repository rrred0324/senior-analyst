# 一、行业基础定义

## 1.1 行业名称
- 行业名称：新能源
- 细分赛道：光伏、风电、储能、动力电池、电池材料、氢能、充电基础设施、能源管理软件、虚拟电厂、综合能源服务等
- 上下游位置：
  - 上游：矿产资源、材料、设备、核心零部件、软件与控制系统
  - 中游：电池、电芯、组件、逆变器、储能系统、整机设备、系统集成
  - 下游：发电侧、电网侧、工商业用户、居民用户、车企、运营商、能源投资方
- 主要服务对象：To B、To G、部分 To C

## 1.2 行业一句话定义
> 新能源行业的本质是：通过新型发电、储能、电能转换与能源管理技术，替代高碳能源结构并提升能源系统效率，在设备制造、系统集成和长期运营中创造经济价值。

## 1.3 行业边界

### 覆盖范围
- 光伏、风电、储能、电池及相关核心零部件与材料
- 氢能、充电基础设施、能源管理与调度系统
- 新能源项目开发、系统集成、运营维护和能源服务

### 不覆盖范围
- 传统化石能源主导业务
- 与新能源弱相关的一般电气设备贸易
- 不具备核心技术、产品或项目能力的泛概念公司
- 单纯房地产属性且不具备能源运营属性的项目

# 二、行业本质与核心价值

## 2.1 商业本质

新能源行业的本质不是“卖设备”，而是：

> 用更低度电成本、更高系统效率、更强安全性和更优能源调度能力，完成能源生产、转换、存储和消费方式的升级。

### 1）客户为什么需要它？
客户需要新能源产品和服务，通常因为：
- 降低能源成本
- 满足减碳与 ESG 要求
- 提高能源安全与自给率
- 适应分布式和电气化趋势
- 提升电力系统灵活性和稳定性
- 获取政策补贴、绿电收益或容量收益

### 2）企业提供的核心价值是什么？
- 提供清洁能源供给能力
- 提供储能与调峰能力
- 提供高效率电能转换设备
- 提供安全可靠的系统集成方案
- 提供持续运维与能量管理能力
- 提供电力市场交易和调度优化能力

### 3）企业为什么能赚钱？
新能源企业的盈利来源通常来自：
- 设备销售收入
- 系统集成收入
- EPC 收入
- 运营维护收入
- 电费/绿电交易收入
- 容量租赁或辅助服务收入
- 软件订阅和能源管理服务收入

## 2.2 价值创造链条

新能源行业典型链路：

### 光伏/风电设备型
```text
研发与产品设计
→ 产能建设
→ 渠道/项目客户导入
→ 销售交付
→ 装机
→ 运维服务
→ 收入确认
```

### 储能系统型
```latex
需求识别
→ 系统方案设计
→ 电芯/PCS/BMS 集成
→ 项目交付
→ 并网/投运
→ 运维与调度
→ 持续服务收入
```

### 新能源运营型
```latex
项目开发
→ 备案/审批/并网
→ 建设投产
→ 发电或储能运营
→ 电力交易/补贴/容量收益
→ 长期现金流回收
```

## 2.3 行业核心飞轮
```latex
更优技术与系统效率
→ 更低成本与更强项目回报
→ 更多装机/更多项目
→ 更大规模采购与制造效率
→ 更优成本与品牌信任
→ 更优技术与系统效率
```

新能源行业真正强的飞轮是：

> 技术、成本、渠道、项目经验和长期运营数据共同推动规模化，从而不断降低单位成本并提升项目回报。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：设备销售
+ 名称：Equipment Sales
+ 收费对象：开发商 / EPC / 集成商 / 终端客户
+ 收费方式：按台、按 W、按 Wh、按套销售
+ 公式：

```latex
收入 = 出货量 × 单位售价
```

### 模式二：系统集成 / EPC
+ 名称：System Integration / EPC
+ 收费对象：项目业主 / 开发商 / 企业用户
+ 收费方式：按项目合同额收费
+ 公式：

```latex
收入 = 项目数量 × 单项目合同额
```

### 模式三：项目运营
+ 名称：Asset Operation
+ 收费对象：电网 / 电力市场 / 用能客户
+ 收费方式：售电收入、补贴、容量费、辅助服务费
+ 公式：

```latex
# 光伏/风电运营（度电收入 + 补贴）
收入 = 发电量(MWh) × (上网电价 + 度电补贴)(元/MWh)

# 储能运营（能量收入 + 容量收入，两项互不重叠）
能量收入 = 净放电量(MWh) × 峰谷价差(元/MWh)
容量收入 = 装机功率(MW) × 容量补贴标准(元/MW/年)
总收入 = 能量收入 + 容量收入 + 辅助服务收入
```

### 模式四：运维与能源服务
+ 名称：O&M / Energy Service
+ 收费对象：资产业主 / 工商业客户
+ 收费方式：运维费、托管费、节能分成
+ 公式：

```latex
收入 = 服务资产规模 × 服务费率
```

### 模式五：软件与平台服务
+ 名称：Software / Platform Service
+ 收费对象：园区 / 企业 / 聚合商 / 售电公司
+ 收费方式：订阅费、按容量收费、交易分成
+ 公式：

```latex
收入 = 客户数 × 客均合同额 + 平台分成
```

## 4.2 行业最优商业模式
新能源中高质量模型通常具备：

+ 明确的成本或效率优势
+ 产品安全与可靠性验证通过
+ 渠道和客户资源稳定
+ 供给能力可扩张
+ 项目回报率健康
+ 现金流与 CAPEX 匹配
+ 政策依赖可控

理想模型不是：

> 靠补贴或单次项目冲收入，但无法形成持续竞争力
>

而是：

> 通过技术、成本、交付和长期运营数据，建立可复制的项目回报与客户信任体系。
>

## 4.3 从单一设备到综合能源服务路径
```latex
先做核心设备
→ 进入项目交付链路
→ 扩展系统集成和运维
→ 叠加能源管理与交易能力
→ 成为综合能源解决方案提供商
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 设备销售收入 + 系统集成/EPC 收入 + 运维收入 + 项目运营收入 + 软件/平台收入 + 其他收入
```

## 5.2 拆解驱动因子
### 制造型常见拆法
```latex
收入 = 出货量 × ASP
```

### 项目型常见拆法
```latex
收入 = 项目数量 × 平均项目金额
```

### 运营型常见拆法
```latex
# 发电型（光伏/风电）：
发电量 = 装机规模(MW) × 利用小时数(h)
收入 = 发电量(MWh) × 单位收益(元/MWh)

# 储能型：
充放电量 = 装机规模(MWh) × 循环次数 × 充放电深度
收入 = 充放电量(MWh) × 单位收益(元/MWh)
```

### 软件平台型常见拆法
```latex
收入 = 客户数 × 客均合同额 + 交易/调度分成
```

## 5.3 收入增长来源
+ 出货量增长
+ 单位价值量提升
+ 新客户导入
+ 新场景渗透
+ 系统集成渗透率提升
+ 运维与服务收入增加
+ 装机和运营资产扩大
+ 电力交易和辅助服务参与增加
+ 国际化扩张

# 六、成本模型
## 6.1 主要成本构成
+ 原材料成本

+ 外协与系统集成成本

## 6.2 成本分类方式
### 固定成本
+ 厂房和设备折旧
+ 研发团队
+ 系统平台建设
+ 管理团队
+ 项目开发团队

### 可变成本
+ 材料采购
+ 生产加工
+ 物流与安装
+ EPC 外包
+ 维修更换
+ 电站运营中的变动支出

### 前端成本
+ 销售与渠道
+ 项目开发
+ 客户认证
+ 招投标成本

### 后端成本
+ 生产交付
+ 并网与调试
+ 质保
+ 运维
+ 电站管理

## 6.3 单位经济模型
### 光伏/电池制造型
```latex
单位毛利 = 单位售价 - 单位材料成本 - 单位制造成本
```

### 储能系统型
```latex
单项目毛利 = 项目合同额 - 电芯/PCS/BMS 等硬件成本 - 集成安装成本 - 质保准备
```

### 充电桩运营型
```latex
单桩利润 = 充电服务收入 - 电力采购成本 - 场地/运维成本 - 折旧
```

### 电站/储能运营型
```latex
项目年度现金流 = 发电/放电收益 + 补贴/容量收益 - 运维成本 - 财务成本
```

### 核心判断
+ 新能源很多赛道本质是制造业，出货增长必须建立在成本下降和毛利稳定基础上
+ 项目型业务看收入不够，要重点看回款和现金流
+ 运营型业务看账面利润不够，要看项目 IRR、融资结构和长期收益稳定性
+ 储能和电池等赛道安全事故会极大侵蚀价值

## 6.4 利润公式
```latex
利润 = 收入 - 材料/制造/集成成本 - 研发成本 - 销售费用 - 运维与质保成本 - 管理费用 - 财务费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
新能源增长通常来自：

+ 下游装机增长
+ 技术进步带来的成本下降
+ 新应用场景扩大
+ 政策驱动和能源转型
+ 国际市场渗透
+ 设备向系统和服务延伸
+ 存量资产进入运维和管理阶段

## 8.2 规模效应
规模扩大后可能带来：

+ 材料采购议价增强
+ 制造效率提高
+ 品牌与渠道增强
+ 研发投入摊薄
+ 系统方案标准化
+ 运维网络成本下降

## 8.3 网络效应
新能源多数赛道不是强网络效应行业，但存在：

+ 平台型能源管理系统的调度网络效应
+ 充电网络的点位密度效应
+ 虚拟电厂的聚合规模效应
+ 项目数据和运行经验形成的学习效应

## 8.4 标准化与政策影响
+ 制造端标准化程度高，但价格竞争激烈
+ 项目端受政策、并网、电价机制影响较大
+ 电力市场化会提升运营和交易能力的重要性
+ 新赛道常受示范项目和政策补贴牵引

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 光伏、电池等制造端竞争激烈，头部集中趋势明显
+ 储能系统处于快速增长和格局重塑阶段
+ 风电和大型项目端更看招投标与交付能力
+ 充电桩和能源数字化更碎片化，但长期看平台化可能增强
+ 氢能仍偏早期，示范项目和政策资源重要

## 9.2 常见壁垒类型
+ 技术和产品壁垒
+ 制造成本壁垒
+ 渠道与客户认证壁垒
+ 项目开发和并网资源壁垒
+ 安全与质量壁垒
+ 融资和资产运营壁垒
+ 软件与调度能力壁垒
+ 品牌和运维能力壁垒

## 9.3 替代风险
+ 技术路线替代
+ 产品同质化导致价格战
+ 上下游挤压利润
+ 政策退坡削弱回报
+ 海外贸易政策限制
+ 客户自建或转向一体化大厂

# 十、行业风险分析
## 10.1 通用风险项
+ 原材料价格波动
+ 产能过剩

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
对应全球或区域新能源设备、系统、服务和运营市场总规模

### SAM
公司当前技术路线、区域覆盖、客户类型和资质下可服务市场

### SOM
公司中短期能够实际拿下的装机、订单和客户份额

## 12.2 通用测算公式
### 方法一：装机法
```latex
市场空间 = 年新增装机规模 × 单位价值量
```

### 方法二：终端渗透法
```latex
市场空间 = 目标场景设备数量 × 单设备价值
```

### 方法三：运营收益法
```latex
市场空间 = 可运营资产规模 × 单位收益
```

## 12.3 市场空间判断注意事项
+ 市场大不代表盈利一定厚
+ 设备制造端要重点区分“量增”和“价跌”
+ 项目运营端要看真实 IRR，不只看装机规模
+ 技术路线变化会重塑 TAM 归属

> 新能源行业本质上是通过新型发电、储能、电能转换与能源管理技术，以更低成本、更高效率和更高安全性重构能源供给与消费体系的行业。

## 核心收入公式

+ 回款与现金流压力
