# 一、行业基础定义

## 1.1 行业名称
- 行业名称：新能源
- 细分赛道：光伏、风电、储能、动力电池、电池材料、氢能、充电基础设施、能源管理软件、虚拟电厂、综合能源服务等
- 上下游位置：
  - 上游：矿产资源、材料、设备、核心零部件、软件与控制系统
  - 中游：电池、电芯、组件、逆变器、储能系统、整机设备、系统集成
  - 下游：发电侧、电网侧、工商业用户、居民用户、车企、运营商、能源投资方
- 主要服务对象：To B、To G、部分 To C

## 1.2 行业一句话定义
> 新能源行业的本质是：通过新型发电、储能、电能转换与能源管理技术，替代高碳能源结构并提升能源系统效率，在设备制造、系统集成和长期运营中创造经济价值。

## 1.3 行业边界

### 覆盖范围
- 光伏、风电、储能、电池及相关核心零部件与材料
- 氢能、充电基础设施、能源管理与调度系统
- 新能源项目开发、系统集成、运营维护和能源服务

### 不覆盖范围
- 传统化石能源主导业务
- 与新能源弱相关的一般电气设备贸易
- 不具备核心技术、产品或项目能力的泛概念公司
- 单纯房地产属性且不具备能源运营属性的项目

# 二、行业本质与核心价值

## 2.1 商业本质

新能源行业的本质不是“卖设备”，而是：

> 用更低度电成本、更高系统效率、更强安全性和更优能源调度能力，完成能源生产、转换、存储和消费方式的升级。

### 1）客户为什么需要它？
客户需要新能源产品和服务，通常因为：
- 降低能源成本
- 满足减碳与 ESG 要求
- 提高能源安全与自给率
- 适应分布式和电气化趋势
- 提升电力系统灵活性和稳定性
- 获取政策补贴、绿电收益或容量收益

### 2）企业提供的核心价值是什么？
- 提供清洁能源供给能力
- 提供储能与调峰能力
- 提供高效率电能转换设备
- 提供安全可靠的系统集成方案
- 提供持续运维与能量管理能力
- 提供电力市场交易和调度优化能力

### 3）企业为什么能赚钱？
新能源企业的盈利来源通常来自：
- 设备销售收入
- 系统集成收入
- EPC 收入
- 运营维护收入
- 电费/绿电交易收入
- 容量租赁或辅助服务收入
- 软件订阅和能源管理服务收入
