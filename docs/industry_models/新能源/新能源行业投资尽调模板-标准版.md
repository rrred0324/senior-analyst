# 三、业务理解

## 3.1 公司到底做什么
1. 公司位于制造、系统集成、项目开发、运营还是能源软件环节？
2. 核心产品或服务是什么？
3. 主要客户是谁？
4. 收入主要来自设备、项目、运营还是软件？
5. 公司本质更像制造企业、工程企业、资产运营商还是平台公司？

## 3.2 解决什么问题
1. 公司为客户解决的是成本、清洁能源、调峰、安全还是管理问题？
2. 与竞品相比，优势在效率、寿命、交付、价格还是运维？
3. 若没有该公司，客户的替代方案是什么？
4. 客户购买决策是财务驱动、政策驱动还是战略驱动？

## 3.3 商业模式
1. 收入是一次性设备销售，还是持续运营与服务收入？
2. 是否存在从设备延展至系统、运维和平台的升级路径？
3. 是否对补贴、容量电价、政策性项目高度敏感？
4. 是否依赖大客户、大项目或单一区域？

# 九、财务尽调

## 9.1 收入质量
1. 收入是高质量回款收入，还是低毛利冲规模收入？
2. 是否依赖单一项目、单一客户或单一政策区域？
3. ASP 下行是否快于成本下降？
4. 服务和运维收入占比是否提升？

## 9.2 利润质量
1. 毛利率是否有持续性？
2. 价格竞争是否侵蚀利润？
3. 质保与售后成本是否被低估？
4. 项目型业务是否存在低价中标问题？

## 9.3 现金流质量
1. 应收账款和存货是否显著上升？
2. 项目制业务是否占用大量营运资金？
3. CAPEX 是否超出融资能力？
4. 经营现金流是否与利润匹配？

## 9.4 资产负债表风险
重点看：
- 现金
- 应收账款
- 存货
- 固定资产
- 在建工程
- 合同资产/负债
- 有息负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备新能源技术、制造、项目和客户资源背景？
2. 是否有大型交付和运维经验？
3. 是否过度依赖单一技术或销售负责人？
4. 国际化和融资能力如何？

## 10.2 组织能力
1. 公司更强在研发、制造、渠道、项目开发还是运营？
2. 是否具备跨区域项目管理能力？
3. 安全、质量和售后体系是否成熟？
4. 是否具备从单产品向系统和服务延伸的组织能力？

## 10.3 激励机制
1. 销售激励是否导致低价拿单？
2. 项目团队是否兼顾交付质量和回款？
3. 核心技术和运营人才稳定性如何？
