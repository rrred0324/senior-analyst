## 一、币安 App 核心架构：CEX 与 Binance Wallet

### 1.1 一句话区分

打开币安 App，你面对的是**两个完全不同的世界**：

| | CEX（中心化交易所） | Binance Wallet（自托管钱包） |
|---|---|---|
| **比喻** | 银行账户 | 自己家的保险柜 |
| **谁控制资产** | 币安替你保管 | 你自己保管（MPC密钥分片） |
| **登录方式** | 邮箱/手机号+密码+2FA | 币安账户内直接切换 |
| **操作入口** | App底部"交易"/"理财" | App"资产"页顶部切换到"钱包" |
| **需要身份认证** | 需要（KYC） | 不需要（但需有币安账户） |
| **丢了密码** | 找客服重置 | **靠云备份恢复，否则永远找不回来** |

### 1.2 为什么要同时理解两者？

- **CEX**是你用法币（人民币/美元）买入加密货币的入口，也是执行高级交易（合约、杠杆）的平台
- **Binance Wallet**是你持有、使用、投资加密货币的链上主战场
- 典型流程：CEX买币 → 划转到Binance Wallet → 在DeFi/DEx中使用

### 1.3 币安 App 底部导航栏对应

```
┌───────────────────────────────────────────────────┐
│  首页  │  行情  │  交易(CEX)  │  理财  │  资产    │
│        │  涨跌榜 │  现货/合约   │ 赚币   │  现货钱包│
│        │  热门币 │  闪兑/杠杆   │ 质押   │  资金钱包│
│        │        │              │ Launchpool │ 钱包(Web3)│
│        │        │              │       │          │
│  ─── 额外入口 ───                              │
│  Square(广场) │ 合约(独立标签) │ 抄单 │ 机器人     │
└───────────────────────────────────────────────────┘
```

### 1.4 币安 vs OKX 关键差异速览

| 维度 | 币安 | OKX |
|------|------|-----|
| 自托管钱包名称 | **Binance Wallet**（已去掉"Web3"字样） | **OKX Web3 钱包** |
| 钱包技术 | **MPC（2/3密钥分片）**，创建时无需助记词 | MPC，同样支持助记词导入 |
| CEX钱包结构 | **现货钱包 + 资金钱包**（双钱包） | 交易账户 + 资金账户 |
| 社交功能 | **Binance Square**（广场） | OKX社区 |
| 新手模式 | **Binance Junior**（简化界面） | OKX Lite |
| 早期代币发现 | **Binance Alpha** | Jumpstart |
| 平台代币 | **BNB**（手续费25%折扣） | **OKB**（手续费折扣） |
| BSC网络名称 | BEP-20 | BSC/BEP-20 |

## 二、Binance Wallet：MPC 自托管钱包

### 2.1 什么是 Binance Wallet？

Binance Wallet 是币安内置的**自托管钱包**，采用 **MPC（多方计算）** 技术管理密钥。与传统的助记词钱包不同，它**创建时无需生成或记录助记词**。

**MPC 钱包的核心原理**：

```
传统钱包（如 MetaMask）：
  1个助记词 = 1把万能钥匙 → 丢了 = 资产没了

MPC 钱包（Binance Wallet）：
  3个密钥分片（Key-Shares）→ 需要至少2个才能签名交易
  ┌─────────────┬──────────────┬─────────────┐
  │ 分片1：设备  │ 分片2：云端   │ 分片3：币安  │
  │ 存在你的手机 │ 存在iCloud/  │ 存在币安服务器│
  │              │ Google Drive │             │
  └─────────────┴──────────────┴─────────────┘
  → 任意2个分片 = 可以签名交易
  → 单个分片泄露 = 无法单独操作你的资产
```

**MPC 钱包的优势与风险**：

| | 优势 | 风险 |
|---|---|---|
| **安全性** | 单点故障消除，1个分片被盗不会丢资产 | 云端账号被盗+设备被盗=2个分片泄露=资产危险 |
| **便利性** | 创建秒级完成，无需手抄助记词 | 依赖云备份，忘记备份=换设备后无法恢复 |
| **自托管** | 币安不持有全部密钥，无法动用你的资产 | 币安持有1个分片，但无法单独操作 |

### 2.2 创建 Binance Wallet

```
步骤1：打开币安App → 底部"资产"
步骤2：在顶部标签页切换到"钱包"（Wallet）
步骤3：点击"创建钱包"
步骤4：⚠️ 系统提示你备份密钥分片
       → 选择备份到云端（iCloud / Google Drive）
       → 选择备份到设备
       → ⚠️ 至少完成一种备份！
步骤5：设置本地安全密码（保护App内钱包访问）
步骤6：钱包创建完成（秒级，无需抄写助记词）
```

**关键提醒**：
- 创建时虽然不需要助记词，但**必须备份密钥分片**
- 换手机或卸载App前，确认云备份已生效
- 如果同时丢失设备和云端备份，将**永远无法恢复钱包**

### 2.3 导入已有钱包

如果你之前有其他钱包（如MetaMask、Trust Wallet），可以导入：

```
步骤1：打开币安App → 资产 → "钱包"标签
步骤2：点击"导入钱包"
步骤3：选择导入方式：
       → 助记词导入（输入12/24个英文单词）
       → 私钥导入（输入一串字符）
步骤4：设置本地安全密码
步骤5：导入完成
```

**注意**：导入的钱包**不会自动享受MPC保护**，仍然依赖原始助记词。请务必安全保存原始助记词。

### 2.4 钱包地址详解

一个钱包可以拥有**多条链的地址**，每条链的地址格式不同：

| 区块链 | 地址格式示例 | 特征 |
|--------|-------------|------|
| 以太坊/EVM链 | `0x71C7...3bE4` | 以0x开头，42位 |
| 比特币 | `bc1q...w5r4` | 以bc1（SegWit）或1/3开头 |
| Solana | `7xKX...3nVd` | Base58编码 |
| Tron | `TJYe...8kV2` | 以T开头 |
| BSC | `0x55d3...9aF1` | 与以太坊格式相同，但链不同 |

**重要**：给不同链的币转账，必须用对应链的地址。以太坊地址收BTC会丢币！BSC地址和以太坊地址格式相同（都是0x开头），但**链完全不同**，转错链=丢币！

### 2.5 CEX账户与 Binance Wallet 的资产互转

```
CEX现货钱包 → "划转/提币" → Binance Wallet地址    （从币安托管转到自己控制）
Binance Wallet → "转账" → CEX充币地址              （从自己控制转到币安托管）
```

在币安App中的操作路径：

```
CEX → Binance Wallet：
  资产 → 现货钱包 → 提币 → 选择币种 → 选择"Binance Wallet"或粘贴钱包地址 → 确认

Binance Wallet → CEX：
  资产 → 钱包 → 选择币种 → 发送 → 输入CEX充币地址 → 确认
```

**币安内部划转**（CEX现货钱包 ↔ 资金钱包）：
```
资产 → 划转 → 从"现货钱包"到"资金钱包"（或反向）→ 选择币种和数量 → 确认
⚠️ 这是CEX内部账户间转移，不上链，即时到账，无手续费
```

## 三、发送与接收币种

### 3.1 接收（收币）

别人给你转账，你只需要提供**你的钱包地址**：

```
步骤1：打开币安App → 资产 → "钱包"标签
步骤2：选择你要接收的币种（如USDT）
步骤3：点击"收款"或"接收"
步骤4：显示你的钱包地址（二维码+文字格式）
步骤5：将地址发送给对方
步骤6：等待对方发起交易，区块链确认后到账
```

**注意点**：
- 确认对方和你使用的是**同一条链**（如都用以太坊ERC-20，或都用Tron TRC-20）
- USDT在多条链上都有发行（ERC-20/TRC-20/BEP-20等），链不同地址不同
- 到账时间取决于区块链网络拥堵程度，通常1-30分钟

### 3.2 发送（转币）

```
步骤1：打开币安App → 资产 → "钱包"标签
步骤2：选择你要发送的币种
步骤3：点击"发送"
步骤4：输入或粘贴对方地址（⚠️ 务必逐字核对）
步骤5：选择网络/链（如ERC-20、TRC-20、BEP-20）
步骤6：输入转账数量
步骤7：确认交易详情：
       → 收款地址
       → 转账金额
       → 网络手续费（Gas费）
       → 预计到账时间
步骤8：输入本地密码确认
步骤9：交易发送，等待区块链确认
```

**关键概念：Gas费（网络手续费）**

Gas费是支付给区块链矿工/验证者的交易处理费：
- 以太坊主网Gas费较高（$1-$50不等，取决于网络拥堵程度）
- BSC Gas费极低（通常<$0.1，需BNB支付）
- Tron/Solana等链Gas费极低（通常<$0.1）
- Gas费从你的钱包中扣除（需要留足对应链的原生代币：以太坊需ETH、BSC需BNB、Tron需TRX）

### 3.3 常见转账问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 转账长时间不到账 | 网络拥堵/Gas费设太低 | 等待确认或用交易加速器 |
| 转到了错误地址 | 地址复制错误/选错链 | **无法撤回**，联系收款方 |
| "Insufficient gas" | 钱包缺少原生代币付Gas | 先转入一些ETH/BNB/TRX等 |
| USDT转账失败 | 合约授权不足 | 先在链上approve授权 |
| BSC和ETH地址混淆 | 两者都是0x开头但链不同 | 确认网络选择与实际链一致 |

## 四、CEX 链上充币：从外部钱包转入币安

**充币**（Deposit）是将数字资产从外部钱包或其他平台转入你的币安CEX账户。这是你在CEX上进行交易的前提——必须先有币在CEX账户里。

### 4.1 充币前必读：三要素核对法

每一笔充币操作，都必须核对**三个关键要素**，任何一个出错都可能导致**资产丢失且无法撤回**：

```
┌─────────────────────────────────────────────────────┐
│              充币三要素核对清单                        │
│                                                     │
│  1. 币种    ──  你充的是USDT还是USDC？BTC还是BCH？    │
│  2. 网络    ──  你选的是ERC-20还是TRC-20？BEP-20？    │
│  3. 地址+标签 ──  地址是否正确？是否需要填Memo/Tag？  │
│                                                     │
│  ⚠️ 三项全部正确才能到账，任一错误可能丢币！          │
└─────────────────────────────────────────────────────┘
```

### 4.2 选择资产（币种）

**为什么币种选择很重要？**

加密货币世界中存在大量名称相似但完全不同的资产：

| 易混淆币种 | 实际区别 | 充错后果 |
|-----------|---------|---------|
| USDT vs USDC | 两种不同的稳定币，合约地址完全不同 | 无法自动到账，需人工申诉 |
| BTC vs BCH | 比特币 vs 比特币现金，完全不同的链 | 无法自动到账 |
| ETH vs ETC | 以太坊 vs 以太经典，分叉后的两条链 | 无法自动到账 |
| BNB (BEP2) vs BNB (BEP20) | 币安链 vs 币安智能链，不同网络 | 可能无法到账 |
| SOL vs Staked SOL | Solana vs 质押版SOL | 可能无法正确到账 |

**操作规范**：

```
步骤1：在币安App中打开 资产 → 充币（或"添加资金"→"链上充币"）
步骤2：选择你要充入的币种
       → ⚠️ 在搜索框输入币种名称时，仔细确认下拉列表中的选项
       → 不要只看简称，注意全称和图标
步骤3：确认币安支持该币种的充币（未上架币种无法充值到账）
```

### 4.3 选择网络（最关键的一步）

**为什么网络选择如此重要？**

同一种币（如USDT）可以在多条不同的区块链上发行和流通。每条链上的USDT是**不同的资产**，使用不同的地址格式和智能合约。

```
USDT 的多条链版本示例：

以太坊 (ERC-20) USDT  ──  地址格式: 0x...     ──  合约地址: 0xdAC17F9...
波场 (TRC-20) USDT    ──  地址格式: T...      ──  合约地址: TR7NHqje...
BSC (BEP-20) USDT     ──  地址格式: 0x...     ──  合约地址: 0x55d398...
Solana (SPL) USDT     ──  地址格式: 基于SPL   ──  合约地址: EPjFWdd...

⚠️ 虽然都叫"USDT"，但它们是不同链上的不同代币！
⚠️ ERC-20和BEP-20地址格式相同（0x开头），但链完全不同！
```

**币安网络名称对照**：

| 币安显示名称 | 对应区块链 | 地址特征 | 常见混淆 |
|-------------|-----------|---------|---------|
| ERC20 | 以太坊 | 0x开头 | 与BEP20地址格式相同 |
| BEP20 | BNB Smart Chain（BSC） | 0x开头 | 与ERC20地址格式相同 |
| TRC20 | 波场（Tron） | T开头 | 不易混淆 |
| BTC | 比特币原生 | bc1/1/3开头 | 注意SegWit vs Legacy |
| BTC (SegWit) | 比特币原生SegWit | bc1开头 | 仅支持bc1地址 |
| EOS | EOS网络 | 12位字符 | 必须填Memo |
| BEP2 | 币安链（BNB Beacon Chain） | bnb开头 | 与BEP20不同！ |

**选择网络的操作规范**：

```
步骤1：在币安充币页面，选择币种后，查看"网络"选项
步骤2：币安会列出该币种支持的所有充币网络
步骤3：⚠️ 你必须选择与转出方（外部钱包）所在链一致的网络
       → 如果你的USDT在以太坊上 → 选择 ERC20
       → 如果你的USDT在波场上 → 选择 TRC20
       → 如果你的USDT在BSC上 → 选择 BEP20
       → 如果不确定 → 去转出方查看该USDT的网络类型
步骤4：确认后，币安显示对应网络的充币地址
```

**常见币种的网络选择速查**：

| 币种 | 可选网络 | Gas费 | 推荐网络 | 备注 |
|------|---------|-------|---------|------|
| USDT | ERC20 / TRC20 / BEP20 / SPL | ERC高/TRC低/BSC低/SPL极低 | TRC20 | 日常使用首选TRC20，费用低 |
| BTC | BTC / BTC(SegWit) / Lightning | 中 / 中 / 极低 | BTC原生 | Lightning适合小额快速 |
| ETH | ERC20 / Arbitrum / Optimism / Base | 主网高/L2低 | 主网大额/L2日常 | L2上的ETH是wrapped版本 |
| BNB | BEP20 / BEP2 | BEP20低/BEP2低 | BEP20 | BEP2是老版币安链，BEP20是BSC |
| SOL | SPL | 极低 | SPL | Solana原生网络 |

**选择网络时的核心判断逻辑**：

```
                    你要从哪里转出？
                         │
              ┌──────────┼──────────┐
              ▼          ▼          ▼
         另一个CEX    Web3钱包    硬件钱包
              │          │          │
              ▼          ▼          ▼
      查看对方提币    查看钱包中     查看硬件
      页面的网络      币种的链      钱包支持的链
              │          │          │
              └──────────┼──────────┘
                         ▼
              必须选择与转出方一致的网络
                         │
                         ▼
                    ⚠️ 不确定？
              → 先用小额测试（如$1）
              → 确认到账后再转大额
```

### 4.4 选择充币目标钱包

币安CEX有**两个内部钱包**，充币时需要选择目标：

```
┌───────────────────────────────────────────────────────┐
│              币安CEX双钱包体系                          │
│                                                       │
│  现货钱包（Spot Wallet）     资金钱包（Funding Wallet） │
│  ├── 用于现货/合约交易        ├── 用于P2P买卖           │
│  ├── 交易手续费从此扣除       ├── 用于充提币             │
│  └── 理财产品从此扣款         └── 部分充币默认到账此钱包 │
│                                                       │
│  ⚠️ 两个钱包之间需要"划转"才能互用！                    │
│  ⚠️ 充币前确认目标钱包，避免到账后找不到资产！           │
└───────────────────────────────────────────────────────┘
```

**充币时的钱包选择**：

```
步骤1：充币页面 → 选择币种和网络后
步骤2：点击"更多详情"或钱包选择区域
步骤3：选择充币目标：
       → 现货钱包（Spot Wallet）— 如果你要直接交易
       → 资金钱包（Funding Wallet）— 如果你要P2P卖出
步骤4：确认地址
```

**常见困惑**：充币后资产看不到？检查是否充到了另一个钱包里，通过"资产"页面顶部的"现货"/"资金"标签切换查看。

### 4.5 标签（Memo/Tag）：最容易忽略的关键项

**什么是标签？**

部分币种（如XRP、EOS、XLM、BNB(BEP2)、BAND等）在充值时，除了地址外还需要填写**标签（Memo/Tag）**。标签用于区分同一地址下不同用户的存款——币安为所有用户共享少数几个充币地址，靠标签区分谁充了多少钱。

```
没有标签的币种（如BTC、ETH、USDT）：
  你的充币地址 = 你的专属地址  →  地址对就行

需要标签的币种（如XRP、EOS、XLM、BNB(BEP2)）：
  你的充币地址 = 币安的共享地址  →  地址+标签 才能区分是你充的
```

**忘记填标签或填错标签怎么办？**

1. 资产会到达币安的地址，但无法自动分配到你的账户
2. 需要通过币安自助工具提交申诉
3. 提供交易哈希（TxHash）、充值币种、数量、正确的标签等信息
4. 币安核实后可人工入账，但**处理周期较长**（数天到数周）

**操作规范**：

```
⚠️ 充币前先确认该币种是否需要标签：
   → 充币页面如果出现"标签/Memo/Tag"输入框 = 必须填写
   → 没有该输入框 = 不需要填
   → 标签通常是纯数字，复制时注意不要多空格或换行
   → ⚠️ 标签和地址必须同时正确，缺一不可
   → BNB的BEP2网络充值必须填Memo！
```

### 4.6 完整充币操作流程

**从外部钱包/其他交易所充值到币安CEX账户**：

```
第一步：获取币安充币地址
────────────────────────
  1. 打开币安App → 资产 → 充币（或"添加资金"→"链上充币"）

  5. 复制充币地址（如需要，同时复制标签/Memo）
  6. ⚠️ 确认页面上的最低充值额度

第二步：在转出方发起提币
────────────────────────
  7. 打开转出方（其他交易所或Web3钱包）
```

### 4.7 最低充值额度

币安对每种币的充值有**最低额度要求**，低于该额度的充值**将无法到账且无法找回**：

```
如何查看最低充值额度：
  币安App → 资产 → 充币 → 选择币种和网络 → 页面显示"最低充值量"

常见币种最低充值额度（参考值，以页面显示为准）：
  ┌──────────┬──────────────┬──────────────────┐
  │ 币种     │ 网络         │ 最低充值额度(约) │
  ├──────────┼──────────────┼──────────────────┤
  │ BTC      │ BTC原生      │ 0.0005 BTC       │
  │ ETH      │ ERC20        │ 0.001 ETH        │
  │ USDT     │ TRC20        │ 1 USDT           │
  │ USDT     │ ERC20        │ 5 USDT           │
  │ BNB      │ BEP20        │ 0.01 BNB         │
  │ SOL      │ SPL          │ 0.1 SOL          │
  └──────────┴──────────────┴──────────────────┘
```

**低于最低额度怎么办？**
- 部分币种可通过币安客服申诉，处理周期较长
- 多数币种低于最低额度**无法找回**，资产永久丢失
- **预防远比补救重要**：充值前务必确认最低额度

### 4.8 充币到账确认数

不同网络需要不同的区块确认数才会到账：

| 网络 | 确认数要求 | 预计等待时间 |
|------|-----------|------------|
| BTC | 1次确认 | 10-60分钟 |
| ETH (ERC20) | 12次确认 | 2-5分钟 |
| TRC20 | 20次确认 | 1-3分钟 |
| BEP20 (BSC) | 1次确认 | 1分钟内 |
| SOL (SPL) | 1次确认 | 几秒-1分钟 |

> ⚠️ 在达到所需确认数之前，币安资产页面可能显示"确认中"，这属于正常现象。

### 4.9 充币问题完整排查清单

如果充币后长时间未到账，按以下顺序排查：

```
排查步骤                         →    如果是这个问题...
──────────────────────────────────────────────────────
1. 区块链确认是否完成？           →  等待确认，耐心即可
   (用TxHash在区块链浏览器查看)

2. 币种是否正确？                 →  充错币种：提交币安客服工单
   (充的USDT，但选了USDC？)

3. 网络是否匹配？                 →  网络不匹配：提交币安客服工单
   (转出方ERC20，币安选TRC20？)

4. 地址是否正确？                 →  充错地址：联系地址所有方
   (地址是否与币安充币页面一致？)

5. 是否需要标签但未填/填错？      →  提交币安客服工单，提供TxHash
   (XRP/EOS/XLM/BNB(BEP2)等币种)

6. 是否低于最低充值额度？         →  尝试客服申诉，部分币种无法找回

7. 是否充值到了正确的钱包？       →  切换"现货"/"资金"标签查看
   (充到了资金钱包但你在看现货？)

8. 是否充值到合约地址？           →  ❌ 勿使用合约地址充币，提交工单

9. 币安是否暂停了该币种充提？     →  关注币安公告，等待恢复
```

**提交充币反馈的自助入口**：
- 币安App → 资产 → 充币 → 右上角"历史记录" → 选择问题交易 → 提交工单
- 或直接访问币安客服中心在线提交工单

**反馈时需要准备的信息**：
1. 交易哈希（TxHash / TxID）—— 从转出方获取
2. 充值币种和数量
3. 充值网络
4. 币安充币地址
5. 如果涉及标签问题：正确的标签/Memo

### 4.10 充币安全操作十诫

| # | 规则 | 原因 |
|---|------|------|
| 1 | **先小额测试，再大额充值** | 确认流程正确，避免大额损失 |
| 2 | **币种、网络、地址三次核对** | 任一错误可能导致丢币 |
| 3 | **不确定网络时不要操作** | 去转出方确认或联系客服 |
| 4 | **复制地址后粘贴前核对首尾各4位** | 防止恶意软件篡改剪贴板 |
| 5 | **需要标签的币种必须填写** | 没标签=无法分配到你的账户 |
| 6 | **充值额度必须≥最低要求** | 低于最低额度可能永久丢失 |
| 7 | **不要充到合约地址** | 合约地址≠充币地址 |
| 8 | **关注币安充提暂停公告** | 暂停期间充币无法到账 |
| 9 | **保存交易哈希（TxHash）** | 出问题时必须提供 |
| 10 | **充币地址可能更新** | 每次充值前重新获取地址，不要用旧地址 |

## 五、DeFi 与 DApp：去中心化世界入门

### 5.1 什么是 DApp？

DApp = Decentralized Application（去中心化应用）

与传统App（如微信、淘宝）的区别：

| | 传统App | DApp |
|---|---|---|
| **运行在** | 某公司的服务器 | 区块链（智能合约） |
| **控制者** | 公司可以随时修改/关闭 | 代码部署后不可篡改 |
| **你的数据** | 公司存储和控制 | 你自己控制（链上） |
| **登录方式** | 手机号/微信登录 | 钱包连接 |
| **典型例子** | 支付宝、微信 | Uniswap、Aave、OpenSea |

### 5.2 什么是 DeFi？

DeFi = Decentralized Finance（去中心化金融）

简单说，DeFi就是**用智能合约替代银行/券商等金融中介**，让你直接在链上完成金融操作。

| 传统金融 | DeFi对应 | 说明 |
|---------|---------|------|
| 银行存款 | 质押/流动性挖矿 | 存币生息 |
| 银行贷款 | 借贷协议（Aave/Compound） | 抵押借币 |
| 证券交易所 | DEX（Uniswap/PancakeSwap） | 币币兑换 |
| 理财产品 | 收益聚合器（Yearn/Venus） | 自动优化收益 |
| 保险 | 链上保险（Nexus Mutual） | 智能合约保险 |

### 5.3 在币安中使用DeFi

Binance Wallet内置了DeFi入口，你不需要单独访问各种DApp网站：

```
步骤1：打开币安App → 资产 → "钱包"标签
步骤2：点击"发现"或"DeFi"入口
步骤3：浏览可用的DeFi项目，按类型筛选：
       → 赚币（存币生息）
       → 借贷（抵押借币/存币放贷）
       → 流动性（做市提供流动性）
       → 质押（Staking）
步骤4：选择感兴趣的项目，查看：
       → 年化收益率（APY/APR）
       → TVL（总锁仓量，衡量规模和安全性的指标）
       → 支持的币种
       → 风险提示
步骤5：点击"参与"或"存入"
步骤6：选择要存入的币种和数量
步骤7：确认交易（App自动处理智能合约交互）
步骤8：等待链上确认，即可开始赚取收益
```

**币安特有的DeFi产品**：

| 产品 | 说明 | 特点 |
|------|------|------|
| **Binance Earn** | CEX端理财（非DeFi） | 托管式，低风险，收益率较低 |
| **On-Chain Yields** | 链上收益产品 | 通过Binance Wallet参与链上DeFi |
| **Launchpool** | 新币挖矿 | 质押BNB/稳定币获取新代币 |
| **Megadrop** | 新型代币分发 | 结合链上任务的代币空投 |
| **Binance Wallet Earn** | 钱包内DeFi收益 | 自托管，直接参与链上协议 |

### 5.4 DeFi 风险提示

| 风险类型 | 说明 | 防范方法 |
|---------|------|---------|
| **智能合约风险** | 代码漏洞可能导致资金丢失 | 只用经过审计的大项目 |
| **无常损失** | 流动性提供者因价格波动受损 | 理解原理后再参与 |
| **Rug Pull** | 项目方卷款跑路 | 警惕超高APY，查团队背景 |
| **清算风险** | 借贷抵押率不足被强制清算 | 保持安全抵押率，设置提醒 |
| **钓鱼DApp** | 假冒网站骗取授权 | 只通过Binance Wallet内置入口访问 |

## 六、DEX 交易：兑换与跨链互换

### 6.1 CEX 交易 vs DEX 交易

| | CEX交易（中心化交易所） | DEX交易（去中心化交易所） |
|---|---|---|
| **比喻** | 菜市场：卖家挂单，买家摘单 | 自动售货机：算法自动定价 |
| **定价机制** | 订单簿（买卖挂单撮合） | AMM（自动做市商算法） |
| **需要注册** | 需要（KYC） | 不需要 |
| **资产控制** | 交易所托管 | 自己控制 |
| **交易对象** | 交易所上架的币对 | 任何链上的代币 |
| **滑点** | 深度好时几乎没有 | 取决于流动性池大小 |
| **费用** | 交易手续费（0.02%-0.1%） | 网络Gas费 + DEX手续费 |

### 6.2 什么是 AMM（自动做市商）？

DEX不用订单簿，而是用**流动性池**：

```
传统交易所（订单簿）：
  买家出价 $100  ←→  卖家要价 $101  →  成交

DEX（AMM流动性池）：
  池子里有 100 BNB + 60,000 USDT
  价格 = 60,000 / 100 = $600/BNB
  你买入10 BNB → 池子剩90 BNB + 更多USDT → 价格自动上升
  你卖出10 BNB → 池子剩110 BNB + 更少USDT → 价格自动下降
```

**核心概念：滑点（Slippage）**

你看到的价格和实际成交价格的差异。交易金额越大，或流动性池越浅，滑点越大。

### 6.3 DEX 兑换（Swap 模式）

这是最简单的DEX交易方式，类似"闪兑"：

```
步骤1：打开币安App → 资产 → "钱包"标签
步骤2：点击"Swap"或进入DEX交易页面
步骤3：选择"支付币种"（你持有的，如USDT）
步骤4：选择"获得币种"（你想买的，如BNB）
步骤5：输入支付数量
步骤6：系统自动显示：
       → 预计获得数量
       → 当前汇率
       → 价格影响（滑点）
       → 最少获得数量（Min Received）
       → 网络手续费
       → 路由路径（经哪些DEX和池子）
步骤7：确认交易 → 输入密码 → 等待链上确认
```

**Binance Wallet DEX的特点**：它是一个**DEX聚合器**，自动比较多个DEX（PancakeSwap、Uniswap、1inch等）的价格，帮你找到最优路径。BSC链上交易默认优先走PancakeSwap（币安生态DEX）。

### 6.4 DEX 限价单模式

限价单允许你**设定目标价格**，到达后自动成交：

```
步骤1：打开Binance Wallet → 交易 → 限价单
步骤2：设置交易参数：
       → 支付币种和数量
       → 获得币种
       → 目标价格（你期望的成交价）
       → 有效期（如24小时/7天/30天）
步骤3：确认委托
步骤4：等待市场价格到达你的目标价时自动成交
```

**适用场景**：
- 你觉得当前价格偏高，想等跌到目标价再买
- 你想在高点卖出但不想一直盯盘
- 你想在睡觉时自动完成交易

### 6.5 跨链互换（Cross-Chain Swap）

币安集成了**跨链互换**功能，允许你在Swap页面直接完成跨链交易，无需单独使用跨链桥：

```
步骤1：打开Binance Wallet → Swap
步骤2：选择"来源链"的币种（如以太坊上的ETH）
步骤3：选择"目标链"的币种（如BSC上的BNB）
步骤4：输入数量
步骤5：系统显示跨链汇率、手续费、预计到账数量
步骤6：确认交易
步骤7：等待跨链完成
```

**与普通Swap的区别**：
- 普通Swap：同一链上两种代币互换（如BSC上USDT→BNB）
- 跨链Swap：不同链上代币互换（如以太坊ETH→BSC BNB），后台自动执行跨链桥+Swap

### 6.6 DEX 交易的关键参数解读

| 参数 | 含义 | 新手建议 |
|------|------|---------|
| **汇率** | 两种币的兑换比例 | 与CEX对比，差距过大需警惕 |
| **价格影响** | 你的交易对池子价格的影响 | >3%需注意，>5%建议拆分交易 |
| **最少获得** | 考虑滑点后你最少能拿到的数量 | 设置滑点保护（通常1%-3%） |
| **Gas费** | 网络手续费 | BSC极低，以太坊主网较贵 |
| **路由** | 交易经过的路径 | 币安自动优化，一般无需手动调整 |
| **滑点容忍度** | 你能接受的最大价格偏差 | 常规币设1-2%，小币设3-5% |

### 6.7 网络选择建议

| 网络 | Gas费 | 速度 | 代币丰富度 | 建议场景 |
|------|-------|------|-----------|---------|
| 以太坊主网 | 高（$2-$50） | 较慢(1-5分钟) | 最丰富 | 大额交易、主流币 |
| BSC (BEP20) | 极低（<$0.1） | 快(3秒) | 丰富 | 日常交易、BSC生态 |
| Arbitrum/Optimism | 低（$0.1-$1） | 快(秒级) | 丰富 | L2生态交易 |
| Solana | 极低（<$0.01） | 极快(400ms) | 中等 | 高频交易 |
| Base | 低（$0.01-$0.5） | 快 | 增长中 | 新兴生态 |

**BSC生态优势**：作为币安的亲儿子链，BSC上的DEX交易Gas费极低且速度极快，PancakeSwap是BSC上最大的DEX，流动性深度好。

## 七、跨链桥：资产跨链搬运工

### 7.1 什么是跨链桥？

不同区块链之间是**互相隔离**的——以太坊上的ETH无法直接在BSC上使用。跨链桥就是连接不同链的"桥梁"，将资产从一条链转移到另一条链。

```
以太坊上的USDT  ──跨链桥──→  BSC上的USDT
   (ERC-20)                    (BEP-20)
```

### 7.2 跨链桥的工作原理

**锁定-铸造模式（最常见）**：

```
步骤1：你在以太坊上锁定 100 USDT
步骤2：桥的智能合约验证锁定成功
步骤3：桥在BSC上铸造 100 USDT 给你
步骤4：你赎回时，BSC上的100 USDT 被销毁
步骤5：以太坊上的 100 USDT 被解锁还给你
```

### 7.3 在币安中使用跨链桥

**方式一：Binance Wallet 内置跨链**

```
步骤1：打开币安App → 资产 → "钱包"标签
步骤2：进入Swap/跨链功能
步骤3：选择"来源链"（资产当前所在的链，如以太坊）
步骤4：选择"目标链"（你想转到的链，如BSC）
步骤5：选择币种和数量
步骤6：系统显示：
       → 跨链汇率
       → 跨链手续费
       → 预计到账时间
       → 最少获得数量
步骤7：确认交易
步骤8：等待来源链确认 + 目标链铸造完成
```

**方式二：通过CEX充提实现"跨链"**

币安CEX本身就是一个天然的跨链枢纽：

```
步骤1：从链A提币到币安CEX（如从以太坊充入USDT）
步骤2：在币安CEX上，资产自动整合（不分链）
步骤3：从币安CEX提币到链B（如提USDT到BSC）
       → 提币时选择目标链网络即可
```

> 这种方式最简单安全，但需要币安支持两条链的充提。

### 7.4 跨链桥的关键风险

| 风险 | 说明 | 防范方法 |
|------|------|---------|
| **桥被攻击** | 跨链桥是黑客最爱攻击的目标 | 使用大品牌桥，分散风险 |
| **到账延迟** | 部分桥需要较长时间 | 查看预计时间，选择快速桥 |
| **费用较高** | 桥费+双链Gas费 | 对比不同桥的费用 |
| **目标链Gas** | 跨链后需要目标链的原生代币付Gas | 提前准备或选择自动兑换Gas的桥 |
| **MPC钱包兼容性** | 部分跨链桥可能不完全支持MPC钱包签名 | 优先使用币安内置跨链功能 |

### 7.5 常见跨链桥对比

| 桥 | 支持链 | 费用 | 速度 | 安全性 |
|----|--------|------|------|--------|
| **Binance Bridge**（内置） | 多链 | 中低 | 快 | 币安风控审核 |
| **PancakeSwap Bridge** | BSC生态为主 | 低 | 快 | 高 |
| **Stargate** | 主流L1/L2 | 低 | 快 | 高（LayerZero协议） |
| **Across** | 以太坊L2生态 | 极低 | 极快(秒级) | 高 |
| **Wormhole** | 多链 | 中 | 中 | 中（曾遭攻击） |
| **官方桥** | 各L2专属 | 视链而定 | L2快/L1慢 | 最高 |

**新手建议**：优先使用币安内置跨链功能或通过CEX充提实现跨链，自动匹配最优路线，省去手动比较的麻烦。

## 八、安全红线：新手必读

### 8.1 绝对不能做的事

| ❌ 禁止行为 | 后果 |
|------------|------|
| 向任何人透露密码、2FA验证码 | 账户被盗，资产被转走 |
| 点击不明链接连接钱包 | 授权被恶意合约掏空 |
| 在多个DApp授权无限额度 | 一个DApp被黑，所有资产危险 |
| 使用公共WiFi操作钱包 | 中间人攻击窃取签名 |
| 忽略Binance Wallet的云备份提示 | 换手机后无法恢复钱包 |
| 将密钥分片备份到不安全的位置 | 分片泄露增加资产风险 |

### 8.2 必须做的事

| ✅ 必做事项 | 原因 |
|------------|------|
| 完成**双重认证（2FA）**设置 | Google验证器+手机验证，双重保护 |
| 设置**反钓鱼码** | 区分真假币安邮件，防止钓鱼 |
| 开启**提币地址白名单** | 即使被盗也无法提币到非白名单地址 |
| 大额资产使用硬件钱包（如Ledger） | 私钥永不触网 |
| 操作前核对地址前后几位和末尾几位 | 防止恶意软件篡改剪贴板地址 |
| 定期撤销不用的DApp授权 | 减少攻击面 |
| 先用小额测试，确认流程后再大额操作 | 避免操作失误导致大额损失 |
| Binance Wallet密钥分片备份到云端和设备 | 换设备后恢复钱包的唯一方式 |

### 8.3 币安安全功能详解

**1. 双重认证（2FA）**

```
设置路径：币安App → 个人中心 → 安全 → 2FA设置

推荐方案：
  ✅ Google Authenticator（首选）— 离线生成验证码，不依赖手机号
  ✅ Passkeys（生物识别/WebAuthn）— 最便捷的新方式
  ⚠️ 短信验证 — 有SIM卡劫持风险，仅作为辅助
```

**2. 反钓鱼码（Anti-Phishing Code）**

```
设置路径：币安App → 个人中心 → 安全 → 反钓鱼码

作用：
  → 设置后，所有真实的币安邮件都会包含你的反钓鱼码
  → 收到的邮件没有反钓鱼码 = 钓鱼邮件
  → 这是区分真假币安邮件的唯一可靠方法
```

**3. 提币地址白名单（Withdrawal Whitelist）**

```
设置路径：币安App → 资产 → 提币 → 地址管理 → 添加白名单地址

作用：
  → 开启后，只能向白名单中的地址提币
  → 即使账户被盗，黑客也无法将资产转到非白名单地址
  → ⚠️ 添加白名单地址后有24小时冷却期（安全缓冲）
  → ⚠️ 大额资产必须开启此功能！
```

**4. Binance Wallet 安全功能**

```
内置安全机制：
  → 错误地址保护：发送到可疑地址时自动警告
  → 恶意合约检测：与高风险合约交互时弹出警告
  → 安全风险通知：检测到异常操作时提醒
  → MPC 2/3签名：单个密钥分片泄露不会导致资产丢失
```

### 8.4 钱包授权管理

当你使用DApp时，需要授权（Approve）合约访问你的代币。这就像"给某人一把有限权限的钥匙"。

```
查看和管理授权：
Binance Wallet → 安全 → 授权管理

操作建议：
1. 只授权你需要的额度（不要选"无限"）
2. 用完后及时撤销授权
3. 看到陌生代币被授权，立即撤销
```

### 8.5 识别常见骗局

| 骗局类型 | 特征 | 防范 |
|---------|------|------|
| **假客服** | 主动联系你，索要密码/验证码 | 币安客服绝不会主动索要密码或2FA |
| **空投骗局** | 钱包突然收到陌生代币+引导你去某DApp | 不要交互不明空投代币 |
| **钓鱼网站** | 高仿币安网站，骗取登录信息 | 核对域名，检查反钓鱼码 |
| **高收益陷阱** | 承诺极高APY（>100%） | 天上不会掉馅饼 |
| **假币同名** | 伪造与知名币种同名的代币 | 核对合约地址，不只看币种名称 |
| **钓鱼邮件** | 伪造币安官方邮件 | 检查是否有你的反钓鱼码 |
| **SIM卡劫持** | 骗取运营商将你的号转到骗子手机 | 使用Google验证器而非短信验证 |

## 附录：核心术语速查

| 术语 | 一句话解释 |
|------|----------|
| **MPC** | 多方计算，Binance Wallet使用的密钥管理技术，3个分片需2个才能签名 |
| **密钥分片（Key-Share）** | MPC钱包将私钥拆成的多个片段，分散存储提高安全性 |
| **Gas费** | 区块链交易手续费，付给矿工/验证者 |
| **APY** | 年化收益率（含复利） |
| **APR** | 年化收益率（不含复利） |
| **TVL** | 总锁仓量，衡量DeFi项目规模 |
| **Slippage** | 滑点，预期价格与实际成交价的偏差 |
| **TxHash** | 交易哈希，每笔链上交易的唯一标识符，出问题时必须提供 |
| **Memo/Tag** | 标签，部分币种充值时用于区分用户的附加信息，不填=不到账 |
| **Confirmations** | 区块确认数，交易被区块链确认的次数，币安要求达到指定数才到账 |
| **BEP-20** | BSC（BNB Smart Chain）上的代币标准，类似以太坊的ERC-20 |
| **BEP-2** | 旧版币安链（BNB Beacon Chain）上的代币标准，需Memo充值 |
| **Rug Pull** | 项目方卷款跑路 |
| **HODL** | 长期持有不卖（Hold On for Dear Life） |
| **DYOR** | 自己做研究（Do Your Own Research） |
| **WAGMI** | 我们都会成功（We're All Gonna Make It） |
| **现货钱包** | 币安CEX中用于交易的主钱包 |
| **资金钱包** | 币安CEX中用于P2P和充提的钱包，与现货钱包需划转互用 |
| **反钓鱼码** | 你设置的自定义码，所有真实币安邮件都会包含，用于识别钓鱼邮件 |
| **提币白名单** | 开启后只能向已添加的地址提币，防止被盗后资产转移 |
