# 一、行业基础定义

## 1.1 行业名称
- 行业名称：电商
- 细分赛道：平台电商、自营电商、品牌 DTC、电商 SaaS 支撑、内容电商、跨境电商、即时零售
- 上下游位置：
  - 上游：品牌商、工厂、经销商、供应链服务商
  - 中游：平台、自营零售商、渠道商、内容流量平台
  - 下游：消费者、部分中小商家
- 主要服务对象：To C 为主，部分 To B / To 小B

## 1.2 行业一句话定义
> 电商行业的本质是：通过线上流量、商品供给、交易系统和履约能力，把“找货、选货、买货、收货”的消费过程数字化，并通过商品差价、平台佣金、广告和服务费实现变现。

## 1.3 行业边界

### 覆盖范围
- 在线商品交易平台
- 自营或平台型零售
- 内容驱动或流量驱动的商品销售
- 跨境线上零售
- 线上导购与交易闭环型业务

### 不覆盖范围
- 纯线下零售
- 仅提供营销服务但不形成交易闭环的业务
- 纯物流、纯支付、纯供应链 SaaS
- 二手非标交易中高度非平台化的小规模撮合业务

# 二、行业本质与核心价值

## 2.1 商业本质

电商的本质不是“线上卖货”，而是：

> 以更高效率组织供给、流量和履约，降低消费者决策与购买成本，并提升交易频次和转化效率。

### 1）客户为什么需要它？
消费者需要电商，通常是因为：
- 商品选择更多
- 价格更透明
- 购买更方便
- 比价成本更低
- 交易更快、更即时
- 可突破地域限制
- 内容种草和社交推荐提升决策效率

商家需要电商，通常是因为：
- 获客渠道更丰富
- 可触达更大市场
- 销售数字化
- 可借助平台流量和履约设施降低经营门槛

### 2）企业提供的核心价值是什么？
- 流量组织能力
- 商品供给组织能力
- 交易撮合能力
- 履约能力
- 信任和支付基础设施
- 内容影响购买决策
- 数据化运营能力

### 3）企业为什么能赚钱？
电商公司的常见变现方式包括：
- 商品进销差价
- 平台佣金 / take rate
- 广告收入
- 商家服务费
- 会员收入
- 物流与履约服务收入
- 金融与支付增值收入

## 2.2 价值创造链条

电商行业的典型链路为：

```text
组织商品供给
→ 获取流量
→ 商品展示与推荐
→ 用户浏览与决策
→ 下单与支付
→ 仓储/拣货/配送
→ 签收与售后
→ 复购与会员沉淀
→ 收入确认
→ 利润释放
