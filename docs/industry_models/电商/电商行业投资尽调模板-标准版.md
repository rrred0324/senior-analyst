# 三、业务理解

## 3.1 公司到底做什么
1. 公司是平台撮合、自营零售还是内容驱动交易？
2. 核心销售品类是什么？
3. 主要服务对象是谁？
4. 公司位于价值链哪个位置？
5. 主要收入来自佣金、广告、差价还是服务费？

## 3.2 解决什么问题
1. 为什么消费者愿意在该平台/渠道购买？
2. 为什么商家愿意在此经营？
3. 相比传统渠道或竞品，核心优势是什么？
4. 公司解决的是价格问题、选择问题、履约问题还是内容决策问题？

## 3.3 商业模式
1. 核心变现方式有哪些？
2. 收入中交易、广告、服务分别占比多少？
3. 是否有可持续的会员或增值收入？
4. 平台是否具备提高综合变现率的空间？

4. 是否受制于单一流量平台？

## 5.3 行业趋势
1. 流量结构是否正在变化？
2. 内容电商和搜索电商谁在分流？
3. 即时零售是否影响传统电商场景？
4. 平台规则和监管环境是否变化？

# 九、财务尽调

## 9.1 收入质量
1. 交易收入、广告收入、服务收入结构是否清晰？
2. 是否依赖少数大商家或单一类目？
3. GMV 增长是否能带动净收入增长？
4. 平台变现率提升是否健康？

## 9.2 利润质量
1. 毛利率变化来自哪里？
2. 履约成本率是否可持续下降？
3. 营销投放是否换来高质量用户？
4. 自营库存损耗是否侵蚀利润？

## 9.3 现金流质量
1. 平台型是否具备较强经营现金流？
2. 自营业务是否占用大量营运资金？
3. 应付账款和存货周转是否健康？
4. 补贴和促销是否扭曲真实现金表现？

## 9.4 资产负债表风险
重点看：
- 现金
- 存货
- 应付账款
- 商家保证金
- 应收账款
- 退货准备
- 有息负债

---

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队更擅长流量、供应链还是运营？
2. 是否有相关品类或平台经验？
3. 是否具备电商高频运营经验？
4. 是否过度依赖单一主播、达人或采销负责人？

## 10.2 组织能力
1. 公司更强在流量、供应链、内容还是履约？
2. 扩品类、扩区域能力是否可复制？
3. 数据化运营是否成熟？
4. 是否建立有效中层和类目经营体系？

## 10.3 激励机制
1. 运营、采销、投流团队激励是否合理？
2. 是否过度鼓励 GMV，而忽视毛利和复购？
3. 核心人才流失风险如何？
