# 一、行业基础定义

## 1.1 行业名称
- 行业名称：电商
- 细分赛道：平台电商、自营电商、垂直电商、内容/直播电商、社交电商、跨境电商、B2B电商
- 上下游位置：
  - 上游：品牌商、工厂、经销商、供应链服务商、仓储物流、支付服务商、流量平台
  - 中游：电商平台 / 电商零售商 / 电商服务商
  - 下游：消费者、商家、企业采购方
- 主要服务对象：To C 为主，部分 To B / To SMB

## 1.2 行业一句话定义
> 电商行业的本质是：通过线上流量获取、商品组织、交易撮合和履约交付，连接供给与需求，并通过差价、佣金、广告、服务费等方式实现商业化。

## 1.3 行业边界

### 覆盖范围
- 线上商品交易平台
- 自营零售型电商
- 第三方商家平台型电商
- 直播/内容驱动交易
- 跨境零售与跨境平台业务
- B2B线上采购撮合业务

### 不覆盖范围
- 纯线下零售
- 仅提供物流、支付、代运营而不直接参与电商交易的独立服务商
- 无交易闭环的内容导购媒体
- 传统外贸公司但不具备电商平台化或线上零售特征的业务

# 二、行业本质与核心价值

## 2.1 商业本质

电商的核心不是“在线卖货”，而是：

> 用更高效率的供需匹配、更低交易摩擦和更强履约能力，重构商品流通与消费者购买路径。

### 1）客户为什么需要它？
消费者需要：
- 更多选择
- 更低价格
- 更便捷购买
- 更快履约
- 更透明的信息和评价体系

商家需要：
- 更低开店门槛
- 更大流量触达
- 更高交易效率
- 更低渠道成本
- 更强的经营工具和营销能力

### 2）企业提供的核心价值是什么？
- 流量聚合
- 商品供给组织
- 交易撮合
- 信任与支付基础设施
- 物流履约
- 定价和促销机制
- 商家经营工具
- 内容种草和转化机制

### 3）企业为什么能赚钱？
- 平台佣金 / take rate
- 广告营销收入
- 自营商品差价
- 商家服务费
- 物流/仓储服务费
- 金融及其他增值服务收入

## 2.2 价值创造链条

电商行业核心经营链路：

```text
组织供给
→ 获取流量
→ 展示商品
→ 用户浏览与转化
→ 下单支付
→ 仓储/发货/配送
→ 签收与售后
→ 复购/商家续投
→ 收入确认
→ 利润释放
```

如果是平台型电商，也可表示为：

```latex
更多商家和商品
→ 更丰富供给
→ 更高用户活跃与购买率
→ 更大GMV
→ 更强广告和佣金变现
→ 更多资源反哺流量与履约
→ 更多商家和商品
```

## 2.3 行业核心飞轮
电商核心飞轮通常是：

```latex
更多供给
→ 更好用户体验
→ 更多订单
→ 更高GMV
→ 更强变现能力
→ 更多投入流量/履约/补贴/工具
→ 更多供给
```

优秀电商公司的关键不是单点低价，而是：

> 供给、流量、转化、履约和复购形成闭环。
>

## 3.3 不同赛道差异点
+ 平台电商：资产更轻，但依赖流量和生态
+ 自营电商：收入可控，但库存和履约压力大
+ 内容电商：转化快，但流量波动大
+ 垂直电商：用户更精准，但市场空间可能偏窄
+ 跨境电商：供应链更复杂，政策和物流变量更大
+ B2B 电商：客单价高，但决策链更长、回款周期更长

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：平台佣金
+ 名称：Commission / take rate
+ 收费对象：商家
+ 收费方式：按成交额抽佣
+ 公式：

```latex
佣金收入 = GMV × take rate
```

### 模式二：广告收入
+ 名称：Merchant Ads
+ 收费对象：商家 / 品牌
+ 收费方式：按点击、曝光、成交投放
+ 公式：

```latex
广告收入 = 广告主数量 × 平均投放金额
```

或：

```latex
广告收入 = 流量 × 广告加载率 × eCPM
```

### 模式三：自营差价
+ 名称：Retail Margin
+ 收费对象：消费者
+ 收费方式：商品采购价与售价差额
+ 公式：

```latex
商品毛利 = 销售收入 - 商品采购成本
```

### 模式四：商家服务费
+ 名称：Merchant Services
+ 收费对象：商家
+ 收费方式：店铺服务、技术服务、代运营、工具等
+ 公式：

```latex
服务收入 = 商家数 × 平均服务费
```

### 模式五：物流/仓储/金融增值收入
+ 名称：Value-added Services
+ 收费对象：商家或消费者
+ 收费方式：仓配、供应链金融、支付、保险等
+ 公式：

```latex
增值收入 = 使用商家数 × 平均增值服务ARPU
```

## 4.2 行业最优商业模式
电商行业不存在单一最优模型，不同模式有不同优势：

### 平台电商更优的地方
+ 资产轻
+ 收入结构更偏佣金和广告
+ 库存风险较低
+ 规模效应和网络效应更强

### 自营电商更优的地方
+ 可控体验更强
+ 品牌和履约一致性更高
+ 在高频标准品类中有供应链效率优势

总体而言，从资本效率和长期壁垒看：

> 高质量平台型电商通常优于重资产自营模式；  
但在特定品类中，供应链能力极强的自营电商也可能形成壁垒。
>

## 4.3 从单点收费到综合变现路径
```latex
交易起量
→ 佣金收费
→ 广告变现
→ 商家服务
→ 仓配服务
→ 金融/支付/数据增值
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 佣金收入 + 广告收入 + 自营销售收入 + 商家服务收入 + 物流/金融等增值收入
```

## 5.2 拆解驱动因子
### 平台电商核心收入拆法
```latex
收入 = GMV × 综合变现率
```

其中：

```latex
综合变现率 = 佣金率 + 广告率 + 其他服务费率
```

GMV 可继续拆为：

```latex
GMV = 购买用户数 × 购买频次 × 客单价
```

### 自营电商核心收入拆法
```latex
收入 = 订单量 × 客单价
```

```latex
毛利 = 收入 - 采购成本
```

### 内容电商核心收入拆法
```latex
GMV = 流量 × 转化率 × 客单价
```

## 5.3 收入增长来源
+ 用户数增长
+ 购买频次提升
+ 客单价提升
+ 商家数增长
+ 广告渗透率提升
+ take rate 提升
+ 品类扩张
+ 区域扩张
+ 履约改善带来的复购提升

长期更高质量的增长通常来自：

> 复购率提升 + 商家经营深度提升，而不是短期补贴拉新。
>

+ 管理费用

## 6.2 成本分类方式
### 固定成本
+ 技术研发
+ 平台运维
+ 管理费用
+ 核心仓网基础设施（部分）

### 可变成本
+ 流量投放
+ 配送成本
+ 商家激励
+ 退款与售后
+ 主播/达人佣金
+ 支付通道成本

### 前端成本
+ 买量
+ 补贴
+ 市场营销
+ 销售与招商

### 后端成本
+ 仓配
+ 客服
+ 退换货处理
+ 技术支持
+ 供应链管理

## 6.3 单位经济模型
### 平台电商单订单经济
```latex
单订单经济 = 单订单变现收入 - 单订单补贴 - 单订单履约成本 - 单订单支付/售后成本
```

### 自营电商单订单经济
```latex
单订单毛利 = 客单价 - 商品采购成本 - 履约成本 - 售后成本
```

### 用户生命周期经济
```latex
LTV = 用户生命周期内毛利贡献
```

```latex
CAC = 获客总成本 / 新增购买用户数
```

电商核心判断：

+ 如果复购差，买量只会不断吞噬利润
+ 如果履约成本过高，规模扩大不一定带来利润释放
+ 如果补贴一停，GMV 下滑严重，则增长质量偏弱

## 6.4 利润公式
```latex
利润 = 收入 - 采购/供给成本 - 流量成本 - 履约成本 - 售后成本 - 技术研发费用 - 管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
电商增长通常来自五类变量：

+ 更多用户
+ 更多商家和更强供给
+ 更高转化率
+ 更高复购
+ 更强变现能力

### 货架型电商更看重
+ 搜索效率
+ SKU 丰富度
+ 价格竞争力
+ 履约能力

### 内容型电商更看重
+ 流量分发
+ 内容供给
+ 主播 / 达人效率
+ 冲动消费转化

## 8.2 规模效应
规模扩大后，电商可能出现：

+ 更强议价能力
+ 更低履约成本
+ 更强品牌和流量心智
+ 更丰富供给和商家生态
+ 更高广告变现效率
+ 技术和仓配成本摊薄

## 8.3 网络效应
电商通常存在明显双边网络效应：

+ 更多商家 → 更多商品 → 更多用户
+ 更多用户 → 更多订单 → 更多商家愿意入驻

内容电商还有：

+ 更多内容供给 → 更多停留时间 → 更多购买机会

## 8.4 标准化与人力依赖程度
+ 平台电商标准化较高
+ 自营电商更依赖供应链和仓配管理
+ 直播电商更依赖达人、主播和内容供给
+ B2B 电商更依赖销售和履约协同

# 九、竞争格局与壁垒
## 9.1 竞争格局
电商行业通常具有：

+ 头部平台集中度较高
+ 流量入口变化快
+ 品类之间竞争结构差异大
+ 新平台往往从低价、内容、细分供给或特殊人群切入

## 9.2 常见壁垒类型
+ 流量壁垒
+ 供给壁垒
+ 品牌壁垒
+ 履约网络壁垒
+ 低价供应链壁垒
+ 商家生态壁垒
+ 数据与推荐算法壁垒
+ 用户心智壁垒

## 9.3 替代风险
+ 被超级平台流量挤压
+ 被品牌 DTC 替代
+ 被线下即时零售替代部分场景
+ 被内容平台吞掉交易入口
+ 被低价平台或上游工厂直连重构供给链条

# 十、行业风险分析
## 10.1 通用风险项
+ 流量成本持续上升
+ 复购率不足
+ 补贴依赖
+ 履约成本高
+ 库存风险（自营）
+ 假货和商家治理风险
+ 内容合规风险
+ 平台二选一/反垄断/监管风险
+ 退货率过高
+ 价格战侵蚀利润

## 10.2 风险信号模板
看到以下情况要警惕：

+ GMV 很大但变现率长期上不去
+ 收入增长快但补贴更快
+ 自营收入增长但库存周转恶化
+ 用户增长靠低价补贴，停补贴后留存差
+ 广告收入过度挤压商家 ROI，影响长期生态
+ 内容电商过度依赖头部达人
+ 跨境电商受物流、关税或平台政策冲击严重

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM

### SAM
公司当前品类、区域、人群和模式下可服务的市场

### SOM
公司中短期可获取的实际份额

## 12.2 通用测算公式
### 方法一：零售支出法
```latex
市场空间 = 目标人群年度品类支出 × 在线化率 × 可服务份额
```

### 方法二：用户法
```latex
市场空间 = 潜在购买用户数 × 年度购买频次 × 客单价
```

### 方法三：B2B采购法
```latex
市场空间 = 企业采购客户数 × 年均采购额 × 可线上化比例
```

## 12.3 市场空间判断注意事项
+ 不能把社会零售总额直接当电商可得市场
+ 不同品类的线上化率差异很大
+ 高退货率和低毛利品类未必适合大规模线上化
+ 跨境电商要考虑税务、物流和本地履约限制

2. 复购是否足够好

+ take rate / 广告率

# 二、行业本质与核心价值

## 2.1 商业本质

电商的本质不是“线上卖货”，而是：

> 以更高效率组织供给、流量和履约，降低消费者决策与购买成本，并提升交易频次和转化效率。

### 1）客户为什么需要它？
消费者需要电商，通常是因为：
- 商品选择更多
- 价格更透明
- 购买更方便
- 比价成本更低
- 交易更快、更即时
- 可突破地域限制
- 内容种草和社交推荐提升决策效率

商家需要电商，通常是因为：
- 获客渠道更丰富
- 可触达更大市场
- 销售数字化
- 可借助平台流量和履约设施降低经营门槛

### 2）企业提供的核心价值是什么？
- 流量组织能力
- 商品供给组织能力
- 交易撮合能力
- 履约能力
- 信任和支付基础设施
- 内容影响购买决策
- 数据化运营能力

### 3）企业为什么能赚钱？
电商公司的常见变现方式包括：
- 商品进销差价
- 平台佣金 / take rate
- 广告收入
- 商家服务费
- 会员收入
- 物流与履约服务收入
- 金融与支付增值收入

## 2.2 价值创造链条

电商行业的典型链路为：

```text
组织商品供给
→ 获取流量
→ 商品展示与推荐
→ 用户浏览与决策
→ 下单与支付
→ 仓储/拣货/配送
→ 签收与售后
→ 复购与会员沉淀
→ 收入确认
→ 利润释放
```

平台型可写为：

```latex
更多商家和商品
→ 更丰富供给
→ 更强用户吸引力
→ 更多流量和订单
→ 更高广告与佣金收入
→ 更多资源反哺供给和履约
→ 更多商家和商品
```

## 2.3 行业核心飞轮
```latex
更多优质供给
→ 更高用户转化与复购
→ 更多订单与交易额
→ 更高广告/佣金/差价收入
→ 更多投入流量、履约和商家运营
→ 更多优质供给
```

电商的核心不是单次 GMV，而是：

> 供给质量、流量效率、转化效率、履约效率和复购结构能否形成正循环。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：平台佣金
+ 名称：Marketplace Commission
+ 收费对象：商家
+ 收费方式：按成交额抽佣
+ 公式：

```latex
佣金收入 = GMV × take rate
```

### 模式二：广告收入
+ 名称：Merchant Advertising
+ 收费对象：商家/品牌
+ 收费方式：按展示、点击、成交或投放预算收费
+ 公式：

```latex
广告收入 = 广告主数量 × 平均投放金额
```

### 模式三：商品差价
+ 名称：Retail Margin
+ 收费对象：消费者
+ 收费方式：通过进销差赚取毛利
+ 公式：

```latex
商品毛利 = 销售收入 - 商品采购成本
```

### 模式四：服务费
+ 名称：Merchant Service Fee
+ 收费对象：商家
+ 收费方式：店铺服务、仓配服务、运营服务、跨境服务
+ 公式：

```latex
服务收入 = 服务客户数 × 客均服务费
```

### 模式五：会员与增值收入
+ 名称：Membership / Value-added
+ 收费对象：消费者 / 商家
+ 收费方式：会员费、仓配增值、金融、数据服务
+ 公式：

```latex
会员收入 = 会员数 × 会员年费
```

## 4.2 行业最优商业模式
电商中理想的高质量商业模式通常具备以下特征：

+ 有稳定低成本流量来源
+ 优质供给可持续
+ 履约能力高效
+ 复购强
+ 不依赖持续补贴
+ 平台型收入或高毛利差价结构占比较高

平台电商的理想模式是：

> 高 GMV + 广告高渗透 + 稳定佣金 + 商家生态稳定。
>

自营电商的理想模式是：

> 高复购 + 高周转 + 低损耗 + 可控库存 + 稳定毛利。
>

## 4.3 从单点收费到综合变现路径
```latex
先做交易规模
→ 再做佣金/差价
→ 再做广告与营销服务
→ 再做物流/仓配/金融等增值服务
→ 再做会员与生态变现
```

# 五、收入模型
## 5.1 总收入公式
### 平台型
```latex
总收入 = 佣金收入 + 广告收入 + 商家服务收入 + 会员收入 + 其他增值收入
```

### 自营型
```latex
总收入 = 商品销售收入 + 会员收入 + 服务收入 + 其他收入
```

## 5.2 拆解驱动因子
### 平台电商常见拆法
```latex
收入 = GMV × 综合变现率
```

其中：

```latex
GMV = 购买用户数 × 购买频次 × 客单价
综合变现率 = 佣金率 + 广告变现率 + 其他服务费率
```

### 自营电商常见拆法
```latex
收入 = 订单量 × 客单价
```

```latex
毛利 = 收入 × 毛利率
```

### 内容电商常见拆法
```latex
GMV = 流量 × 点击率 × 转化率 × 客单价
```

## 5.3 收入增长来源
+ 用户数增长
+ 购买频次提升
+ 客单价提升
+ 品类扩张
+ 商家数量增加
+ 广告加载率提升
+ take rate 提升
+ 区域扩张
+ 私域复购提升
+ 会员渗透提升

## 6.3 单位经济模型
### 平台型

+ 订单密度不足时，履约成本很难优化
+ 内容电商若转化不稳定，收入波动会很大

## 6.4 利润公式
```latex
利润 = 收入 - 商品成本 - 流量成本 - 履约成本 - 内容/分成成本 - 技术成本 - 管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
电商增长主要来自：

+ 更多流量
+ 更高转化率
+ 更高复购
+ 更丰富供给
+ 更低价格或更高性价比
+ 更快配送
+ 内容提升购买决策效率

## 8.2 规模效应
规模扩大后，电商可能出现：

+ 更强供应链议价
+ 更高广告变现
+ 更低单票物流成本
+ 更强品牌心智
+ 更多数据优化推荐和转化
+ 更高商家入驻意愿

## 8.3 网络效应
平台型电商常有明显双边网络效应：

+ 更多商家 → 更多商品
+ 更多商品 → 更吸引消费者
+ 更多消费者 → 更吸引商家

同时还有数据网络效应：

+ 更多交易数据 → 更准推荐 → 更高转化

## 8.4 标准化与人力依赖程度
+ 平台电商标准化高
+ 自营电商运营和供应链管理更重
+ 内容电商对达人、内容和投流依赖较强
+ 即时零售对线下履约组织和调度能力要求高
