# 三、业务理解

## 3.1 公司到底做什么
1. 公司核心是内容平台、创作者平台还是版权/IP 公司？
2. 主要消费场景是什么？
3. 用户消费内容的核心动机是什么？
4. 收入主要来自广告、会员、打赏、内容付费还是版权授权？
5. 公司本质更像流量平台、内容资产方还是创作者生态方？

## 3.2 解决什么问题
1. 对用户来说，产品提供的是娱乐、陪伴、信息还是社交认同？
2. 对创作者/版权方来说，平台提供的是流量、收益还是品牌放大？
3. 如果没有这个平台，用户和创作者会选择什么替代方案？
4. 公司最核心的价值点是什么？

## 3.3 商业模式
1. 是否依赖单一收入来源？
2. 是否依赖单一头部 IP、头部主播或头部创作者？
3. 是否有从流量到会员、广告、版权、IP 的升级路径？
4. 内容供给和商业化之间是否形成正循环？

# 九、财务尽调

## 9.1 收入质量
1. 收入来源是否足够多元？
2. 广告、会员、打赏收入结构是否健康？
3. 是否依赖单一爆款、单一主播或头部版权？
4. 海外和国内收入结构差异如何？

## 9.2 利润质量
1. 内容与版权成本是否可控？
2. 分成成本是否随着平台规模恶化？
3. 广告和会员收入增长是否快于内容成本增长？
4. 长期毛利率改善空间在哪里？

## 9.3 现金流质量
1. 内容采购和自制投入是否透支现金流？
2. 创作者结算节奏是否对现金流有压力？
3. 会员预收能否有效改善经营现金流？
4. 是否依赖融资支持内容扩张？

## 9.4 资产负债表风险
重点看：
- 现金
- 版权和内容资产
- 应付创作者/版权方款项
- 递延收入
- 商誉
- 有息负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否兼具内容判断、产品分发和商业化能力？

1. 公司更强在内容、算法、社区、版权还是商业化？

3. 是否建立起创作者运营和内容审核体系？

## 10.3 激励机制
1. 创作者激励是否可持续？
