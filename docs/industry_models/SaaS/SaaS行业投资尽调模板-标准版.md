# 三、业务理解

## 3.1 公司到底做什么
1. 核心产品解决什么问题？
2. 面向什么客户群体？
3. 位于客户业务流程的哪个环节？
4. 当前主要收入来自哪个产品或模块？
5. 产品是单点工具还是流程型系统？

## 3.2 解决什么问题
1. 客户原本如何解决该问题？
2. 现有替代方案的不足在哪里？
3. 公司方案在效率、成本、管理、数据或合规上提升了什么？
4. 客户采购的核心驱动力是什么？
5. 这是“可选工具”还是“准基础设施”？

## 3.3 商业模式
1. 收入来自订阅费、席位费、模块费、Usage-based 还是实施服务？
2. 当前收入结构中，经常性收入占比多少？
3. 是否存在显著一次性收入？
4. 是否有明显的升级路径和扩单路径？
5. 中长期是否具备平台化和生态化空间？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在细分赛道 TAM / SAM / SOM 多大？
2. 客户数字化渗透率处于什么阶段？
3. 当前市场增长来自新客户教育还是存量替换？
4. 赛道最终可能形成集中还是分散格局？
5. 市场是否足够支撑公司成长为大体量平台？

## 5.2 行业格局
1. 头部玩家有哪些？
2. 直接竞品和替代方案分别是谁？
3. 是产品竞争、销售竞争还是生态竞争为主？
4. 是否存在大厂入局压制？
5. 细分行业中是否有本地化、区域化竞争特征？

## 5.3 行业趋势
1. 云化率提升是否继续利好？
2. AI 是否在重构产品形态或价格体系？
3. 客户更倾向购买点工具还是套件？
4. 未来 3-5 年行业最关键变量是什么？

- 工单响应效率
- 客户成功人效
- 实施人员人效
- 开发迭代速度
- 客户支持成本率

# 九、财务尽调

## 9.1 收入质量
1. 经常性订阅收入占比多少？
2. 服务收入是否掩盖了真实 SaaS 质量？
3. 是否存在大客户一次性签约导致收入波动？
4. 客户结构是否过于集中？
5. 是否存在低价签约换增长的情况？

## 9.2 利润质量
1. 毛利率水平是否符合赛道特征？
2. 销售费用率是否过高？
3. 研发投入是否充分且持续？
4. 交付成本是否随规模下降？
5. 盈利改善是效率提升还是压缩投入带来的？

## 9.3 现金流质量
1. 经营现金流是否与收入增长匹配？
2. 是否有稳定预收款和合同负债沉淀？
3. 回款周期是否健康？
4. 是否存在应收账款快速上升问题？

## 9.4 资产负债表风险
重点看：
- 现金余额
- 合同负债 / 递延收入
- 应收账款
- 资本化研发
- 有息负债
- 商誉
- 或有负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始人是否具备行业和产品背景？
2. 核心高管是否覆盖产品、销售、交付、技术四项能力？
3. 团队是否了解目标客户真实流程？
4. 是否过度依赖少数销售或交付骨干？

## 10.2 组织能力
1. 公司更强在产品、销售还是交付？
2. 是否能从单行业复制到多行业？
3. 中层组织和客户成功体系是否成熟？
4. 是否建立了数据驱动的经营管理体系？

## 10.3 激励机制
1. 销售激励是否只鼓励签单，不鼓励高质量留存？
2. 交付和客户成功团队激励是否与续费挂钩？
3. 核心技术与产品人才稳定性如何？

## 11.2 公司壁垒
1. 壁垒来自产品、数据、流程嵌入还是生态？
2. 客户切换成本体现在哪？

3. AI 是否会压缩当前产品的功能价值？

# 十二、风险尽调

## 12.1 业务风险
- 客户续费率低
- 扩单能力弱
- 交付太重
- 过度依赖大客户
- 增长依赖销售扩张而非产品驱动
- 赛道同质化严重

## 12.2 财务风险
- 毛利率低于合理 SaaS 水平
- 现金流弱
- 应收账款增长快
- 服务收入占比过高
- CAC 回收周期过长

## 12.3 合规与法律风险
- 数据隐私与安全
- 跨境数据合规
- 知识产权风险
- 合同与服务责任风险
- 特定行业监管要求
