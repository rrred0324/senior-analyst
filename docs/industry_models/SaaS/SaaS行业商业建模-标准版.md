# 一、行业基础定义

## 1.1 行业名称
- 行业名称：SaaS（Software as a Service）
- 细分赛道：水平 SaaS、垂直 SaaS、工具型 SaaS、流程型 SaaS、平台型 SaaS
- 上下游位置：
  - 上游：云基础设施、数据库、中间件、开发框架、渠道生态、咨询实施伙伴
  - 中游：SaaS 软件提供商
  - 下游：企业客户、政府机构、组织用户
- 主要服务对象：以 To B 为主，部分为 To G / To SMB / To C-prosumer

## 1.2 行业一句话定义
> SaaS 行业的本质是：以持续订阅方式向客户提供可快速部署、持续迭代的软件服务，帮助客户提升效率、规范流程、沉淀数据或完成数字化经营，并通过订阅费、模块费、实施费和增值服务实现商业化。

## 1.3 行业边界

### 覆盖范围
- 标准化软件订阅产品
- 云端部署或以云为主的软件服务
- 企业管理、业务协同、经营分析、客户管理、财务、人力、营销、供应链等 SaaS 业务
- 以年度或月度订阅为核心收入形态的软件产品

### 不覆盖范围
- 纯项目制软件外包
- 以硬件收入为主的软件附属业务
- 一次性 License 为主的传统本地化软件
- 与 SaaS 无订阅关系的 IT 集成服务

# 二、行业本质与核心价值

## 2.1 商业本质

SaaS 的核心不是“卖软件”，而是：

> 以更低部署门槛和持续服务方式，持续嵌入客户业务流程，并通过长期续费与扩模块实现累计收入增长。

### 1）客户为什么需要它？
客户采购 SaaS，通常是为了解决以下问题：
- 流程依赖人工，效率低
- 组织协同成本高
- 数据分散，经营不可视
- 管理标准化不足
- 传统软件部署慢、维护重、升级难
- 业务线上化和数字化需求提升

### 2）企业提供的核心价值是什么？
- 流程数字化
- 协同效率提升
- 管理标准化
- 数据可视化和决策支持
- 降低 IT 运维负担
- 更快上线与持续迭代
- 在客户组织中形成经营基础设施属性

### 3）企业为什么能赚钱？
SaaS 公司之所以能赚钱，不是因为单次售卖，而是因为：
- 客户持续订阅
- 客户从低配版本升级到高配版本
- 用户数、模块数、使用量扩大
- 增值服务（实施、培训、咨询、API、生态分成）带来追加收入
- 客户切换成本提升后，续费和提价能力增强

## 2.2 价值创造链条

SaaS 行业的典型经营链路为：

```text
发现客户需求
→ 产品设计与开发
→ 获客（销售/渠道/内容/生态）
→ 演示与试用
→ 首次付费签约
→ 上线实施与培训
→ 客户使用与嵌入流程
→ 续费与扩模块
→ NRR提升
→ 收入和毛利释放
