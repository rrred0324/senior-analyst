# 三、业务理解

## 3.1 公司到底做什么
1. 公司本质上是代理商、服务商、平台还是媒体资源方？
2. 帮客户解决的是曝光、品牌、线索还是成交问题？
3. 公司核心竞争力在媒介资源、内容创意、技术产品还是客户关系？
4. 当前收入主要来自哪些客户类型和媒介类型？

## 3.2 解决什么问题
1. 客户为什么愿意把预算交给它？
2. 是否显著提升了投放 ROI、传播效果或执行效率？
3. 客户若不用该公司，会选择平台直投、其他代理还是自建团队？
4. 公司是否在某一行业或媒介有明确优势？

## 3.3 商业模式
1. 收入来自服务费、价差、返点、项目费、抽佣还是 SaaS 费？
2. 哪一部分收入最稳定？
3. 哪一部分收入毛利最高？
4. 是否具备从项目制走向长期服务或平台化的趋势？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在赛道主要依赖品牌广告预算还是效果广告预算？
2. 市场增长来自预算增量还是渠道迁移？
3. 平台直营和 AI 自动化会压缩多少中间层空间？
4. 技术平台化机会大不大？

## 5.2 行业格局
1. 头部集中度如何？
2. 传统代理、平台直营、MCN 和 MarTech 各自竞争边界如何？
3. 公司所处位置是高附加值环节还是低附加值执行层？
4. 是否存在强地域性或强行业垂直属性？

## 5.3 行业趋势
1. 短视频和内容营销预算是否持续增长？
2. 品牌广告是否承压，效果预算是否更稳？
3. 程序化和自动化投放是否提高？
4. AI 对创意、投放和报告环节影响多大？

# 九、财务尽调

## 9.1 收入质量
1. 收入是否来自持续客户预算，还是一次性项目？
2. 毛收入和净收入口径是否清晰？
3. 高增长是否由低毛利媒介代投驱动？
4. 收入确认是否谨慎合规？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 人工成本与人效是否匹配？
3. 平台政策变化是否侵蚀利润？
4. 内容制作和达人成本是否不可控？

## 9.3 现金流质量
1. 经营现金流是否与利润匹配？
2. 是否存在长期垫资？
3. 应收回款是否健康？
4. 客户账期是否持续拉长？

## 9.4 资产负债表风险
重点看：
- 应收账款
- 合同资产
- 预付款
- 现金
- 商誉
- 递延收入
- 或有负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备广告、媒介、内容或平台经验？
2. 是否过度依赖少数销售、高管、达人或投手？
3. 是否具备客户管理与项目管理能力？
4. 是否有财务风控和回款意识？

## 10.2 组织能力
1. 是否有清晰的销售、提案、交付和复盘流程？
2. 是否能标准化复制优秀项目经验？
3. 是否有数据分析和工具化能力？
4. 是否存在严重的人才流失问题？

## 10.3 激励机制
1. 销售是否只看签单，不看回款和毛利？
2. 交付团队是否对客户续约负责？
3. 项目经理是否对交付质量和利润负责？
4. 是否有对坏账和风控的约束机制？

# 十二、风险尽调

## 12.1 业务风险
- 客户预算收缩
- 平台依赖
- 低毛利竞争
- 客户集中
- 达人和内容不稳定
- 项目制波动大
- 技术平台渗透不及预期

## 12.2 财务风险
- 回款慢
- 坏账风险
- 垫资压力
- 毛利率下降
- 人效下滑
- 高收入低现金流

## 12.3 合规与法律风险
- 广告法与内容审核风险
- 数据合规风险
- 版权和素材侵权风险
- 公关舆情风险
- 达人合作争议风险
