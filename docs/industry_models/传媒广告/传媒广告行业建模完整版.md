# 一、行业基础定义

## 1.1 行业名称
- 行业名称：传媒广告
- 英文常用称呼：Media & Advertising / Advertising & Marketing Services
- 细分赛道：品牌广告、效果广告、媒介代理、整合营销、数字营销、内容营销、MCN、程序化广告、户外广告、公关传播、营销技术（MarTech）等
- 上下游位置：
  - 上游：媒体平台、流量平台、KOL/KOC、内容制作方、创意团队、技术供应商、数据供应商
  - 中游：广告代理商、营销服务商、MCN、程序化平台、营销技术平台、整合传播公司
  - 下游：品牌主、商家、APP、游戏公司、互联网平台、线下连锁、消费品牌、汽车、房产、金融等广告主
- 主要服务对象：To B 为主

## 1.2 行业一句话定义
> 传媒广告行业的本质是：通过流量、内容、媒介资源、数据和策略能力，帮助广告主更高效地获取用户、建立品牌认知或提升转化，并从预算分配和传播效果中实现变现。

## 1.3 行业边界

### 覆盖范围
- 以广告预算为核心收入来源的媒介、代理、服务、平台和技术业务
- 通过内容、流量、创意、数据、技术帮助客户传播或获客的业务
- 线上与线下广告资源和广告服务体系

### 不覆盖范围
- 纯内容付费平台但不以广告为核心商业模式的业务
- 与广告预算弱相关的纯软件外包业务
- 单纯做影视制作但不承接营销传播逻辑的业务
- 企业内部品牌部门本体

# 二、行业本质与核心价值

## 2.1 商业本质

传媒广告行业的本质不是“帮客户投广告”，而是：

> 帮助广告主在有限预算下更高效地完成“曝光—认知—转化—复购”中的某一环节，并证明自身创造的传播或转化价值。

### 1）客户为什么需要它？
广告主需要传媒广告服务，通常因为：
- 需要扩大品牌曝光和市场声量
- 需要更高效率地获取新用户或销售线索
- 需要专业能力管理复杂的媒体渠道和内容生产
- 需要通过数据、创意和策略提高预算使用效率
- 需要外部团队补足内部营销能力不足

### 2）企业提供的核心价值是什么？
- 帮助客户获取流量和用户注意力
- 优化广告投放和媒介预算分配
- 提供创意内容、整合营销和传播策略
- 提供 KOL/KOC、MCN、媒介采购和资源撮合能力
- 通过数据、技术和复盘证明效果，帮助客户持续投放

### 3）企业为什么能赚钱？
传媒广告企业盈利来源通常包括：
- 广告代理服务费
- 媒介采买价差
- 效果广告分成
- 按项目收费的整合营销费
- 内容制作费
- MCN 抽佣和营销分成
- 平台技术服务费 / SaaS 费
- 户外媒体广告位售卖收入

## 2.2 价值创造链条

传媒广告行业典型链路：

### 代理服务型
```text
获取广告主预算
→ 制定策略与媒介计划
→ 采购流量和媒体资源
→ 执行投放和优化
→ 复盘效果
→ 获得服务费/返点/续约
```

### 内容营销型
```text
洞察品牌传播需求
→ 创意策划
→ 内容生产/达人合作
→ 多平台分发
→ 形成曝光/互动/转化
→ 获得项目费和后续预算
```

### 程序化/技术平台型
```text
连接广告主与媒体流量
→ 数据定向与自动投放
→ 提升投放效率
→ 优化 ROI
→ 收取技术费/抽佣
```

## 2.3 行业核心飞轮
```text
更强客户案例和 ROI 证明
→ 更多预算与客户续约
→ 更大媒体资源和数据积累
→ 更强投放、创意和交付能力
→ 更强客户案例和 ROI 证明
```

传媒广告行业真正强的飞轮是：

> 客户预算、成功案例、媒介资源和交付能力之间的复利循环。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：代理服务费
+ 名称：Agency Fee
+ 收费对象：广告主
+ 收费方式：按预算比例或月服务费收费
+ 公式：

```latex
收入 = 广告投放额 × 服务费率
或
收入 = 固定月费/项目费
```

### 模式二：媒介价差 / 返点
+ 名称：Media Margin / Rebate
+ 收费对象：广告主或媒体平台间接形成
+ 收费方式：采买折扣与售卖价差、年度返点
+ 公式：

```latex
收入 = 媒介售卖价 - 媒介采购价
```

### 模式三：效果分成
+ 名称：Performance-based Revenue
+ 收费对象：广告主
+ 收费方式：按线索、注册、成交、GMV 分成
+ 公式：

```latex
收入 = 成交量 × 单位分成
或
收入 = GMV × 分成比例
```

### 模式四：项目制收费
+ 名称：Project Fee
+ 收费对象：广告主
+ 收费方式：按 campaign / 活动 / 内容项目收费
+ 公式：

```latex
收入 = 项目数量 × 项目客单价
```

### 模式五：技术平台收费
+ 名称：Platform / SaaS Fee
+ 收费对象：广告主 / 代理商
+ 收费方式：订阅费、技术服务费、按消耗抽成
+ 公式：

```latex
收入 = 客户数 × ARPU
或
收入 = 投放消耗 × 技术费率
```

## 4.2 行业最优商业模式
传媒广告中高质量模型通常具备：

+ 客户预算稳定且续约率高
+ 不完全依赖单一平台流量红利
+ 能清晰证明 ROI 或品牌效果
+ 人效高，项目交付标准化较强
+ 回款周期可控，坏账风险低
+ 有技术、数据、内容或媒介资源形成壁垒

理想模型不是：

> 完全靠人脉接单、低毛利跑量、平台政策驱动、回款慢且项目交付高度非标
>

而是：

> 在客户预算中占据稳定位置，通过可证明的效果、可复制的交付和一定的技术/资源壁垒，实现预算留存与利润扩张。
>

## 4.3 从项目制到可复用模型路径
```text
先通过项目交付进入客户名单
→ 形成成功案例
→ 获得长期服务预算
→ 标准化交付流程
→ 数据化/平台化提升效率
→ 提高客户份额与人效
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 代理服务费收入 + 媒介价差收入 + 效果分成收入 + 项目制收入 + 技术平台收入 + 广告位售卖收入
```

## 5.2 拆解驱动因子
### 代理公司
```latex
收入 = 客户数 × 单客户预算 × 服务费率
```

### 项目制整合营销
```latex
收入 = 项目数量 × 单项目客单价
```

### 效果广告公司
```latex
收入 = 投放消耗 × 服务费率
或
收入 = 线索/成交量 × 单位收入
```

### MCN / 内容营销
```latex
# MCN/内容电商净收入口径（GMV → 净收入两层拆解）
GMV = 合作品牌数 × 单品牌投放额
净收入 = GMV × 抽佣率 × (1 - 平台技术服务费率) - 达人合作成本 - 内容制作成本
     ≈ GMV × 综合净变现率
```

### 户外媒体
```latex
收入 = 可售广告位数量 × 上刊率 × 单位刊例价
```

### MarTech 平台
```latex
收入 = 付费客户数 × ARPU
```

## 5.3 收入增长来源
+ 客户数增长
+ 单客户预算提升
+ 客户钱包份额提升
+ 新媒体渠道扩张
+ 高毛利服务品类增加
+ 技术平台渗透率提升
+ 达人/媒介资源网络扩大
+ 续约率提升
+ 跨行业客户拓展
+ 海外媒体或跨境业务扩张

## 6.3 单位经济模型
### 代理服务型
```latex
单客户贡献毛利 = 客户收入 - 媒介/达人/执行成本 - 客户服务人工成本
```

### 项目制公司
```latex
单项目毛利 = 项目收入 - 外包制作成本 - 执行成本 - 项目团队人工分摊
```

### 平台型
```latex
单客户年贡献毛利 = 年收入 - 流量/服务成本 - 技术运维分摊
```

### 核心判断
+ 传媒广告行业很多公司“收入大、利润薄”，关键要看净收入口径和真实毛利
+ 回款周期和垫资压力常常比表面收入更重要
+ 平台依赖型业务在流量红利消退后容易利润下滑
+ 人效和项目标准化能力决定能否从“人力生意”走向“可规模化生意”

## 6.4 利润公式
```latex
利润 = 总收入
      - 媒介采购/流量采买成本
      - 达人/KOL 合作成本
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
传媒广告增长通常来自：

+ 更多广告主预算
+ 同一客户预算份额提升
+ 从单一媒介扩展到多媒介
+ 从执行层扩展到策略层
+ 从项目制扩展到长期服务
+ 从人工交付扩展到技术化平台
+ 从本地市场扩展到全国/海外
+ 从效果广告延伸到品牌预算或反向延伸

## 8.2 规模效应
规模扩大后可能带来：

+ 更强媒介议价能力
+ 更高品牌背书和中标率
+ 更丰富的客户案例
+ 更强的数据积累和投放优化能力
+ 更高的人才吸引力
+ 更低单位交付成本

## 8.3 网络效应
行业整体网络效应不强，但部分赛道存在弱网络效应：

+ MCN：达人越多，品牌合作机会越多
+ 程序化平台：广告主和媒体两边越多，撮合效率越高
+ MarTech：数据积累越多，产品能力越强
+ 户外媒体：点位网络越密集，客户采购效率越高

## 8.4 预算周期与宏观逻辑
+ 行业强相关于宏观经济和品牌投放意愿
+ 效果广告相对更接近 ROI 驱动，预算韧性更强
+ 品牌广告更容易受经济预期影响
+ 大客户常有季度、年度预算周期，回款和确认收入节奏需重点分析

+ 大客户服务与交付壁垒
+ 行业垂直 know-how 壁垒

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
目标市场中，广告主在品牌广告、效果广告、内容营销、媒介采买和营销技术上**年度**总预算（理论上限）

### SAM
在 TAM 内，公司现有媒介类型、地域、客户层级能力**可触达**的广告预算总和

### SOM
基于现有客户关系和销售能力，公司中短期**实际可获取**的客户预算份额或收入规模

## 12.2 通用测算公式
### 方法一：客户预算法
```latex
市场空间 = 目标广告主数量 × 年均广告预算
```

### 方法二：媒介拆分法
```latex
市场空间 = 搜索广告 + 信息流广告 + 短视频广告 + 户外广告 + 内容营销预算
```

### 方法三：服务费率法
```latex
可得收入空间 = 广告投放总额 × 可抽取服务费率
```

### 方法四：行业垂直法
```latex
市场空间 = 某垂直行业广告主数量 × 年均营销预算 × 可服务渗透率
```

## 12.3 市场空间判断注意事项
+ 预算空间不等于收入空间，要看服务费率和可切入深度
+ 毛收入大不代表利润空间大
+ 品牌广告和效果广告预算逻辑完全不同
+ 平台直采趋势可能压缩中间层空间

# 十四、快速分析卡
## 一句话本质
> 传媒广告行业本质上是通过流量、内容、媒介资源、数据和策略能力，帮助广告主更高效地完成品牌传播或用户转化，并从广告预算中获得可持续的服务费、差价或技术收入。
>

## 核心收入公式
```latex
收入 = 客户数 × 单客户预算 × 服务费率
或
收入 = 项目数 × 单项目客单价
```

## 核心成本公式
```latex
成本 = 媒介/达人/制作成本 + 客户服务人工成本 + 销售成本 + 技术与管理成本 + 坏账损失
```

## 核心判断三要素
1. 是否能持续拿到并留住客户预算
2. 是否能证明效果并形成稳定毛利
3. 是否具备标准化交付或技术/资源壁垒

## 最重要指标
+ 净收入
+ 毛利率
+ 客户续约率
+ 单客户 ARPU
+ 人均净收入
+ 回款周期
+ 应收账款周转
+ 单一客户/平台依赖度

## 最大风险
+ 平台依赖
+ 预算波动
+ 回款拖延
+ 低毛利竞争
+ 客户集中
+ 合规风险

## 最终结论模板
> 传媒广告行业的核心不是做大毛收入，而是能否在客户预算中占据稳定份额，并用可验证的效果、可复制的交付和一定的技术或资源壁垒，形成健康净收入、稳定现金流和可扩张利润结构。
>
