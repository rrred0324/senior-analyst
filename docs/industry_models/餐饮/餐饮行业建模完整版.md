# 一、行业基础定义

## 1.1 行业名称
- 行业名称：餐饮
- 英文常用称呼：Food & Beverage / Restaurant Industry
- 细分赛道：中式正餐、火锅、烧烤、西式快餐、中式快餐、茶饮、咖啡、烘焙、小吃、团餐、外卖餐饮、连锁加盟、餐饮供应链等
- 上下游位置：
  - 上游：农产品、食材加工、调味品、冷链物流、中央厨房、包装材料、设备供应商、数字化系统服务商
  - 中游：餐饮品牌、直营门店、加盟门店、团餐运营商、餐饮 SaaS、外卖代运营
  - 下游：个人消费者、家庭消费、办公人群、商圈客流、旅游人群、企业团餐客户
- 主要服务对象：To C 为主，部分 To B（团餐、供应链、加盟、SaaS）

## 1.2 行业一句话定义
> 餐饮行业的本质是：通过门店、外卖或团餐等场景，向消费者持续提供标准化或体验型的即时餐食服务，并通过品牌、选址、供应链和运营效率实现盈利与扩张。

## 1.3 行业边界

### 覆盖范围
- 提供即时餐食和饮品消费的品牌和门店
- 提供到店、外卖、到家、团餐等餐饮服务
- 餐饮连锁、加盟、供应链和餐饮数字化服务

### 不覆盖范围
- 纯食品制造但不直接服务餐饮消费场景的业务
- 与餐饮弱相关的泛零售业务
- 单纯做厨房设备但不参与餐饮经营逻辑的企业
- 单纯卖预包装食品而非餐饮服务的消费品牌

# 二、行业本质与核心价值

## 2.1 商业本质

餐饮行业的本质不是“卖一顿饭”，而是：

> 在特定时间、地点和价格带下，为消费者提供稳定可接受的口味、效率和体验，并通过高频消费、门店复制和供应链优化持续获取利润。

### 1）客户为什么需要它？
消费者需要餐饮服务，通常因为：
- 日常就餐具备高频刚需
- 即时性需求强，不愿自行做饭或时间不足
- 社交、聚会、商务、休闲等场景驱动消费
- 对口味、便利性、环境和品牌有不同偏好
- 外卖和同城配送强化了即时消费需求

### 2）企业提供的核心价值是什么？
- 提供方便、快捷、稳定的餐食和饮品
- 节省消费者时间和烹饪成本
- 提供社交、聚会、休闲和体验空间
- 提供可预期的品质和服务标准
- 在不同价格带满足不同人群消费需求

### 3）企业为什么能赚钱？
餐饮企业盈利来源通常包括：
- 到店销售收入
- 外卖销售收入
- 团餐和企业客户收入
- 加盟费和供应链收入
- 周边零售和预包装产品收入
- 会员储值和增值服务收入

## 2.2 价值创造链条

餐饮行业典型链路：

### 直营门店型
```text
选址获取流量
→ 产品和服务交付
→ 提升翻台与复购
→ 优化门店模型
→ 复制扩店
```

### 加盟连锁型
```latex
建立品牌和标准化体系
→ 招募加盟商
→ 输出供应链和运营能力
→ 加盟店稳定经营
→ 扩大网络和品牌覆盖
```

### 外卖餐饮型
```latex
获取线上流量
→ 履约出餐
→ 配送到家
→ 提升评分和复购
→ 扩展多店与多平台
```

## 2.3 行业核心飞轮
```latex
更强品牌和产品力
→ 更高客流与复购
→ 更高单店收入和利润
→ 更强供应链和组织效率
→ 更强品牌和产品力
```

餐饮行业真正强的飞轮是：

> 稳定产品 + 高效门店模型 + 品牌认知 + 供应链能力 + 连锁复制效率。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：到店销售
+ 名称：Dine-in Revenue
+ 收费对象：消费者
+ 收费方式：按订单/餐次收费
+ 公式：

```latex
收入 = 客流量 × 转化率 × 客单价
```

### 模式二：外卖销售
+ 名称：Delivery Revenue
+ 收费对象：消费者
+ 收费方式：线上下单按单收费
+ 公式：

```latex
收入 = 外卖订单数 × 外卖客单价
```

### 模式三：加盟收入
+ 名称：Franchise Revenue
+ 收费对象：加盟商
+ 收费方式：加盟费、管理费、培训费
+ 公式：

```latex
收入 = 新增加盟店数 × 单店加盟费 + 存量加盟店管理费
```

### 模式四：供应链收入
+ 名称：Supply Chain Revenue
+ 收费对象：加盟店/第三方门店
+ 收费方式：食材、包材、设备供货
+ 公式：

```latex
收入 = 供货量 × ASP
```

### 模式五：团餐合同收入
+ 名称：B2B Catering Revenue
+ 收费对象：企业/学校/机构
+ 收费方式：按合同、人数、餐次结算
+ 公式：

```latex
收入 = 服务人数 × 餐次频率 × 单餐价格
```

## 4.2 行业最优商业模式
餐饮行业中高质量模型通常具备：

+ 单店模型清晰，回本周期短
+ 产品高度标准化，可跨区域复制
+ 同店增长稳健，不依赖过度促销
+ 外卖与堂食结构合理
+ 品牌在目标价格带有明确认知
+ 供应链和门店运营效率强
+ 加盟扩张可控，闭店率低

理想模型不是：

> 靠短期营销制造排队、门店模型脆弱、供应链不稳定、加盟粗放扩张、同店持续下滑
>

而是：

> 在稳定门店利润基础上，通过品牌、供应链和标准化体系实现低失真的区域扩张和长期复购。
>

## 4.3 从单店到连锁路径
```latex
验证单店模型
→ 优化产品、出餐和人效
→ 打磨 SOP 和培训体系
→ 建立供应链能力
→ 区域复制开店
→ 形成品牌规模和采购优势
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 到店收入 + 外卖收入 + 团餐收入 + 加盟收入 + 供应链收入 + 零售化收入
```

## 5.2 拆解驱动因子
### 直营餐饮
```latex
收入 = 门店数 × 单店收入
单店收入 = 客流量 × 转化率 × 客单价
```

### 门店时段模型
```latex
单店收入 = 座位数 × 翻台率 × 人均消费 × 营业天数
```

### 外卖模型
```latex
外卖收入 = 外卖订单数 × 客单价
```

### 加盟模型
```latex
加盟收入 = 新增加盟店数 × 加盟费 + 存量门店管理费 + 供应链供货收入
```

### 团餐模型
```latex
团餐收入 = 覆盖单位数 × 单位服务人数 × 单餐价格 × 餐次频次
```

## 5.3 收入增长来源
+ 门店数增长
+ 同店销售增长
+ 客流增长
+ 客单价提升
+ 翻台率提升
+ 外卖订单增长
+ 新品和高毛利产品占比提升
+ 加盟开店增长
+ 团餐客户扩张
+ 零售化和会员收入增加

## 6.3 单位经济模型
### 直营单店模型
```latex
单店门店利润 = 单店收入 - 食材成本 - 人工 - 租金 - 水电 - 营销 - 平台佣金 - 其他运营费用
```

### 单订单模型
```latex
单订单毛利 = 客单价 - 食材包材成本 - 配送/平台抽佣 - 人工分摊
```

### 加盟总部模型
```latex
单加盟店年贡献 = 加盟费 + 管理费 + 供货毛利 - 培训督导和服务成本
```

### 核心判断
+ 餐饮行业关键不是“销售额看起来高”，而是单店是否健康赚钱
+ 同店增长比盲目开店更重要
+ 外卖增长若被平台抽佣和补贴吞噬，不一定创造利润
+ 加盟扩张若闭店率高，会伤害品牌和长期现金流

## 6.4 利润公式
```latex
利润 = 总收入 - 食材包材成本 - 门店人工租金 - 平台佣金配送成本 - 营销费用 - 供应链与总部管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
餐饮增长通常来自：

+ 新店扩张
+ 同店客流提升
+ 新品带动客单提升
+ 外卖渗透率提高
+ 会员和私域复购增强
+ 供应链优化提升利润率
+ 区域品牌升级为全国连锁
+ 加盟模式带动轻资产扩张

## 8.2 规模效应
规模扩大后可能带来：

+ 食材采购议价增强
+ 供应链效率提升
+ 品牌认知加强
+ 选址和组织能力复制
+ 营销摊薄
+ 数字化和培训体系提升门店一致性

## 8.3 网络效应
餐饮行业网络效应有限，但品牌和平台评价存在弱网络效应：

+ 门店越多，品牌认知越强
+ 会员越多，复购和裂变越强
+ 外卖平台评分和销量越高，排序和转化越好
+ 加盟网络越大，供应链效率越高

## 8.4 周期与消费逻辑
+ 餐饮属于高频消费，但不同品类受经济波动影响不同
+ 快餐、茶饮等性价比品类抗周期性相对更强
+ 正餐和高客单社交餐饮受宏观消费情绪影响更明显
+ 房租、人力、原材料波动对利润影响很大
+ 区域饮食偏好和本地竞争格局决定扩张边界

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 餐饮行业整体高度分散，连锁化率持续提升
+ 茶饮、咖啡、快餐赛道连锁化更快

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
目标区域内消费者在相关餐饮品类上的总支出

### SAM
公司当前价格带、区域、渠道和品类下可服务市场

### SOM
公司中短期可获取的门店收入、消费者订单或市场份额

## 12.2 通用测算公式
### 方法一：消费频次法
```latex
市场空间 = 目标人群数量 × 年消费频次 × 客单价
```

### 方法二：门店容量法
```latex
市场空间 = 可开店点位数 × 单店成熟收入
```

### 方法三：区域渗透法
```latex
市场空间 = 区域人口 × 渗透率 × 年均消费额
```

### 方法四：加盟扩张法
```latex
市场空间 = 潜在加盟门店数 × 单店总部贡献收入
```

## 12.3 市场空间判断注意事项
+ 餐饮行业空间大不等于单品牌空间大
+ 单店模型和扩张半径比理论 TAM 更重要
+ 需区分到店、外卖、团餐与零售化空间
+ 区域适配性和竞争密度会显著限制扩张速度

# 十四、快速分析卡
## 一句话本质
> 餐饮行业本质上是以门店或配送场景为载体，在特定价格带和消费场景下向消费者持续提供稳定餐食和服务，并通过品牌、供应链、标准化和门店运营效率实现复购与扩张。
>

## 核心收入公式
```latex
收入 = 门店数 × 单店收入
单店收入 = 客流 × 转化率 × 客单价
或
单店收入 = 座位数 × 翻台率 × 人均消费 × 营业天数
```

## 核心成本公式
```latex
成本 = 食材包材成本 + 人工租金 + 平台佣金配送 + 营销费用 + 供应链与总部管理成本
```

## 核心判断三要素
1. 单店模型是否健康且可复制
2. 同店增长和复购是否成立
3. 供应链和加盟/组织扩张能力是否足够强

## 最重要指标
+ 同店销售增长
+ 翻台率
+ 客单价
+ 坪效
+ 人效
+ 门店 EBITDA
+ 回本周期
+ 加盟店闭店率

## 最大风险
+ 食安风险
+ 同店下滑
+ 加盟失控
+ 原料/租金/人工上涨
+ 平台抽佣
+ 区域扩张失效

## 最终结论模板
> 餐饮行业的核心不是开出多少店，而是能否验证并复制一个健康的单店模型。真正决定长期价值的，是同店增长能力、品牌在目标价格带的心智、供应链和标准化体系、加盟质量以及跨区域扩张时的低失真复制能力。
>
