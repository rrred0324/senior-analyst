# 三、业务理解

## 3.1 公司到底做什么
1. 公司本质上是直营餐饮品牌、加盟总部、团餐服务商还是供应链公司？
2. 收入主要来自门店零售、外卖、加盟费还是供货？
3. 目标消费场景是刚需快餐、休闲饮品还是社交型正餐？
4. 品牌核心竞争力在产品、价格、效率、体验还是选址？

## 3.2 解决什么问题
1. 用户为什么选择它，而不是周边餐饮替代品？
2. 是解决了便捷、性价比、口味、体验还是社交需求？
3. 用户对品牌认知是否清晰？
4. 外卖或堂食场景中，最核心的消费驱动是什么？

## 3.3 商业模式
1. 收入来自直营开店、加盟扩张、供应链输出还是团餐合同？
2. 哪部分收入最稳定？
3. 哪部分收入毛利最高？
4. 品牌是否具备从区域到全国复制的潜力？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在品类处于高增长、成熟竞争还是出清整合阶段？
2. 目标价格带是否还有增长空间？
3. 连锁化率是否持续提升？
4. 外卖和即时零售是否会改变市场边界？

## 5.2 行业格局
1. 头部连锁和区域品牌竞争如何？
2. 同品类竞争是否已陷入价格战？
3. 供应链和加盟体系是否成为行业核心壁垒？
4. 公司在所在区域是否有领先优势？

## 5.3 行业趋势
1. 性价比消费是否持续增强？
2. 茶饮、咖啡、快餐等高频品类是否继续扩张？
3. 正餐是否受到消费谨慎影响？
4. 预制化、标准化和数字化是否提升行业效率？

4. 门店出品和服务是否稳定？
5. 供应链支持和食安管理是否让加盟商/店长满意？

# 九、财务尽调

## 9.1 收入质量
1. 收入是否建立在健康同店和真实客流上？
2. 门店增长与收入增长是否匹配？
3. 外卖增长是否依赖补贴？
4. 加盟收入是否可持续，还是一次性收加盟费？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 食材、人工、租金成本率是否可控？
3. 新店爬坡对利润拖累多大？
4. 总部费用能否被门店规模摊薄？

## 9.3 现金流质量
1. 直营扩张是否吞噬现金流？
2. 加盟模式是否带来正向现金回笼？
3. 团餐账期是否影响回款？
4. 装修、设备和开店投入对现金流压力多大？

## 9.4 资产负债表风险
重点看：
- 现金
- 存货
- 预付款
- 应付账款
- 固定资产
- 租赁负债
- 合同负债/加盟预收款

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备餐饮、供应链和连锁经验？
2. 是否懂产品、门店和加盟管理？
3. 是否具备食安和品控意识？
4. 是否过度依赖某位主厨、区域负责人或加盟招商负责人？

## 10.2 组织能力
1. 是否具备开店、运营、督导、培训和食安体系？
2. 是否有完善 SOP？
3. 是否具备区域扩张的组织深度？
4. 加盟管理和淘汰机制是否健全？

## 10.3 激励机制
1. 店长是否对利润和服务质量负责？
2. 区域团队是否对同店增长负责？
3. 招商团队是否只看开店数，不看存活率？
4. 是否有对食安和客诉的红线管理机制？

# 十二、风险尽调

## 12.1 业务风险
- 同店下滑
- 食品安全事故
- 爆品失效
- 过度依赖外卖
- 加盟失控
- 区域扩张不适配
- 门店密度过高自我蚕食

## 12.2 财务风险
- 原料涨价
- 人工租金上涨
- 门店回本周期拉长
- 外卖平台费用上升
- 开店资本开支过大
- 加盟收入透支

## 12.3 合规与法律风险
- 食品安全与卫生问题
- 劳务用工风险
- 加盟合同争议
- 预付卡和储值合规风险
- 广告宣传与配料标识风险
