# 三、业务理解

## 3.1 公司到底做什么
1. 公司本质上是家装交付公司、家具零售商、定制品牌、平台还是 SaaS 公司？
2. 主要收入来自施工、材料、家具、定制、平台佣金还是系统订阅？
3. 核心客户是新房业主、旧改用户还是 B 端项目客户？
4. 是单点服务还是一体化整单交付？

## 3.2 解决什么问题
1. 用户为什么选择它，而不是传统装修队、头部品牌或电商渠道？
2. 是解决省心、性价比、设计感、交付效率还是品牌信任问题？
3. 公司最强卖点是设计、交付、价格、产品还是供应链？
4. 用户最看重的是哪个环节，最容易投诉的是哪个环节？

## 3.3 商业模式
1. 收入来自前端签单、后端交付差价，还是产品零售毛利？
2. 哪部分收入最稳定？
3. 哪部分收入毛利最高？
4. 是否具备从单一装修或单一家具销售扩展到整单方案的能力？

# 五、市场与行业尽调

## 5.1 市场空间
1. 主要机会来自新房交付、改善型装修还是存量房旧改？

3. 行业集中度是否提升？
4. 家居零售、整装和定制之间的边界是否在融合？

1. 区域家装公司、全国整装品牌、卖场和平台竞争格局如何？

2. 整装一体化是否提升行业集中度？

# 九、财务尽调

## 9.1 收入质量
1. 签单增长是否建立在真实高质量交付基础上？
2. 是否存在低价签单、后期增项或退款风险？
3. 收入确认与交付进度是否匹配？
4. 高客单和低客单业务结构是否变化异常？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 获客成本是否快速上升？
3. 返工、赔付和售后是否侵蚀利润？
4. 门店扩张是否稀释利润率？

## 9.3 现金流质量
1. 是否依赖预收款维持运营？
2. 尾款回收是否稳定？
3. 材料备货和库存是否占用现金？
4. 新店、工厂和展厅投入是否造成现金流压力？

## 9.4 资产负债表风险
重点看：
- 现金
- 应收账款与尾款
- 合同负债 / 预收款
- 存货及库龄
- 预付款
- 固定资产
- 诉讼与预计负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备家装、零售、制造或供应链经验？
2. 是否懂交付、施工和本地运营？
3. 是否具备多城市复制能力？
4. 是否过度依赖明星设计师或核心城市负责人？

## 10.2 组织能力
1. 是否有标准化销售、设计、施工和售后流程？
2. 是否有成熟培训和质检体系？
3. 是否具备供应链、仓配和安装协同能力？
4. 是否有数据化经营与过程管理能力？

## 10.3 激励机制
1. 前端签单团队是否只看签单额，不看利润和投诉？
2. 交付团队是否对工期和满意度负责？
3. 是否有尾款回收和返工控制机制？
4. 总部与门店/城市团队目标是否一致？

## 11.2 公司壁垒

# 十二、风险尽调

## 12.1 业务风险
- 获客成本上升

- 门店扩张失控

- 低毛利高签单
- 预收下降
- 尾款回收恶化
- 库存积压
- 新店投入过重
- 现金流失衡

## 12.3 合规与法律风险
- 合同纠纷
- 虚假宣传
- 工地安全责任
- 材料环保与质量风险
- 用工与劳务合规问题
- 消费者维权风险
