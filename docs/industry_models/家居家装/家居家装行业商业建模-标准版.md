# 一、行业基础定义

## 1.1 行业名称
- 行业名称：家居家装
- 英文常用称呼：Home Furnishing & Interior Renovation / Home Improvement
- 细分赛道：家装设计施工、整装、局装、旧改翻新、全屋定制、成品家具、软体家具、建材辅材、软装配套、家居零售、家装平台、家装 SaaS、安装维修后市场服务
- 上下游位置：
  - 上游：板材、五金、涂料、瓷砖、卫浴、家电、软装、工厂制造商、施工队、仓配安装服务商
  - 中游：家装公司、整装公司、设计工作室、定制家居品牌、家具品牌、卖场、经销商、平台、SaaS 服务商
  - 下游：新房业主、二手房业主、租赁房东、企业客户、地产精装配套客户
- 主要服务对象：To C 为主，兼有 To B（地产、酒店、公寓、办公、渠道商）

## 1.2 行业一句话定义
> 家居家装行业的本质是：围绕居住空间的装修、布置和功能升级需求，为用户提供设计、施工、产品和交付服务，并通过材料差价、施工收入、家具零售、定制生产和增值服务实现变现。

## 1.3 行业边界

### 覆盖范围
- 面向家庭和企业空间的装修、家居配置和改造服务
- 家具、建材、定制和软装等与空间交付直接相关的业务
- 家装交易、供应链、数字化工具及后市场服务

### 不覆盖范围
- 纯地产开发业务
- 纯建筑总包工程
- 与居住空间弱相关的工业建材生产
- 单纯家电制造但不属于家居空间交付链条的业务

# 二、行业本质与核心价值

## 2.1 商业本质

家居家装行业的本质不是“卖一套装修方案”或“卖一张沙发”，而是：

> 在高决策成本、长交付链条、强非标和低频消费场景中，帮助用户完成从空间规划到最终入住的复杂交付，并以信任、效率和品质管理实现变现。

### 1）客户为什么需要它？
客户需要家居家装服务，通常因为：
- 装修和空间配置专业门槛高，用户难以独立完成
- 设计、施工、材料、安装环节复杂，协同成本高
- 用户需要兼顾预算、风格、功能和工期
- 存量房翻新、改善型居住和拎包入住需求持续增长
- 家装和家居购买往往希望一体化交付，减少试错和扯皮

### 2）企业提供的核心价值是什么？
- 帮用户完成空间设计和功能规划
- 提供施工管理、主辅材供应和安装交付
- 通过标准化套餐或供应链整合降低决策成本
- 提升工期可控性和整体交付体验
- 提供后续维护、维修、焕新和二次消费服务

### 3）企业为什么能赚钱？
家居家装企业盈利来源通常包括：
- 设计费
- 施工收入
- 主材辅材销售差价
- 定制家居销售收入
- 成品家具和软装零售收入
- 套餐整装收入
- 安装和配送服务费
- 平台佣金
- SaaS 订阅费
- 旧改、维修和后市场服务收入
