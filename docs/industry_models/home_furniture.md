# 一、行业基础定义

## 1.1 行业名称
- 行业名称：家居家装
- 英文常用称呼：Home Furnishing & Interior Renovation / Home Improvement
- 细分赛道：家装设计施工、整装、局装、旧改翻新、全屋定制、成品家具、软体家具、建材辅材、软装配套、家居零售、家装平台、家装 SaaS、安装维修后市场服务
- 上下游位置：
  - 上游：板材、五金、涂料、瓷砖、卫浴、家电、软装、工厂制造商、施工队、仓配安装服务商
  - 中游：家装公司、整装公司、设计工作室、定制家居品牌、家具品牌、卖场、经销商、平台、SaaS 服务商
  - 下游：新房业主、二手房业主、租赁房东、企业客户、地产精装配套客户
- 主要服务对象：To C 为主，兼有 To B（地产、酒店、公寓、办公、渠道商）

## 1.2 行业一句话定义
> 家居家装行业的本质是：围绕居住空间的装修、布置和功能升级需求，为用户提供设计、施工、产品和交付服务，并通过材料差价、施工收入、家具零售、定制生产和增值服务实现变现。

## 1.3 行业边界

### 覆盖范围
- 面向家庭和企业空间的装修、家居配置和改造服务
- 家具、建材、定制和软装等与空间交付直接相关的业务
- 家装交易、供应链、数字化工具及后市场服务

### 不覆盖范围
- 纯地产开发业务
- 纯建筑总包工程
- 与居住空间弱相关的工业建材生产
- 单纯家电制造但不属于家居空间交付链条的业务

# 二、行业本质与核心价值

## 2.1 商业本质

家居家装行业的本质不是“卖一套装修方案”或“卖一张沙发”，而是：

> 在高决策成本、长交付链条、强非标和低频消费场景中，帮助用户完成从空间规划到最终入住的复杂交付，并以信任、效率和品质管理实现变现。

### 1）客户为什么需要它？
客户需要家居家装服务，通常因为：
- 装修和空间配置专业门槛高，用户难以独立完成
- 设计、施工、材料、安装环节复杂，协同成本高
- 用户需要兼顾预算、风格、功能和工期
- 存量房翻新、改善型居住和拎包入住需求持续增长
- 家装和家居购买往往希望一体化交付，减少试错和扯皮

### 2）企业提供的核心价值是什么？
- 帮用户完成空间设计和功能规划
- 提供施工管理、主辅材供应和安装交付
- 通过标准化套餐或供应链整合降低决策成本
- 提升工期可控性和整体交付体验
- 提供后续维护、维修、焕新和二次消费服务

### 3）企业为什么能赚钱？
家居家装企业盈利来源通常包括：
- 设计费
- 施工收入
- 主材辅材销售差价
- 定制家居销售收入
- 成品家具和软装零售收入
- 套餐整装收入
- 安装和配送服务费
- 平台佣金
- SaaS 订阅费
- 旧改、维修和后市场服务收入

## 2.2 价值创造链条

家居家装行业典型链路：

### 整装交付型
```text
获取装修线索
→ 到店量房与方案设计
→ 预算报价与签单
→ 材料选配与施工组织
→ 交付验收
→ 售后维护与转介绍
```

### 家具零售型
```latex
流量获取
→ 门店/线上展示
→ 选品与导购成交
→ 仓配安装
→ 售后服务
→ 连带销售与复购
```

### 全屋定制型
```latex
获取需求
→ 设计方案
→ 复尺下单
→ 工厂生产
→ 配送安装
→ 验收与尾款回收
```

## 2.3 行业核心飞轮
```latex
更好的设计与交付能力
→ 更高客户满意度和口碑
→ 更高签单转化与转介绍
→ 更高订单规模和供应链议价能力
→ 更好的设计与交付能力
```

家居家装行业真正强的飞轮是：

> 获客效率 + 交付能力 + 供应链整合 + 口碑转介绍 + 多品类客单提升。
>

+ 后市场服务更看响应速度、标准化和高频复购潜力

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：设计施工收入
+ 名称：Design & Build
+ 收费对象：业主 / 企业客户
+ 收费方式：设计费、施工费、管理费、套餐费
+ 公式：

```latex
收入 = 签单数 × 平均单值
```

### 模式二：材料和产品销售
+ 名称：Product Sales
+ 收费对象：消费者 / 渠道商
+ 收费方式：零售、分销、整装配套销售
+ 公式：

```latex
收入 = 销量 × ASP
```

### 模式三：定制生产交付
+ 名称：Customized Furniture / Cabinetry
+ 收费对象：家庭用户 / 项目客户
+ 收费方式：按投影面积、延米、套系或整单收费
+ 公式：

```latex
收入 = 定制订单数 × 单均客单价
```

### 模式四：平台撮合
+ 名称：Lead Generation / Marketplace
+ 收费对象：商家 / 消费者
+ 收费方式：线索费、广告费、佣金
+ 公式：

```latex
收入 = 有效线索数 × 单线索收入
或
收入 = 成交额 × 佣金率
```

### 模式五：SaaS / 数字化服务
+ 名称：Software Subscription
+ 收费对象：家装公司、经销商、工厂
+ 收费方式：订阅费、账号费、实施费
+ 公式：

```latex
收入 = 客户数 × ARPU
```

## 4.2 行业最优商业模式
家居家装行业中高质量模型通常具备：

+ 获客稳定，不完全依赖高成本线上投放
+ 设计、报价、施工、安装流程标准化较高
+ 供应链效率强，毛利和交付质量兼顾
+ 交付周期可控，尾款回收稳定
+ 客诉和返工率低，口碑带来转介绍
+ 具备整单提升和多品类连带能力

理想模型不是：

> 获客贵、签单低、低价抢单、交付混乱、返工多、毛利薄、回款慢、现金流差
>

而是：

> 通过品牌、门店或口碑获得稳定线索，以标准化交付控制品质和工期，并依靠供应链整合和整单销售提升毛利与用户价值。
>

## 4.3 从单点业务到生态路径
```latex
获取装修/置家需求
→ 完成高满意度交付
→ 带动家具、软装、家电配套
→ 提升整单客单价
→ 沉淀口碑和二次焕新需求
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 设计施工收入 + 材料销售收入 + 定制家居收入 + 家具零售收入 + 平台收入 + SaaS 收入 + 售后后市场收入
```

## 5.2 拆解驱动因子
### 家装公司模型
```latex
收入 = 到店客户数 × 签约转化率 × 平均合同额
```

### 设计师产能模型
```latex
收入 = 设计师人数 × 人均签单数 × 单均客单价
```

### 门店零售模型
```latex
收入 = 进店客流 × 成交转化率 × 客单价
```

### 定制家居模型
```latex
收入 = 下单客户数 × 单均定制面积/套数 × 单价
```

### 平台模型
```latex
收入 = 线索量 × 有效率 × 单线索收费
```

### 后市场模型
```latex
收入 = 服务订单数 × 单均客单价 × 复购频次
```

## 5.3 收入增长来源

+ 客单价提升
+ 整装配套率提升
+ 门店拓展

+ 存量房旧改需求增长
+ 渠道分销扩张
+ SaaS 客户增长
+ 口碑转介绍增加

# 六、成本模型
## 6.1 主要成本构成
+ 设计师和销售薪酬
+ 项目经理和施工管理成本
+ 工人和安装成本
+ 材料采购成本
+ 工厂制造成本
+ 门店租金
+ 流量投放和线索采买成本
+ 仓储物流成本
+ 售后返工成本
+ 管理费用和数字化投入

## 6.2 成本分类方式
### 固定成本
+ 门店租金
+ 管理层薪酬
+ 核心设计团队
+ 工厂折旧（如有）
+ 数字化系统投入

### 可变成本
+ 材料成本
+ 工人工资
+ 安装配送成本
+ 销售提成
+ 平台佣金
+ 售后维修返工成本

### 前端成本
+ 广告投放
+ 线索采买
+ 门店获客活动
+ 设计量房成本
+ 导购和顾问获客成本

### 后端成本
+ 施工管理
+ 仓配安装
+ 返工与售后
+ 质检和验收
+ 尾款催收

## 6.3 单位经济模型
### 单装修订单模型
```latex
单订单毛利 = 合同收入 - 材料成本 - 人工施工成本 - 获客成本 - 返工售后分摊
```

### 单门店模型
```latex
单店利润 = 单店收入 - 房租 - 人员薪酬 - 营销费用 - 管理分摊
```

### 单定制订单模型
```latex
单定制利润 = 定制收入 - 板材五金成本 - 制造成本 - 安装成本 - 售后成本
```

### 核心判断
+ 家装行业很多公司签单看起来大，但由于增项失控、返工和尾款回收问题，真实利润并不高
+ 家具零售和定制业务毛利看似较高，但若库存、门店和安装效率差，净利会被侵蚀
+ 获客成本与交付成本双高时，规模增长不一定带来利润改善
+ 交付稳定和口碑转介绍往往是长期优质公司的关键分水岭

## 6.4 利润公式
```latex
利润 = 总收入 - 材料与制造成本 - 人工与施工成本 - 获客营销费用 - 门店与履约成本 - 售后返工成本 - 管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
家居家装增长通常来自：

+ 获客能力增强
+ 设计和签单转化率提升
+ 整单价值提升
+ 整装、定制、软装一体化渗透
+ 门店和城市扩张
+ 存量房旧改需求放量
+ 口碑转介绍增加
+ 后市场服务延伸
+ B 端配套项目拓展

## 8.2 规模效应
规模扩大后可能带来：

+ 供应链议价能力增强
+ 品牌提升线索获取效率
+ 设计模板和施工流程标准化
+ 仓储物流和安装成本摊薄
+ 研发和信息化投入更划算
+ 多品类销售交叉带动

## 8.3 网络效应
行业强网络效应有限，但存在局部弱网络效应：

+ 口碑和转介绍越强，获客成本越低
+ 平台商家越多，用户选择越多，反过来吸引更多商家
+ SaaS 客户越多，产品能力和数据壁垒越强
+ 城市项目密度越高，供应链和交付效率越高

## 8.4 周期与地产逻辑
+ 行业受地产销售、新房交付和消费信心影响较大
+ 存量房翻新和局改相对更具韧性
+ 高客单整装受经济周期影响更明显
+ 家具零售受可选消费波动影响较大
+ 平台和 SaaS 更看商家预算与行业景气度

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 家装行业长期分散，区域性强，标准化难
+ 定制家居和家具零售头部化程度相对更高
+ 整装公司、传统装修公司、卖场和平台都在争夺用户入口
+ 存量房时代，旧改和局改机会增加

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
全国新房装修、存量房翻新、家具建材购置和后市场服务总支出

### SAM
公司当前区域、品类、价格带和渠道下可服务市场

### SOM
公司中短期可获取的签单额、零售额、在地市场份额或客户数

## 12.2 通用测算公式
### 方法一：新房交付法
```latex
市场空间 = 年交付住宅套数 × 单套装修/置家支出
```

### 方法二：存量房翻新法
```latex
市场空间 = 可翻新存量房数量 × 翻新渗透率 × 单次翻新客单价
```

### 方法三：门店零售法
```latex
市场空间 = 目标城市家庭数 × 家具建材年消费额
```

### 方法四：整单价值法
```latex
市场空间 = 目标客户数 × 整装/定制/软装整单客单价
```

## 12.3 市场空间判断注意事项
+ 市场空间大不等于公司易复制
+ 强非标服务需要看区域组织能力
+ 家装和家具虽在同一链条，但估值逻辑不同
+ 需区分新房驱动和存量翻新驱动
+ 平台型公司和交付型公司应分别建模

1. 获客和签单模型是否健康
