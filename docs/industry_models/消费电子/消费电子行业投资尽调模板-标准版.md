# 三、业务理解

## 3.1 公司到底做什么
1. 公司卖的是整机、配件、智能硬件还是生态服务？
2. 用户为什么买它，而不是头部品牌或更低价白牌？
3. 公司核心竞争力在产品、品牌、渠道还是供应链？
4. 当前收入主要来自哪些品类和区域？

## 3.2 解决什么问题
1. 满足了消费者什么场景需求？
2. 是性能升级、设计差异、性价比优势还是生态兼容？
3. 产品是刚需、改善型还是可选消费？
4. 客户若不买该产品，会买什么替代品？

## 3.3 商业模式
1. 收入主要来自硬件、配件还是服务？
2. 是否存在高毛利配件或服务补充？
3. 是否形成多设备复购或生态联动？
4. 是否依赖单一平台、单一渠道或单一爆款？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在品类是高渗透存量市场还是新兴增量市场？
2. 增长来自换机还是新增用户？
3. 高中低价格带空间分别如何？
4. 海外市场是否存在更大机会？

## 5.2 行业格局
1. 头部品牌集中度高不高？
2. 白牌和价格战是否严重？
3. 渠道资源是否被大品牌垄断？
4. 公司所在细分赛道是否存在品牌升级机会？

## 5.3 行业趋势
1. 换机周期是在缩短还是拉长？
2. 消费者更偏好高端化还是性价比？
3. 多设备联动和智能家居生态是否提升？
4. 技术代际是否会重构市场？

# 九、财务尽调

## 9.1 收入质量
1. 增长是否由真实终端动销驱动？
2. 是否过度依赖单一爆款或单一渠道？
3. 海外收入是否具备持续性？
4. 服务和高毛利配件占比是否在提升？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 渠道返利和促销是否侵蚀利润？
3. 研发和营销投入是否有效？
4. 售后和质量成本是否可控？

## 9.3 现金流质量
1. 库存是否显著占用现金？
2. 新品备货是否导致现金流波动？
3. 渠道账期是否过长？
4. 是否依赖融资推动扩张？

## 9.4 资产负债表风险
重点看：
- 存货
- 存货跌价准备
- 应收账款
- 预付款
- 现金
- 有息负债
- 渠道保证金

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备产品、品牌或供应链经验？
2. 是否有成熟硬件研发和质量管理能力？
3. 渠道团队是否强？
4. 是否过度依赖创始人做关键决策？

## 10.2 组织能力
1. 是否具备新品开发 SOP？
2. 是否具备预测、备货和库存管理能力？
3. 售后体系是否成熟？
4. 海外团队和本地渠道管理是否有效？

## 10.3 激励机制
1. 销售激励是否导致压货？
2. 产品团队是否对长期用户价值负责？
3. 供应链团队是否兼顾成本与质量？
4. 海外渠道是否有长期激励绑定？

## 11.2 公司壁垒

1. 价格更低的竞品是否快速替代？

# 十二、风险尽调

## 12.1 业务风险
- 新品失败
- 爆款不可持续
- 渠道压货
- 品牌弱化
- 海外拓展不及预期
- 生态协同不足

## 12.2 财务风险
- 毛利下滑
- 返利促销过重
- 库存减值
- 应收回款慢
- 现金流承压
- 高研发投入回报不足

## 12.3 合规与法律风险
- 产品质量和召回风险
- 认证合规风险
- 专利和知识产权风险
- 数据和隐私风险（智能硬件）
- 海外关税与贸易政策风险
