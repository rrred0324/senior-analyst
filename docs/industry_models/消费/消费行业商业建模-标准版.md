# 一、行业基础定义

## 1.1 行业名称
- 行业名称：消费
- 细分赛道：食品饮料、美妆个护、服饰鞋包、母婴、宠物、家清、家居、潮玩、保健品、功能型消费品等
- 上下游位置：
  - 上游：原料、代工厂、包材、设计研发、供应链服务
  - 中游：品牌商、渠道商、零售商
  - 下游：消费者
- 主要服务对象：To C 为主，部分可延伸至渠道商、小B、KA、经销商

## 1.2 行业一句话定义
> 消费行业的本质是：围绕消费者的日常需求、情绪价值或身份表达，提供标准化商品或品牌体验，并通过产品溢价、渠道效率和复购实现持续收入与利润。

## 1.3 行业边界

### 覆盖范围
- 面向个人消费者销售标准化商品的品牌和零售业务
- 可规模化复制的消费品生意
- 具备一定产品、渠道或品牌心智的消费公司
- 线上线下一体化的品牌零售

### 不覆盖范围
- 纯平台流量业务
- 纯服务型消费如无标准化商品或无可复制模型的单店服务
- 纯上游原料公司
- 无稳定复购、无产品结构的临时性贸易业务

# 二、行业本质与核心价值

## 2.1 商业本质

消费行业的本质不是“卖货”，而是：

> 以产品力、品牌力和渠道力影响消费者选择，并在持续复购中实现规模和利润累积。

### 1）客户为什么需要它？
消费者购买消费品，通常出于：
- 基础功能需求
- 品质和体验需求
- 价格和性价比需求
- 情绪价值
- 社交表达和身份认同
- 健康、安全和便利需求

### 2）企业提供的核心价值是什么？
- 稳定满足某类消费需求
- 降低消费者决策成本
- 提供更好的口感/功效/设计/审美/品牌体验
- 建立可信赖的产品认知
- 通过渠道触达和内容传播提高购买便利性

### 3）企业为什么能赚钱？
消费企业赚钱的根本来源通常是：
- 毛利空间
- 品牌溢价
- 复购
- 渠道效率
- SKU 扩展和客单提升
- 规模放大带来的采购、生产和投放效率提升

消费行业典型链路：
