# 一、行业基础定义

## 1.1 行业名称
- 行业名称：消费
- 细分赛道：食品饮料、美妆个护、服饰鞋包、母婴、宠物、家清、家居、潮玩、保健品、功能型消费品等
- 上下游位置：
  - 上游：原料、代工厂、包材、设计研发、供应链服务
  - 中游：品牌商、渠道商、零售商
  - 下游：消费者
- 主要服务对象：To C 为主，部分可延伸至渠道商、小B、KA、经销商

## 1.2 行业一句话定义
> 消费行业的本质是：围绕消费者的日常需求、情绪价值或身份表达，提供标准化商品或品牌体验，并通过产品溢价、渠道效率和复购实现持续收入与利润。

## 1.3 行业边界

### 覆盖范围
- 面向个人消费者销售标准化商品的品牌和零售业务
- 可规模化复制的消费品生意
- 具备一定产品、渠道或品牌心智的消费公司
- 线上线下一体化的品牌零售

### 不覆盖范围
- 纯平台流量业务
- 纯服务型消费如无标准化商品或无可复制模型的单店服务
- 纯上游原料公司
- 无稳定复购、无产品结构的临时性贸易业务

# 二、行业本质与核心价值

## 2.1 商业本质

消费行业的本质不是“卖货”，而是：

> 以产品力、品牌力和渠道力影响消费者选择，并在持续复购中实现规模和利润累积。

### 1）客户为什么需要它？
消费者购买消费品，通常出于：
- 基础功能需求
- 品质和体验需求
- 价格和性价比需求
- 情绪价值
- 社交表达和身份认同
- 健康、安全和便利需求

### 2）企业提供的核心价值是什么？
- 稳定满足某类消费需求
- 降低消费者决策成本
- 提供更好的口感/功效/设计/审美/品牌体验
- 建立可信赖的产品认知
- 通过渠道触达和内容传播提高购买便利性

### 3）企业为什么能赚钱？
消费企业赚钱的根本来源通常是：
- 毛利空间
- 品牌溢价
- 复购
- 渠道效率
- SKU 扩展和客单提升
- 规模放大带来的采购、生产和投放效率提升

## 2.2 价值创造链条

消费行业典型链路：

```text
洞察需求
→ 产品定义
→ 研发/打样/供应链生产
→ 品牌与内容传播
→ 渠道铺设
→ 消费者购买
→ 使用体验
→ 复购/推荐
→ SKU扩展
→ 收入与利润积累
```

## 2.3 行业核心飞轮
```latex
更好的产品和体验
→ 更高复购和口碑
→ 更强品牌认知
→ 更高渠道效率和更低获客成本
→ 更大销售规模
→ 更强供应链议价和研发投入
→ 更好的产品和体验
```

消费里真正强的公司，飞轮不是单纯“投流卖货”，而是：

> 产品被复购，品牌被记住，渠道愿意推，最终形成稳定心智和利润结构。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：商品销售
+ 名称：Product Sales
+ 收费对象：消费者 / 渠道商
+ 收费方式：按件销售
+ 公式：

```latex
收入 = 销量 × 单价
```

### 模式二：品牌溢价
+ 名称：Brand Premium
+ 收费对象：消费者
+ 收费方式：通过高于同类白牌的价格实现更高毛利
+ 公式：

```latex
毛利 = 收入 - 商品成本
```

### 模式三：渠道分销
+ 名称：Distribution
+ 收费对象：经销商 / 零售终端
+ 收费方式：经销供货、批发模式
+ 公式：

```latex
分销收入 = 出货量 × 出厂价
```

### 模式四：DTC 直销
+ 名称：Direct-to-Consumer
+ 收费对象：终端消费者
+ 收费方式：电商、私域、小程序、门店直营
+ 公式：

```latex
DTC收入 = 购买用户数 × 购买频次 × 客单价
```

### 模式五：会员/衍生品/联名
+ 名称：Membership / Derivative
+ 收费对象：消费者
+ 收费方式：会员、礼盒、联名款、订阅制补充包等
+ 公式：

```latex
增值收入 = 增值购买人数 × 客均增值消费
```

## 4.2 行业最优商业模式
消费品牌最优模型通常具备：

+ 产品有复购
+ 品牌有心智
+ 渠道有效率
+ 毛利可支撑营销和组织
+ SKU 扩展能提高单客价值
+ 不依赖单一平台或单一爆款

也就是说，真正优质的消费生意不是：

> 一次性把货卖出去
>

而是：

> 让消费者持续回来买，并愿意为品牌和体验支付溢价。
>

## 4.3 从单品到品牌的变现路径
```latex
爆品切入
→ 建立用户认知
→ 提升复购
→ 扩展SKU
→ 建立品牌心智
→ 拓展渠道
→ 提高客单和利润率
→ 形成品牌资产
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 主商品收入 + 新SKU收入 + 渠道收入 + 会员/增值收入 + 其他收入
```

## 5.2 拆解驱动因子
### DTC 消费品牌常见拆法
```latex
收入 = 购买用户数 × 购买频次 × 客单价
```

### 分销型品牌常见拆法
```latex
收入 = 渠道终端数量 × 单终端动销 × 出厂价
```

### 品牌扩张常见拆法
```latex
收入增长 = 用户增长 + 复购提升 + 提价 + SKU扩展 + 渠道扩张
```

## 5.3 收入增长来源
+ 新用户增长
+ 老用户复购
+ 提价
+ 新品上市
+ 类目扩张
+ 渠道扩张
+ 区域扩张
+ 品牌升级带来溢价
+ 会员化和私域运营提升客单

# 六、成本模型
## 6.1 主要成本构成

+ 促销折扣
+ 退货损耗
+ 研发和打样成本
+ 团队与管理费用

## 6.2 成本分类方式
### 固定成本
+ 品牌建设
+ 组织管理
+ 基础研发
+ 部分渠道准入费用

### 可变成本
+ 原料
+ 包材
+ 生产
+ 履约
+ 广告投放
+ 平台佣金
+ 销售返利
+ 促销折扣

### 前端成本
+ 投流
+ 内容营销
+ 渠道上架
+ 达人合作
+ 终端促销

### 后端成本
+ 供应链
+ 仓配
+ 售后
+ 品控
+ 研发

## 6.3 单位经济模型
消费公司最常见看法是“单用户模型”或“单件商品模型”。

### 单用户模型
```latex
LTV = 用户生命周期购买次数 × 平均订单毛利
```

```latex
CAC = 获客总成本 / 新增购买用户数
```

### 单件模型
```latex
单件毛利 = 售价 - 生产成本 - 包材成本 - 平台扣点/渠道费用
```

### 核心判断
+ 投流能拉来首单不代表生意成立
+ 若复购弱，品牌价值往往不稳
+ 若毛利不足，营销放大会把利润吃掉
+ 若渠道铺得快但动销弱，容易形成库存风险

## 6.4 利润公式
```latex
利润 = 收入 - 商品成本 - 渠道费用 - 流量投放 - 仓配售后成本 - 管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
消费增长通常来自三件事：

+ 更多人买
+ 买得更频繁
+ 买得更多/更贵

即：

```latex
增长 = 用户增长 + 复购提升 + 客单提升
```

## 8.2 规模效应
规模扩大可能带来：

+ 原料和代工议价增强
+ 渠道谈判能力增强
+ 品牌投放效率提升
+ 研发和供应链成本摊薄
+ SKU 协同提升单客价值

## 8.3 网络效应
消费行业通常没有强经典网络效应，但会存在：

+ 品牌认知效应：买的人越多，品牌越容易被信任
+ 内容传播效应：社媒和用户分享提高转化
+ 渠道跟随效应：品牌越强，渠道越愿意铺

## 8.4 标准化与人力依赖程度
+ 标准化商品适合复制扩张
+ 若品牌过度依赖创始人 IP、单主播或单达人，稳定性较差
+ 若新品研发、渠道运营和供应链协同成熟，可持续性更强

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 多数消费赛道参与者多、竞争分散
+ 头部品牌会逐步建立心智和渠道优势
+ 白牌、代工、低价替代普遍存在
+ 渠道变化会重塑竞争格局
+ 新媒体时代品牌崛起速度快，但淘汰也快

## 9.2 常见壁垒类型
+ 产品壁垒：口感、配方、功效、设计、品质稳定性
+ 品牌壁垒：认知、信任、心智
+ 渠道壁垒：终端铺货、分销网络、KA关系、私域沉淀
+ 供应链壁垒：产能、品控、交付稳定性
+ 组织壁垒：上新、投放、渠道、运营协同能力
+ 用户复购壁垒：习惯形成和偏好沉淀

## 9.3 替代风险
+ 白牌低价替代
+ 大品牌价格下探
+ 渠道切换导致品牌势能减弱
+ 内容流量衰减
+ 爆品生命周期结束

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
目标品类消费总支出

### SAM
公司目标人群、目标价格带、目标渠道对应的可服务市场

### SOM
公司当前和中短期可实际获取的份额

## 12.2 通用测算公式
### 方法一：人群法
```latex
市场空间 = 目标消费者人数 × 年购买频次 × 客单价
```

### 方法二：品类法
```latex
市场空间 = 品类总体消费额 × 目标价格带占比 × 可触达渠道占比
```

### 方法三：渠道法
```latex
市场空间 = 可覆盖终端数 × 单终端年动销额
```

## 12.3 市场空间判断注意事项
+ 品类大不代表新品牌能轻易切入
+ 价格带、渠道和消费心智决定真实可得市场
+ 高复购赛道和低复购赛道不能同口径比较
+ 爆品型市场空间不等于品牌长期空间

# 十三、尽调与分析问题库
## 13.1 行业层问题

## 13.3 投资层问题

# 十四、快速分析卡
## 一句话本质
> 消费行业本质上是围绕消费者需求和品牌认知，通过产品力、渠道力和复购实现长期收入与利润积累的行业。
>

## 核心收入公式
```latex
收入 = 购买用户数 × 购买频次 × 客单价
```

或

```latex
收入 = 渠道点位数 × 单点位动销 × 出厂价
```

## 核心成本公式
```latex
成本 = 商品成本 + 渠道费用 + 流量投放 + 仓配售后成本 + 管理费用
```

## 核心判断三要素
1. 产品是否能复购
2. 品牌是否在形成心智
3. 渠道和供应链是否高效

## 最重要指标
+ 复购率
+ 毛利率
+ CAC / 投流ROI
+ 库存周转
+ 老客收入占比
+ 终端动销

## 最大风险
+ 爆品不可持续
+ 过度依赖投流
+ 渠道压货
+ 白牌替代
+ 品控风险

## 最终结论模板
> 消费行业的核心不是一时卖了多少货，而是消费者是否愿意持续复购、渠道是否愿意长期推动，以及品牌是否能沉淀为可持续溢价。真正决定长期价值的不是短期爆发，而是复购、心智和渠道效率。
>
