# 三、业务理解

## 3.1 公司到底做什么
1. 公司卖什么产品？
2. 满足的核心消费需求是什么？
3. 是单品公司、品牌公司还是渠道驱动型公司？
4. 当前收入主要由哪些 SKU 贡献？
5. 未来增长靠同品类深化还是跨品类扩张？

## 3.2 解决什么问题
1. 消费者为什么需要这类产品？
2. 为什么选择该品牌而不是竞品或白牌？
3. 产品提供的是功能价值、情绪价值还是身份表达？
4. 该需求是高频刚需还是低频可选？

## 3.3 商业模式
1. 主要收入来自直销、分销还是门店零售？
2. 线上、线下、自营、经销的收入占比各是多少？
3. 是否具备品牌溢价？
4. 是否有会员、订阅、礼盒、联名等额外变现方式？

- 生产方式：自有工厂 / 代工 / 混合

## 4.2 产品竞争力
1. 产品最核心差异化是什么？
2. 与竞品相比，口感、功效、品质、包装、价格有何差异？
3. 该差异化是否容易被模仿？
4. 是否做过盲测、复购追踪或 NPS 调研？
5. 产品是否能自然带动复购和口碑？

## 4.3 供应链与品控
1. 核心原料和代工是否稳定？
2. 是否依赖单一工厂或关键供应商？
3. 品控体系是否成熟？
4. 是否出现过质量事故、召回、食安问题？
5. 产能能否支撑未来增长？

# 五、市场与行业尽调

## 5.1 市场空间
1. 目标品类市场多大？
2. 目标价格带和目标人群空间多大？
3. 公司切入的是成熟市场还是新兴需求？
4. 是否具备从细分品类向更大品类扩张的空间？

## 5.2 行业格局
1. 头部品牌有哪些？
2. 品牌竞争核心在产品、渠道、投放还是价格？
3. 行业集中度如何？
4. 白牌和国际品牌分别构成什么压力？

## 5.3 行业趋势
1. 消费升级还是消费降级？
2. 新渠道是否重构行业？
3. 功能化、健康化、情绪化等趋势是否长期成立？
4. 行业是否存在政策、食安或广告监管变化？

# 九、财务尽调

## 9.1 收入质量
1. 收入增长来自真实终端动销还是压货？
2. 是否过度依赖单渠道、单品类或单 SKU？
3. 新品收入是否可持续？
4. 老客收入占比是否提升？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 销售费用率是否被投流抬高？
3. 渠道返利和促销是否侵蚀利润？
4. 品牌溢价是否真实存在？

## 9.3 现金流质量
1. 存货是否占用现金？
2. 是否存在回款慢或渠道退货风险？
3. 经营现金流是否匹配利润增长？
4. 扩渠道是否带来额外营运资金压力？

## 9.4 资产负债表风险
重点看：
- 现金
- 存货
- 应收账款
- 应付账款
- 预付款
- 渠道返利计提
- 有息负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队更强在产品、品牌、渠道还是供应链？
2. 是否有相应消费品经验？
3. 是否过度依赖单一创始人 IP 或头部操盘手？
4. 核心人才稳定性如何？

## 10.2 组织能力
1. 公司是否具备持续上新和打造 SKU 的能力？
2. 是否具备全渠道协同能力？
3. 供应链和品控团队是否成熟？
4. 数据化经营能力是否完善？

## 10.3 激励机制
1. 销售团队激励是否鼓励真实动销而非压货？
2. 品牌团队和渠道团队目标是否一致？
3. 是否建立对复购和利润负责的组织机制？
