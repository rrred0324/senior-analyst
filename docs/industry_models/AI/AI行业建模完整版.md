# 一、行业基础定义

## 1.1 行业名称
- 行业名称：AI
- 细分赛道：基础模型、垂类模型、AI 应用、AI Agent、Copilot、搜索与问答、内容生成、语音 AI、视觉 AI、AI Infra、向量数据库、模型调度、数据标注、AI 安全、MLOps / LLMOps 等
- 上下游位置：
  - 上游：算力、芯片、云资源、数据、开源模型、训练框架
  - 中游：模型训练、模型微调、中间层、工具链、推理服务
  - 下游：企业应用、开发者、消费者、行业解决方案
- 主要服务对象：To B、To C、开发者生态

## 1.2 行业一句话定义
> AI 行业的本质是：通过数据、模型、算力和产品化能力，将原本需要人工完成的认知、生成、判断和交互任务进行规模化自动化，并在效率提升、体验提升和新场景创造中实现商业价值。

## 1.3 行业边界

### 覆盖范围
- 基础模型、行业模型、推理服务、AI 中间件、AI 原生应用
- 与模型训练、部署、优化、调用、安全和评估直接相关的产品与服务
- 以 AI 能力为核心交付价值的应用或平台

### 不覆盖范围
- 不以 AI 为核心价值的传统软件
- 仅做简单自动化但无模型或智能能力的工具
- 概念性“AI+”但缺乏实际模型能力和产品交付的项目
- 单纯硬件业务且与 AI 软件能力无直接关系者

# 二、行业本质与核心价值

## 2.1 商业本质

AI 行业的本质不是“调用模型接口”，而是：

> 把模型能力稳定、低成本、可控地嵌入真实工作流，并让客户愿意持续为效率、质量或新能力付费。

### 1）客户为什么需要它？
客户需要 AI，通常因为：
- 降低人工成本
- 提升生产效率
- 缩短内容、代码、客服、运营等工作时间
- 获得传统软件无法提供的新能力
- 在复杂信息处理中提高响应质量
- 在用户体验和转化率上获得明显提升

### 2）企业提供的核心价值是什么？
- 提供自动化生成、理解、推荐、交互和决策辅助能力
- 降低客户在特定任务中的时间成本和人力成本
- 帮助客户把 AI 嵌入现有流程和系统
- 提供可控、可扩展、可集成的智能能力
- 提供持续优化和定制化能力

### 3）企业为什么能赚钱？
AI 企业的盈利来源通常包括：
- 订阅费
- 按量调用收费
- 席位费
- API 收入
- 项目实施费
- 私有化部署费
- 增值模块与高级功能收费
- 数据服务与模型优化服务收入

## 2.2 价值创造链条

AI 行业典型链路：

### AI 应用型
```text
识别高价值任务
→ 设计 AI 工作流
→ 集成模型能力
→ 打磨产品体验
→ 获得用户使用
→ 提升留存与复购
→ 放大收入
```

### 基础模型 / Infra 型
```latex
获取算力/数据
→ 模型训练/优化
→ 推理部署
→ 开发者或企业接入
→ 调用量增长
→ 成本优化与平台化
→ 收入增长
```

### 行业解决方案型
```latex
场景选择
→ 数据接入与流程适配
→ 模型微调/规则增强
→ 客户试点
→ 扩展到正式部署
→ 增购/续费/复制到更多客户
```

## 2.3 行业核心飞轮
```latex
更好产品效果与体验
→ 更多使用与数据反馈
→ 更好模型调优和工作流优化
→ 更高留存与口碑
→ 更多客户和调用量
→ 更低单位成本/更强生态
→ 更好产品效果与体验
```

AI 行业真正强的飞轮是：

> 模型效果、产品体验、工作流嵌入、数据反馈和成本优化共同形成的正循环，而不只是“模型参数更大”。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：订阅收费
+ 名称：Subscription
+ 收费对象：企业用户 / 个人用户
+ 收费方式：按月/年订阅、按席位收费
+ 公式：

```latex
收入 = 付费客户数 × ARPU
```

### 模式二：按量调用收费
+ 名称：Usage-based Pricing
+ 收费对象：开发者 / 企业
+ 收费方式：按 token、请求量、时长、生成量收费
+ 公式：

```latex
收入 = 调用量 × 单位调用价格
```

### 模式三：项目制与私有化部署
+ 名称：Project / Deployment
+ 收费对象：大型企业 / 政府 / 特定行业客户
+ 收费方式：一次性项目费 + 部署费 + 维护费
+ 公式：

```latex
收入 = 项目数量 × 平均合同金额
```

### 模式四：平台分成
+ 名称：Marketplace / Revenue Share
+ 收费对象：开发者 / 平台商家 / 合作伙伴
+ 收费方式：平台抽成、收益分成
+ 公式：

```latex
收入 = 平台 GMV 或开发者收入 × 抽成率
```

### 模式五：增值服务
+ 名称：Premium Services
+ 收费对象：企业 / 高阶用户
+ 收费方式：高级功能包、专属模型、客服支持、咨询服务
+ 公式：

```latex
收入 = 增值客户数 × 增值客单价
```

## 4.2 行业最优商业模式
AI 中高质量模型通常具备：

+ 明确高频高价值场景
+ AI 带来可量化 ROI
+ 留存和复购好
+ 模型调用成本可控
+ 对客户工作流嵌入深
+ 不是纯项目制堆收入
+ 有数据反馈和产品优化飞轮

理想模型不是：

> 依靠热点拉新，短期试用很多，但长期留存弱、成本倒挂
>

而是：

> 在真实场景中持续被使用，能证明 AI 带来效率提升、成本下降或收入提升，并且随着规模扩大单位经济持续改善。
>

## 4.3 从单点能力到平台化路径
```latex
先切入一个高频高价值任务
→ 建立用户心智和使用习惯
→ 扩展更多功能和工作流
→ 提升集成和协作能力
→ 形成平台或操作系统级入口
```

# 五、收入模型

```latex
总收入 = 订阅收入 + 按量调用收入 + 项目/部署收入 + 增值服务收入 + 平台分成收入 + 其他收入
```

```latex
收入 = 用户数 × 付费率 × ARPU
```

### 企业 AI SaaS 常见拆法
```latex
收入 = 客户数 × 席位数 × 单席位价格
```

### API / Infra 常见拆法
```latex
收入 = 调用量 × 单位价格
```

### 项目制常见拆法
```latex
收入 = 项目数 × 客单价
```

## 5.3 收入增长来源
+ 新用户获取
+ 付费率提升

# 六、成本模型
## 6.1 主要成本构成
+ 算力成本
+ 模型训练成本
+ 推理成本
+ 数据获取与标注成本
+ 研发人员成本
+ 产品与设计成本
+ 销售与客户成功成本
+ 云基础设施成本
+ 模型安全与合规成本
+ 实施与交付成本

## 6.2 成本分类方式
### 固定成本
+ 核心研发团队
+ 模型训练投入
+ 产品和平台研发
+ 安全与评测体系
+ 管理成本

### 可变成本
+ 推理 token 成本
+ API 调用云资源
+ 第三方模型调用费用
+ 数据处理成本
+ 客服与支持成本
+ 渠道分成

### 前端成本
+ 获客成本
+ 试用和样本交付
+ 售前解决方案支持
+ 实施成本

### 后端成本
+ 模型推理
+ 质量监控
+ 运维
+ 安全合规
+ 客户成功与续费服务

## 6.3 单位经济模型
### AI 应用型
```latex
单用户毛利 = ARPU - 单用户推理成本 - 渠道成本 - 客服成本
```

### API / Infra 型
```latex
单次调用毛利 = 单次调用收入 - 单次推理/带宽/存储成本
```

### 企业 AI SaaS 型
```latex
单客户生命周期价值 = 年合同毛利 × 留存年限 - 实施与服务成本
```

### 项目型
```latex
单项目毛利 = 项目合同金额 - 交付人力成本 - 算力/部署成本
```

### 核心判断
+ AI 公司最容易出现“收入增长，但算力成本吞噬毛利”
+ 使用量增长不一定带来利润增长，关键看单位推理成本是否下降
+ 项目收入看起来大，但若不可复制，估值质量会下降
+ 真正好的模式是：高留存 + 成本可控 + 产品化强 + 复用度高

## 6.4 利润公式
```latex
利润 = 收入 - 算力/推理/云成本 - 研发成本 - 销售费用 - 实施与客户成功成本 - 管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
AI 增长通常来自：

+ 更好的模型效果
+ 更强产品体验
+ 更深场景嵌入
+ 更多调用和使用深度
+ 企业内横向扩张
+ 价格体系优化
+ 新模态能力开放
+ 开发者生态扩张
+ 渠道合作放大分发

## 8.2 规模效应
规模扩大后可能带来：

+ 算力采购议价增强
+ 模型推理优化
+ 更多反馈数据
+ 品牌与生态增强
+ 更低获客成本
+ 更高交叉销售机会

## 8.3 网络效应
AI 不是所有赛道都强网络效应，但可能存在：

+ 平台侧开发者生态网络效应
+ 数据反馈和工作流网络效应
+ 协作场景中的组织嵌入效应
+ 插件与第三方集成生态效应

## 8.4 产品化与切换成本
+ 真正的切换成本来自工作流嵌入，而不是模型本身
+ 单点能力容易同质化，场景和流程整合更重要
+ 企业级产品越深入系统，切换成本越高
+ C 端产品需警惕新鲜感驱动而非刚需驱动

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 基础模型层头部集中明显
+ AI 应用层极度分散，变化快
+ 企业级 AI 解决方案需拼产品化和行业 know-how
+ Infra 工具层更容易形成平台粘性
+ 开源模型降低了底层门槛，但提升了产品层竞争强度

## 9.2 常见壁垒类型
+ 工作流与产品嵌入壁垒
+ 数据与反馈壁垒
+ 算力与成本优化壁垒
+ 开发者生态壁垒
+ 行业 know-how 与场景壁垒
+ 品牌与信任壁垒
+ 安全与合规壁垒
+ 销售和实施壁垒

## 9.3 替代风险
+ 底层模型快速升级导致上层能力被吞噬
+ 开源模型替代闭源能力
+ 大平台进入同类场景
+ 客户自建 AI 能力
+ 项目制方案被标准化产品替代

# 十、行业风险分析
## 10.1 通用风险项
+ 技术迭代过快
+ 成本结构失控
+ 留存差
+ 同质化严重
+ 安全与合规风险
+ 模型效果不稳定
+ 客户 ROI 不明显
+ 对单一模型或云厂商依赖
+ 大厂进入
+ 商业模式不成立

## 10.2 风险信号模板
+ 用户增长快但留存迅速下滑
+ 收入增长依赖低毛利项目
+ API 调用增长但毛利不升反降
+ 大量客户 PoC，正式采购很少
+ 产品高度依赖第三方模型且无差异化
+ 安全、数据或合规问题频发

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
对应目标任务和目标场景的全球/区域总市场，不是“所有知识工作者都算”

### SAM
公司当前模型能力、产品能力、销售能力和区域覆盖下可服务的具体市场

### SOM
公司中短期能实际获取的用户、客户和调用规模

## 12.2 通用测算公式
### 方法一：任务替代法
```latex
市场空间 = 可被 AI 替代/增强的任务量 × 单任务价值
```

### 方法二：席位法
```latex
市场空间 = 目标用户数 × 每用户年收入
```

### 方法三：API 调用法
```latex
市场空间 = 调用次数 × 单次调用价格
```

## 12.3 市场空间判断注意事项

# 十四、快速分析卡
## 一句话本质
> AI 行业本质上是把模型能力嵌入真实工作流，以更低成本、更高效率或全新体验完成原本需要人工完成的认知和生成任务的行业。
>

## 核心收入公式
```latex
收入 = 用户/客户数 × 付费率 × ARPU
或
收入 = 调用量 × 单位调用价格
```

## 核心成本公式
```latex
成本 = 算力/推理/云成本 + 研发成本 + 数据成本 + 销售与客户成功成本
```

## 核心判断三要素
1. 是否解决高频高价值任务
2. 留存和使用深度是否真实
3. 成本结构和单位经济是否可持续

## 最重要指标
+ 留存率
+ NRR
+ 付费率
+ ARPU
+ 调用量
+ 推理成本占比
+ 毛利率
+ CAC 回收周期

## 最大风险
+ 同质化
+ 留存差
+ 模型成本过高
+ 底层替代
+ 合规与安全风险

## 最终结论模板
> AI 行业的核心不是是否使用了最先进的模型，而是能否把模型能力嵌入真实场景并持续创造 ROI。真正决定长期价值的不是“会不会 AI”，而是产品是否高频刚需、工作流是否可嵌入、留存是否扎实、成本是否可控，以及是否能在快速迭代中保持差异化。
>
