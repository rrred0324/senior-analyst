# 三、业务理解

## 3.1 公司到底做什么
1. 公司处于模型层、工具层还是应用层？
2. 核心产品是什么？
3. 面向 C 端、B 端还是开发者？
4. 收入主要来自订阅、调用、项目还是私有化部署？
5. 公司本质更像产品公司、平台公司还是解决方案公司？

## 3.2 解决什么问题
1. AI 帮客户替代或增强了什么任务？
2. 与传统软件或人工方式相比价值提升有多大？
3. 用户最核心的使用动机是什么？
4. 如果不用这个产品，客户会怎么解决？

## 3.3 商业模式
1. 是否具备高复用、可复制的产品形态？
2. 收入中项目制占比高不高？
3. 是否过度依赖第三方模型、云平台或渠道？
4. 是否具备从单点能力向平台扩展的路径？

## 5.3 行业趋势
1. 底层模型迭代是否会压缩上层空间？
2. AI Agent、Copilot、私有化部署等趋势是否利好？

4. 海外和国内市场的节奏是否不同？

# 九、财务尽调

## 9.1 收入质量
1. 收入是订阅型、使用型还是项目型？
2. 是否存在大客户项目撑起收入的情况？
3. 是否有真实续费和扩张收入？
4. 免费用户是否有效转化为付费？

## 9.2 利润质量
1. 推理成本是否可控？
2. 毛利率是否随规模改善？
3. 第三方模型费用是否侵蚀利润？
4. 项目交付成本是否被低估？

## 9.3 现金流质量
1. Burn Rate 多高？
2. Runway 还有多久？
3. 获客投入和收入释放是否匹配？
4. 是否需要持续高额融资维持增长？

## 9.4 资产负债表风险
重点看：
- 现金
- 应收账款
- 递延收入
- 资本化研发
- 有息负债
- 服务器与基础设施投入

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否兼具技术、产品和商业化能力？
2. 是否有大模型、Infra 或 SaaS 产品经验？
3. 是否过度依赖单一技术负责人？
4. 销售与客户成功团队是否适配企业 AI 业务？

## 10.2 组织能力
1. 公司更强在模型、工程、产品还是销售？
2. 是否具备快速迭代能力？
3. 是否建立起数据反馈与模型评测机制？
4. 是否有能力支持企业级部署和售后？

## 10.3 激励机制
1. 研发和产品团队激励是否支持长期创新？
2. 销售激励是否会诱导低质量项目收入？
3. 核心算法与工程人才流失风险如何？

# 十二、风险尽调

## 12.1 业务风险
- 留存弱
- 场景伪需求
- 同质化竞争
- 热点驱动后增长回落
- PoC 多但采购少
- 产品不可复制

## 12.2 财务风险
- 毛利低
- 推理成本高
- 获客成本过高
- 现金消耗快
- 项目制收入波动大

## 12.3 合规与法律风险
- 数据合规风险
- 内容版权风险
- 隐私风险
- AI 生成错误责任风险
- 行业监管变化风险
