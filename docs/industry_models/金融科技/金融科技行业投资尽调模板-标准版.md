# 三、业务理解

## 3.1 公司到底做什么
1. 公司位于支付、融资、理财、保险链条的哪个环节？
2. 核心产品解决什么问题？
3. 目标客户是谁？
4. 核心收入来自哪一类产品和场景？
5. 公司扮演的是平台、技术服务商还是交易基础设施？

## 3.2 解决什么问题
1. 相比传统金融流程，公司提升了什么效率？
2. 用户或机构为什么必须使用它？
3. 核心价值是触达、风控、产品匹配还是运营效率？
4. 若没有该公司，客户会用什么替代？

## 3.3 商业模式
1. 收入来自手续费、技术费、撮合费、分润还是增值服务？
2. 是否承担信用风险、通道风险或资金风险？
3. 变现模式是否清晰且合规？
4. 是否具备多产品、多层次变现空间？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在细分市场交易空间有多大？
2. 可得市场是否受牌照和监管限制？
3. 公司做的是增量需求还是存量数字化替代？
4. 是否具备跨场景扩张机会？

## 5.2 行业格局
1. 头部参与者是谁？
2. 持牌机构、自建系统与第三方科技公司各自份额如何？
3. 是流量竞争、技术竞争、风控竞争还是机构合作竞争？
4. 大平台是否会形成挤压？

## 5.3 行业趋势
1. 监管趋严还是放松？
2. 数据与隐私规则是否变化？
3. 金融机构自建能力是否增强？
4. AI 是否提升风控和客服效率？

# 九、财务尽调

## 9.1 收入质量
1. 各类收入结构是否清晰？
2. 高毛利收入是否可持续？
3. 是否依赖单一机构、单一大客户或单一流量入口？
4. 是否存在高风险收入被包装为科技服务收入？

## 9.2 利润质量
1. 毛利率受通道成本和分润成本影响多大？
2. 风险成本是否被充分体现？
3. 研发投入是否足以支撑长期能力？
4. 合规投入是否充足？

## 9.3 现金流质量
1. 经营现金流是否与收入和利润匹配？
2. 是否存在回款周期过长或风险准备金占用？
3. 交易沉淀资金如何管理？
4. 是否有潜在表外风险压缩未来现金流？

## 9.4 资产负债表风险
重点看：
- 现金
- 应收账款
- 风险准备金
- 表内外敞口
- 有息负债
- 拨备和减值
- 合同负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备金融、技术、风控、合规复合背景？
2. 是否有大型金融机构或平台经验？
3. 是否存在关键岗位单点依赖？
4. 核心团队在监管沟通上是否成熟？

## 10.2 组织能力
1. 公司更强在流量、技术、风控还是机构合作？
2. 合规、法务、风控是否和业务同等重要？
3. 是否具备跨周期运营能力？
4. 数据驱动决策能力是否成熟？

## 10.3 激励机制
1. 是否过度激励规模，忽视资产质量和合规？
2. 风控与业务团队是否存在目标冲突？
3. 核心技术与合规人才稳定性如何？

## 11.2 公司壁垒

# 十二、风险尽调

## 12.1 业务风险
- 单一合作机构依赖
- 通道依赖
- 风控失效
- 交易欺诈
- 增长依赖高风险客群
- 场景集中度过高

## 12.2 财务风险
- 风险成本低估
- 分润和通道成本上升
- 现金流承压
- 应收和准备金波动
- 收入结构失真

## 12.3 合规与法律风险
- 牌照合规
- 数据合规
- 反洗钱与 KYC
- 消费者保护
- 催收合规
- 金融营销合规
- 跨境支付/跨境数据合规
