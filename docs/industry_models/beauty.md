# 一、行业基础定义

## 1.1 行业名称
- 行业名称：美妆个护
- 英文常用称呼：Beauty & Personal Care
- 细分赛道：护肤、彩妆、洗护发、口腔护理、身体护理、香氛、美容仪、男士个护、婴童个护、功能性护肤、专业美业零售化产品等
- 上下游位置：
  - 上游：原料供应商、包材供应商、ODM/OEM、检测备案机构、研发实验室、设备制造商
  - 中游：品牌方、渠道品牌、DTC 品牌、分销商、代运营、电商服务商
  - 下游：消费者、电商平台、线下零售、美妆集合店、商超、CS 渠道、百货、医美/美容院渠道
- 主要服务对象：To C 为主，部分 To B（渠道、代理、专业线机构）

## 1.2 行业一句话定义
> 美妆个护行业的本质是：围绕清洁、护理、修饰、美感和功效需求，向消费者持续提供高感知、高复购或高客单的消费产品，并通过品牌心智、产品功效和渠道运营实现变现。

## 1.3 行业边界

### 覆盖范围
- 直接面向消费者的美妆和个人护理产品
- 通过线上线下渠道销售的品牌型美妆个护业务
- 具备消费属性的功能型护理和仪器类产品
- 相关 ODM/OEM、渠道型和品牌服务型业务

### 不覆盖范围
- 纯医美服务机构本体
- 完全不面向终端消费者的化工原料业务
- 单纯代运营但不深度参与美妆个护品牌逻辑的服务公司
- 医疗器械中与消费个护弱相关的纯医疗产品

# 二、行业本质与核心价值

## 2.1 商业本质

美妆个护行业的本质不是“卖一瓶产品”，而是：

> 在消费者对功效、审美、身份表达和日常护理的持续需求中，通过可信产品力和品牌心智占据用户浴室柜、梳妆台和护肤流程中的固定位置。

### 1）客户为什么需要它？
消费者需要美妆个护产品，通常因为：
- 清洁、护理、防护、修饰等日常需求高频存在
- 对皮肤、头发、口腔、身体状态有持续管理需求
- 希望获得更好的外观表现、自我表达和情绪满足
- 对安全性、成分、功效和使用体验越来越敏感
- 社交媒体和内容种草持续强化消费教育与需求激发

### 2）企业提供的核心价值是什么？
- 提供改善外观、肤感、气味和个人状态的产品
- 满足不同年龄、肤质、场景和预算的护理需求
- 提供功能价值（保湿、美白、抗老、控油、防晒等）
- 提供情绪价值、品牌认同和生活方式表达
- 通过组合产品构建完整护理流程，提高复购和客单

### 3）企业为什么能赚钱？
美妆个护企业盈利来源通常包括：
- 单品销售收入
- 套组销售收入
- 渠道分销收入
- 会员复购收入
- 高毛利爆品收入
- 专业线/机构渠道收入
- OEM/ODM 供货收入
- 跨品类扩展收入

## 2.2 价值创造链条

美妆个护行业典型链路：

### 品牌零售型
```text
洞察消费者需求
→ 产品研发与打样
→ 包装、备案和量产
→ 内容种草与投放
→ 电商/线下销售
→ 复购与品牌沉淀
```

### DTC 品牌型
```latex
打造爆品
→ 获得线上流量
→ 首购转化
→ 私域/会员沉淀
→ 多品类复购
→ 提升 LTV
```

### 渠道分销型
```latex
建立品牌或代理资源
→ 进入渠道网络
→ 铺货陈列和动销
→ 提升周转
→ 扩大渠道覆盖
```

## 2.3 行业核心飞轮
```latex
更强产品力和用户口碑
→ 更高转化与复购
→ 更强渠道议价和品牌势能
→ 更高毛利和研发投入
→ 更强产品力和用户口碑
```

美妆个护行业真正强的飞轮是：

> 爆品验证 + 品牌认知 + 渠道放大 + 复购沉淀 + 多品类扩张。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：品牌零售
+ 名称：Branded Retail
+ 收费对象：消费者 / 渠道
+ 收费方式：按单品或套组销售
+ 公式：

```latex
收入 = 销量 × 单价
```

### 模式二：渠道分销
+ 名称：Channel Distribution
+ 收费对象：经销商 / 零售渠道
+ 收费方式：批发供货
+ 公式：

```latex
收入 = 出货量 × 出厂价
```

### 模式三：DTC 直销
+ 名称：Direct-to-Consumer
+ 收费对象：终端消费者
+ 收费方式：自营电商、小程序、私域成交
+ 公式：

```latex
收入 = 订单数 × 客单价
```

### 模式四：会员与复购
+ 名称：Membership / Repurchase
+ 收费对象：老用户
+ 收费方式：复购、订阅、会员活动
+ 公式：

```latex
收入 = 复购用户数 × 复购频次 × 复购客单价
```

### 模式五：OEM / ODM
+ 名称：OEM / ODM Revenue
+ 收费对象：品牌方 / 渠道方
+ 收费方式：按订单生产供货
+ 公式：

```latex
收入 = 订单量 × 单位供货价
```

## 4.2 行业最优商业模式
美妆个护行业中高质量模型通常具备：

+ 产品在特定人群中具备明确心智和口碑
+ 核心大单品能支撑稳定复购
+ 渠道结构均衡，不严重依赖单一平台
+ 获客成本可控，老客复购能覆盖投放波动
+ 毛利率足够高，支持品牌和研发投入
+ 有能力从单爆品扩展到系列化、多品类

理想模型不是：

> 靠短期流量和达人带货冲销量、退货高、复购弱、上新无体系、渠道切换即崩
>

而是：

> 以可信产品力建立品牌心智，在可控投放成本下获取新客，并通过复购、套组和多品类扩张持续提升用户终身价值。
>

## 4.3 从爆品到品牌路径
```latex
找到细分需求
→ 打造爆品并验证口碑
→ 建立内容和渠道心智
→ 提高复购和会员沉淀
→ 扩展相邻品类
→ 建立品牌矩阵
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 线上零售收入 + 线下零售收入 + 分销收入 + 私域收入 + 专业线收入 + OEM/ODM 收入
```

## 5.2 拆解驱动因子
### 电商品牌
```latex
收入 = 流量 × 转化率 × 客单价
```

### DTC 品牌
```latex
收入 = 新客收入 + 老客复购收入
新客收入 = 新客数 × 首购客单价
老客收入 = 老客数 × 复购频次 × 复购客单价
```

### 线下渠道品牌
```latex
收入 = 覆盖门店数 × 单店动销 × 补货频次
```

### 爆品模型
```latex
收入 = 爆品销量 × 爆品 ASP + 非爆品组合收入
```

### OEM / ODM 模型
```latex
收入 = 客户数 × 单客户订单额
```

## 5.3 收入增长来源
+ 新客增长
+ 转化率提升
+ 客单价提升
+ 复购率提升
+ 爆品持续放量
+ 新品成功率提升
+ 新渠道扩展
+ 线下渗透率提升
+ 海外渠道扩张
+ 多品类扩张

## 6.3 单位经济模型
### 单订单模型
```latex
单订单毛利 = 客单价 - 产品成本 - 平台佣金 - 履约成本 - 投放分摊
```

### 单用户模型
```latex
LTV = 首购毛利 + 各期复购毛利总和
CAC = 获客总投入 / 新客数
```

### 单爆品模型
```latex
单爆品贡献 = 爆品收入 - 爆品生产成本 - 推广成本 - 退货与售后成本
```

### 核心判断
+ 美妆个护很多品牌表面毛利高，但投放后真实利润未必高
+ 新客获客效率与复购质量决定品牌能否穿越平台流量波动
+ 爆品是入口，复购和多品类才决定长期价值
+ 库存周转和退货率常常是容易被忽略的利润杀手

## 6.4 利润公式
```latex
利润 = 总收入 - 产品成本 - 营销投放 - 渠道费用 - 履约售后 - 研发备案 - 团队管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
美妆个护增长通常来自：

+ 打造高转化爆品
+ 增强内容种草和品牌心智
+ 提升复购与会员留存
+ 从单品扩展到系列化
+ 渗透更多渠道和价格带
+ 从线上扩展到线下
+ 从女性扩展到男性、家庭和细分场景
+ 从国内市场扩展到海外市场

## 8.2 规模效应
规模扩大后可能带来：

+ 更强供应链议价
+ 更低采购和生产成本
+ 更强品牌心智
+ 更高渠道议价能力
+ 更高投放效率
+ 更好的新品测试能力
+ 更低单位履约成本

## 8.3 网络效应
行业强网络效应有限，但内容和口碑存在弱网络效应：

+ 用户口碑越强，种草效率越高
+ 达人内容越多，平台转化越强
+ 会员基数越大，复购和新品冷启动越容易
+ 渠道覆盖越广，品牌心智越稳固

## 8.4 周期与消费逻辑
+ 美妆个护整体兼具刚需和可选消费属性
+ 护肤、洗护、口腔更偏刚需，韧性更强
+ 彩妆、香氛、美容仪更受消费情绪影响
+ 平台流量和内容趋势变化会显著影响品牌增长节奏
+ 原料法规、备案规范和宣传监管会影响产品迭代速度

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 国际大牌与本土品牌长期并存
+ 国货品牌在内容电商和成分认知上持续崛起
+ 行业竞争激烈，进入门槛不高但持续胜出难
+ 平台流量重构品牌崛起路径，但也加速淘汰

## 9.2 常见壁垒类型

+ 平台流量迁移导致替代

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
目标人群在护肤、彩妆、洗护、个护等品类上的总消费支出

### SAM
公司当前人群、价格带、渠道和品类下可服务市场

### SOM
公司中短期可获得的品牌销售额或渠道份额

## 12.2 通用测算公式
### 方法一：人群消费法
```latex
市场空间 = 目标人群数量 × 年均消费频次 × 单次消费额
```

### 方法二：品类拆分法
```latex
市场空间 = 护肤市场 + 彩妆市场 + 洗护市场 + 口腔市场 + 身体护理市场
```

### 方法三：渠道渗透法
```latex
市场空间 = 目标渠道终端数 × 单终端年动销额
```

### 方法四：复购模型法
```latex
收入空间 = 用户数 × 客单价 × 年复购次数
```

## 12.3 市场空间判断注意事项
+ 品类空间大不等于品牌空间大
+ 高毛利不代表高净利，要看投放和渠道成本
+ 需区分刚需高复购品类和趋势型低复购品类
+ 爆品型公司和品牌型公司估值逻辑不同

```latex
收入 = 新客数 × 首购客单价 + 老客数 × 复购频次 × 复购客单价

```

1. 产品是否具备真实口碑和复购
2. 获客成本与用户终身价值是否匹配
3. 是否能从爆品走向系列化品牌
