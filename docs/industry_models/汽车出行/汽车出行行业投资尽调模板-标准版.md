# 三、业务理解

## 3.1 公司到底做什么
1. 公司是卖车、卖运力、做平台撮合，还是做车后服务和软件？
2. 核心资产是车辆、品牌、用户、司机网络还是技术系统？
3. 客户最核心的使用场景是什么？
4. 公司在价值链中最强的一环是什么？
5. 公司更像制造业、平台型互联网公司，还是运营型服务公司？

## 3.2 解决什么问题
1. 对用户来说，解决的是购车、叫车、用车还是养车问题？
2. 对司机或车队来说，解决的是获客、调度、收入稳定还是运营成本问题？
3. 对企业客户来说，解决的是车队效率、管理透明度还是运输成本问题？
4. 如果没有该公司，客户会选择什么替代方案？

## 3.3 商业模式
1. 收入来自销售、抽成、租金、服务费还是软件订阅？
2. 是否依赖一次性交易？
3. 是否能延展到金融、保险、维保、能源等增值收入？
4. 是否存在显著补贴依赖？

# 五、市场与行业尽调

## 5.1 市场空间
1. 对应的是整车市场、城市出行市场、企业车队市场还是后市场？
2. 市场是否仍在增长，驱动来自渗透率提升还是存量替代？
3. 不同城市、区域的政策和市场差异如何？
4. 海外市场机会如何？

## 5.2 行业格局
1. 主要竞争对手是谁？
2. 行业头部壁垒来自品牌、资金、牌照、算法还是服务网络？
3. 公司在区域、价格带或场景中的竞争位置是什么？
4. 利润主要沉淀在哪个环节？

## 5.3 行业趋势
1. 新能源渗透、智能化升级是否改变成本结构？
2. 自动驾驶何时会对现有模式构成实质影响？
3. 后市场数字化、连锁化整合趋势如何？
4. 监管政策是否趋严或趋松？

# 九、财务尽调

## 9.1 收入质量
1. 收入结构是否多元？
2. 是否过度依赖单一城市、单一车型或单一客户群？
3. 销售/订单增长是否依赖大额补贴？
4. 软件、服务和后市场收入占比是否提升？

## 9.2 利润质量
1. 单车或单订单毛利是否改善？
2. 折旧、能源、保险和事故成本是否可控？
3. 价格战是否明显侵蚀利润？
4. 平台抽成、软件订阅或后市场服务是否能增厚毛利？

## 9.3 现金流质量
1. 经营现金流是否和规模增长同步？
2. 车辆采购、库存或固定资产是否消耗过多现金？
3. 是否依赖融资支持扩张和补贴？
4. 回款周期是否健康？

## 9.4 资产负债表风险
重点看：
- 存货
- 车辆资产
- 固定资产
- 现金
- 应收账款
- 有息负债
- 合同负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否兼具产品、运营、供应链或交通行业经验？
2. 是否有跨城市或大规模运营经验？
3. 是否过度依赖单一核心人物？
4. 智能化和软件团队是否足够强？

## 10.2 组织能力
1. 公司更强在制造、平台运营、车队管理还是服务网络？
2. 是否具备复杂履约和安全管理能力？
3. 是否能在扩张中保持服务质量？
4. 中后台数据与风控体系是否成熟？

## 10.3 激励机制
1. 销售或城市团队激励是否导致低质量增长？
2. 司机激励是否过度依赖补贴？
3. 是否在规模、盈利和安全之间建立平衡考核？

## 11.2 公司壁垒
1. 壁垒来自品牌、制造、牌照、运力网络还是数据系统？

# 十二、风险尽调

## 12.1 业务风险
- 价格战
- 补贴依赖
- 单车利用率不足
- 司机流失
- 区域扩张失败
- 安全和服务质量恶化

## 12.2 财务风险
- 单位经济恶化
- 重资产扩张导致现金流压力
- 库存与折旧风险
- 事故与保险成本上升
- 融资依赖高

## 12.3 合规与法律风险
- 网约车牌照和合规风险
- 交通事故责任风险
- 自动驾驶测试与运营合规
- 消费者权益风险
- 数据与隐私风险
- 广告和促销合规风险
