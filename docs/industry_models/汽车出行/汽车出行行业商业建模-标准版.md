# 一、行业基础定义

## 1.1 行业名称
- 行业名称：汽车出行
- 细分赛道：乘用车、商用车、新能源汽车、智能驾驶、网约车、共享汽车、车联网、汽车后市场、车队管理、自动驾驶出行服务等
- 上下游位置：
  - 上游：电池、电机、电控、芯片、传感器、域控制器、零部件、地图与软件供应商、能源补给设施
  - 中游：整车厂、Tier1、出行平台、车队运营商、汽车流通与服务商、自动驾驶方案商
  - 下游：个人用户、企业客户、司机、车队、物流公司、公共交通补充需求方
- 主要服务对象：To C + To B 混合，部分环节强运营属性

## 1.2 行业一句话定义
> 汽车出行行业的本质是：围绕“人和货的移动需求”，通过车辆、能源、软件、网络和运营体系，提供更高效、更安全、更低成本的交通工具与出行服务的行业。

## 1.3 行业边界

### 覆盖范围
- 车辆制造与销售
- 出行平台撮合与运营
- 车队与车辆资产运营
- 汽车数字化服务与车联网
- 汽车后市场服务
- 面向出行场景的自动驾驶和智能驾驶服务

### 不覆盖范围
- 与交通运输弱相关的通用消费电子
- 单纯零部件制造但不构成出行业务分析主体的基础工业品
- 不直接围绕车辆使用和出行服务的纯软件工具
- 传统非机动车出行（除非平台业务与汽车出行强绑定）

# 二、行业本质与核心价值

## 2.1 商业本质

汽车出行行业的本质不是“卖车”或“撮合订单”，而是：

> 通过车辆供给、调度能力、能源补给、数字化系统和服务网络，降低单位出行成本、提升通行效率和服务体验，并在高频出行场景中建立持续交易或资产回报能力。

### 1）用户为什么需要它？
用户需要汽车出行产品和服务，通常因为：
- 个人通勤与家庭出行需求
- 商务出行与即时交通需求
- 更高效率、更灵活的点对点移动
- 更低总拥有成本或更低单次出行成本
- 更好的舒适性、安全性和智能体验
- 货运与车队运营效率提升

### 2）企业提供的核心价值是什么？
- 提供可靠交通工具或运力供给
- 让出行更方便、可得、可调度
- 降低购车、用车、出行或运营成本
- 提升车辆使用效率和周转效率
- 提供智能化、联网化和数据化体验
- 对车队和企业客户提供运营优化能力

### 3）企业为什么能赚钱？
汽车出行企业的盈利来源通常包括：
- 整车销售收入
- 软件和智能化功能收入
- 出行订单佣金或抽成
- 运力资产运营收益
- 金融、保险、延保等增值服务收入
- 维保、能源补给和后市场收入
- 车联网和数据服务收入
- 自动驾驶服务收入（中长期）
