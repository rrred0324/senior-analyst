# 一、行业基础定义

## 1.1 行业名称
- 行业名称：汽车出行
- 细分赛道：乘用车、商用车、新能源汽车、智能驾驶、网约车、共享汽车、车联网、汽车后市场、车队管理、自动驾驶出行服务等
- 上下游位置：
  - 上游：电池、电机、电控、芯片、传感器、域控制器、零部件、地图与软件供应商、能源补给设施
  - 中游：整车厂、Tier1、出行平台、车队运营商、汽车流通与服务商、自动驾驶方案商
  - 下游：个人用户、企业客户、司机、车队、物流公司、公共交通补充需求方
- 主要服务对象：To C + To B 混合，部分环节强运营属性

## 1.2 行业一句话定义
> 汽车出行行业的本质是：围绕“人和货的移动需求”，通过车辆、能源、软件、网络和运营体系，提供更高效、更安全、更低成本的交通工具与出行服务的行业。

## 1.3 行业边界

### 覆盖范围
- 车辆制造与销售
- 出行平台撮合与运营
- 车队与车辆资产运营
- 汽车数字化服务与车联网
- 汽车后市场服务
- 面向出行场景的自动驾驶和智能驾驶服务

### 不覆盖范围
- 与交通运输弱相关的通用消费电子
- 单纯零部件制造但不构成出行业务分析主体的基础工业品
- 不直接围绕车辆使用和出行服务的纯软件工具
- 传统非机动车出行（除非平台业务与汽车出行强绑定）

# 二、行业本质与核心价值

## 2.1 商业本质

汽车出行行业的本质不是“卖车”或“撮合订单”，而是：

> 通过车辆供给、调度能力、能源补给、数字化系统和服务网络，降低单位出行成本、提升通行效率和服务体验，并在高频出行场景中建立持续交易或资产回报能力。

### 1）用户为什么需要它？
用户需要汽车出行产品和服务，通常因为：
- 个人通勤与家庭出行需求
- 商务出行与即时交通需求
- 更高效率、更灵活的点对点移动
- 更低总拥有成本或更低单次出行成本
- 更好的舒适性、安全性和智能体验
- 货运与车队运营效率提升

### 2）企业提供的核心价值是什么？
- 提供可靠交通工具或运力供给
- 让出行更方便、可得、可调度
- 降低购车、用车、出行或运营成本
- 提升车辆使用效率和周转效率
- 提供智能化、联网化和数据化体验
- 对车队和企业客户提供运营优化能力

### 3）企业为什么能赚钱？
汽车出行企业的盈利来源通常包括：
- 整车销售收入
- 软件和智能化功能收入
- 出行订单佣金或抽成
- 运力资产运营收益
- 金融、保险、延保等增值服务收入
- 维保、能源补给和后市场收入
- 车联网和数据服务收入
- 自动驾驶服务收入（中长期）

## 2.2 价值创造链条

汽车出行行业典型链路：

### 整车销售型
```text
产品研发与制造
→ 建立品牌、渠道和交付体系
→ 销售车辆给个人/企业用户
→ 提供售后、金融、保险、软件升级
→ 增加全生命周期价值
```

### 平台撮合型
```text
获取乘客需求
→ 组织司机和运力供给
→ 通过算法调度撮合订单
→ 提升履约效率和用户体验
→ 平台抽成与增值服务变现
```

### 车队运营型
```text
采购/租赁车辆
→ 管理司机与车队
→ 优化排班、补能、保养和利用率
→ 提升单车收入和降低单车成本
→ 实现资产回报
```

### 智能化服务型
```text
通过车联网和软件接入车辆
→ 采集运行与用户数据
→ 提供导航、娱乐、远程控制、辅助驾驶和车队管理
→ 软件订阅/服务收费
```

## 2.3 行业核心飞轮
```text
更优产品/更高运力效率
→ 更好用户体验与更低成本
→ 更高销量/更高订单量
→ 更多数据与更强网络效应
→ 更强调度、研发和服务能力
→ 更优产品/更高运力效率
```

汽车出行行业真正强的飞轮是：

> 产品力、运营效率、服务网络、用户规模和数据能力之间的正循环，而不是单次销量或短期补贴。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：整车销售
+ 名称：Vehicle Sales
+ 收费对象：个人用户 / 企业客户 / 经销商
+ 收费方式：按辆销售
+ 公式：

```latex
收入 = 销量 × ASP
```

### 模式二：平台佣金 / 抽成
+ 名称：Commission / Take Rate
+ 收费对象：司机 / 乘客 / 商户
+ 收费方式：按订单抽成
+ 公式：

```latex
收入 = GMV × 抽成率
```

### 模式三：资产运营收益
+ 名称：Fleet Operation
+ 收费对象：乘客 / 企业客户
+ 收费方式：运费、租金、包月、包车
+ 公式：

```latex
收入 = 单车收入 × 车队规模
```

### 模式四：软件与订阅
+ 名称：Software / Subscription
+ 收费对象：车主 / 车队 / OEM
+ 收费方式：功能订阅、SaaS、一次性开通
+ 公式：

```latex
收入 = 付费车辆数 × ARPU
```

### 模式五：后市场与增值服务
+ 名称：Aftermarket / Value-added Service
+ 收费对象：车主 / 司机 / 企业
+ 收费方式：维修保养、保险、金融、延保、充电服务
+ 公式：

```latex
收入 = 服务用户数 × 客单价
```

## 4.2 行业最优商业模式
汽车出行中高质量模型通常具备：

+ 高复购或高频交易
+ 单位经济清晰
+ 资产效率高
+ 用户获取和留存成本可控
+ 服务网络和供给网络稳定
+ 软件和服务收入能持续增厚利润
+ 不完全依赖补贴或一次性硬件销售

理想模型不是：

> 靠高补贴拉订单、低毛利卖车、重资产扩张但单车回本周期不清晰
>

而是：

> 以产品或平台切入，建立供给与需求网络，在提升车辆或运力使用效率的同时，通过软件、服务和后市场延长客户生命周期价值。
>

## 4.3 从单点交易到全生命周期价值路径
```text
先完成车辆销售/订单交易
→ 建立用户或司机关系
→ 提供金融、保险、维保、能源、软件等服务
→ 提升留存和复购
→ 获得全生命周期收益
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 整车销售收入 + 平台佣金收入 + 资产运营收入 + 软件订阅收入 + 后市场收入 + 金融保险收入 + 数据服务收入 + 其他收入
```

## 5.2 拆解驱动因子
### 整车厂常见拆法
```latex
收入 = 销量 × ASP
```

### 网约车平台常见拆法
```latex
收入 = 订单量 × 平均客单价 × 抽成率
```

### 共享出行 / 车队常见拆法
```latex
收入 = 车队规模 × 单车日收入 × 运营天数
```

### 软件服务型常见拆法
```latex
收入 = 连接车辆数 × 付费率 × ARPU
```

### 后市场型常见拆法
```latex
收入 = 活跃车主数 × 到店频次 × 客单价
```

## 5.3 收入增长来源
+ 销量增长
+ 订单量增长
+ 车队规模扩大
+ 单车利用率提升
+ 软件激活率提升
+ 后市场复购提升
+ 金融保险等附加率提升
+ 城市和区域扩张
+ 海外市场拓展

# 六、成本模型
## 6.1 主要成本构成
+ 整车制造成本
+ 电池及核心零部件成本
+ 司机补贴和乘客补贴
+ 运力获取成本

+ 平台研发和调度系统成本
+ 销售与市场成本
+ 门店、服务网络和履约成本

## 6.2 成本分类方式
### 固定成本
+ 研发
+ 工厂与产能
+ 平台技术系统
+ 品牌建设
+ 直营网点和服务网络基础设施

### 可变成本
+ 单车 BOM
+ 物流交付
+ 司机补贴
+ 能源成本
+ 维修保养
+ 保险
+ 支付手续费
+ 履约成本

### 前端成本
+ 拉新补贴
+ 市场营销
+ 渠道返利
+ 销售佣金
+ 司机招募激励

### 后端成本
+ 售后维保
+ 事故处理
+ 客服
+ 调度运营
+ 仓储配件
+ 软件云成本

## 6.3 单位经济模型
### 整车厂
```latex
单车毛利 = ASP - 单车 BOM - 制造与交付成本 - 渠道成本
```

### 网约车平台
```latex
单订单毛利 = 客单价 × 抽成率 - 补贴 - 支付成本 - 客服/运营分摊
```

### 共享汽车 / 车队运营
```latex
单车月毛利 = 单车月收入 - 折旧/租赁 - 能源 - 维保 - 保险 - 停车/运营成本
```

### 后市场平台
```latex
单用户毛利 = 单用户年收入 - 流量成本 - 履约/门店服务成本
```

### 软件服务型
```latex
单车软件毛利 = ARPU - 云服务成本 - 客服支持成本
```

### 核心判断
+ 汽车出行行业最关键不是规模本身，而是单位经济和资产效率
+ GMV、销量或车队规模大不必然代表盈利质量高
+ 若补贴、折旧和事故成本过高，表面增长可能掩盖真实亏损
+ 高质量公司通常能把一次性交易转化为长期服务收入

## 6.4 利润公式
```latex
利润 = 销售/订单/服务总收入 - 制造成本 - 运力成本 - 折旧租赁 - 能源/保险/维保成本 - 补贴 - 研发销售管理费用
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
汽车出行增长通常来自：

+ 产品力提升
+ 新能源渗透提升
+ 智能化体验升级
+ 城市和区域覆盖扩大
+ 供需匹配效率改善
+ 单车利用率提升
+ 后市场与软件收入拓展
+ 企业车队数字化升级
+ 自动驾驶商业化突破

## 8.2 规模效应
规模扩大后可能带来：

+ 采购与制造成本下降
+ 品牌认知增强
+ 服务网络效率提升
+ 调度和匹配效率提升
+ 数据积累改善算法表现
+ 备件、维保、能源体系协同增强

## 8.3 网络效应
汽车出行中的网络效应主要体现在：

+ 平台用户越多，司机收入越稳定，更多司机加入
+ 司机越多，叫车更快，用户体验更好，更多用户使用
+ 连接车辆越多，软件和数据服务价值越高
+ 服务网点越多，车主使用和复购意愿越高

## 8.4 资产模式与平台模式差异
+ 平台撮合轻资产，但高度依赖供给和补贴平衡
+ 车队和共享运营重资产，更看单车回本和稼动率
+ 整车销售规模大，但毛利率和库存管理关键
+ 软件与服务收入弹性更高，通常估值质量更好

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 整车市场通常品牌集中度较高

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
对应整车消费、城市出行交易、企业车队运营、后市场服务和车联网服务的总市场空间

### SAM
公司当前产品品类、区域覆盖、客户定位和政策许可范围内可服务市场

### SOM
公司中短期可实际获取的销量、订单量、车队规模和服务收入份额

## 12.2 通用测算公式
### 方法一：车辆销售法
```latex
市场空间 = 目标购车用户数 × ASP
```

### 方法二：出行交易法
```latex
市场空间 = 目标城市出行次数 × 平均客单价 × 平台可渗透率
```

### 方法三：车队运营法
```latex
市场空间 = 可运营车辆数 × 单车年收入
```

### 方法四：存量车服务法
```latex
市场空间 = 保有量车辆数 × 单车年服务价值
```

## 12.3 市场空间判断注意事项
+ 市场大不等于利润高，关键看补贴、资产效率和服务成本
+ 需区分高增长但低毛利环节与高粘性高利润环节
+ 不同城市和区域政策差异巨大
+ 自动驾驶等新业务应谨慎估算商业化节奏

# 十四、快速分析卡
## 一句话本质
> 汽车出行行业本质上是围绕人和货的移动需求，通过车辆、能源、软件和运营网络提升出行效率与体验，并将其转化为销售、佣金、运营和服务收入的行业。
>

## 核心收入公式
```latex
收入 = 销量 × ASP
或
收入 = 订单量 × 客单价 × 抽成率
或
收入 = 车队规模 × 单车收入
```

## 核心成本公式
```latex
成本 = 制造/车辆成本 + 补贴/运力成本 + 能源/维保/保险成本 + 研发销售管理费用
```

## 核心判断三要素
1. 单位经济是否清晰
2. 资产或平台效率是否持续改善
3. 是否能从单次交易延展到长期服务收入

## 最重要指标
+ 销量 / 订单量
+ 单车毛利 / 单订单毛利
+ 车辆利用率
+ 抽成率
+ 软件付费率
+ CAC / LTV
+ 经营现金流
+ 单车回本周期

## 最大风险
+ 价格战和补贴依赖
+ 安全和政策风险
+ 供应链和库存风险
+ 重资产扩张带来的现金流压力
+ 用户与司机双边流失

## 最终结论模板
> 汽车出行行业的核心不是单纯卖出更多车或做更多订单，而是能否在保证安全与服务质量的前提下，持续优化单位经济、提升资产和运力效率，并通过软件、服务和后市场延长客户生命周期价值。真正决定长期价值的不是短期规模，而是盈利模型、网络效率和资本回报。
