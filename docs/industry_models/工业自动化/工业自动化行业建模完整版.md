# 一、行业基础定义

## 1.1 行业名称
- 行业名称：工业自动化
- 细分赛道：控制层、驱动层、执行层、感知层、工业软件层、系统集成层、智能制造解决方案等
- 代表产品：
  - 控制：PLC、PAC、DCS、SCADA、HMI
  - 驱动：伺服系统、变频器、运动控制器
  - 执行：工业机器人、协作机器人、电机、执行器
  - 感知：机器视觉、工业相机、传感器、编码器
  - 软件：MES、APS、工业组态、设备管理、边缘计算平台
  - 集成：自动化产线、检测设备、仓储物流自动化
- 上下游位置：
  - 上游：芯片、电子元件、精密零部件、机械结构件、控制算法、软件开发工具
  - 中游：自动化设备厂商、工业软件厂商、机器人厂商、系统集成商
  - 下游：汽车、锂电、光伏、3C、半导体、食品饮料、医药、化工、物流、装备制造等工业客户
- 主要服务对象：To B / To 工厂客户为主

## 1.2 行业一句话定义
> 工业自动化行业的本质是：通过控制、感知、执行和软件系统，替代或增强人工与传统设备协同，提高工业生产中的效率、精度、稳定性和可复制性的行业。

## 1.3 行业边界

### 覆盖范围
- 用于工厂生产、装配、检测、搬运、控制、监测和调度的自动化软硬件系统
- 面向生产制造环节的工业控制和数字化系统
- 为工业客户提供自动化设备、软件和整体解决方案的业务

### 不覆盖范围
- 与工业场景弱相关的消费机器人和家用智能设备
- 单纯通用 IT 软件且不直接服务生产制造的产品
- 不涉及控制、执行、感知或产线自动化的普通机械设备
- 纯人工服务型工程业务且缺乏自动化产品化能力

# 二、行业本质与核心价值

## 2.1 商业本质

工业自动化行业的本质不是“卖设备”，而是：

> 用标准化或半标准化的自动化能力，帮助工业客户在复杂制造场景中降低单位成本、提升良率、提高节拍、降低对人工依赖，并增强生产过程的确定性。

### 1）客户为什么需要它？
工业客户需要自动化，通常因为：
- 人工成本上升
- 招工难、用工不稳定
- 产品良率要求提高
- 产能爬坡速度要求提高
- 工艺复杂度提升
- 质量可追溯和过程可视化要求提高
- 柔性制造和小批量多品种需求增加

### 2）企业提供的核心价值是什么？
- 提升生产效率和产线节拍
- 提升一致性和产品良率
- 降低人工成本和人为波动
- 缩短换线时间和导入周期
- 实现设备联网、数据采集和过程控制
- 帮助客户构建可复制、可扩展的制造能力

### 3）企业为什么能赚钱？
工业自动化企业的盈利来源通常包括：
- 设备销售收入
- 软件授权收入
- 系统集成收入
- 工程实施收入
- 售后服务和维保收入
- 备件和耗材收入
- 升级改造收入
- 订阅型工业软件或数据服务收入

## 2.2 价值创造链条

工业自动化行业典型链路：

### 标准品设备型
```text
研发控制/驱动/感知产品
→ 建立渠道或直销体系
→ 进入客户设备/产线
→ 批量复制到更多场景
→ 通过设备、备件和服务持续变现
```

### 解决方案型
```latex
理解客户工艺与痛点
→ 方案设计与验证
→ 设备交付与集成
→ 调试验收与爬坡
→ 售后维保与二次扩产
```

### 工业软件型
```latex
采集设备和生产数据
→ 构建监控、计划、执行和分析系统
→ 提升生产透明度与决策效率
→ 形成长期续费和增购
```

## 2.3 行业核心飞轮
```latex
更多客户项目
→ 更多场景理解和工艺 know-how
→ 产品能力和交付能力增强
→ 更高成功率和更优 ROI
→ 赢得更多客户项目
```

工业自动化行业真正强的飞轮是：

> 产品可靠性、工艺理解、客户案例、交付能力和售后服务持续增强，从而不断提高客户信任和复制效率。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：设备销售
+ 名称：Hardware Sales
+ 收费对象：OEM / 工厂客户 / 集成商
+ 收费方式：按台、按套、按项目
+ 公式：

```latex
收入 = 出货量 × ASP
```

### 模式二：软件授权与订阅
+ 名称：Software License / Subscription
+ 收费对象：工业客户
+ 收费方式：一次性授权、按模块收费、年费订阅
+ 公式：

```latex
收入 = 客户数 × ARPU
```

### 模式三：系统集成与工程实施
+ 名称：System Integration / Project Delivery
+ 收费对象：工厂客户
+ 收费方式：按项目合同额收费
+ 公式：

```latex
收入 = 项目数量 × 平均项目合同额
```

### 模式四：售后维保与升级
+ 名称：After-sales / Maintenance / Retrofit
+ 收费对象：存量客户
+ 收费方式：维保合同、备件、更换升级
+ 公式：

```latex
收入 = 存量装机客户数 × 服务ARPU
```

### 模式五：解决方案打包销售
+ 名称：Turnkey Solution
+ 收费对象：工厂客户
+ 收费方式：整线、整站、整厂打包
+ 公式：

```latex
收入 = 解决方案项目数 × 单项目金额
```

## 4.2 行业最优商业模式
工业自动化中高质量模型通常具备：

+ 产品标准化程度较高
+ 进入客户后替换成本高
+ 服务能力支撑长期合作
+ 复购和扩线机会多
+ 软件或核心零部件具备较高毛利
+ 下游行业景气波动不至于单点冲击过大

理想模型不是：

> 过度依赖单一大项目、低毛利集成和一次性交付，项目完成后缺乏持续收益
>

而是：

> 以核心产品切入客户产线，逐步从单机到整线、从硬件到软件、从首次采购到维保升级，形成高粘性复购和长期服务收入。
>

## 4.3 从单品到平台型工业自动化路径
```latex
先做单一关键产品
→ 切入设备厂或终端客户
→ 建立行业案例和可靠性口碑
→ 扩展配套产品和软件
→ 向解决方案与生态平台升级
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 设备销售收入 + 软件收入 + 系统集成收入 + 维保收入 + 备件耗材收入 + 升级改造收入 + 其他收入
```

## 5.2 拆解驱动因子
### 标准品厂商常见拆法
```latex
收入 = 出货量 × ASP
```

### 软件厂商常见拆法
```latex
收入 = 客户数 × 客单价 × 续费率
```

### 项目制厂商常见拆法
```latex
收入 = 项目数 × 平均项目金额
```

### 存量服务型常见拆法
```latex
收入 = 存量装机量 × 服务渗透率 × 服务 ARPU
```

## 5.3 收入增长来源
+ 下游行业资本开支增长
+ 客户扩产
+ 新品导入
+ 国产替代提升
+ 新行业渗透
+ 渠道扩张
+ 从设备向软件/维保延伸
+ 存量客户复购与升级改造
+ 海外市场拓展

## 6.3 单位经济模型
### 标准硬件产品
```latex
单台毛利 = ASP - BOM 成本 - 制造成本 - 渠道返利
```

### 机器人 / 设备型
```latex
单机毛利 = 设备售价 - 硬件成本 - 装配调试成本 - 售后预提
```

### 项目制解决方案
```latex
单项目毛利 = 合同额 - 设备采购/自制成本 - 实施成本 - 调试验收成本
```

### 软件型
```latex
单客户毛利 = 授权/订阅收入 - 实施交付成本 - 客户成功成本
```

### 核心判断
+ 工业自动化的核心不是只看收入增长，而是看毛利结构、交付效率和可复制性
+ 标准化产品通常毛利与估值质量优于重项目集成
+ 集成业务能放大收入，但若项目管理能力不足，利润波动大
+ 软件和服务收入占比提升，通常代表收入质量改善

## 6.4 利润公式
```latex
利润 = 设备/软件/项目/服务收入 - 硬件成本 - 制造成本 - 实施成本 - 销售成本 - 研发费用 - 管理费用 - 质保与售后成本
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
工业自动化增长通常来自：

+ 制造业升级
+ 人工替代
+ 良率和节拍提升需求
+ 新能源、半导体等高景气下游扩产
+ 国产替代
+ 智能化、柔性化需求增强
+ 工厂数字化和数据闭环建设
+ 海外客户拓展

## 8.2 规模效应
规模扩大后可能带来：

+ 采购成本下降
+ 研发平台复用
+ 品牌和认证口碑增强
+ 渠道网络扩张
+ 服务网络完善
+ 软件模块和工艺 know-how 复用

## 8.3 网络效应
工业自动化网络效应相对弱于互联网行业，但存在以下类网络效应：

+ 客户案例越多，行业信任越强
+ 装机量越大，售后体系越成熟
+ 数据积累越多，软件和算法效果越好
+ 生态兼容性越强，客户切换成本越高

## 8.4 标准化与项目化的平衡
+ 标准化越高，规模和毛利通常越好
+ 项目化越重，收入体量可大但管理复杂
+ 很多优秀公司路径是“标准品切入 + 方案化放大 + 软件服务增厚利润”

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 高端市场往往由国际龙头占据
+ 中端和细分场景国产替代机会较大
+ 项目型集成市场相对分散
+ 工业软件和控制核心环节壁垒较高
+ 下游景气行业会吸引大量新进入者

## 9.2 常见壁垒类型
+ 核心技术和算法壁垒
+ 产品可靠性壁垒
+ 工艺 know-how 壁垒
+ 客户认证壁垒
+ 渠道与服务网络壁垒
+ 软硬件一体化壁垒
+ 行业案例与品牌壁垒
+ 生态兼容性壁垒

## 9.3 替代风险
+ 国际厂商价格下探
+ 客户自研或自集成
+ 下游景气下行导致 CAPEX 缩减
+ 核心零部件被卡脖子
+ 新技术路线替代旧控制架构
+ 通用化产品压缩定制方案空间

# 十、行业风险分析
## 10.1 通用风险项
+ 制造业资本开支周期波动
+ 大客户依赖
+ 交付延期
+ 质量事故
+ 应收账款高
+ 集成项目低毛利
+ 核心器件断供
+ 下游行业景气反转
+ 国产替代进度不及预期
+ 技术迭代风险

## 10.2 风险信号模板
+ 订单增长但回款恶化
+ 收入增长但毛利率持续下滑

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
对应工业制造自动化和数字化总投入，包括控制、驱动、执行、软件和集成等总市场

### SAM
公司当前产品品类、技术能力、客户行业和销售区域覆盖范围内可服务市场

### SOM
公司中短期可实际获得的订单、装机和客户份额

## 12.2 通用测算公式
### 方法一：设备渗透率法
```latex
市场空间 = 目标行业设备数量 × 自动化渗透率 × 单设备价值量
```

### 方法二：产线投资法
```latex
市场空间 = 新增/改造产线数量 × 单产线自动化投资额
```

### 方法三：客户数法
```latex
市场空间 = 可触达客户数 × 平均客单价
```

### 方法四：软件渗透法
```latex
市场空间 = 工厂数量 × 工业软件渗透率 × 单厂年价值
```

## 12.3 市场空间判断注意事项
+ TAM 很大不代表单家公司可切到的份额大
+ 不同层级产品价值量和毛利差异明显
+ 需结合认证周期、销售周期和客户替换意愿
+ 需区分周期性扩产需求与长期结构性升级需求

# 十四、快速分析卡
## 一句话本质
> 工业自动化行业本质上是用控制、感知、执行和软件系统提升工业生产效率、良率和确定性，并通过设备、软件、项目和服务实现变现的行业。
>

## 核心收入公式
```latex
收入 = 出货量 × ASP + 软件/服务收入 + 项目收入
```

## 核心成本公式
```latex
成本 = BOM/制造成本 + 实施交付成本 + 销售渠道成本 + 研发成本 + 售后维保成本
```

## 核心判断三要素
1. 是否具备可复制的产品和场景能力
2. 毛利与现金流是否匹配
3. 客户认证、复购和扩线逻辑是否成立

## 最重要指标
+ 新签订单
+ 在手订单
+ 出货量 / 装机量
+ 毛利率
+ 客户复购率
+ 应收周转
+ 存货周转
+ 研发费用率

## 最大风险
+ 下游 CAPEX 波动
+ 交付与回款风险
+ 质量事故
+ 核心器件断供
+ 大客户依赖

## 最终结论模板
> 工业自动化行业的核心不是简单卖设备，而是能否通过可靠产品、工艺 know-how、交付能力和客户服务建立长期进入壁垒。真正决定长期价值的不是短期订单高低，而是标准化能力、复购能力、毛利质量和穿越制造周期的能力。
