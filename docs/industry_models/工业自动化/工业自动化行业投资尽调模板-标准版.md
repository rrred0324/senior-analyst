# 三、业务理解

## 3.1 公司到底做什么
1. 公司核心是卖产品、卖项目，还是卖软件和整体方案？
2. 产品位于控制、驱动、执行、感知还是软件层？
3. 主要应用在哪些制造环节？
4. 客户采购核心动机是什么？
5. 公司更像产品公司、工程公司还是平台型解决方案公司？

## 3.2 解决什么问题
1. 帮客户提升的是节拍、良率、人工替代还是数据透明度？
2. 替代的是进口品牌、人工流程还是旧设备？
3. 如果没有该公司，客户的替代方案是什么？
4. 客户 ROI 多久回本？

## 3.3 商业模式
1. 收入主要来自设备、项目、软件还是服务？
2. 是否有从单点产品到整线/整厂延展能力？
3. 是否具备售后、备件、升级等持续性收入？
4. 标准化能力和项目化程度如何平衡？

# 九、财务尽调

## 9.1 收入质量
1. 收入中标准产品、项目和服务占比分别多少？
2. 是否存在低毛利项目拉高收入规模？
3. 新签订单和收入确认节奏是否匹配？
4. 海外和国内订单质量差异如何？

## 9.2 利润质量
1. 毛利率变化由产品结构还是价格竞争导致？
2. 标准品业务和项目制业务利润差异如何？
3. 软件和服务收入是否改善利润结构？
4. 质保和售后预提是否充分？

## 9.3 现金流质量
1. 经营现金流是否与收入同步改善？
2. 应收账款和存货是否吞噬利润？
3. 项目验收周期是否过长？
4. 扩产和备库是否占用过多现金？

## 9.4 资产负债表风险
重点看：
- 存货
- 应收账款
- 合同资产/合同负债
- 固定资产
- 现金
- 有息负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否兼具技术、销售和交付背景？
2. 是否有头部工业客户导入经验？
3. 是否过度依赖少数技术骨干或大客户销售？
4. 海外业务与渠道团队是否成熟？

## 10.2 组织能力
1. 公司更强在研发、销售、交付还是售后？
2. 是否能支撑跨行业复制？
3. 项目管理体系是否成熟？
4. 质量管理和供应链管理是否稳定？

## 10.3 激励机制
1. 销售激励是否鼓励低质量订单？
2. 交付团队激励是否兼顾进度和质量？
3. 研发激励是否聚焦平台化而非客户定制化碎片需求？

# 十二、风险尽调

## 12.1 业务风险
- 大客户依赖
- 单一下游景气依赖
- 项目延迟验收
- 质量与稳定性问题
- 交付能力不足
- 海外拓展失败

## 12.2 财务风险
- 毛利率下滑
- 应收与存货高企
- 经营现金流恶化
- 质保成本上升
- CAPEX 压力大

## 12.3 合规与法律风险
- 知识产权风险
- 安全生产和产品责任风险
- 出口合规风险
- 商业贿赂与招投标合规风险
- 数据安全风险（工业软件类）
