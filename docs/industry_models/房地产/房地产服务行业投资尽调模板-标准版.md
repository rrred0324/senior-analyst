# 三、业务理解

## 3.1 公司到底做什么
1. 公司本质上是交易撮合平台、租赁运营商、物业公司还是社区服务运营商？
2. 主要收入来自佣金、租金差、管理费还是增值服务？
3. 核心客户是购房者、租客、业主、开发商还是企业客户？
4. 服务链条覆盖交易前、中、后哪些环节？

## 3.2 解决什么问题
1. 用户为什么需要这家公司，而不是自己交易、房东直租或其他物业公司？
2. 是解决效率、信任、履约、资产保值还是社区便利问题？
3. 用户最核心的决策因素是价格、服务、口碑还是房源/项目资源？
4. 公司是否在本地市场建立了可信赖的服务心智？

## 3.3 商业模式
1. 收入来自高频服务还是低频大额交易？
2. 哪部分收入最稳定？
3. 哪部分收入毛利最高？
4. 是否具备从单一服务向多元居住服务延伸的能力？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在细分赛道处于增长、成熟还是收缩阶段？
2. 区域市场容量多大？
3. 受地产周期影响程度如何？
4. 存量房、租赁和物业服务是否提供长期机会？

## 5.2 行业格局
1. 本地竞争是高度分散还是头部集中？
2. 平台型公司、线下连锁和社区型服务商各自优势是什么？
3. 行业竞争是否以佣金价格战为主？
4. 公司在目标区域是否有领先地位？

## 5.3 行业趋势
1. 存量房时代是否利好中介和后服务？
2. 租赁市场规范化是否利好正规运营商？
3. 物业和社区服务是否持续走向增值化？
4. 数字化和 AI 是否会改变服务效率和组织结构？

# 九、财务尽调

## 9.1 收入质量
1. 收入是否建立在真实成交和稳定在管基础上？
2. 是否存在一次性大客户或大项目拉动？
3. 新房分销佣金回款是否及时？
4. 增值服务收入是否为高质量、可持续收入？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 线索和经纪人成本是否上升过快？
3. 长租业务是否被空置和坏账侵蚀？
4. 物业基础服务和增值服务利润结构是否健康？

## 9.3 现金流质量
1. 是否存在高额前置装修和改造支出？
2. 押金、租金、物业费回收节奏是否健康？
3. 是否有明显账期错配？
4. 增长是否依赖持续外部融资支撑？

## 9.4 资产负债表风险
重点看：
- 现金
- 应收账款
- 押金和预收款
- 固定资产和装修改造资产
- 租赁负债
- 坏账准备
- 或有诉讼负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备房产、物业、租赁或本地生活服务经验？
2. 是否懂重运营和本地服务管理？
3. 是否具备区域扩张和组织复制经验？
4. 是否过度依赖关键招商负责人、城市总或店长？

## 10.2 组织能力
1. 是否有标准化培训、督导、客服和风控体系？
2. 是否具备多城市、多项目协同管理能力？
3. 是否有成熟数字化系统支撑？
4. 增值服务和后市场服务是否有独立运营能力？

## 10.3 激励机制
1. 经纪人和项目团队是否只看规模，不看利润和客诉？
2. 区域团队是否对续约、收缴和满意度负责？
3. 是否有坏账、投诉和合规红线约束？
4. 总部与一线激励是否一致？

## 11.2 公司壁垒
1. 壁垒来自房源、项目、品牌、服务口碑还是组织能力？

1. 是否会被平台直连、房东直租或开发商直销替代？

4. SaaS 产品是否容易被通用工具替代？

# 十二、风险尽调

## 12.1 业务风险
- 地产周期波动
- 成交量下滑
- 房源获取恶化
- 长租空置率上升
- 续约率下降
- 物业费收缴压力
- 客诉和纠纷增加
- 区域扩张失效

## 12.2 财务风险
- 回款周期拉长
- 坏账增加
- 前置改造投入过大
- 现金流失衡
- 高固定成本压力
- 融资依赖

## 12.3 合规与法律风险
- 经纪业务合规问题
- 租赁合同与押金争议
- 物业服务纠纷
- 收费合规与政府监管
- 安全生产和消防责任
- 数据和隐私合规风险
