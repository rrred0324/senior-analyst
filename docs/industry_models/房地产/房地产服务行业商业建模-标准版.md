# 一、行业基础定义

## 1.1 行业名称
- 行业名称：房地产服务 / 居住服务
- 英文常用称呼：Real Estate Services / Housing Services / Property Services
- 细分赛道：房产经纪、新房分销、二手房经纪、房屋租赁、长租公寓、物业管理、社区增值服务、家装家政、商办运营、产业园运营、房产 SaaS 等
- 上下游位置：
  - 上游：开发商、房东、资管机构、施工装修方、设备设施供应商、金融机构、政府与监管部门
  - 中游：房产经纪公司、租赁运营商、物业公司、社区服务平台、商办/园区运营商、数字化服务商
  - 下游：购房者、租客、业主、住户、企业客户、开发商渠道客户
- 主要服务对象：To C 与 To B 并存，兼具本地服务与运营服务属性

## 1.2 行业一句话定义
> 房地产服务行业的本质是：围绕不动产的交易、租住、运营与维护需求，为业主、租客、开发商和企业客户提供撮合、管理、增值和数字化服务，并通过佣金、管理费、租金差和服务费实现变现。

## 1.3 行业边界

### 覆盖范围
- 房产买卖、租赁、托管、物业、社区及不动产运营相关服务
- 面向业主、租客、购房者、开发商和企业客户提供的中介、运营和管理服务
- 房地产后市场服务及相关数字化工具服务

### 不覆盖范围
- 纯房地产开发销售主体
- 纯建筑施工企业
- 单纯家居制造但不提供居住服务的企业
- 纯金融产品而非房产服务本身的机构

# 二、行业本质与核心价值

## 2.1 商业本质

房地产服务行业的本质不是“卖房子”或“管物业”，而是：

> 在高价值、低频或长期居住场景中，降低信息不对称、提升运营效率、保障服务质量，并持续提高房产资产使用效率和用户居住体验。

### 1）客户为什么需要它？
客户需要房地产服务，通常因为：
- 房产交易和租赁信息高度分散，匹配成本高
- 房屋管理、维修、安保、保洁等专业运营需要持续服务
- 业主与租客之间存在信任、履约和效率问题
- 开发商和资管机构需要更高效的去化与运营渠道
- 居住服务已从单一交易延伸到全生命周期管理

### 2）企业提供的核心价值是什么？
- 帮助用户更高效找到房源、客户或租客
- 降低交易和租赁过程中的信息不对称和履约风险
- 为业主提供专业化资产管理和托管服务
- 为住户提供稳定、安全、便利的社区与物业服务
- 提升不动产运营效率和资产收益率

### 3）企业为什么能赚钱？
房地产服务企业盈利来源通常包括：
- 房产交易佣金
- 新房分销佣金
- 租赁中介费
- 房屋托管与管理费
- 长租公寓租金差和服务费
- 物业管理费
- 社区增值服务收入
- 装修、维修、家政等后市场服务收入
- SaaS 或数字化系统服务收入
