# 三、业务理解

## 3.1 公司到底做什么
1. 公司本质上是品牌方、渠道方、DTC 公司还是 OEM/ODM 厂商？
2. 收入主要来自护肤、彩妆、洗护还是其他赛道？
3. 目标用户是谁？价格带在哪里？
4. 品牌定位更偏功效、审美、平价还是高端？

## 3.2 解决什么问题
1. 消费者为什么买它，而不是买国际大牌或平替？
2. 是解决功效、安全感、审美表达还是情绪价值？
3. 产品核心卖点是否可感知、可验证、可传播？
4. 用户信任建立主要来自成分、口碑、达人还是品牌故事？

## 3.3 商业模式
1. 收入来自直营零售、分销铺货、私域复购还是 OEM/ODM？
2. 哪部分收入最稳定？
3. 哪部分收入毛利最高？
4. 公司是否具备从线上走向多渠道、从单品走向系列化的能力？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在品类是高频刚需还是趋势型消费？
2. 目标人群和价格带的增长空间如何？
3. 是否有国货替代或渠道重构机会？
4. 海外市场是否存在扩张空间？

## 5.2 行业格局
1. 国际品牌和国货品牌竞争态势如何？
2. 行业更看品牌力、渠道力还是内容投放力？
3. ODM 成熟是否降低了进入门槛？
4. 公司是否在某个细分人群中已形成优势？

## 5.3 行业趋势
1. 成分党、功效护肤是否持续？
2. 内容电商对品牌崛起是否仍有效？
3. 线下集合店和商超渠道是否重回增长？
4. 监管加强对行业宣传和备案有何影响？

# 九、财务尽调

## 9.1 收入质量
1. 收入是否来自健康复购和自然动销？
2. 是否过度依赖大促、直播或头部达人？
3. 渠道出货和终端动销是否匹配？
4. 是否存在压货式增长？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 投放费用是否侵蚀真实利润？
3. 渠道返利和平台活动成本是否被充分反映？
4. 新品试错和滞销是否吞噬利润？

## 9.3 现金流质量
1. 库存备货是否吞噬现金流？
2. 分销账期是否导致应收上升？
3. 大促和新品上线前后现金流波动如何？
4. 是否存在长期高投放低回收问题？

## 9.4 资产负债表风险
重点看：
- 存货与库龄
- 应收账款
- 预付款
- 现金
- 合同负债
- 存货减值准备
- 品牌相关无形资产

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备品牌、研发、渠道或供应链经验？
2. 是否过度依赖某位主播、达人或产品经理？
3. 是否懂合规和质量控制？
4. 是否具备多渠道运营能力？

## 10.2 组织能力
1. 是否有成熟的产品开发、投放、供应链和客服体系？
2. 是否有用户洞察和数据分析能力？
3. 是否能持续迭代新品和内容素材？
4. 是否具备线下或海外拓展组织能力？

## 10.3 激励机制
1. 团队是否只追求 GMV，不看毛利和复购？
2. 产品团队是否对退货和客诉负责？
3. 渠道团队是否对真实动销负责？
4. 是否有库存健康和合规风险约束机制？

## 11.2 公司壁垒

# 十二、风险尽调

## 12.1 业务风险
- 爆品失速
- 新品接不上
- 复购不足
- 平台依赖
- 达人依赖
- 渠道窜货
- 用户口碑反转
- 海外合规不确定性

## 12.2 财务风险
- 高营销费用
- 库存积压
- 存货减值
- 分销回款慢
- 高退货率
- 大促驱动虚高增长

## 12.3 合规与法律风险
- 功效宣传违规
- 备案与标签不合规
- 原料使用合规风险
- 知识产权和包装侵权风险
- 虚假宣传和消费者索赔风险
