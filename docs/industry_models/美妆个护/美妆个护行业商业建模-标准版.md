# 一、行业基础定义

## 1.1 行业名称
- 行业名称：美妆个护
- 英文常用称呼：Beauty & Personal Care
- 细分赛道：护肤、彩妆、洗护发、口腔护理、身体护理、香氛、美容仪、男士个护、婴童个护、功能性护肤、专业美业零售化产品等
- 上下游位置：
  - 上游：原料供应商、包材供应商、ODM/OEM、检测备案机构、研发实验室、设备制造商
  - 中游：品牌方、渠道品牌、DTC 品牌、分销商、代运营、电商服务商
  - 下游：消费者、电商平台、线下零售、美妆集合店、商超、CS 渠道、百货、医美/美容院渠道
- 主要服务对象：To C 为主，部分 To B（渠道、代理、专业线机构）

## 1.2 行业一句话定义
> 美妆个护行业的本质是：围绕清洁、护理、修饰、美感和功效需求，向消费者持续提供高感知、高复购或高客单的消费产品，并通过品牌心智、产品功效和渠道运营实现变现。

## 1.3 行业边界

### 覆盖范围
- 直接面向消费者的美妆和个人护理产品
- 通过线上线下渠道销售的品牌型美妆个护业务
- 具备消费属性的功能型护理和仪器类产品
- 相关 ODM/OEM、渠道型和品牌服务型业务

### 不覆盖范围
- 纯医美服务机构本体
- 完全不面向终端消费者的化工原料业务
- 单纯代运营但不深度参与美妆个护品牌逻辑的服务公司
- 医疗器械中与消费个护弱相关的纯医疗产品

# 二、行业本质与核心价值

## 2.1 商业本质

美妆个护行业的本质不是“卖一瓶产品”，而是：

> 在消费者对功效、审美、身份表达和日常护理的持续需求中，通过可信产品力和品牌心智占据用户浴室柜、梳妆台和护肤流程中的固定位置。

### 1）客户为什么需要它？
消费者需要美妆个护产品，通常因为：
- 清洁、护理、防护、修饰等日常需求高频存在
- 对皮肤、头发、口腔、身体状态有持续管理需求
- 希望获得更好的外观表现、自我表达和情绪满足
- 对安全性、成分、功效和使用体验越来越敏感
- 社交媒体和内容种草持续强化消费教育与需求激发

### 2）企业提供的核心价值是什么？
- 提供改善外观、肤感、气味和个人状态的产品
- 满足不同年龄、肤质、场景和预算的护理需求
- 提供功能价值（保湿、美白、抗老、控油、防晒等）
- 提供情绪价值、品牌认同和生活方式表达
- 通过组合产品构建完整护理流程，提高复购和客单

### 3）企业为什么能赚钱？
美妆个护企业盈利来源通常包括：
- 单品销售收入
- 套组销售收入
- 渠道分销收入
- 会员复购收入
- 高毛利爆品收入
- 专业线/机构渠道收入
- OEM/ODM 供货收入
- 跨品类扩展收入
