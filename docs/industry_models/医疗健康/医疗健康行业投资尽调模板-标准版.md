# 三、业务理解

## 3.1 公司到底做什么
1. 公司位于诊断、治疗、康复、健康管理哪一环？
2. 核心服务或产品是什么？
3. 主要客户是谁？
4. 收入主要来自服务、产品还是软件/项目？
5. 公司更像医疗服务组织、产品公司还是数字化平台？

## 3.2 解决什么问题
1. 为患者或机构解决了什么核心痛点？
2. 为什么客户要选择该公司而不是公立医院、传统器械商或其他服务商？
3. 核心价值是专业能力、效率、便利性还是成本优势？
4. 若没有该公司，客户会用什么替代？

## 3.3 商业模式
1. 收入来自诊疗收费、药械销售、项目费、平台费还是会员费？
2. 收入中一次性收入和持续性收入分别占比多少？
3. 是否有明确支付方支持？
4. 是否具备向上下游延伸变现的空间？

# 九、财务尽调

## 9.1 收入质量
1. 收入是一次性还是持续性？
2. 患者/机构增长是否带来真实现金流？
3. 是否过度依赖单医生、单机构或单渠道？
4. 医疗服务收入和产品收入的结构是否健康？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 医护人力成本和获客成本是否可控？
3. 研发/注册投入是否合理？
4. 合规和质控投入是否充分？

## 9.3 现金流质量
1. 回款周期是否过长？
2. 医院项目是否拖累现金流？
3. 门店扩张和设备投放是否占用大量现金？
4. 经营现金流是否支持持续扩张？

## 9.4 资产负债表风险
重点看：
- 现金
- 应收账款
- 存货
- 固定资产
- 无形资产/注册证
- 有息负债
- 合同负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备医疗、运营、合规、产业资源复合背景？
2. 核心医生团队是否稳定？
3. 是否存在明星医生单点依赖？
4. 管理层是否有连锁复制或医疗产品商业化经验？

## 10.2 组织能力
1. 更强在医疗专业、渠道销售、医院关系还是管理复制？
2. 是否建立标准化服务和培训体系？
3. 是否具备跨区域、跨科室扩张能力？
4. 数据化和运营管理是否成熟？

## 10.3 激励机制
1. 医生激励是否兼顾质量和效率？
2. 销售激励是否可能诱导不健康增长？
3. 核心人才流失风险如何？

## 11.2 公司壁垒
1. 壁垒来自资质、医生、临床验证、渠道还是系统？

## 11.3 替代风险
1. 公立医院是否能替代？
2. 低价竞争者是否会快速侵蚀市场？

4. 新技术是否会颠覆现有产品和流程？

# 十二、风险尽调

## 12.1 业务风险
- 医生依赖
- 复诊不足
- 交付质量不稳
- 扩张失控
- 产品注册延期
- 医院准入不及预期

## 12.2 财务风险
- 回款周期过长
- 存货和设备占资
- 获客成本过高
- 新店爬坡慢
- 现金流紧张

## 12.3 合规与法律风险
- 医疗执业合规
- 广告与宣传合规
- 医疗事故责任
- 数据与隐私合规
- 器械注册与质量管理合规
- 医保/商保合规
