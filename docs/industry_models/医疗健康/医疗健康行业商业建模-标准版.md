# 一、行业基础定义

## 1.1 行业名称
- 行业名称：医疗健康
- 细分赛道：医疗服务、专科医院、连锁诊所、互联网医疗、数字健康、医疗器械、IVD、药店/流通、健康管理、医疗信息化等
- 上下游位置：
  - 上游：药企、器械厂商、原材料供应商、医生资源、科研与技术平台
  - 中游：医院、诊所、平台、渠道商、医疗信息化和服务公司
  - 下游：患者、支付方、企业客户、政府和医疗机构
- 主要服务对象：To C、To B、To G、To H（医院）

## 1.2 行业一句话定义
> 医疗健康行业的本质是：围绕疾病预防、诊断、治疗、康复和健康管理，通过医疗服务、产品和数字化能力提升健康结果，并在合规和信任基础上实现收入与利润。

## 1.3 行业边界

### 覆盖范围
- 医疗与健康相关的服务、产品和数字化基础设施
- 面向患者、医院、医生、企业和政府的健康解决方案
- 具有诊疗、检测、器械、信息化、药械流通或健康管理属性的业务

### 不覆盖范围
- 与健康弱相关的泛养生内容业务
- 无医学专业能力或资质支撑的伪医疗业务
- 纯医药研发本体若不涉及商业化服务平台
- 一次性贸易型、无持续能力沉淀的短期业务

# 二、行业本质与核心价值

## 2.1 商业本质

医疗健康的本质不是“卖药”或“看病”，而是：

> 在严格合规和专业信任基础上，提升健康服务的可及性、有效性、效率和结果质量。

### 1）客户为什么需要它？
患者、医院、企业和政府需要医疗健康服务，通常是因为：
- 疾病诊断与治疗需要专业能力
- 健康管理需求持续提升
- 医疗资源分布不均
- 就医效率低、信息不透明
- 人口老龄化与慢病管理需求增长
- 数字化可提升服务效率和覆盖范围

### 2）企业提供的核心价值是什么？
- 提供专业诊疗或检测能力
- 提供高质量医疗器械、药械或诊断产品
- 提升医疗服务效率和可及性
- 降低患者决策成本
- 优化医院与医生工作流程
- 在合规前提下提高医疗结果和体验

### 3）企业为什么能赚钱？
医疗健康公司的盈利来源通常包括：
- 诊疗服务收入
- 检测收入
- 药品/器械销售收入
- 平台服务费
- 软件和信息化收入
- 会员和健康管理收入
- 医院或企业项目收入
- 医保/商保支付相关收入
