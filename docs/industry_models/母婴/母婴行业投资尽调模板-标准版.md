# 三、业务理解

## 3.1 公司到底做什么
1. 公司卖的是高频消耗品、耐用品、服务还是内容？
2. 用户为什么选择它，而不是综合电商、大品牌或线下门店？
3. 公司核心竞争力在品牌、渠道、私域、内容还是供应链？
4. 当前收入主要来自哪些品类和阶段人群？

## 3.2 解决什么问题
1. 是否解决了安全、品质、专业建议或便利性问题？
2. 用户选择的核心原因是信任、价格、功效还是服务？
3. 新手父母是否因内容或顾问服务而提高转化？
4. 家长若不用该产品/服务，会使用什么替代方案？

## 3.3 商业模式
1. 收入来自商品、会员、服务还是平台佣金？
2. 是否具备高复购基础 SKU？
3. 是否能从低毛利引流品扩展到高毛利品类？
4. 是否有私域和会员作为长期变现基础？

3. 是否具备选品、组套和阶段化推荐能力？

# 五、市场与行业尽调

## 5.1 市场空间
1. 所在细分赛道受出生率影响有多大？
2. 行业是总量收缩还是结构升级？
3. 用户更愿意为哪些品类支付溢价？
4. 服务类和商品类空间差异如何？

## 5.2 行业格局
1. 头部品牌集中度如何？
2. 综合平台和即时零售是否形成挤压？
3. 垂直母婴平台还有什么差异空间？
4. 白牌和低价竞争是否明显？

## 5.3 行业趋势
1. 精细育儿和品质升级是否增强？
2. 内容种草对转化影响是否持续？
3. 私域会员模式是否有效？
4. 从商品到服务的一体化是否成为趋势？

3. 用户对价格敏感还是对安全和口碑敏感？

## 6.3 渠道结构
1. 线上平台、私域、门店、经销分别占比多少？

# 九、财务尽调

## 9.1 收入质量
1. 收入是否建立在高复购基础上？
2. 高频刚需品类和高毛利品类结构是否合理？
3. 自有品牌收入增长是否健康？
4. 促销是否透支未来需求？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 流量成本是否持续上升？
3. 私域和会员是否改善利润结构？
4. 质量、售后和退货是否侵蚀利润？

## 9.3 现金流质量
1. 库存是否占用过多现金？
2. 门店扩张是否吞噬现金流？
3. 大促后退货和回款情况如何？
4. 是否存在高额预付款或压货行为？

## 9.4 资产负债表风险
重点看：
- 存货
- 存货跌价准备
- 应收账款
- 预付款
- 现金
- 租赁负债
- 退款准备

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否懂母婴消费、零售或品牌运营？
2. 是否具备质量和合规意识？
3. 是否有私域和会员运营能力？
4. 是否过度依赖单一主播、达人或核心采购？

## 10.2 组织能力
1. 是否具备稳定供应链和选品能力？
2. 是否具备导购、顾问、客服和社群运营体系？
3. 线下门店标准化能力如何？
4. 是否具备从单品到多品类扩张能力？

## 10.3 激励机制
1. 销售激励是否导致重促销轻复购？
2. 私域团队是否对用户长期价值负责？
3. 采购和品类团队是否对周转和毛利负责？
4. 是否有质量和客诉红线管理机制？

## 11.2 公司壁垒
1. 壁垒来自品牌信任、私域、门店、内容还是供应链？
2. 是否形成会员体系和强复购关系？

4. 是否具备质量与合规护城河？

## 11.3 替代风险
1. 用户是否容易被价格更低平台吸走？
2. 综合平台是否会替代垂直母婴购买场景？
3. 内容流量迁移是否会削弱获客能力？
4. 大品牌进入后是否会挤压生存空间？

# 十二、风险尽调

## 12.1 业务风险
- 出生率下行
- 流量依赖
- 爆款依赖
- 品类扩张失控
- 会员价值不成立
- 门店模型跑不通

## 12.2 财务风险
- 毛利率下滑
- 库存积压
- 促销过度
- 现金流承压
- 租金人工拖累线下利润
- 自有品牌周转差

## 12.3 合规与法律风险
- 食安和质量事故
- 宣传合规风险
- 配方、标签、认证风险
- 数据隐私风险（会员/内容平台）
- 服务类纠纷风险
