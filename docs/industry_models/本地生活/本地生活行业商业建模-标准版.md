# 一、行业基础定义

## 1.1 行业名称
- 行业名称：本地生活
- 细分赛道：到店餐饮、酒旅、本地服务、到家配送、即时零售、社区生活服务、家政维修、美业、亲子、运动健身、休闲娱乐、商户 SaaS 与营销服务等
- 上下游位置：
  - 上游：商户供给、品牌商、服务提供者、配送运力、内容流量、支付与 SaaS 工具
  - 中游：交易平台、聚合平台、履约平台、营销分发平台、数字化服务商
  - 下游：消费者、企业团购客户、社区用户
- 主要服务对象：To C 为主，兼具 To B（商户）和部分 To G

## 1.2 行业一句话定义
> 本地生活行业的本质是：围绕“本地供给 + 本地需求 + 本地履约/到店消费”，通过流量分发、交易撮合、履约服务和商户数字化，提升本地服务交易效率并从中变现的行业。

## 1.3 行业边界

### 覆盖范围
- 到店消费和到家服务相关平台与服务
- 餐饮、酒旅、家政、美业、休娱、即时零售等本地消费场景
- 服务于商户获客、履约、会员管理、支付和经营分析的数字化产品
- 围绕本地生活的内容种草、交易闭环和运营平台

### 不覆盖范围
- 纯全国仓配型电商且不具备本地履约特征的业务
- 与线下本地消费弱相关的泛内容平台
- 不参与交易、不提供线索、不提供履约或数字化能力的纯信息黄页型服务
- 非生活消费属性的工业或企业服务类场景

# 二、行业本质与核心价值

## 2.1 商业本质

本地生活行业的本质不是“发优惠券”或“做配送”，而是：

> 在有限地理半径内，把分散的本地供给与即时或近即时需求高效匹配，并尽可能降低获客成本、履约成本和交易摩擦。

### 1）客户为什么需要它？
消费者需要本地生活平台，通常因为：
- 找到更便宜或更合适的本地服务
- 提高决策效率
- 获得更快履约和更稳定服务
- 享受套餐、优惠和会员权益
- 减少线下搜索和比价成本

商户需要本地生活平台，通常因为：
- 获取新客
- 提高翻台率 / 订单量
- 提高复购和会员沉淀
- 提高履约效率
- 获得经营数据与数字化工具支持

### 2）企业提供的核心价值是什么？
- 帮消费者找到合适服务并完成交易
- 帮商户获取客流和订单
- 帮服务供给方提高履约和调度效率
- 帮本地品牌建立线上经营能力
- 帮商户实现会员、营销和复购管理

### 3）企业为什么能赚钱？
本地生活企业的盈利来源通常包括：
- 交易佣金
- 广告与流量推广费
- 配送费 / 履约服务费
- 会员收入
- 团购抽佣
- SaaS 订阅费
- 增值营销服务费
- 金融与供应链服务收入（部分平台）
