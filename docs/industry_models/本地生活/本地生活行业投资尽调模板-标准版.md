# 三、业务理解

## 3.1 公司到底做什么
1. 公司核心是流量撮合、履约配送还是商户经营工具？
2. 用户主要在什么场景下使用？
3. 商户为什么接入平台？
4. 收入主要来自佣金、广告、配送费、会员还是 SaaS？
5. 公司本质更像平台、服务商还是工具商？

## 3.2 解决什么问题
1. 对用户解决的是便利、便宜、选择多还是服务更稳定？
2. 对商户解决的是获客、增收、复购还是运营效率？
3. 如果没有该平台，商户和用户的替代方案是什么？
4. 用户和商户的核心付费/参与动机是什么？

## 3.3 商业模式
1. 是否依赖高补贴才能维持增长？
2. 是否存在跨品类扩展能力？
3. 是否有从交易走向广告、会员、SaaS 的升级路径？
4. 是单城模型还是区域模型，复制性如何？

# 九、财务尽调

## 9.1 收入质量
1. GMV 和收入增长是否同步？
2. 收入是佣金驱动、广告驱动还是履约驱动？
3. 是否存在少数大商户或核心城市贡献过高？
4. 商户服务收入是否提升利润质量？

## 9.2 利润质量
1. 补贴退坡后是否仍有留存和订单？
2. 履约成本是否随订单密度下降？
3. 广告收入增长是否建立在真实商户 ROI 基础上？
4. 城市扩张期与成熟城市利润结构差异如何？

## 9.3 现金流质量
1. 平台经营现金流是否改善？
2. 补贴和运力投入是否造成长期现金消耗？
3. 城市扩张是否显著拉长回收周期？
4. SaaS 和会员是否改善现金流稳定性？

## 9.4 资产负债表风险
重点看：
- 现金
- 应付账款
- 预收款
- 营销应付款
- 有息负债
- 或有赔付责任

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否兼具流量运营、地推管理、履约调度和本地供给组织能力？
2. 是否有成熟城市运营经验？
3. 是否过度依赖单一核心城市负责人？
4. 技术和运营协同是否顺畅？

## 10.2 组织能力
1. 公司更强在流量、商户 BD、履约还是商户 SaaS？
2. 跨城市复制能力是否已验证？
3. 售后与风控体系是否成熟？
4. 是否能管理复杂的线下供给和服务质量？

## 10.3 激励机制
1. 地推和城市团队激励是否鼓励低质量扩张？
2. 履约团队激励是否兼顾效率与服务质量？
3. 商户成功团队是否围绕商户 ROI 设计激励？
