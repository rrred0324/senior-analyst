# 三、业务理解

## 3.1 公司到底做什么
1. 公司位于设计、制造、封测、设备、材料还是工具链环节？
2. 核心产品是什么？
3. 目标客户是谁？
4. 收入主要来自芯片、服务、设备、材料还是授权？
5. 公司本质更像产品公司、制造平台还是基础工具提供方？

## 3.2 解决什么问题
1. 产品为客户解决了什么核心问题？
2. 相比国际/国内竞品，差异是什么？
3. 客户购买的核心因素是性能、成本、功耗、可靠性还是供应安全？

## 3.3 商业模式
1. 收入来自一次性销售、长期量产、持续耗材还是授权订阅？
2. 是否存在从单产品扩展到平台产品的路径？
3. 研发投入到收入释放周期多长？
4. 是否对特定客户、晶圆厂或节点高度依赖？

# 九、财务尽调

## 9.1 收入质量
1. 收入是样品收入还是量产收入？
2. 是否依赖单一产品或单一客户？
3. ASP 和出货量的增长是否健康？
4. 是否存在提前确认收入或渠道压货风险？

## 9.2 利润质量
1. 毛利率是否具备持续性？
2. 研发投入是否形成未来产品力？
3. 良率、折旧和供应链是否侵蚀利润？
4. FAE 和支持成本是否被低估？

## 9.3 现金流质量
1. 经营现金流是否显著落后于收入增长？
2. 存货和应收是否占用大量现金？
3. 扩产 CAPEX 是否超出融资能力？
4. 是否存在大额预付款给供应链的情况？

## 9.4 资产负债表风险
重点看：
- 现金
- 存货
- 应收账款
- 固定资产
- 在建工程
- 无形资产
- 有息负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备芯片设计、制造、供应链和客户资源复合背景？
2. CTO 和核心研发团队是否有成功量产经验？
3. 是否过度依赖个别技术骨干？
4. 商业化团队是否懂下游应用与客户导入？

## 10.2 组织能力
1. 公司更强在研发、量产管理还是客户导入？
2. 研发流程、质量体系和项目管理是否成熟？
3. 是否具备多产品线协同能力？
4. 是否具备供应链协调和风险管理能力？

## 10.3 激励机制
1. 研发激励是否支持长期创新？
2. 销售激励是否会诱导低质量订单？
3. 核心技术和量产人才流失风险如何？

# 十二、风险尽调

## 12.1 业务风险
- 技术不达标
- 客户验证失败
- 量产不顺
- 良率不稳
- 单一客户依赖
- 需求周期下行
- 平台拓展不及预期

## 12.2 财务风险
- 高研发投入无回报
- 存货减值
- 应收账款上升
- CAPEX 过重
- 现金流不足

## 12.3 合规与法律风险
- 知识产权纠纷
- 出口管制风险
- 供应链合规风险
- 安全与质量责任
