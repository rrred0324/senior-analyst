# 一、行业基础定义

## 1.1 行业名称
- 行业名称：半导体
- 细分赛道：IC 设计、Fabless、IDM、Foundry、封测、设备、材料、EDA、IP、功率器件、模拟芯片、数字芯片、MCU、存储、传感器、化合物半导体等
- 上下游位置：
  - 上游：EDA/IP、硅片、光刻胶、特气、靶材、设备、制造工艺平台
  - 中游：芯片设计、晶圆制造、封装测试、模组集成
  - 下游：消费电子、汽车电子、工业、通信、数据中心、能源、医疗、军工等
- 主要服务对象：To B、To G

## 1.2 行业一句话定义
> 半导体行业的本质是：通过先进设计、制造、封装和材料设备能力，将电路功能集成到芯片中，为下游电子系统提供算力、控制、连接、感知和电能转换能力，并在高技术门槛、高资本投入和长周期验证中实现商业回报。

## 1.3 行业边界

### 覆盖范围
- 芯片与器件的设计、制造、封装、测试、销售
- 半导体设备、材料、EDA 和 IP 等产业基础能力
- 与芯片性能、良率、功耗、可靠性和量产能力直接相关的业务

### 不覆盖范围
- 纯终端整机厂商且无芯片能力
- 与半导体弱相关的一般电子贸易业务
- 不具备技术壁垒和量产能力的概念型项目
- 纯软件业务若与芯片产业链无明确耦合

# 二、行业本质与核心价值

## 2.1 商业本质

半导体行业的本质不是“卖芯片”，而是：

> 以技术、工艺和供应链能力为核心，在性能、成本、功耗、可靠性和可量产性之间找到最优解，并服务下游系统需求。

### 1）客户为什么需要它？
下游客户需要半导体产品，通常是因为：
- 电子系统必须依赖芯片实现功能
- 对算力、控制、通信、存储、功率管理、感知有持续需求
- 产品升级需要更高性能或更低功耗
- 成本优化与国产替代需要新的供应方
- 汽车、工业、AI、新能源等新需求快速增长

### 2）企业提供的核心价值是什么？
- 提供特定功能和性能的芯片或器件
- 提供稳定量产和供货能力
- 提供更优的成本、功耗、面积和可靠性组合
- 帮助客户缩短研发周期和降低系统复杂度
- 在供应链安全和本地化上提供保障

### 3）企业为什么能赚钱？
半导体公司的盈利来源通常包括：
- 芯片销售收入
- 晶圆代工收入
- 封装测试收入
- 设备销售收入
- 材料销售收入
- EDA / IP 授权与订阅收入
- 模组与解决方案收入
- 售后与技术支持收入
