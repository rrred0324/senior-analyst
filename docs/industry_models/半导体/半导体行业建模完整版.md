# 一、行业基础定义

## 1.1 行业名称
- 行业名称：半导体
- 细分赛道：IC 设计、Fabless、IDM、Foundry、封测、设备、材料、EDA、IP、功率器件、模拟芯片、数字芯片、MCU、存储、传感器、化合物半导体等
- 上下游位置：
  - 上游：EDA/IP、硅片、光刻胶、特气、靶材、设备、制造工艺平台
  - 中游：芯片设计、晶圆制造、封装测试、模组集成
  - 下游：消费电子、汽车电子、工业、通信、数据中心、能源、医疗、军工等
- 主要服务对象：To B、To G

## 1.2 行业一句话定义
> 半导体行业的本质是：通过先进设计、制造、封装和材料设备能力，将电路功能集成到芯片中，为下游电子系统提供算力、控制、连接、感知和电能转换能力，并在高技术门槛、高资本投入和长周期验证中实现商业回报。

## 1.3 行业边界

### 覆盖范围
- 芯片与器件的设计、制造、封装、测试、销售
- 半导体设备、材料、EDA 和 IP 等产业基础能力
- 与芯片性能、良率、功耗、可靠性和量产能力直接相关的业务

### 不覆盖范围
- 纯终端整机厂商且无芯片能力
- 与半导体弱相关的一般电子贸易业务
- 不具备技术壁垒和量产能力的概念型项目
- 纯软件业务若与芯片产业链无明确耦合

# 二、行业本质与核心价值

## 2.1 商业本质

半导体行业的本质不是“卖芯片”，而是：

> 以技术、工艺和供应链能力为核心，在性能、成本、功耗、可靠性和可量产性之间找到最优解，并服务下游系统需求。

### 1）客户为什么需要它？
下游客户需要半导体产品，通常是因为：
- 电子系统必须依赖芯片实现功能
- 对算力、控制、通信、存储、功率管理、感知有持续需求
- 产品升级需要更高性能或更低功耗
- 成本优化与国产替代需要新的供应方
- 汽车、工业、AI、新能源等新需求快速增长

### 2）企业提供的核心价值是什么？
- 提供特定功能和性能的芯片或器件
- 提供稳定量产和供货能力
- 提供更优的成本、功耗、面积和可靠性组合
- 帮助客户缩短研发周期和降低系统复杂度
- 在供应链安全和本地化上提供保障

### 3）企业为什么能赚钱？
半导体公司的盈利来源通常包括：
- 芯片销售收入
- 晶圆代工收入
- 封装测试收入
- 设备销售收入
- 材料销售收入
- EDA / IP 授权与订阅收入
- 模组与解决方案收入
- 售后与技术支持收入

## 2.2 价值创造链条

半导体行业典型链路：

### Fabless 设计公司
```text
市场需求定义
→ 芯片架构与设计
→ 流片
→ 验证与测试
→ 客户导入
→ 量产爬坡
→ 持续出货
→ 收入确认
```

### Foundry / 制造公司
```latex
工艺开发
→ 客户导入
→ 晶圆生产
→ 良率提升
→ 产能利用率优化
→ 稳定交付
→ 收入与利润释放
```

### 设备/材料公司
```latex
研发
→ 客户验证
→ 产线导入
→ 小批量试用
→ 大规模采购
→ 存量产线持续消耗/替换
```

## 2.3 行业核心飞轮
```latex
产品性能/良率/可靠性提升
→ 客户导入与信任增强
→ 更多量产订单
→ 更高出货规模
→ 更强研发摊薄和工艺迭代能力
→ 产品性能/良率/可靠性继续提升
```

半导体行业真正强的飞轮是：

> 技术迭代、客户验证、量产能力和供应链协同共同形成的正循环，而不是单纯依赖销售扩张。
>

# 四、商业模式分类
## 4.1 主要收入模式
### 模式一：芯片销售
+ 名称：Chip Sales
+ 收费对象：系统厂商 / 模组厂 / 渠道商
+ 收费方式：按颗、按片、按模组销售
+ 公式：

```latex
收入 = 出货量 × ASP
```

### 模式二：晶圆代工
+ 名称：Foundry Revenue
+ 收费对象：Fabless / IDM
+ 收费方式：按晶圆片数、工艺节点、加工步骤收费
+ 公式：

```latex
收入 = 投片量 × 单片价格
```

### 模式三：封测服务
+ 名称：OSAT Revenue
+ 收费对象：设计公司 / 制造厂
+ 收费方式：按封装测试数量或项目收费
+ 公式：

```latex
收入 = 封测量 × 单位封测价格
```

### 模式四：设备/材料销售
+ 名称：Equipment / Material Sales
+ 收费对象：晶圆厂 / 封测厂 / IDM
+ 收费方式：一次性设备采购 + 持续材料消耗
+ 公式：

```latex
收入 = 销量 × 单价
```

### 模式五：EDA / IP 授权
+ 名称：EDA / IP Licensing
+ 收费对象：设计公司 / IDM / 研究机构
+ 收费方式：授权费、订阅费、版税
+ 公式：

```latex
收入 = 授权客户数 × 客均合同额 + 版税收入
```

## 4.2 行业最优商业模式
半导体中高质量模型通常具备：

+ 技术与产品差异化明确
+ 客户导入和验证通过
+ 量产能力稳定
+ ASP 与毛利率有支撑
+ 供应链可控
+ 研发投入可以被规模摊薄
+ 客户结构分散且长期合作

理想模型不是：

> 只完成流片，但迟迟无法量产或没有稳定客户
>

而是：

> 完成技术验证、客户导入、稳定量产和持续迭代，并形成可复制的产品平台或工艺平台。
>

## 4.3 从单一产品到平台化变现路径
```latex
切入单一高价值芯片/设备/材料
→ 完成客户导入与验证
→ 获得量产订单
→ 拓展系列产品与更多客户
→ 形成平台化产品矩阵或工艺平台
```

# 五、收入模型
## 5.1 总收入公式
```latex
总收入 = 芯片销售收入 + 代工收入 + 封测收入 + 设备收入 + 材料收入 + EDA/IP 收入 + 其他收入
```

## 5.2 拆解驱动因子
### 芯片设计公司常见拆法
```latex
收入 = 客户数 × 单客户出货量 × ASP
```

或

```latex
收入 = 出货量 × ASP
```

### 晶圆厂常见拆法
```latex
收入 = 产能 × 产能利用率 × 单位产出价格
```

### 设备材料常见拆法
```latex
收入 = 导入客户数 × 单客户采购量 × ASP
```

### EDA / IP 常见拆法
```latex
收入 = 新签授权收入 + 续费收入 + 版税收入
```

## 5.3 收入增长来源
+ 新客户导入
+ 单客户份额提升
+ ASP 提升
+ 新产品放量
+ 新工艺/新封装平台上线
+ 产能扩张
+ 良率提升释放有效产出
+ 国产替代渗透率提升
+ 从单颗芯片向模组/方案升级

+ 管理费用
+ 良率损失和报废成本

## 6.2 成本分类方式
### 固定成本
+ 研发团队
+ 工艺开发
+ 厂房与设备折旧
+ 管理团队
+ EDA 工具和设计平台投入

### 可变成本
+ 晶圆采购
+ 封测
+ 原材料消耗
+ 按出货增长的测试与物流成本
+ 渠道返利

### 前端成本
+ 销售与客户导入
+ FAE 和样品支持
+ 认证测试成本

### 后端成本
+ 量产制造
+ 品控与可靠性测试
+ 售后支持
+ 失效率与赔偿成本

## 6.3 单位经济模型
### Fabless 型
```latex
单颗毛利 = ASP - 晶圆成本分摊 - 封测成本 - 测试成本 - 渠道成本
```

### Foundry 型
```latex
单片毛利 = 单片收入 - 材料成本 - 制造变动成本 - 折旧分摊
```

### 设备型
```latex
单台设备毛利 = 设备售价 - BOM 成本 - 制造装配成本 - 售后安装成本
```

### 材料型
```latex
单客户生命周期价值 = 材料导入后持续采购毛利 - 前期认证与导入成本
```

### 核心判断
+ 设计公司最怕出货不及预期，研发摊不过来
+ 制造和设备最怕 CAPEX 重且稼动率不足
+ 材料最怕长验证后难以大规模切入
+ 高毛利不一定高利润，研发和验证周期常很长

## 6.4 利润公式
```latex
利润 = 收入 - 生产/采购成本 - 研发成本 - 销售与 FAE 成本 - 折旧摊销 - 管理费用 - 良率损失
```

# 八、行业经营逻辑
## 8.1 核心增长逻辑
半导体增长通常来自：

+ 新客户导入
+ 新产品放量
+ 下游景气提升
+ ASP 提升
+ 国产替代推进
+ 工艺和良率提升
+ 产能释放
+ 从单颗器件向模组和方案升级

## 8.2 规模效应
规模扩大后可能带来：

+ 研发成本摊薄
+ 晶圆和材料采购议价增强
+ 客户信任提升
+ 更强产品矩阵协同
+ 制造端折旧摊薄
+ 工艺和良率持续优化

## 8.3 网络效应
半导体不是典型网络效应行业，但存在：

+ 客户导入与生态绑定效应
+ EDA/IP 的标准化和生态嵌入效应
+ 量产数据反哺产品和工艺优化的学习效应

## 8.4 标准化与周期性
+ 芯片本身具备高标准化特征，但导入周期长
+ 行业受库存周期和资本开支周期影响明显
+ 汽车、工业等赛道验证更长但粘性更高
+ 消费电子波动更大但放量更快

# 九、竞争格局与壁垒
## 9.1 竞争格局
+ 先进制程制造集中度高
+ 模拟、功率、MCU 等赛道既有国际龙头也有区域替代机会
+ 设备和材料赛道验证门槛高、客户粘性强
+ EDA/IP 头部效应显著
+ 国产替代、地缘政治和供应链安全重塑格局

## 9.2 常见壁垒类型
+ 技术与设计壁垒
+ 工艺与良率壁垒
+ 客户验证壁垒
+ 资本投入壁垒
+ 供应链与产能壁垒
+ 生态兼容与软件工具壁垒
+ 品牌与可靠性壁垒
+ 专利与知识产权壁垒

## 9.3 替代风险
+ 被国际大厂降价或升级替代
+ 工艺路线变化导致旧产品失效
+ 下游客户自研
+ 供应链受限导致交付风险
+ 需求下行导致价格和库存双杀

# 十、行业风险分析
## 10.1 通用风险项
+ 技术迭代风险
+ 客户验证不通过
+ 量产爬坡不及预期
+ 良率不达标
+ 大客户依赖
+ 晶圆产能受限
+ 行业周期下行
+ 高研发投入长期无法变现
+ 出口管制和地缘风险
+ 存货减值风险

## 10.2 风险信号模板
+ 流片成功但迟迟没有量产客户
+ 收入增长依赖单一客户或单一产品
+ 良率长期低于行业水平
+ 存货和应收快速增加
+ CAPEX 大幅投入但稼动率不升
+ 研发费用高企但新产品放量滞后

# 十二、市场空间分析模板
## 12.1 TAM / SAM / SOM
### TAM
对应相关芯片、器件、设备、材料或设计工具的全球/区域总体市场

### SAM
公司所在工艺、应用场景、区域和客户类型对应的可服务市场

### SOM
公司当前和中短期能够拿下的客户份额与出货规模

## 12.2 通用测算公式
### 方法一：终端需求倒推法
```latex
市场空间 = 下游终端出货量 × 单机芯片价值量
```

### 方法二：客户采购法
```latex
市场空间 = 目标客户数 × 客均采购额
```

### 方法三：产能法
```latex
市场空间 = 目标产能 × 单位产出价格
```

## 12.3 市场空间判断注意事项
+ 市场大不等于公司能导入客户
+ 半导体最核心不是 TAM，而是验证通过率和量产能力
+ 替代空间大，但进入节奏取决于认证和供应链切换
+ 周期下行时，市场空间和价格可能同步收缩
