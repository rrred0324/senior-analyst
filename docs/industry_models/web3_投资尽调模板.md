## 三、业务理解

### 3.1 公司到底做什么
1. 公司位于区块链产业链的哪个环节？
2. 核心产品解决什么问题？
3. 目标客户是谁？
4. 核心收入来自哪类产品和场景？
5. 是否有明确的中国业务边界？

### 3.2 解决什么问题
1. 相比传统解决方案，公司提升了什么效率？
2. 用户或机构为什么必须使用它？
3. 核心价值是触达、流动性、合规还是资产安全？
4. 若没有该公司，客户会用什么替代？

### 3.3 商业模式
1. 收入来自交易费、资金费率、上币费、理财利差还是协议收入？
2. 是否承担信用风险或流动性风险？
3. 变现模式是否清晰且符合监管要求？
4. 是否具备多产品、多层次变现空间？
5. 代币经济模型是否可持续？

## 九、财务尽调

### 9.1 收入质量
1. 各类收入结构是否清晰？
2. 高毛利收入是否可持续？
3. 是否依赖单一产品、单一客户或单一区域？
4. 是否存在高风险收入被包装为其他收入？

### 9.2 利润质量
1. 毛利率受激励支出影响多大？
2. 研发投入是否足以支撑长期能力？
3. 合规投入是否充足？
4. 是否存在隐性负债或或有风险？

### 9.3 现金流质量
1. 经营现金流是否与收入和利润匹配？
2. 是否存在代币解锁抛压？
3. 资金沉淀如何管理？
4. 是否有潜在表外风险压缩未来现金流？

### 9.4 资产负债表风险
重点看：
- 现金
- 数字资产储备
- 代币库存和解锁节奏
- 跨链桥锁定资产
- 储备证明
- 有息负债
- 或有负债

## 十、团队与组织尽调

### 10.1 核心团队
1. 创始团队是否公开可验证？
2. 是否有区块链、金融、合规复合背景？
3. 是否有监管沟通经验？
4. 是否存在关键岗位单点依赖？

### 10.2 组织能力
1. 公司更强在技术、运营、合规还是机构合作？
2. 合规、法务、风控是否和业务同等重要？
3. 是否具备跨周期运营能力？
4. 数据驱动决策能力是否成熟？

### 10.3 激励机制
1. 是否过度激励规模，忽视资产质量和合规？
2. 技术与业务团队是否存在目标冲突？
3. 核心技术与合规人才稳定性如何？
