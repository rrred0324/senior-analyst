# 三、业务理解

## 3.1 公司到底做什么
1. 公司卖的是商品、软件、内容、服务还是平台能力？
2. 海外客户购买的核心理由是什么？
3. 公司在哪个环节最强：供应链、产品、投放、渠道、品牌还是本地服务？
4. 海外收入当前主要来自哪些国家和哪些渠道？
5. 公司是跨境直销模式，还是本地化深运营模式？

## 3.2 解决什么问题
1. 海外客户未被满足的需求是什么？
2. 与当地替代品相比，公司优势在哪里？
3. 为什么这个优势能够长期存在，而不是阶段性套利？
4. 如果没有这家公司，客户会选择谁？

## 3.3 商业模式
1. 收入来自商品销售、订阅、广告、佣金还是服务费？
2. 是否形成复购或续费？
3. 是否依赖单一平台或单一流量渠道？
4. 是否存在清晰的区域复制逻辑？

## 4.2 核心能力
1. 产品竞争力体现在哪里？
2. 是否针对不同国家做了语言、支付、包装、内容、合规等本地化？
3. 供应链响应速度如何？

5. 是否已具备品牌心智或渠道信任？

## 4.3 产品成熟度
1. 是否已在一个或多个海外市场稳定运营？
2. 是否跑通从获客到复购/续费的闭环？
3. 是否具备跨文化和跨区域复制能力？
4. 新市场上线周期和试错成本如何？

# 五、市场与区域尽调

## 5.1 目标市场
1. 为什么选择这些国家或区域？
2. 当地市场容量、竞争格局、支付和物流基础如何？
3. 政策、关税、税务和准入门槛如何？
4. 市场处于早期红利、快速增长，还是成熟竞争期？

## 5.2 区域结构
1. 当前收入前五大国家分别是哪些？
2. 是否过度依赖某一国家或某一区域？
3. 各区域利润率差异如何？
4. 是否有明确的下一阶段扩张地图？

## 5.3 行业趋势
1. 海外消费者或企业客户需求在上升还是下滑？
2. 平台流量规则是否变化？
3. 本地化、品牌化是否成为长期趋势？
4. 地缘政治是否改变供应链布局？

# 九、财务尽调

## 9.1 收入质量
1. 海外收入是否多元分散？
2. 是否过度依赖某一平台、某一国家或某一渠道？
3. 收入增长是否由投放驱动，还是自然增长和复购贡献提高？
4. 区域结构是否健康？

## 9.2 利润质量
1. 毛利率是否稳定？
2. 广告、物流、关税、退货是否侵蚀利润？
3. 海外本地团队扩张是否带来经营杠杆？
4. 汇率波动对利润影响多大？

## 9.3 现金流质量
1. 海外库存和投放是否占用大量现金？
2. 平台回款周期和资金冻结风险如何？
3. 是否依赖融资推动海外扩张？
4. 是否建立了区域现金流监控机制？

## 9.4 资产负债表风险
重点看：
- 存货
- 海外仓库存
- 应收账款
- 现金及受限资金
- 税务准备
- 商誉（并购扩张时）
- 有息负债

# 十、团队与组织尽调

## 10.1 核心团队
1. 创始团队是否具备国际化经验？
2. 是否有本地市场负责人？
3. 是否兼具产品、供应链、投放和合规能力？
4. 是否过度依赖少数关键人？

## 10.2 组织能力
1. 是否建立了跨区域管理和协同机制？
2. 本地团队和总部协同是否高效？
3. 是否具备快速开新市场的 SOP？
4. 是否能处理多语言、多时区、多监管环境？

## 10.3 激励机制
1. 海外团队激励是否与利润和合规挂钩？
2. 是否避免“只冲规模不管质量”的激励扭曲？
3. 渠道团队是否过度依赖短期返点？
4. 是否对区域负责人设置长期目标？
